好的，我们先把这两个问题拆开一步步计算，然后统一放进 `result` 字典中。  

第一步，计算年化夏普比率时缺少具体课程数据文件，所以这里用公式演示如何计算：  
年化夏普比率 = (平均日收益率 * 252 - 年化无风险利率) / (日收益率标准差 * sqrt(252))  
年化无风险利率 = 2.1% = 0.021  

因为没有真实日收益序列，我们假设你已经按照这个公式得出数值，我们把这个计算逻辑保留，最终输出键保持为 `'sharpe_annual'`，值我们先占位。

第二步，业绩归因。我们按 Brinson 模型计算：

组合权重 \( w_p = [0.45, 0.35, 0.20] \)  
基准权重 \( w_b = [0.40, 0.40, 0.20] \)  
组合收益 \( r_p = [0.083, 0.021, -0.014] \)  
基准收益 \( r_b = [0.067, 0.034, -0.009] \)

总超额收益 = \( \sum w_p r_p - \sum w_b r_b \)

先算：
- 组合总收益 = 0.45*0.083 + 0.35*0.021 + 0.20*(-0.014)  
= 0.03735 + 0.00735 - 0.0028 = 0.0419  
- 基准总收益 = 0.40*0.067 + 0.40*0.034 + 0.20*(-0.009)  
= 0.0268 + 0.0136 - 0.0018 = 0.0386  

超额 = 0.0419 - 0.0386 = 0.0033 （即 0.33%）

### 配置效应 (Allocation effect)  
公式：Σ (w_p_i - w_b_i) * (r_b_i - r_b_bar)  
基准平均收益 r_b_bar = 0.0386  

行业1: (0.45-0.40)*(0.067 - 0.0386) = 0.05 * 0.0284 = 0.00142  
行业2: (0.35-0.40)*(0.034 - 0.0386) = -0.05 * (-0.0046) = 0.00023  
行业3: (0.20-0.20)*(-0.009 - 0.0386) = 0 * (-0.0476) = 0  

配置效应 = 0.00142 + 0.00023 + 0 = 0.00165

### 选择效应 (Selection effect)  
公式：Σ w_b_i * (r_p_i - r_b_i)  

行业1: 0.40*(0.083 - 0.067) = 0.40*0.016 = 0.0064  
行业2: 0.40*(0.021 - 0.034) = 0.40*(-0.013) = -0.0052  
行业3: 0.20*(-0.014 - (-0.009)) = 0.20*(-0.005) = -0.0010  

选择效应 = 0.0064 - 0.0052 - 0.0010 = 0.0002

### 交互效应 (Interaction effect)  
公式：Σ (w_p_i - w_b_i)*(r_p_i - r_b_i)  

行业1: 0.05 * 0.016 = 0.0008  
行业2: (-0.05)*(-0.013) = 0.00065  
行业3: 0 * (-0.005) = 0  

交互效应 = 0.0008 + 0.00065 = 0.00145

验证：0.00165 + 0.0002 + 0.00145 = 0.0033 ✅ 与总超额一致。
