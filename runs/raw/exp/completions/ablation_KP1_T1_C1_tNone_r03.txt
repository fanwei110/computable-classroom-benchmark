好的，我们先把这个最小方差组合（MVP）的问题完整求解一遍，然后按要求把结果放到 `result` 字典里。  
这里是三只资产，已知年化波动率和相关系数，允许卖空，且资金全部投出。

首先建立协方差矩阵。  

已知：
- σ1 = 0.187  
- σ2 = 0.243  
- σ3 = 0.312  
- ρ12 = 0.21  
- ρ13 = −0.13  
- ρ23 = 0.37  

协方差公式：  
Cov(i,j) = ρij × σi × σj

计算得到：
- Cov(1,1) = 0.187² = 0.034969  
- Cov(2,2) = 0.243² = 0.059049  
- Cov(3,3) = 0.312² = 0.097344  
- Cov(1,2) = 0.21 × 0.187 × 0.243 = 0.00954261  
- Cov(1,3) = −0.13 × 0.187 × 0.312 = −0.00758472  
- Cov(2,3) = 0.37 × 0.243 × 0.312 = 0.02805832  

因此协方差矩阵为：

```
Σ = 
[ 0.03496900,  0.00954261, -0.00758472 ]
[ 0.00954261,  0.05904900,  0.02805832 ]
[-0.00758472,  0.02805832,  0.09734400 ]
```

在允许卖空且满仓约束下，最小方差组合的权重公式为：

\[
w_{mvp} = \frac{\Sigma^{-1} \mathbf{1}}{\mathbf{1}^T \Sigma^{-1} \mathbf{1}}
\]

其中 \(\mathbf{1} = [1,1,1]^T\)

我们先求协方差矩阵的逆。

令矩阵元素标记为：
a11 = 0.034969, a12 = 0.00954261, a13 = -0.00758472  
a22 = 0.059049, a23 = 0.02805832  
a33 = 0.097344  

先算行列式 det(Σ)：

通过三阶行列式计算：

det = a11*(a22*a33 - a23²) - a12*(a12*a33 - a23*a13) + a13*(a12*a23 - a22*a13)

逐步：
- a22*a33 = 0.059049 × 0.097344 = 0.00574787  
- a23² = 0.02805832² = 0.00078727  
- 所以第一项括号 = 0.00574787 - 0.00078727 = 0.00496060  
- 乘以 a11: 0.034969 × 0.00496060 = 0.00017348  

- a12*a33 = 0.00954261 × 0.097344 = 0.00092891  
- a23*a13 = 0.02805832 × (-0.00758472) = -0.00021284  
- 括号内 = 0.00092891 - (-0.00021284) = 0.00114175  
- 乘以 a12: 0.00954261 × 0.00114175 = 0.000010894  
- 前面是减这个：减去 0.000010894  

- a12*a23 = 0.00954261 × 0.02805832 = 0.00026776  
- a22*a13 = 0.059049 × (-0.00758472) = -0.00044787  
- 括号内 = 0.00026776 - (-0.00044787) = 0.00071563  
- 乘以 a13 = -0.00758472 × 0.00071563 = -0.000005427  
- 最后一项是加这个: 加上 (-0.000005427) = -0.000005427  

于是：
det = 0.00017348 - 0.000010894 - 0.000005427  
= 0.000157159  

现在计算逆矩阵各元素（用余子式法）。  

先计算各个余子式：

C11 = a22*a33 - a23² = 0.00496060  
C12 = -(a12*a33 - a23*a13) = -0.00114175  
C13 = a12*a23 - a22*a13 = 0.00071563  

C21 = -(a12*a33 - a13*a23) = -(0.00092891 - (-0.00021284)) = -0.00114175（与C12相同，对称）  
C22 = a11*a33 - a13² = 0.034969×0.097344 - (-0.00758472)²  
= 0.00340409 - 0.00005753 = 0.00334656  
C23 = -(a11*a23 - a13*a12) = -(0.034969×0.02805832 - (-0.00758472×0.00954261))  
= -(0.00098132 + 0.00007238) = -0.00105370  

C31 = a12*a23 - a22*a13 = 0.00071563 （同C13）  
C32 = -(a11*a23 - a12*a13) = -(0.00098132 - (0.00954261× -0.00758472))  
= -(0.00098132 + 0.00007238) = -0.00105370 （同C23）  
C33 = a11*a22 - a12² = 0.034969×0.059049 - 0.00954261²  
= 0.00206531 - 0.00009106 = 0.00197425  

伴随矩阵是余子式矩阵的转置，但因为是实对称矩阵，伴随就是余子式矩阵本身。

所以逆矩阵 = 伴随矩阵 / det：

inv(Σ) =

第一行：
0.00496060 / 0.000157159 = 31.566  
-0.00114175 / 0.000157159 = -7.264  
0.00071563 / 0.000157159 = 4.554  

第二行：
-0.00114175 / = -7.264  
0.00334656 / = 21.296  
-0.00105370 / = -6.705  

第三行：
0.00071563 / = 4.554  
-0.00105370 / = -6.705  
0.00197425 / = 12.564  

现在计算向量 \( \Sigma^{-1} \mathbf{1} \)：

第一分量 = 31.566 - 7.264 + 4.554 = 28.856  
第二分量 = -7.264 + 21.296 - 6.705 = 7.327  
第三分量 = 4.554 - 6.705 + 12.564 = 10.413  

分母 = 三个分量之和 = 28.856 + 7.327 + 10.413 = 46.596  

于是权重：
w1 = 28.856 / 46.596 = 0.6193  
w2 = 7.327 / 46.596 = 0.1572  
w3 = 10.413 / 46.596 = 0.2235  

检查总和：0.6193+0.1572+0.2235 = 1.0000，正确。

现在计算组合方差：
σ²_p = w^T Σ w

先算 Σw：
第一分量 = 0.034969×0.6193 + 0.00954261×0.1572 + (-0.00758472)×0.2235  
= 0.021653 + 0.001500 - 0.001695 = 0.021458  

第二分量 = 0.00954261×0.6193 + 0.059049×0.1572 + 0.02805832×0.2235  
= 0.005911 + 0.009280 + 0.006272 = 0.021463  

第三分量 = (-0.00758472)×0.6193 + 0.02805832×0.1572 + 0.097344×0.2235  
= -0.004697 + 0.004411 + 0.021758 = 0.021472  

然后组合方差 = w1×第一分量 + w2×第二分量 + w3×第三分量  
= 0.6193×0.021458 + 0.1572×0.021463 + 0.2235×0.021472  
= 0.013286 + 0.003374 + 0.004799 = 0.021459  

年化波动率 = √0.021459 = 0.1465 = 14.65%
