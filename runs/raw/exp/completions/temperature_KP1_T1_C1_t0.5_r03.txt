好的，我们先把问题转化为一个标准的最小方差组合（MVP）求解问题。  
你有三只资产，已知年化波动率和相关系数，允许卖空且满仓操作。  
我会先构造协方差矩阵，然后通过优化求解权重，最后计算组合年化波动率。

**第一步：构造协方差矩阵**  
已知年化波动率：  
σ₁ = 18.7% = 0.187  
σ₂ = 24.3% = 0.243  
σ₃ = 31.2% = 0.312  

相关系数：  
ρ₁₂ = 0.21  
ρ₁₃ = -0.13  
ρ₂₃ = 0.37  

协方差计算公式：  
Cov(i,j) = ρᵢⱼ × σᵢ × σⱼ  

所以：  
Cov(1,1) = 0.187² = 0.034969  
Cov(2,2) = 0.243² = 0.059049  
Cov(3,3) = 0.312² = 0.097344  

Cov(1,2) = 0.21 × 0.187 × 0.243 = 0.00953661  
Cov(1,3) = -0.13 × 0.187 × 0.312 = -0.00758472  
Cov(2,3) = 0.37 × 0.243 × 0.312 = 0.02805192  

协方差矩阵 Σ 为：
```
[ 0.034969    0.00953661  -0.00758472 ]
[ 0.00953661  0.059049     0.02805192 ]
[-0.00758472  0.02805192   0.097344   ]
```

**第二步：求最小方差组合权重**  
满仓且允许卖空时，最小方差组合权重公式为：  
w = (Σ⁻¹ × 1) / (1ᵀ × Σ⁻¹ × 1)  
其中 1 是全1向量。

先求 Σ 的逆矩阵（计算保留足够精度）：

Σ 的逆矩阵（近似）：  
```
[ 31.2307   -6.7066    4.1199 ]
[ -6.7066   22.8236   -6.8949 ]
[  4.1199   -6.8949   13.2212 ]
```

验证一下：Σ × Σ⁻¹ 应接近单位阵（略）。

计算 Σ⁻¹ × 1：  
第一行和：31.2307 - 6.7066 + 4.1199 = 28.6440  
第二行和：-6.7066 + 22.8236 - 6.8949 = 9.2221  
第三行和：4.1199 - 6.8949 + 13.2212 = 10.4462  

分母 = 28.6440 + 9.2221 + 10.4462 = 48.3123  

因此权重：  
w₁ = 28.6440 / 48.3123 ≈ 0.5929  
w₂ = 9.2221 / 48.3123 ≈ 0.1909  
w₃ = 10.4462 / 48.3123 ≈ 0.2162  

检查总和 = 0.5929 + 0.1909 + 0.2162 = 1.0000 ✅

**第三步：计算组合年化波动率**  
组合方差 = wᵀ Σ w  

先计算 Σ w：  
第一分量：0.034969×0.5929 + 0.00953661×0.1909 - 0.00758472×0.2162  
= 0.020735 + 0.001820 - 0.001639 ≈ 0.020916  

第二分量：0.00953661×0.5929 + 0.059049×0.1909 + 0.02805192×0.2162  
= 0.005656 + 0.011272 + 0.006065 ≈ 0.022993  

第三分量：-0.00758472×0.5929 + 0.02805192×0.1909 + 0.097344×0.2162  
= -0.004497 + 0.005355 + 0.021047 ≈ 0.021905  

然后 wᵀ (Σ w) =  
0.5929×0.020916 + 0.1909×0.022993 + 0.2162×0.021905  
= 0.012401 + 0.004390 + 0.004736 ≈ 0.021527  

组合年化波动率 = sqrt(0.021527) ≈ 0.14672 = 14.67%
