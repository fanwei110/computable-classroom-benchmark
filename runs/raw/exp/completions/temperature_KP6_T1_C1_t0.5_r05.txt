**第一问：年化夏普比率**  
由于你没有提供具体的日收益率数据，我先给出计算逻辑与公式，假设你已经有了日收益率序列 `daily_returns`。  

- 无风险利率年化：2.1% → 日化无风险利率 ≈ 0.021 / 252  
- 计算日收益率均值与标准差  
- 年化夏普 = (日收益率均值 - 日无风险利率) / 日收益率标准差 × sqrt(252)  

代码逻辑如下（假设 `daily_returns` 是 pandas Series 或 numpy array）：  

```python
import numpy as np

rf_annual = 0.021
rf_daily = rf_annual / 252

mean_daily_return = np.mean(daily_returns)
std_daily_return = np.std(daily_returns, ddof=1)  # 样本标准差

sharpe_annual = (mean_daily_return - rf_daily) / std_daily_return * np.sqrt(252)
```

**第二问：业绩归因（Brinson 模型）**

公式：  
- 配置效应 = \( (w_{p,i} - w_{b,i}) \times (r_{b,i} - r_b^{\text{total}}) \)  
- 选择效应 = \( w_{b,i} \times (r_{p,i} - r_{b,i}) \)  
- 交互效应 = \( (w_{p,i} - w_{b,i}) \times (r_{p,i} - r_{b,i}) \)  

其中基准总收益 \( r_b^{\text{total}} = \sum w_{b,i} r_{b,i} \)。

\( 0.40 \times 0.067 + 0.40 \times 0.034 + 0.20 \times (-0.009) \)
