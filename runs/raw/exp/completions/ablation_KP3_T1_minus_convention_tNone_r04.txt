```python
import numpy as np

# 债券参数
face_value = 100.0          # 面值
coupon_rate = 0.046         # 票息率
coupon = face_value * coupon_rate  # 每年票息额
maturity_years = 7          # 期限（年）
ytm = 0.053                 # 到期收益率

# 现金流时间点（每年一次，第1年到第7年）
t = np.arange(1, maturity_years + 1)
# 现金流：前6年只有票息，最后一年票息+面值
cash_flows = np.full(maturity_years, coupon)
cash_flows[-1] += face_value

# 贴现因子
discount_factors = (1 + ytm) ** (-t)

# 1. 计算价格
price = np.sum(cash_flows * discount_factors)

# 2. 计算麦考利久期（单位：年）
macaulay_duration = np.sum(t * cash_flows * discount_factors) / price

# 修正久期
modified_duration = macaulay_duration / (1 + ytm)

# 3. 计算凸性（年平方）
convexity = np.sum(t * (t + 1) * cash_flows * discount_factors) / (price * (1 + ytm)**2)

# 4. 整理结果字典
result = {
    'price': price,
    'macaulay_duration_years': macaulay_duration,
    'modified_duration_years': modified_duration,
    'convexity': convexity
}

# 输出结果（教师可投屏）
print("计算结果：")
for key, value in result.items():
    print(f"{key}: {value:.6f}")

```

此脚本完全自包含，仅依赖 numpy。运行时将打印并保存结果至字典 `result`，键名严格符合要求，数值可复现。教师可直接投屏运行。
