好的，我们先把两个问题拆开处理，然后汇总到 `result` 字典中。  

**问题一：年化夏普比率**  
- 日收益数据来自课程数据文件的 `fund` 列（这里我们没有实际数据文件，我假设你已有日收益序列）。  
- 无风险利率年化 2.1%，换算成日无风险利率 ≈ 2.1% / 252 ≈ 0.008333%。  
- 年化夏普比率公式：  
\[
\text{Sharpe} = \frac{E(R_p) - R_f}{\sigma_p} \times \sqrt{252}
\]  
其中 \(E(R_p)\) 是日平均收益，\(\sigma_p\) 是日收益标准差。  

由于没有具体数值，这里用符号表示计算过程，最终输出时需填入真实计算结果。  

**问题二：业绩归因（Brinson 模型）**  
组合权重 \(w_p = [0.45, 0.35, 0.20]\)  
组合收益 \(R_p = [8.3\%, 2.1\%, -1.4\%]\)  
基准权重 \(w_b = [0.40, 0.40, 0.20]\)  
基准收益 \(R_b = [6.7\%, 3.4\%, -0.9\%]\)  

先算基准总收益：  
\[
R_b^{\text{total}} = 0.40\times6.7\% + 0.40\times3.4\% + 0.20\times(-0.9\%) = 2.68\% + 1.36\% - 0.18\% = 3.86\%
\]  

配置效应（Allocation effect）：  
\[
\sum (w_{p,i} - w_{b,i}) \times (R_{b,i} - R_b^{\text{total}})
\]  
- 行业1: \((0.45-0.40)\times(6.7\% - 3.86\%) = 0.05 \times 2.84\% = 0.142\%\)  
- 行业2: \((0.35-0.40)\times(3.4\% - 3.86\%) = (-0.05) \times (-0.46\%) = 0.023\%\)  
- 行业3: \((0.20-0.20)\times(-0.9\% - 3.86\%) = 0\)  
合计配置效应 = \(0.142\% + 0.023\% = 0.165\%\)  

选择效应（Selection effect）：  
\[
\sum w_{b,i} \times (R_{p,i} - R_{b,i})
\]  
- 行业1: \(0.40 \times (8.3\% - 6.7\%) = 0.40 \times 1.6\% = 0.64\%\)  
- 行业2: \(0.40 \times (2.1\% - 3.4\%) = 0.40 \times (-1.3\%) = -0.52\%\)  
- 行业3: \(0.20 \times (-1.4\% - (-0.9\%)) = 0.20 \times (-0.5\%) = -0.10\%\)  
合计选择效应 = \(0.64\% - 0.52\% - 0.10\% = 0.02\%\)  

交互效应（Interaction effect）：  
\[
\sum (w_{p,i} - w_{b,i}) \times (R_{p,i} - R_{b,i})
\]  
- 行业1: \(0.05 \times 1.6\% = 0.08\%\)  
- 行业2: \((-0.05) \times (-1.3\%) = 0.065\%\)  
- 行业3: \(0 \times (-0.5\%) = 0\)  
合计交互效应 = \(0.08\% + 0.065\% = 0.145\%\)
