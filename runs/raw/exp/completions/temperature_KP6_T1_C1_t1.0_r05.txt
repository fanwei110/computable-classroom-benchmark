**第二问：业绩归因**

组合权重 \( w_p = [0.45, 0.35, 0.20] \)  
基准权重 \( w_b = [0.40, 0.40, 0.20] \)  
行业收益（组合） \( R_p = [8.3\%, 2.1\%, -1.4\%] \)  
行业收益（基准） \( R_b = [6.7\%, 3.4\%, -0.9\%] \)

公式：
- 配置效应：\(\sum (w_{p,i} - w_{b,i}) \times R_{b,i}\)  
- 选择效应：\(\sum w_{b,i} \times (R_{p,i} - R_{b,i})\)  
- 交互效应：\(\sum (w_{p,i} - w_{b,i}) \times (R_{p,i} - R_{b,i})\)

计算过程（用小数）：

**配置效应**  
= (0.45-0.40)*0.067 + (0.35-0.40)*0.034 + (0.20-0.20)*(-0.009)  
= 0.05*0.067 + (-0.05)*0.034 + 0  
= 0.00335 - 0.00170  
= 0.00165 → 0.165%

**选择效应**  
= 0.40*(0.083-0.067) + 0.40*(0.021-0.034) + 0.20*(-0.014 - (-0.009))  
= 0.40*0.016 + 0.40*(-0.013) + 0.20*(-0.005)  
= 0.0064 - 0.0052 - 0.0010  
= 0.0002 → 0.02%

**交互效应**  
= (0.05)*(0.016) + (-0.05)*(-0.013) + (0)*(-0.005)  
= 0.0008 + 0.00065 + 0  
= 0.00145 → 0.145%
