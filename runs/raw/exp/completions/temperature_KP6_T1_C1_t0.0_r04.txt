### 第一问：年化夏普比率

**公式**：  
\[
\text{Sharpe Ratio (annual)} = \frac{E(R_p) - R_f}{\sigma_p} \times \sqrt{252}
\]  
其中：  
- \(E(R_p)\)：组合日平均收益率  
- \(R_f\)：日无风险利率 = \( \frac{2.1\%}{252} \)  
- \(\sigma_p\)：日收益率标准差  
- 乘以 \(\sqrt{252}\) 实现年化

**步骤**：  
1. 从课程数据文件 `fund` 列获取每日收益率序列  
2. 计算日收益率均值 \( \bar{r} \)  
3. 计算日收益率标准差 \( \sigma_{\text{daily}} \)  
4. 日无风险利率 \( r_{f,\text{daily}} = 0.021 / 252 \)  
5. 日夏普比率 = \((\bar{r} - r_{f,\text{daily}}) / \sigma_{\text{daily}}\)  
6. 年化夏普 = 日夏普 × \(\sqrt{252}\)

### 第二问：业绩归因（Brinson 模型）

已知：  
组合权重 \(w_p = [0.45, 0.35, 0.20]\)  
组合收益 \(R_p = [8.3\%, 2.1\%, -1.4\%]\)  
基准权重 \(w_b = [0.40, 0.40, 0.20]\)  
基准收益 \(R_b = [6.7\%, 3.4\%, -0.9\%]\)

#### 1. 配置效应（Allocation effect）
公式：  
\[
\text{Allocation}_i = (w_{p,i} - w_{b,i}) \times (R_{b,i} - R_{b,\text{total}})
\]  
其中基准总收益：  
\[
R_{b,\text{total}} = 0.40\times6.7\% + 0.40\times3.4\% + 0.20\times(-0.9\%) = 2.68\% + 1.36\% - 0.18\% = 3.86\%
\]

计算各行业：  
- 行业1：\((0.45-0.40) \times (6.7\% - 3.86\%) = 0.05 \times 2.84\% = 0.1420\%\)  
- 行业2：\((0.35-0.40) \times (3.4\% - 3.86\%) = (-0.05) \times (-0.46\%) = 0.0230\%\)  
- 行业3：\((0.20-0.20) \times (-0.9\% - 3.86\%) = 0\)  

总配置效应 = \(0.1420\% + 0.0230\% + 0 = 0.1650\%\)

#### 2. 选择效应（Selection effect）
公式：  
\[
\text{Selection}_i = w_{b,i} \times (R_{p,i} - R_{b,i})
\]  
- 行业1：\(0.40 \times (8.3\% - 6.7\%) = 0.40 \times 1.6\% = 0.64\%\)  
- 行业2：\(0.40 \times (2.1\% - 3.4\%) = 0.40 \times (-1.3\%) = -0.52\%\)  
- 行业3：\(0.20 \times (-1.4\% - (-0.9\%)) = 0.20 \times (-0.5\%) = -0.10\%\)  

总选择效应 = \(0.64\% - 0.52\% - 0.10\% = 0.02\%\)

#### 3. 交互效应（Interaction effect）
公式：  
\[
\text{Interaction}_i = (w_{p,i} - w_{b,i}) \times (R_{p,i} - R_{b,i})
\]  
- 行业1：\((0.45-0.40) \times (8.3\% - 6.7\%) = 0.05 \times 1.6\% = 0.08\%\)  
- 行业2：\((0.35-0.40) \times (2.1\% - 3.4\%) = (-0.05) \times (-1.3\%) = 0.065\%\)  
- 行业3：\((0.20-0.20) \times (-1.4\% + 0.9\%) = 0\)  

总交互效应 = \(0.08\% + 0.065\% + 0 = 0.145\%\)
