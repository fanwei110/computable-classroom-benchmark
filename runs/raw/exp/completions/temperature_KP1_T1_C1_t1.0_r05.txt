首先构建协方差矩阵 Σ：

\[
\Sigma =

所以协方差矩阵为：

\[
\Sigma = 
\begin{bmatrix}

0.009546 & 0.059049 & 0.028061 \\
-0.007581 & 0.028061 & 0.097344
\end{bmatrix}
\]

最小方差组合的权重公式（允许卖空且全投资）：

\[
w_{mvp} = \frac{\Sigma^{-1} \mathbf{1}}{\mathbf{1}^T \Sigma^{-1} \mathbf{1}}
\]

首先计算 Σ 的逆矩阵（近似数值计算）：

设矩阵 Σ：

```
0.034969   0.009546  -0.007581
0.009546   0.059049   0.028061
-0.007581  0.028061   0.097344
```

它的逆矩阵（保留足够精度）约为：

```
Σ⁻¹ ≈ 
[ 30.7504,  -4.4682,   3.8204 ]
[ -4.4682,  20.4652,  -5.4241 ]
[  3.8204,  -5.4241,  11.9308 ]
```

接着计算 Σ⁻¹ 乘以全1向量（列和）：

第一行和：30.7504 - 4.4682 + 3.8204 = 30.1026  
第二行和：-4.4682 + 20.4652 - 5.4241 = 10.5729  
第三行和：3.8204 - 5.4241 + 11.9308 = 10.3271

因此：
Σ⁻¹·1 = [30.1026, 10.5729, 10.3271]^T

分母 1^T Σ⁻¹ 1 = 30.1026 + 10.5729 + 10.3271 = 51.0026

最后权重：

w₁ = 30.1026 / 51.0026 ≈ 0.5901  
w₂ = 10.5729 / 51.0026 ≈ 0.2073  
w₃ = 10.3271 / 51.0026 ≈ 0.2025

检查：0.5901 + 0.2073 + 0.2025 = 1.000 左右，合理。

接着求组合方差：

\[
\sigma_p^2 = w^T \Sigma w
\]

计算：

先算 Σw：

第一分量：0.034969×0.5901 + 0.009546×0.2073 + (-0.007581)×0.2025

然后 w·(Σw) =

所以年化波动率 σ_p = √0.021583 ≈ 0.14692 = 14.69%
