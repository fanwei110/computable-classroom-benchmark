好的，我们先明确一下已知条件，然后按CAPM公式计算。  
CAPM公式为：

\[
E(R_i) = R_f + \beta_i \times (E(R_m) - R_f)
\]

这里要注意时间单位：题目给的无风险利率是年化的4.7%，市场月跌幅是-5.8%，所以我们需要把年化无风险利率换算成月无风险利率。

**步骤 1：月无风险利率**  
年化无风险利率 = 4.7%  
月无风险利率 ≈ 4.7% / 12 ≈ 0.39167%  
用小数表示：0.0039167

**步骤 2：市场月收益**  
市场跌了5.8%，即 \(E(R_m) = -0.058\)

**步骤 3：代入CAPM**  
\[
E(R_i) = 0.0039167 + 1.42 \times (-0.058 - 0.0039167)
\]  
先算市场超额收益：  
\[
-0.058 - 0.0039167 = -0.0619167
\]  
乘以beta：  
\[
1.42 \times (-0.0619167) \approx -0.087922
\]  
加上无风险利率：  
\[
0.0039167 - 0.087922 \approx -0.084005
\]  
换算成百分比：约 -8.40%

**最终结果存入字典：**

```python
result = {
    'capm_return_monthly': -0.0840  # 即 -8.40%
}
```
