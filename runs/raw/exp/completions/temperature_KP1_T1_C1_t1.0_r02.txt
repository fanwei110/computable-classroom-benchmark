### 步骤：求解最小方差组合（允许卖空，满仓）

最小方差组合权重公式为：
\[
\mathbf{w}_{\text{mvp}} = \frac{\Sigma^{-1} \mathbf{1}}{\mathbf{1}^T \Sigma^{-1} \mathbf{1}}
\]
其中 \(\mathbf{1} = (1,1,1)^T\)。

先求 Σ 的逆矩阵：

Σ 矩阵（保留6位小数便于手算）：  
0.034969, 0.009544, -0.007587  
0.009544, 0.059049, 0.028056  
-0.007587, 0.028056, 0.097344  

计算行列式 det(Σ)：

分步：  
a = 0.034969*(0.059049*0.097344 - 0.028056²)  
  = 0.034969*(0.005748 - 0.000787)  
  = 0.034969 * 0.004961 = 0.0001735  

b = 0.009544*(0.009544*0.097344 - (-0.007587)*0.028056)  
  = 0.009544*(0.000929 + 0.000213)  
  = 0.009544 * 0.001142 = 0.00001090  

c = -0.007587*(0.009544*0.028056 - 0.059049*(-0.007587))  
  = -0.007587*(0.000268 + 0.000448)  
  = -0.007587 * 0.000716 = -0.00000543  

det(Σ) = a - b + c = 0.0001735 - 0.0000109 - 0.00000543 ≈ 0.00015717  

---

现在求逆矩阵元素（用伴随矩阵法简化，仅求我们需要的 Σ⁻¹·1 向量）：

设  
S₁ = 0.059049*0.097344 - 0.028056² = 0.004961  
S₂ = 0.034969*0.097344 - (-0.007587)² = 0.003404 - 0.0000576 = 0.0033464  
S₃ = 0.034969*0.059049 - 0.009544² = 0.002065 - 0.0000911 = 0.0019739  

Cofactor矩阵 (转置前)：  
C₁₁ = S₁ = 0.004961  
C₁₂ = -(0.009544*0.097344 - (-0.007587)*0.028056) = -(0.000929 + 0.000213) = -0.001142  
C₁₃ = (0.009544*0.028056 - 0.059049*(-0.007587)) = 0.000268 + 0.000448 = 0.000716  

C₂₁ = C₁₂ = -0.001142  
C₂₂ = S₂ = 0.0033464  
C₂₃ = -(0.034969*0.028056 - (-0.007587)*0.009544) = -(0.000981 + 0.0000724) = -0.0010534  

C₃₁ = C₁₃ = 0.000716  
C₃₂ = C₂₃ = -0.0010534  
C₃₃ = S₃ = 0.0019739  

则伴随矩阵（转置后与上面相同，因为对称）就是  
Adj =  
[0.004961, -0.001142, 0.000716  
 -0.001142, 0.0033464, -0.0010534  
 0.000716, -0.0010534, 0.0019739]  

逆矩阵 Σ⁻¹ = Adj / det = Adj / 0.00015717  

---

计算 Σ⁻¹·1（每个元素是Adj行和除以det）：

第一行求和 = 0.004961 - 0.001142 + 0.000716 = 0.004535  
第二行求和 = -0.001142 + 0.0033464 - 0.0010534 = 0.001151  
第三行求和 = 0.000716 - 0.0010534 + 0.0019739 = 0.0016365  

则：  
Σ⁻¹·1 = [0.004535/0.00015717, 0.001151/0.00015717, 0.0016365/0.00015717]  
= [28.85, 7.32, 10.41] （约数）

分母 1^T Σ⁻¹ 1 = 28.85 + 7.32 + 10.41 = 46.58  

所以权重：  
w₁ = 28.85 / 46.58 ≈ 0.6193  
w₂ = 7.32 / 46.58 ≈ 0.1572  
w₃ = 10.41 / 46.58 ≈ 0.2235  

检查总和 ≈ 1.0000，允许。

### 组合波动率：

计算：
先算 Σw：  
第一分量 = 0.034969*0.6193 + 0.009544*0.1572 - 0.007587*0.2235

年化波动率 = sqrt(0.021463) ≈ 0.1465 = 14.65%
