### 最小方差组合权重公式
当允许卖空并且满仓时，MVP权重向量为：

\[
\mathbf{w}_{mvp} = \frac{\Sigma^{-1} \mathbf{1}}{\mathbf{1}^T \Sigma^{-1} \mathbf{1}}
\]

其中 \(\mathbf{1}\) 是全1列向量。

---

我们先求 Σ 的逆矩阵。

令  
a = 0.034969, b = 0.00954261, c = -0.00758472  
d = 0.059049, e = 0.02805192  
f = 0.097344  

写成：
```
Σ = 
[ a  b  c ]
[ b  d  e ]
[ c  e  f ]
```

先计算行列式 det(Σ)：

det = a*(d*f - e²) - b*(b*f - c*e) + c*(b*e - c*d)

分步：  
d*f = 0.059049 * 0.097344 ≈ 0.00574857  
e² = 0.02805192² ≈ 0.00078691  
所以 d*f - e² ≈ 0.00574857 - 0.00078691 = 0.00496166  

第一部分：a * 0.00496166 ≈ 0.034969 * 0.00496166 ≈ 0.00017353  

第二项：b*f = 0.00954261 * 0.097344 ≈ 0.00092867  
c*e = (-0.00758472) * 0.02805192 ≈ -0.00021280  
b*f - c*e = 0.00092867 - (-0.00021280) = 0.00114147  
b * 该值 = 0.00954261 * 0.00114147 ≈ 0.00001089  
第二项前面是减号，所以贡献是 -0.00001089  

第三项：b*e = 0.00954261*0.02805192 ≈ 0.00026764  
c*d = (-0.00758472)*0.059049 ≈ -0.00044791  
b*e - c*d = 0.00026764 - (-0.00044791) = 0.00071555  
乘以 c： (-0.00758472)*0.00071555 ≈ -0.000005427  
前面的符号是正，所以这项是 -0.000005427  

于是 det = 0.00017353 - 0.00001089 - 0.000005427  
= 0.000157213

### 逆矩阵元素（用对称性）

伴随矩阵第一列：

C₁₁ = d*f - e² = 0.00496166  
C₁₂ = -(b*f - c*e) = -0.00114147

由于对称矩阵的逆元为 C_ij / det：

第二列 (由于对称，inv21=inv12, 需要计算inv22, inv23)：

c² = (−0.00758472)² ≈ 0.00005753  
C₂₂ ≈ 0.003404 - 0.00005753 = 0.00334647

a*e - b*c = 0.00098122 - (-0.00007238) = 0.00105360  
C₂₃ = -0.00105360  

inv23 = (-0.00105360)/0.000157213 ≈ -6.702  

第三列（inv31=inv13, inv32=inv23, 计算inv33）：

C₃₃ = a*d - b²  
a*d = 0.034969*0.059049 ≈ 0.002065  
b² = 0.00954261² ≈ 0.00009106  
C₃₃ = 0.002065 - 0.00009106 = 0.00197394  

inv33 = 0.00197394 / 0.000157213 ≈ 12.557

\[
