好的，我们先把问题转化为一个标准的最小方差组合（MVP）优化问题。  
已知三只资产的年化波动率与相关系数，允许卖空，资金全投，那么我们可以先构建协方差矩阵，再求解权重。

**第一步：构建协方差矩阵**  
年化波动率：  
σ₁ = 0.187，σ₂ = 0.243，σ₃ = 0.312  

相关系数：  
ρ₁₂ = 0.21，ρ₁₃ = -0.13，ρ₂₃ = 0.37  

协方差公式：  
Cov(i,j) = ρᵢⱼ × σᵢ × σⱼ  

计算得到：

- Cov(1,1) = 0.187² = 0.034969  
- Cov(2,2) = 0.243² = 0.059049  
- Cov(3,3) = 0.312² = 0.097344  
- Cov(1,2) = 0.21 × 0.187 × 0.243 = 0.00954561  
- Cov(1,3) = -0.13 × 0.187 × 0.312 = -0.00758712  
- Cov(2,3) = 0.37 × 0.243 × 0.312 = 0.02805192  

所以协方差矩阵 Σ 为：
```
[ 0.034969,   0.00954561, -0.00758712 ]
[ 0.00954561, 0.059049,    0.02805192 ]
[-0.00758712, 0.02805192,  0.097344   ]
```

**第二步：求解最小方差组合权重**  
在允许卖空且权重和为1的条件下，最小方差组合的权重公式为：

\[
\mathbf{w}_{mvp} = \frac{\Sigma^{-1} \mathbf{1}}{\mathbf{1}^T \Sigma^{-1} \mathbf{1}}
\]

其中 \(\mathbf{1} = [1,1,1]^T\)。

先求 Σ 的逆矩阵（保留足够精度计算）：

Σ⁻¹ ≈  
```
[ 31.7926,   -6.2912,    4.0289 ]
[ -6.2912,   21.5977,   -6.7380 ]
[  4.0289,   -6.7380,   13.2761 ]
```

然后计算 Σ⁻¹·1：  
第一行：31.7926 - 6.2912 + 4.0289 = 29.5303  
第二行：-6.2912 + 21.5977 - 6.7380 = 8.5685  
第三行：4.0289 - 6.7380 + 13.2761 = 10.5670  

分母 = 29.5303 + 8.5685 + 10.5670 = 48.6658  

因此权重：
- w₁ = 29.5303 / 48.6658 ≈ 0.6068  
- w₂ = 8.5685 / 48.6658 ≈ 0.1761  
- w₃ = 10.5670 / 48.6658 ≈ 0.2171  

验算：0.6068 + 0.1761 + 0.2171 = 1.0000 ✔

**第三步：组合年化波动率**  
组合方差 = wᵀ Σ w  

计算：
- 第一项：w₁²×0.034969 = 0.3682²×0.034969 ≈ 0.012876  
- 第二项：w₂²×0.059049 = 0.03101×0.059049 ≈ 0.001831  
- 第三项：w₃²×0.097344 = 0.04713×0.097344 ≈ 0.004588  
- 交叉项 2×w₁×w₂×Cov(1,2) = 2×0.6068×0.1761×0.00954561 ≈ 0.002039  
- 交叉项 2×w₁×w₃×Cov(1,3) = 2×0.6068×0.2171×(-0.00758712) ≈ -0.001998  
- 交叉项 2×w₂×w₃×Cov(2,3) = 2×0.1761×0.2171×0.02805192 ≈ 0.002145  

求和：  
0.012876 + 0.001831 + 0.004588 + 0.002039 - 0.001998 + 0.002145  
= 0.021481  

年化波动率 = √0.021481 ≈ 0.14656 → 14.66%

result = {
