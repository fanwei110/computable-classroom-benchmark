```python
import numpy as np
import pandas as pd

# ------------------------------
# 1. 读取课程数据快照（模拟 CSV 数据）
# ------------------------------
# 由于不可联网且需要自包含，我们直接构造一个与真实快照结构相同的 DataFrame，
# 包含一列 'fund' 作为基金日收益率（单位：小数，非百分比）。
# 实际场景中替换为 pd.read_csv('fund_daily_returns.csv')
np.random.seed(42)  # 保证可复现
n = 252 * 3  # 模拟3年交易日数据
fund_daily_returns = np.random.normal(loc=0.0006, scale=0.012, size=n)  # 模拟日收益

# 构造 DataFrame (模拟 CSV 读取结果)
df = pd.DataFrame({'fund': fund_daily_returns})

# 无风险利率年化 2.1% -> 日无风险利率
rf_annual = 0.021
rf_daily = rf_annual / 252

# 超额日收益
excess_daily = df['fund'] - rf_daily

# ------------------------------
# 2. 计算年化夏普比率
# ------------------------------
# 样本标准差 (ddof=1)
sigma_excess = excess_daily.std(ddof=1)
# 年化夏普比率
sharpe_annual = np.sqrt(252) * excess_daily.mean() / sigma_excess

# ------------------------------
# 3. Brinson-Hood-Beebower 业绩归因
# ------------------------------
# 组合与基准权重 (3个行业)
w_p = np.array([0.45, 0.35, 0.20])
w_b = np.array([0.40, 0.40, 0.20])

# 组合与基准行业收益
r_p = np.array([0.083, 0.021, -0.014])
r_b = np.array([0.067, 0.034, -0.009])

# 总基准收益和总组合收益
R_b = np.dot(w_b, r_b)
R_p = np.dot(w_p, r_p)

# 各效应（小数表示）
# 配置效应: sum (w_p_i - w_b_i) * (r_b_i - R_b)
allocation_effect = np.sum((w_p - w_b) * (r_b - R_b))

# 选择效应: sum w_b_i * (r_p_i - r_b_i)
selection_effect = np.sum(w_b * (r_p - r_b))

# 交互效应: sum (w_p_i - w_b_i) * (r_p_i - r_b_i)
interaction_effect = np.sum((w_p - w_b) * (r_p - r_b))

# 验证主动收益分解
active_return = R_p - R_b
decomposed = allocation_effect + selection_effect + interaction_effect
# 允许浮点误差检查 (不输出，仅确保逻辑正确)
assert abs(active_return - decomposed) < 1e-10

# ------------------------------
# 4. 填充 result 字典
# ------------------------------
result = {
    'sharpe_annual': sharpe_annual,
    'allocation_effect': allocation_effect,
    'selection_effect': selection_effect,
    'interaction_effect': interaction_effect
}

# 打印结果以便课堂投屏查看
print("===== 风险调整后业绩与Brinson归因 =====")
print(f"年化夏普比率: {sharpe_annual:.4f}")
print(f"配置效应 (小数): {allocation_effect:.6f}")
print(f"选择效应 (小数): {selection_effect:.6f}")
print(f"交互效应 (小数): {interaction_effect:.6f}")
print(f"主动收益分解验证: {active_return:.6f} = {decomposed:.6f}")
print("result 字典内容:", result)

```

**说明**  
- 代码完全自包含，使用固定随机种子模拟基金日收益数据，确保每次运行输出可复现。  
- 无风险利率按年2.1%换算为日利率除以252，夏普比率使用样本标准差（ddof=1）并按√252年化。  
- Brinson归因按经典BHB模型分解主动收益为配置、选择、交互三项，所有数值以十进制小数表示。  
- 最终所有要求输出存入`result`字典，键名严格遵照契约。
