### 第一问：年化夏普比率

公式：  
\[
\text{Sharpe Ratio (annual)} = \frac{E(R_p) - R_f}{\sigma_p} \times \sqrt{252}
\]  
其中：  
- \(E(R_p)\)：日平均收益率  
- \(R_f\)：日无风险利率 = 2.1% / 252  
- \(\sigma_p\)：日收益率标准差  

假设示例数据（你实际使用时替换成你的数据）：  
日收益率均值 = 0.0005，日收益率标准差 = 0.01  

计算：  
日无风险利率 = 0.021 / 252 ≈ 0.00008333  
超额日收益 = 0.0005 - 0.00008333 = 0.00041667  
日夏普 = 0.00041667 / 0.01 = 0.041667  
年化夏普 = 0.041667 × √252 ≈ 0.041667 × 15.8745 ≈ 0.661  

（这里只是示例，实际数值取决于你的数据）

### 第二问：业绩归因

已知：  
组合权重 \(W_{p,i}\) = [0.45, 0.35, 0.20]  
组合收益 \(R_{p,i}\) = [8.3%, 2.1%, -1.4%]  
基准权重 \(W_{b,i}\) = [0.40, 0.40, 0.20]  
基准收益 \(R_{b,i}\) = [6.7%, 3.4%, -0.9%]  

基准总收益 \(R_b = 0.40×6.7 + 0.40×3.4 + 0.20×(-0.9)\)  
= 2.68 + 1.36 - 0.18 = 3.86%  

#### 配置效应（Allocation effect）  
公式：  
\[
\text{Allocation} = \sum_i (W_{p,i} - W_{b,i}) \times (R_{b,i} - R_b)
\]  
计算：  
行业1: (0.45 - 0.40) × (6.7% - 3.86%) = 0.05 × 2.84% = 0.142%  
行业2: (0.35 - 0.40) × (3.4% - 3.86%) = (-0.05) × (-0.46%) = 0.023%  
行业3: (0.20 - 0.20) × (-0.9% - 3.86%) = 0 × (-4.76%) = 0%  
合计 = 0.142% + 0.023% = 0.165%

#### 选择效应（Selection effect）  
公式：  
\[
\text{Selection} = \sum_i W_{b,i} \times (R_{p,i} - R_{b,i})
\]  
行业1: 0.40 × (8.3% - 6.7%) = 0.40 × 1.6% = 0.64%  
行业2: 0.40 × (2.1% - 3.4%) = 0.40 × (-1.3%) = -0.52%  
行业3: 0.20 × (-1.4% - (-0.9%)) = 0.20 × (-0.5%) = -0.10%  
合计 = 0.64% - 0.52% - 0.10% = 0.02%

#### 交互效应（Interaction effect）  
公式：  
\[
\text{Interaction} = \sum_i (W_{p,i} - W_{b,i}) \times (R_{p,i} - R_{b,i})
\]  
行业1: 0.05 × 1.6% = 0.08%  
行业2: (-0.05) × (-1.3%) = 0.065%  
行业3: 0 × (-0.5%) = 0%  
合计 = 0.08% + 0.065% = 0.145%
