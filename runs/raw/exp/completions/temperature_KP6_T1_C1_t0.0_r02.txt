### 第一问：年化夏普比率

公式：  
\[
\text{Sharpe Ratio} = \frac{E(R_p) - R_f}{\sigma_p}
\]  
其中：  
- \(E(R_p)\) 是日平均收益率  
- \(R_f\) 是无风险日利率  
- \(\sigma_p\) 是日收益率标准差  
- 年化时，将日夏普乘以 \(\sqrt{252}\)

无风险年利率 = 2.1% → 日无风险利率 ≈ \(0.021 / 252 \approx 0.00008333\)

假设你从数据中计算得到：  
- 日平均收益率 = `mean_daily_return`  
- 日收益率标准差 = `std_daily_return`

则：  
日超额收益均值 = `mean_daily_return - 0.00008333`  
日夏普 = 日超额收益均值 / `std_daily_return`  
年化夏普 = 日夏普 × \(\sqrt{252}\)

### 第二问：业绩归因（Brinson模型）

已知：  
组合权重 \(W_p = [0.45, 0.35, 0.20]\)  
基准权重 \(W_b = [0.40, 0.40, 0.20]\)  
组合收益 \(R_p = [0.083, 0.021, -0.014]\)  
基准收益 \(R_b = [0.067, 0.034, -0.009]\)

#### 1. 配置效应（Allocation Effect）  
公式：  
\[
\text{Allocation}_i = (W_{p,i} - W_{b,i}) \times (R_{b,i} - R_b^{\text{total}})
\]  
其中基准总收益 \(R_b^{\text{total}} = \sum W_{b,i} \times R_{b,i}\)  

先算基准总收益：  
\[
0.40 \times 0.067 = 0.0268  
0.40 \times 0.034 = 0.0136  
0.20 \times (-0.009) = -0.0018  
\]  
总和 = \(0.0268 + 0.0136 - 0.0018 = 0.0386\)（即3.86%）

各行业配置效应：  
- 行业1: \((0.45 - 0.40) \times (0.067 - 0.0386) = 0.05 \times 0.0284 = 0.00142\)  
- 行业2: \((0.35 - 0.40) \times (0.034 - 0.0386) = (-0.05) \times (-0.0046) = 0.00023\)  
- 行业3: \((0.20 - 0.20) \times (-0.009 - 0.0386) = 0\)  

总配置效应 = \(0.00142 + 0.00023 + 0 = 0.00165\)（即0.165%）

#### 2. 选择效应（Selection Effect）  
公式：  
\[
\text{Selection}_i = W_{b,i} \times (R_{p,i} - R_{b,i})
\]  
- 行业1: \(0.40 \times (0.083 - 0.067) = 0.40 \times 0.016 = 0.0064\)  
- 行业2: \(0.40 \times (0.021 - 0.034) = 0.40 \times (-0.013) = -0.0052\)  
- 行业3: \(0.20 \times (-0.014 - (-0.009)) = 0.20 \times (-0.005) = -0.0010\)  

总选择效应 = \(0.0064 - 0.0052 - 0.0010 = 0.0002\)（即0.02%）

#### 3. 交互效应（Interaction Effect）  
公式：  
\[
\text{Interaction}_i = (W_{p,i} - W_{b,i}) \times (R_{p,i} - R_{b,i})
\]  
- 行业1: \(0.05 \times 0.016 = 0.0008\)  
- 行业2: \((-0.05) \times (-0.013) = 0.00065\)  
- 行业3: \(0 \times (-0.005) = 0\)  

总交互效应 = \(0.0008 + 0.00065 + 0 = 0.00145\)（即0.145%）
