好的，我们先明确一下条件，再用数学方法推导出最小方差组合（MVP）的权重和波动率。

**最小方差组合（允许卖空）**  
MVP的权重向量公式为：

\[
w_{mvp} = \frac{\Sigma^{-1} \mathbf{1}}{\mathbf{1}^T \Sigma^{-1} \mathbf{1}}
\]

其中 \(\mathbf{1} = [1,1,1]^T\)。

我们先求逆矩阵 Σ⁻¹。  

计算过程采用数值方式（保留高精度）：

先求行列式：  
det(Σ) 大约计算为：

= 0.034969*(0.059049*0.097344 - 0.02804184²)  
  - 0.00954081*(0.00954081*0.097344 - (-0.00758392)*0.02804184)  
  + (-0.00758392)*(0.00954081*0.02804184 - 0.059049*(-0.00758392))

第一部分：  
0.059049*0.097344 = 0.005748...  
0.02804184² = 0.000786345...  
差值 = 0.00496166  
乘0.034969 ≈ 0.000173485

第二部分：  
0.00954081*0.097344 = 0.00092864  
(-0.00758392)*0.02804184 = -0.00021271  
括号里 = 0.00092864 - (-0.00021271) = 0.00114135  
乘 0.00954081 = 1.089e-5  
再取负号：-0.00001089

第三部分：  
0.00954081*0.02804184 = 0.00026759  
0.059049 * (-0.00758392) = -0.00044784  
括号内 = 0.00026759 - (-0.00044784) = 0.00071543  
乘 (-0.00758392) = -0.000005425

总和 det = 0.000173485 - 0.00001089 - 0.000005425  
= 0.00015717

然后求逆矩阵每一个元素（对称），用伴随矩阵除以det。

我们可以直接计算 Σ⁻¹ * 1 向量：

设  
a = Σ₁₁⁻¹ + Σ₁₂⁻¹ + Σ₁₃⁻¹  
b = Σ₂₁⁻¹ + Σ₂₂⁻¹ + Σ₂₃⁻¹

通过计算（我这里直接数值求解）得：

验证一下矩阵乘法近似单位阵。

**组合年化波动率**：
