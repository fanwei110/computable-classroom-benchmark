根据你提供的参数，我们可以使用Black-Scholes公式对欧式看涨期权进行定价。  

参数汇总：  
- 标的价格 S = 103.7  
- 行权价 K = 97.5  
- 隐含波动率 σ = 27.6% = 0.276  
- 无风险利率 r = 4.3% = 0.043  
- 剩余时间 T = 0.58 年  
- 不分红（股息率 q = 0）  

先计算关键中间变量：  

d1 = [ln(S/K) + (r + σ²/2)T] / (σ√T)  
d2 = d1 - σ√T  

然后：  
- call_price = S * N(d1) - K * e^{-rT} * N(d2)  
- call_delta = N(d1)  
- call_vega = S * √T * n(d1) （其中 n() 为标准正态密度函数）  

逐步计算：  

ln(S/K) = ln(103.7 / 97.5) = ln(1.0635897) ≈ 0.06166  

σ²/2 = 0.276² / 2 = 0.076176 / 2 = 0.038088  

(r + σ²/2)T = (0.043 + 0.038088) * 0.58 = 0.081088 * 0.58 ≈ 0.047031  

σ√T = 0.276 * √0.58  
√0.58 ≈ 0.761577  
σ√T ≈ 0.276 * 0.761577 ≈ 0.210195  

d1 = (0.06166 + 0.047031) / 0.210195 = 0.108691 / 0.210195 ≈ 0.5171  
d2 = 0.5171 - 0.210195 ≈ 0.3069  

查标准正态分布：  
N(d1) ≈ N(0.5171) ≈ 0.6975  
N(d2) ≈ N(0.3069) ≈ 0.6205  

e^{-rT} = e^{-0.043*0.58} = e^{-0.02494} ≈ 0.97537  

看涨期权价格：  
call_price = 103.7 * 0.6975 - 97.5 * 0.97537 * 0.6205  
= 72.33075 - (97.5 * 0.97537 ≈ 95.0986) * 0.6205  
= 72.33075 - 59.028  
≈ 13.3028  

delta = N(d1) ≈ 0.6975  

vega 计算：  
标准正态密度 n(d1) = (1/√(2π)) * e^{-d1²/2}  
d1² = 0.5171² ≈ 0.2674  
e^{-0.1337} ≈ 0.8748  
n(d1) ≈ 0.398942 * 0.8748 ≈ 0.3490  

vega = S * √T * n(d1) = 103.7 * 0.761577 * 0.3490  
= 103.7 * 0.2658 ≈ 27.56
