好的，我们先按题目分两步走，并把结果汇总进 `result` 字典中。  

**第一步：年化夏普比率**  
已知条件：  
- 日收益率数据来自“fund列”  
- 无风险利率年化 2.1% → 每日无风险利率 ≈ 2.1% / 252  
- 年化夏普比率的公式是：  
\[
\text{Sharpe} = \frac{E(R_p) - R_f}{\sigma_p} \times \sqrt{252}
\]  
假设我们从课程数据已经计算出：  
- 日平均收益（均值）  
- 日收益率标准差  
因为这里你没有直接贴数据，我们用假设的数值举例计算方式（我将在最后用占位符保留真实计算逻辑）：

假设计算得：  
- 日平均收益 = 0.0005  
- 日标准差 = 0.01  
- 日无风险利率 = 0.021/252 ≈ 0.00008333  

则：
\[
\text{日超额收益} = 0.0005 - 0.00008333 = 0.00041667
\]
\[
\text{年化夏普} = \frac{0.00041667}{0.01} \times \sqrt{252} \approx 0.041667 \times 15.8745 \approx 0.661
\]

**第二步：业绩归因（Brinson模型）**  
公式：  

- 配置效应：  
\[
\sum (w_{p,i} - w_{b,i}) \times R_{b,i}
\]
- 选择效应：  
\[
\sum w_{b,i} \times (R_{p,i} - R_{b,i})
\]
- 交互效应：  
\[
\sum (w_{p,i} - w_{b,i}) \times (R_{p,i} - R_{b,i})
\]

代入数据：

行业1：组合权重0.45，基准0.40；组合收益8.3%，基准6.7%  
行业2：组合权重0.35，基准0.40；组合收益2.1%，基准3.4%  
行业3：组合权重0.20，基准0.20；组合收益-1.4%，基准-0.9%

计算：

配置效应：  
=(0.45-0.40)×6.7% + (0.35-0.40)×3.4% + (0.20-0.20)×(-0.9%)  
= 0.05×0.067 + (-0.05)×0.034 + 0  
= 0.00335 - 0.00170 = 0.00165 → 0.165%

选择效应：  
= 0.40×(8.3%-6.7%) + 0.40×(2.1%-3.4%) + 0.20×(-1.4%+0.9%)  
= 0.40×0.016 + 0.40×(-0.013) + 0.20×(-0.005)  
= 0.0064 - 0.0052 - 0.0010 = 0.0002 → 0.02%

交互效应：  
= (0.45-0.40)×(8.3%-6.7%) + (0.35-0.40)×(2.1%-3.4%) + (0.20-0.20)×(-1.4%+0.9%)  
= 0.05×0.016 + (-0.05)×(-0.013) + 0  
= 0.0008 + 0.00065 = 0.00145 → 0.145%
