我们需要使用 Black-Scholes 公式对该欧式看涨期权进行定价。参数如下：

- 标的价格 S = 103.7  
- 行权价 K = 97.5  
- 无风险利率 r = 4.3% = 0.043  
- 波动率 σ = 27.6% = 0.276  
- 剩余时间 T = 0.58 年  
- 无分红（q=0）

Black-Scholes 公式：

\[
d_1 = \frac{\ln(S/K) + (r + \sigma^2/2)T}{\sigma \sqrt{T}}
\]
\[
d_2 = d_1 - \sigma \sqrt{T}
\]
看涨期权价格：
\[
C = S N(d_1) - K e^{-rT} N(d_2)
\]
看涨 Delta：
\[
\Delta = N(d_1)
\]
Vega（每变动一个百分点的波动率，通常先求每变动1的波动率，再除以100）：
\[
\mathrm{Vega} = S \, \sqrt{T} \, \phi(d_1)
\]
其中 φ 是标准正态密度函数。

下面是逐步计算。

第一步，计算 d1 和 d2：

\[
\ln(S/K) = \ln(103.7 / 97.5) = \ln(1.0635897) \approx 0.061685
\]
\[
(r + \sigma^2/2)T = (0.043 + (0.276^2/2)) \times 0.58
\]
0.276^2 = 0.076176，一半是 0.038088。  
所以 r + σ²/2 = 0.043 + 0.038088 = 0.081088。  
乘 T = 0.58: 0.081088 × 0.58 = 0.047031

\[
\sigma \sqrt{T} = 0.276 \times \sqrt{0.58}
\]
√0.58 ≈ 0.761577，乘得 0.276 × 0.761577 ≈ 0.210195

\[
d_1 = \frac{0.061685 + 0.047031}{0.210195} = \frac{0.108716}{0.210195} \approx 0.5173
\]

\[
d_2 = 0.5173 - 0.2102 = 0.3071
\]

第二步，查标准正态分布函数值：

N(d1) ≈ N(0.5173) 可通过查表或近似：  
0.5173 对应概率约 0.6975（查正态表：0.51→0.6950, 0.52→0.6985，插值得约 0.6975）。

更精确一点使用计算：0.5173 的累积概率约为 0.69753。

N(d2) ≈ N(0.3071)  
0.3071 对应概率约 0.6206（0.30→0.6179，0.31→0.6217，插值得0.6206）。

第三步，计算期权价格 C：

\[
K e^{-rT} = 97.5 \times e^{-0.043 \times 0.58}
\]
-0.043 × 0.58 = -0.02494  
e^{-0.02494} ≈ 0.97537  
所以 K e^{-rT} ≈ 97.5 × 0.97537 ≈ 95.0986

因此：
\[
C = 103.7 \times 0.69753 - 95.0986 \times 0.6206
\]
第一项：103.7 × 0.69753 ≈ 72.329  
第二项：95.0986 × 0.6206 ≈ 59.042  
C ≈ 72.329 - 59.042 = 13.287

第四步，Delta：
\[
\Delta = N(d_1) = 0.69753
\]

第五步，Vega（每变动1单位波动率，即σ变化1=100%，对应的变化值；通常输出为每1%波动率变化时的价格变化，因此结果除以100）：

先求：
\[
\phi(d_1) = \frac{1}{\sqrt{2\pi}} e^{-d_1^2/2}
\]
d1=0.5173, d1²=0.2676, 一半=0.1338  
e^{-0.1338} ≈ 0.87476  
1/√(2π) ≈ 0.398942  
所以 φ ≈ 0.398942 × 0.87476 ≈ 0.3491

Vega（相对于σ变化1，即100%）：
\[
\mathrm{Vega_{raw}} = S \sqrt{T} \, \phi(d_1) = 103.7 \times 0.761577 \times 0.3491
\]
先 103.7 × 0.761577 ≈ 78.977  
再乘 0.3491 ≈ 27.566

所以每1%波动率变化时价格变化 ≈ 27.566 / 100 = 0.27566。

通常要求的Vega是“波动率增加1个百分点时价格变化”，因此数值是0.2757。

保留合理小数位数（例如4位有效）：

- 价格：13.287 → 13.29  
- Delta: 0.6975  
- Vega: 0.2757

最终字典输出：

```python
result = {
    'call_price': 13.29,
    'call_delta': 0.6975,
    'call_vega': 0.2757
}
```
