好的，我们先把问题转化为一个标准的均值-方差优化问题，这里因为只求最小方差组合（MVP），不需要预期收益率数据，只需要协方差矩阵。  

已知三只资产的年化波动率：  
σ1 = 18.7% = 0.187  
σ2 = 24.3% = 0.243  
σ3 = 31.2% = 0.312  

相关系数：  
ρ12 = 0.21  
ρ13 = -0.13  
ρ23 = 0.37  

先构建协方差矩阵 Σ：  

Σ₁₁ = σ1² = 0.034969  
Σ₂₂ = σ2² = 0.059049  
Σ₃₃ = σ3² = 0.097344  

Σ₁₂ = σ1 * σ2 * ρ12 = 0.187 * 0.243 * 0.21 ≈ 0.00954261  
Σ₁₃ = σ1 * σ3 * ρ13 = 0.187 * 0.312 * (-0.13) ≈ -0.00758232  
Σ₂₃ = σ2 * σ3 * ρ23 = 0.243 * 0.312 * 0.37 ≈ 0.02804592  

所以协方差矩阵为：
```
Σ = [[ 0.034969,   0.00954261, -0.00758232],
     [ 0.00954261,  0.059049,   0.02804592],
     [-0.00758232,  0.02804592,  0.097344  ]]
```

最小方差组合权重公式（允许卖空，满仓）：  
w_mvp = (Σ⁻¹ * 1) / (1ᵀ * Σ⁻¹ * 1)  

先求 Σ 的逆矩阵。  
令：
```
a = 0.034969
b = 0.00954261
c = -0.00758232
d = 0.059049
e = 0.02804592
f = 0.097344
```

行列式 det(Σ) 计算：  
det = a*(d*f - e²) - b*(b*f - e*c) + c*(b*e - d*c)  

先算：  
d*f = 0.059049 * 0.097344 ≈ 0.005748  
e² = 0.02804592² ≈ 0.00078657  
所以 d*f - e² ≈ 0.00496143  

b*f = 0.00954261 * 0.097344 ≈ 0.0009289  
e*c = 0.02804592 * (-0.00758232) ≈ -0.00021268  
b*f - e*c = 0.0009289 - (-0.00021268) = 0.00114158  

b*e = 0.00954261 * 0.02804592 ≈ 0.00026766  
d*c = 0.059049 * (-0.00758232) ≈ -0.00044776  
b*e - d*c = 0.00026766 - (-0.00044776) = 0.00071542  

所以：  
det = a * 0.00496143 - b * 0.00114158 + c * 0.00071542  
= 0.034969*0.00496143 ≈ 0.00017353  
减去 b*0.00114158 = 0.00954261*0.00114158 ≈ 0.00001089  
加上 c*0.00071542 = (-0.00758232)*0.00071542 ≈ -0.000005424  

det ≈ 0.00017353 - 0.00001089 - 0.000005424 ≈ 0.000157216  

现在求逆矩阵元素（用对称性）：  

Σ⁻¹ = (1/det) * 余子式矩阵的转置（即伴随矩阵）。  

先算各余子式：  

C11 = d*f - e² = 0.00496143  
C12 = -(b*f - e*c) = -0.00114158  
C13 = b*e - d*c = 0.00071542  

C21 = C12 = -0.00114158  
C22 = a*f - c² = 0.034969*0.097344 - (-0.00758232)²  
= 0.003404 - 0.00005749 ≈ 0.00334651  
C23 = -(a*e - c*b) = -(0.034969*0.02804592 - (-0.00758232)*0.00954261)  
= -(0.0009809 + 0.00007236) = -0.00105326  

C31 = C13 = 0.00071542  
C32 = C23 = -0.00105326  
C33 = a*d - b² = 0.034969*0.059049 - (0.00954261)²  
= 0.002065 - 0.00009106 ≈ 0.00197394  

伴随矩阵（余子式矩阵的转置）就是：
```
adj = [[C11, C21, C31],
       [C12, C22, C32],
       [C13, C23, C33]]
```
即：
```
adj = [[ 0.00496143, -0.00114158,  0.00071542],
       [-0.00114158,  0.00334651, -0.00105326],
       [ 0.00071542, -0.00105326,  0.00197394]]
```

所以逆矩阵：
```
Σ⁻¹ = adj / det
```
det ≈ 0.000157216  

计算每个元素：

Σ⁻¹₁₁ = 0.00496143 / 0.000157216 ≈ 31.558  
Σ⁻¹₁₂ = -0.00114158 / 0.000157216 ≈ -7.261  
Σ⁻¹₁₃ = 0.00071542 / 0.000157216 ≈ 4.550  

Σ⁻¹₂₂ = 0.00334651 / 0.000157216 ≈ 21.286  
Σ⁻¹₂₃ = -0.00105326 / 0.000157216 ≈ -6.699  

Σ⁻¹₃₃ = 0.00197394 / 0.000157216 ≈ 12.556  

所以：
```
Σ⁻¹ = [[31.558, -7.261,  4.550],
       [-7.261, 21.286, -6.699],
       [ 4.550, -6.699, 12.556]]
```

现在计算 1ᵀ Σ⁻¹：  
行向量 [1,1,1] 乘 Σ⁻¹：  
第一列：31.558 -7.261 + 4.550 = 28.847  
第二列：-7.261 + 21.286 -6.699 = 7.326  
第三列：4.550 -6.699 + 12.556 = 10.407  

所以 1ᵀ Σ⁻¹ = [28.847, 7.326, 10.407]  

分母：1ᵀ Σ⁻¹ 1 = 28.847 + 7.326 + 10.407 = 46.58  

权重向量 w = (Σ⁻¹ 1) / 46.58  

先算 Σ⁻¹ 1：  
第一行：31.558 -7.261 + 4.550 = 28.847  
第二行：-7.261 + 21.286 -6.699 = 7.326  
第三行：4.550 -6.699 + 12.556 = 10.407  

所以：
w1 = 28.847 / 46.58 ≈ 0.6193  
w2 = 7.326 / 46.58 ≈ 0.1573  
w3 = 10.407 / 46.58 ≈ 0.2234  

检查总和：0.6193+0.1573+0.2234=1.0000  

组合方差 = wᵀ Σ w  
先算 Σ w：  
第一行：0.034969*0.6193 + 0.00954261*0.1573 + (-0.00758232)*0.2234  
= 0.021658 + 0.001501 - 0.001694 ≈ 0.021465  

第二行：0.00954261*0.6193 + 0.059049*0.1573 + 0.02804592*0.2234  
= 0.005910 + 0.009288 + 0.006266 ≈ 0.021464  

第三行：(-0.00758232)*0.6193 + 0.02804592*0.1573 + 0.097344*0.2234  
= -0.004696 + 0.004412 + 0.021748 ≈ 0.021464  

组合方差 = w·(Σ w) = 0.6193*0.021465 + 0.1573*0.021464 + 0.2234*0.021464  
= 0.013293 + 0.003376 + 0.004795 ≈ 0.021464  

组合年化波动率 = sqrt(0.021464) ≈ 0.1465 = 14.65%
