好的，我们来一步一步计算这个债券的各项指标。我将严格遵循债券定价和久期、凸性的金融公式。

已知条件：  
- 面值（Face Value, FV）= 100  
- 票面利率（Coupon Rate）= 4.6%，年付息，因此每年利息（Coupon, C）= 4.6  
- 期限（Maturity, T）= 7年  
- 到期收益率（Yield to Maturity, YTM）= 5.3% = 0.053（年化）  

我们将进行以下计算：

### 1. 债券价格
债券价格是各期现金流折现之和：年利息C = 4.6，最后一年加上本金100，所以现金流为：  
第1到第6年：4.6  
第7年：104.6  

折现公式：  
\[
P = \sum_{t=1}^{7} \frac{CF_t}{(1+0.053)^t}
\]

手动计算过程：

- t=1: \(4.6 / 1.053 = 4.3685\)  
- t=2: \(4.6 / 1.053^2 = 4.6 / 1.108809 = 4.1488\)  
- t=3: \(4.6 / 1.053^3 = 4.6 / 1.167576 = 3.9396\)  
- t=4: \(4.6 / 1.053^4 = 4.6 / 1.229456 = 3.7405\)  
- t=5: \(4.6 / 1.053^5 = 4.6 / 1.294627 = 3.5512\)  
- t=6: \(4.6 / 1.053^6 = 4.6 / 1.363279 = 3.3712\)  
- t=7: \(104.6 / 1.053^7 = 104.6 / 1.435795 = 72.8477\)  

求和：  
4.3685 + 4.1488 = 8.5173  
+3.9396 = 12.4569  
+3.7405 = 16.1974  
+3.5512 = 19.7486  
+3.3712 = 23.1198  
+72.8477 = **95.9675**  

所以价格 ≈ **95.9675**。

---

### 2. Macaulay久期（年）
Macaulay久期公式：
\[
D_{mac} = \frac{ \sum_{t=1}^7 t \cdot \frac{CF_t}{(1+y)^t} }{P}
\]

我们已算出各期现值，现在乘以时间t：

- t=1: \(1 \times 4.3685 = 4.3685\)  
- t=2: \(2 \times 4.1488 = 8.2976\)  
- t=3: \(3 \times 3.9396 = 11.8188\)  
- t=4: \(4 \times 3.7405 = 14.9620\)  
- t=5: \(5 \times 3.5512 = 17.7560\)  
- t=6: \(6 \times 3.3712 = 20.2272\)  
- t=7: \(7 \times 72.8477 = 509.9339\)  

求和分子：  
4.3685 + 8.2976 = 12.6661  
+11.8188 = 24.4849  
+14.9620 = 39.4469  
+17.7560 = 57.2029  
+20.2272 = 77.4301  
+509.9339 = 587.3640  

除以价格95.9675：  
\( D_{mac} = 587.3640 / 95.9675 \approx 6.1195 \) 年。

---

### 3. 修正久期（年）
\[
D_{mod} = \frac{D_{mac}}{1+y} = \frac{6.1195}{1.053} \approx 5.8135
\]

---

### 4. 凸性（Convexity）
凸性公式（年化）：
\[
Convexity = \frac{1}{P (1+y)^2} \sum_{t=1}^{7} t(t+1) \frac{CF_t}{(1+y)^t}
\]

第一步：计算每个 \( t(t+1) \times PV(CF_t) \)  
- t=1: \(1\times2 = 2\)，乘4.3685 = 8.7370  
- t=2: \(2\times3 = 6\)，乘4.1488 = 24.8928  
- t=3: \(3\times4 = 12\)，乘3.9396 = 47.2752  
- t=4: \(4\times5 = 20\)，乘3.7405 = 74.8100  
- t=5: \(5\times6 = 30\)，乘3.5512 = 106.5360  
- t=6: \(6\times7 = 42\)，乘3.3712 = 141.5904  
- t=7: \(7\times8 = 56\)，乘72.8477 = 4079.4712  

求和：  
8.7370 + 24.8928 = 33.6298  
+47.2752 = 80.9050  
+74.8100 = 155.7150  
+106.5360 = 262.2510  
+141.5904 = 403.8414  
+4079.4712 = 4483.3126  

第二步：除以 \( P \times (1+y)^2 \)：
- \((1+y)^2 = 1.053^2 = 1.108809\)  
- \(P \times (1+y)^2 = 95.9675 \times 1.108809 \approx 106.4057\)  

凸性 = 4483.3126 / 106.4057 ≈ **42.131**
