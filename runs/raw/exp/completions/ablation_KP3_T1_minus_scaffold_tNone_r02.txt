我来写一个完整的债券定价与久期、凸性计算的Python脚本。

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from scipy import optimize

# 债券参数
face_value = 100.0      # 面值
coupon_rate = 0.046     # 票息率 4.6%
maturity_years = 7      # 剩余期限
ytm = 0.053             # 到期收益率 5.3%

# ===== 1. 计算债券价格 =====
# 生成现金流时间点（年）
t = np.arange(1, maturity_years + 1)

# 现金流：前n-1年是票息，最后一年是票息+面值
cash_flows = np.full_like(t, coupon_rate * face_value, dtype=float)
cash_flows[-1] += face_value

# 贴现因子
discount_factors = (1 + ytm) ** (-t)

# 债券价格 = 现金流贴现之和
price = np.sum(cash_flows * discount_factors)

# ===== 2. 计算麦考利久期 =====
# 麦考利久期 = Σ[t * CF_t / (1+y)^t] / P
macaulay_duration = np.sum(t * cash_flows * discount_factors) / price

# ===== 3. 计算修正久期 =====
modified_duration = macaulay_duration / (1 + ytm)

# ===== 4. 计算凸性 =====
# 凸性 = Σ[t(t+1) * CF_t / (1+y)^(t+2)] / P
convexity = np.sum(t * (t + 1) * cash_flows / (1 + ytm) ** (t + 2)) / price

# ===== 输出结果 =====
result = {
    'price': price,
    'macaulay_duration_years': macaulay_duration,
    'modified_duration_years': modified_duration,
    'convexity': convexity
}

# 打印结果（保留足够精度）
print("=" * 55)
print("债券定价与久期、凸性计算")
print("=" * 55)
print(f"面值: {face_value}")
print(f"票息率: {coupon_rate*100:.2f}%")
print(f"期限: {maturity_years} 年")
print(f"到期收益率: {ytm*100:.2f}%")
print("-" * 55)
print(f"价格 (Price): {result['price']:.6f}")
print(f"麦考利久期 (Macaulay Duration): {result['macaulay_duration_years']:.6f} 年")
print(f"修正久期 (Modified Duration): {result['modified_duration_years']:.6f} 年")
print(f"凸性 (Convexity): {result['convexity']:.6f} 年²")
print("=" * 55)

# 额外：绘制价格-收益率曲线，展示凸性
yield_range = np.linspace(0.02, 0.10, 100)
prices = []
for y in yield_range:
    df = (1 + y) ** (-t)
    p = np.sum(cash_flows * df)
    prices.append(p)

# 计算当前收益率处的切线（用修正久期）
# 价格变化近似: ΔP/P ≈ -D_mod * Δy + (1/2) * C * (Δy)²
y0 = ytm
p0 = price
dm = modified_duration
cv = convexity

dy_range = yield_range - y0
linear_approx = p0 * (1 - dm * dy_range)
quadratic_approx = p0 * (1 - dm * dy_range + 0.5 * cv * dy_range**2)

# 绘图
plt.figure(figsize=(10, 6))
plt.plot(yield_range * 100, prices, 'b-', linewidth=2, label='实际价格')
plt.plot(yield_range * 100, linear_approx, 'r--', linewidth=1.5, label='久期近似（线性）')
plt.plot(yield_range * 100, quadratic_approx, 'g-.', linewidth=1.5, label='久期+凸性近似（二次）')
plt.axvline(x=ytm * 100, color='gray', linestyle=':', alpha=0.7)
plt.axhline(y=price, color='gray', linestyle=':', alpha=0.7)
plt.scatter([ytm * 100], [price], color='red', s=100, zorder=5, label='当前价格')

plt.xlabel('到期收益率 (%)')
plt.ylabel('债券价格')
plt.title('债券价格-收益率曲线与久期/凸性近似')
plt.legend()
plt.grid(True, alpha=0.3)
plt.tight_layout()

# 检查结果字典
print("\nresult 字典内容:")
for key, value in result.items():
    print(f"  '{key}': {value:.6f}")
```

这个脚本完成了以下功能：

1. **价格计算**：将未来7年的现金流（票息和面值）按5.3%的到期收益率贴现求和。

2. **麦考利久期**：计算加权平均回收期，权重为每期现金流现值的比例。

3. **修正久期**：麦考利久期除以(1+y)，用于直接衡量价格对收益率变化的敏感度。

4. **凸性**：衡量久期本身的变动率，即价格-收益率曲线的曲率。

5. **可视化**：绘制价格-收益率曲线，并展示只用久期（线性近似）和加入凸性（二次近似）的效果对比，直观展示凸性对价格估计的改善作用。

输出的 `result` 字典可以直接用于教学演示中的所有后续计算。
