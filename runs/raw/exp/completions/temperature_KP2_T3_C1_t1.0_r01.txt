好的，我们先明确一下题目条件，再根据CAPM公式计算。注意题目问的是“上个月”的收益率，所以我们需要把年化无风险利率转换成月利率。  

**1. 已知条件整理：**  
- β = 1.42  
- 市场月收益率 = -5.8%（即 -0.058）  
- 年化无风险利率 = 4.7%  
- 要求的是上个月的期望收益（CAPM月收益）  

**2. 月无风险利率转换**  
年化利率4.7%意味着月无风险利率一般是：  
\[
R_f = \frac{4.7\%}{12} \approx 0.39167\% = 0.0039167
\]  

**3. CAPM公式（月度）**  
\[
E(R_i) = R_f + \beta \times (R_m - R_f)
\]  
其中 \(R_m\) 已经是月市场收益率。  

代入数值：  
\[
E(R_i) = 0.0039167 + 1.42 \times (-0.058 - 0.0039167)
\]  

先计算市场超额收益：  
\[
-0.058 - 0.0039167 = -0.0619167
\]  

乘以β：  
\[
1.42 \times (-0.0619167) \approx -0.087922
\]  

加上无风险利率：  
\[
0.0039167 - 0.087922 = -0.0840053
\]  

转化为百分比大约是 -8.40%（保留两位小数：-8.40%）。  

**4. 输出结果**  
最终存入字典：

```python
result = {
    'capm_return_monthly': -0.0840
}
```  

这样，就得到了该股票按CAPM模型在上个月应该有的期望月收益率。
