### 第二部分：业绩归因（Brinson模型）

已知：

组合权重 \(W_{p,i}\) = [0.45, 0.35, 0.20]  
组合收益 \(R_{p,i}\) = [8.3%, 2.1%, -1.4%]  
基准权重 \(W_{b,i}\) = [0.40, 0.40, 0.20]  
基准收益 \(R_{b,i}\) = [6.7%, 3.4%, -0.9%]

首先计算基准总收益：
\[
R_b = 0.40 \times 6.7\% + 0.40 \times 3.4\% + 0.20 \times (-0.9\%)
\]
\[
= 2.68\% + 1.36\% - 0.18\% = 3.86\%
\]

#### 1. 配置效应（Allocation effect）
公式：
\[
\text{Allocation}_i = (W_{p,i} - W_{b,i}) \times (R_{b,i} - R_b)
\]

- 行业1: \((0.45 - 0.40) \times (6.7\% - 3.86\%) = 0.05 \times 2.84\% = 0.1420\%\)
- 行业2: \((0.35 - 0.40) \times (3.4\% - 3.86\%) = (-0.05) \times (-0.46\%) = 0.0230\%\)
- 行业3: \((0.20 - 0.20) \times (-0.9\% - 3.86\%) = 0\)

合计配置效应：
\[
0.1420\% + 0.0230\% + 0 = 0.1650\%
\]

#### 2. 选择效应（Selection effect）
公式：
\[
\text{Selection}_i = W_{b,i} \times (R_{p,i} - R_{b,i})
\]

- 行业1: \(0.40 \times (8.3\% - 6.7\%) = 0.40 \times 1.6\% = 0.64\%\)
- 行业2: \(0.40 \times (2.1\% - 3.4\%) = 0.40 \times (-1.3\%) = -0.52\%\)
- 行业3: \(0.20 \times (-1.4\% - (-0.9\%)) = 0.20 \times (-0.5\%) = -0.10\%\)

合计选择效应：
\[
0.64\% - 0.52\% - 0.10\% = 0.02\%
\]

#### 3. 交互效应（Interaction effect）
公式：
\[
\text{Interaction}_i = (W_{p,i} - W_{b,i}) \times (R_{p,i} - R_{b,i})
\]

- 行业1: \(0.05 \times 1.6\% = 0.08\%\)
- 行业2: \((-0.05) \times (-1.3\%) = 0.065\%\)
- 行业3: \(0 \times (-0.5\%) = 0\)

合计交互效应：
\[
0.08\% + 0.065\% + 0 = 0.145\%
\]
