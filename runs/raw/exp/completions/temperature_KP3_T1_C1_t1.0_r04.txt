好的，我们来一步一步计算你要求的债券指标。  
已知条件：  
- 面值（Face Value）：100  
- 票面利率（Coupon Rate）：4.6%，即每年付息4.6元  
- 期限（Maturity）：7年  
- 到期收益率（Yield to Maturity, YTM）：5.3%  
- 付息频率：默认一年一次  

我将使用标准的债券定价、久期和凸性公式。

---

**1. 计算价格 (Price)**  

每期现金流：  
第1-6年：利息 4.6元  
第7年：利息 4.6元 + 本金 100元 = 104.6元  

折现率 = 5.3% = 0.053  

价格公式：  
\[
P = \sum_{t=1}^{7} \frac{4.6}{(1+0.053)^t} + \frac{100}{(1+0.053)^7}
\]

计算各年折现因子和现值：

t=1: 4.6 / 1.053 = 4.36847  
t=2: 4.6 / 1.108809 = 4.14907  
t=3: 4.6 / 1.16761 = 3.94059  
t=4: 4.6 / 1.22952 = 3.74279  
t=5: 4.6 / 1.29470 = 3.55433  
t=6: 4.6 / 1.36333 = 3.37543  
t=7: 104.6 / 1.43578 = 72.86079  

求和：  
利息现值总和 ≈ 4.36847 + 4.14907 + 3.94059 + 3.74279 + 3.55433 + 3.37543 = 23.13068  
加上最后一期本息 = 23.13068 + 72.86079 = **95.99147**  

所以：
```
price ≈ 95.9915
```

---

**2. Macaulay久期（年）**  

公式：
\[
MacD = \frac{ \sum_{t=1}^{7} t \times \frac{CF_t}{(1+y)^t} }{P}
\]

计算每期加权：

t=1: 1 × 4.36847 = 4.36847  
t=2: 2 × 4.14907 = 8.29814  
t=3: 3 × 3.94059 = 11.82177  
t=4: 4 × 3.74279 = 14.97116  
t=5: 5 × 3.55433 = 17.77165  
t=6: 6 × 3.37543 = 20.25258  
t=7: 7 × 72.86079 = 510.02553  

求和：  
4.36847 + 8.29814 = 12.66661  
+11.82177 = 24.48838  
+14.97116 = 39.45954  
+17.77165 = 57.23119  
+20.25258 = 77.48377  
+510.02553 = 587.50930  

Macaulay久期：
\[
MacD = 587.50930 / 95.99147 ≈ 6.1195 \ \text{年}
\]

---

**3. 修正久期 (Modified Duration)**  

\[
ModD = \frac{MacD}{1 + y} = \frac{6.1195}{1.053} ≈ 5.8124
\]

---

**4. 凸性 (Convexity)**  

公式：
\[
Convexity = \frac{1}{P(1+y)^2} \sum_{t=1}^{n} \frac{CF_t}{(1+y)^t} (t^2 + t)
\]

我们先计算每一项（t^2 + t）：

t=1: (1+1)=2 → 2 × 4.36847 = 8.73694  
t=2: (4+2)=6 → 6 × 4.14907 = 24.89442  
t=3: (9+3)=12 → 12 × 3.94059 = 47.28708  
t=4: (16+4)=20 → 20 × 3.74279 = 74.85580  
t=5: (25+5)=30 → 30 × 3.55433 = 106.62990  
t=6: (36+6)=42 → 42 × 3.37543 = 141.76806  
t=7: (49+7)=56 → 56 × 72.86079 = 4080.20424  

求和：  
8.73694 + 24.89442 = 33.63136  
+47.28708 = 80.91844  
+74.85580 = 155.77424  
+106.62990 = 262.40414  
+141.76806 = 404.17220  
+4080.20424 = 4484.37644  

凸性：
\[
Convexity = \frac{4484.37644}{95.99147 \times (1.053)^2} 
= \frac{4484.37644}{95.99147 \times 1.108809}
= \frac{4484.37644}{106.42855} ≈ 42.134
\]
