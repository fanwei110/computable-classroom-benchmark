按照CAPM公式，月度收益率的计算方式是：

\[
R_i = R_f + \beta \times (R_m - R_f)
\]

这里给出的数据是：
- 无风险利率是年化4.7%，需要转为月利率：  
  \( R_f = \frac{4.7\%}{12} \approx 0.39167\% \)
- 市场月收益率 \( R_m = -5.8\% \)
- \(\beta = 1.42\)

代入公式：

\[
R_i = 0.39167\% + 1.42 \times (-5.8\% - 0.39167\%)
\]

先算市场超额部分：
\[
-5.8\% - 0.39167\% = -6.19167\%
\]

乘以β：
\[
1.42 \times (-6.19167\%) \approx -8.79217\%
\]

加上无风险利率：
\[
0.39167\% + (-8.79217\%) = -8.4005\%
\]

因此：

```python
result = {
    'capm_return_monthly': -8.4005  # 单位：百分比
}
```
