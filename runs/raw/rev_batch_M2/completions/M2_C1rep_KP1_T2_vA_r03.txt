首先，计算所需指标。

给定：
- 资产1：年收益率 \(r_1 = 7.1\% = 0.071\)，年化波动率 \(\sigma_1 = 16.3\% = 0.163\)  
- 资产2：年收益率 \(r_2 = 12.4\% = 0.124\)，年化波动率 \(\sigma_2 = 28.9\% = 0.289\)  
- 相关系数 \(\rho = 0.45\) 时的最小方差组合（MVP），以及 \(\rho = 0.45\)、目标收益 \(10\%\) 时的最小波动率。

### 1. \(\rho = 0.45\) 时最小方差组合的波动率
最小方差组合权重：
\[
w_1 = \frac{\sigma_2^2 - \rho\sigma_1\sigma_2}{\sigma_1^2 + \sigma_2^2 - 2\rho\sigma_1\sigma_2},\quad w_2 = 1 - w_1
\]
\[
\sigma_1^2 = 0.026569,\quad \sigma_2^2 = 0.083521,\quad \sigma_1\sigma_2 = 0.047107,\quad \rho\sigma_1\sigma_2 = 0.021198
\]
\[
w_1 = \frac{0.083521 - 0.021198}{0.026569 + 0.083521 - 2 \times 0.021198} = \frac{0.062323}{0.067694} \approx 0.92066
\]
组合方差：
\[
\sigma_p^2 = w_1^2\sigma_1^2 + w_2^2\sigma_2^2 + 2w_1w_2\rho\sigma_1\sigma_2
\]
代入得 \(\sigma_p^2 \approx 0.0261425\)，波动率：
\[
\sigma_p = \sqrt{0.0261425} \approx 0.16169 \;(16.17\%)
\]
**因此：`mvp_vol_at_rho45 = 0.16169`**

### 2. 目标收益 \(10\%\) 时的最小波动率（\(\rho = 0.45\)）
组合收益 \(E = w_1r_1 + w_2r_2 = 0.10\)，且 \(w_2 = 1 - w_1\)：
\[
0.071w_1 + 0.124(1 - w_1) = 0.10 \;\Rightarrow\; -0.053w_1 = -0.024 \;\Rightarrow\; w_1 = \frac{0.024}{0.053} \approx 0.45283
\]
相应的波动率：
\[
\sigma = \sqrt{0.45283^2\cdot0.026569 + 0.54717^2\cdot0.083521 + 2\cdot0.45283\cdot0.54717\cdot0.021198} \approx \sqrt{0.040954} \approx 0.20237 \;(20.24\%)
\]
**因此：`frontier_vol_at_target = 0.20237`**

**附：绘图代码（仅供参考）**
```python
import numpy as np
import matplotlib.pyplot as plt

r1, r2 = 0.071, 0.124
s1, s2 = 0.163, 0.289
rhos = [0.15, 0.45, 0.75]
ws = np.linspace(-0.5, 1.5, 500)

plt.figure(figsize=(8,5))
for rho in rhos:
    var = ws**2*s1**2 + (1-ws)**2*s2**2 + 2*ws*(1-ws)*rho*s1*s2
    std = np.sqrt(var)
    ret = ws*r1 + (1-ws)*r2
    # 分离有效前沿（收益高于MVP的部分）
    mvp_w = (s2**2 - rho*s1*s2) / (s1**2 + s2**2 - 2*rho*s1*s2)
    mvp_ret = mvp_w*r1 + (1-mvp_w)*r2
    mvp_std = np.sqrt(mvp_w**2*s1**2 + (1-mvp_w)**2*s2**2 + 2*mvp_w*(1-mvp_w)*rho*s1*s2)
    mask = ret >= mvp_ret
    plt.plot(std[mask], ret[mask], label=f'ρ={rho}')
    plt.scatter(mvp_std, mvp_ret, marker='*', s=100, zorder=5)

plt.title('Efficient Frontier for Different Correlations')
plt.xlabel('Volatility')
plt.ylabel('Expected Return')
plt.legend()
plt.grid(True)
plt.savefig('efficient_frontier.png')
plt.show()
```
