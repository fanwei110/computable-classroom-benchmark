以下代码将读取 `data/market_snapshot_v1.csv` 中的 `fund` 列日收益率，计算 100 万头寸的损益序列，绘制直方图并标注 95% 1日历史 VaR，最后将 VaR 数值与图片路径存入 `result` 字典。

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import os

# ------------------------------
# 参数设置（置信度可在此调整）
# ------------------------------
confidence = 0.95          # 置信度，例如 0.95 对应 95% VaR
position = 1_000_000       # 头寸 100 万
data_path = "data/market_snapshot_v1.csv"
figure_filename = "var_histogram.png"

# ------------------------------
# 1. 读取数据并计算损益
# ------------------------------
df = pd.read_csv(data_path)
# 假设 fund 列为日收益率（例如 0.01 代表 1%），直接使用
returns = pd.to_numeric(df["fund"], errors="coerce").dropna()
pnl = returns * position          # 损益序列

# ------------------------------
# 2. 计算历史 VaR（绝对值，表示损失）
# ------------------------------
# 损益的 (1-confidence) 分位数（左尾），取负后代表损失金额
var_cutoff = np.percentile(pnl, (1 - confidence) * 100)
hist_var = -var_cutoff            # 95% VaR 为正损失值

# ------------------------------
# 3. 绘制直方图并保存
# ------------------------------
plt.figure(figsize=(10, 6))
plt.hist(pnl, bins=60, edgecolor='k', alpha=0.7, color='steelblue')
plt.axvline(var_cutoff, color='red', linestyle='dashed', linewidth=2,
            label=f'{confidence*100:.0f}% 1-Day Hist VaR: {hist_var:.2f}')
plt.title("Daily P&L Distribution (Historical VaR)", fontsize=14)
plt.xlabel("Profit / Loss")
plt.ylabel("Frequency")
plt.legend()
plt.tight_layout()
plt.savefig(figure_filename, dpi=150)
plt.close()

# ------------------------------
# 4. 输出结果字典
# ------------------------------
result = {
    'hist_var_95_1d': round(hist_var, 2),          # VaR 数值
    'figure_path': os.path.abspath(figure_filename) # 图片绝对路径
}

# 打印结果以便查看
print(result)
```

**运行说明：**
- 请确保当前工作目录下存在 `data/market_snapshot_v1.csv` 文件，且含有 `fund` 列（日收益率数值）。
- 该脚本会生成直方图文件（默认保存为 `var_histogram.png`），并将绝对路径与 VaR 值存入字典 `result`。
- 若需调整置信度，直接修改 `confidence` 变量即可。
