### 完整脚本
请将下列代码保存为 Python 文件并执行，它会读取数据、计算历史 VaR、绘制直方图并保存图片，最后输出所需字典。

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# 1. 读取数据
df = pd.read_csv('data/market_snapshot_v1.csv')
returns = df['fund'].dropna()

# 2. 参数设定
position = 1_000_000          # 头寸 100 万
confidence = 0.95             # 置信度可调（此处95%）
alpha = 1 - confidence        # 分位数 5%

# 3. 计算每日损益（P&L）
pnl = position * returns

# 4. 历史法计算 VaR（取第 alpha*100 百分位数的绝对值）
var_95 = -np.percentile(pnl, alpha * 100)

# 5. 绘制损益直方图并标注 VaR 线
plt.figure(figsize=(10, 6))
plt.hist(pnl, bins=50, edgecolor='black', alpha=0.7)
plt.axvline(x=-var_95, color='red', linestyle='--', linewidth=2,
            label=f'95% 1-Day VaR: {var_95:,.2f}')
plt.xlabel('Profit & Loss (P&L)')
plt.ylabel('Frequency')
plt.title('Historical VaR: P&L Distribution')
plt.legend()
plt.tight_layout()

# 保存图片
fig_path = 'var_histogram.png'
plt.savefig(fig_path)
plt.close()

# 6. 输出契约字典
result = {
    'hist_var_95_1d': var_95,
    'figure_path': fig_path
}

print(result)  # 打印确认
```

运行后，终端会打印类似 `{'hist_var_95_1d': 16250.78, 'figure_path': 'var_histogram.png'}` 的实际结果，并且直方图已保存到 `var_histogram.png`。您可根据需要调整置信度（修改 `confidence` 变量）。
