```python
import numpy as np
from scipy.stats import norm

# 给定的参数
annual_volatility = 0.24         # 年化波动率 24%
position_value = 2_700_000.0     # 头寸金额 2,700,000 元
confidence_level = 0.95          # 95% 置信水平
trading_days_year = 252          # 假设每年252个交易日

# 1. 年化波动率换算为一日波动率
daily_volatility = annual_volatility / np.sqrt(trading_days_year)

# 2. 正态分布下 95% 置信水平对应的分位数（左尾）
z_score = norm.ppf(1 - confidence_level)  # 约 -1.64485

# 3. 计算一天 95% VaR（通常以正数表示损失金额）
var_95_1d = position_value * daily_volatility * abs(z_score)

# 按输出契约存入字典
result = {
    'var_95_1d': round(var_95_1d, 2)  # 保留两位小数，与常见报告一致
}

# 显示结果（教师投屏时可直接看到）
print("95% 一日 VaR 计算结果：")
print(f"var_95_1d = {result['var_95_1d']:,.2f} 元")
```
该脚本自包含，仅使用 numpy 和 scipy，假设每年 252 个交易日进行波动率换算，最终将 95% 一日 VaR 金额存入 `result` 字典，键名为 `'var_95_1d'`。
