根据您的要求，我将计算证券市场线（SML）的斜率、beta=1.27对应的期望收益，并绘制可调参数的SML图。以下是Python代码实现：

```python
import numpy as np
import matplotlib.pyplot as plt
import os

# 参数设置
rf = 0.023  # 无风险利率
market_return = 0.094  # 市场期望收益

# 计算SML斜率
sml_slope = market_return - rf

# 计算beta=1.27对应的期望收益
beta_127 = 1.27
er_at_beta_127 = rf + beta_127 * sml_slope

# 绘制SML图
def plot_sml(rf, market_return):
    betas = np.linspace(0, 2, 100)
    expected_returns = rf + betas * (market_return - rf)

    plt.figure(figsize=(10, 6))
    plt.plot(betas, expected_returns, label='Security Market Line (SML)')

    # 标记三个点
    points = {'X': (0.62, 0.081), 'Y': (1.18, 0.131), 'Z': (1.51, 0.099)}
    for label, (beta, er) in points.items():
        plt.scatter(beta, er, color='red')
        plt.text(beta, er, f' {label}', verticalalignment='bottom')

    plt.xlabel('Beta')
    plt.ylabel('Expected Return')
    plt.title('Security Market Line (SML)')
    plt.grid(True)
    plt.legend()

    # 保存图片
    figure_path = 'sml_plot.png'
    plt.savefig(figure_path)
    plt.close()

    return figure_path

figure_path = plot_sml(rf, market_return)

# 存储结果
result = {
    'sml_slope': sml_slope,
    'er_at_beta_127': er_at_beta_127,
    'figure_path': os.path.abspath(figure_path)
}

print(result)
```

输出结果（`result`字典）：

```python
    'er_at_beta_127': 0.11217,  # 11.217%
    'figure_path': '/path/to/your/sml_plot.png'  # 实际路径取决于运行环境
}
```

### 说明：
1. **SML斜率**：市场风险溢价（市场期望收益 - 无风险利率）= 9.4% - 2.3% = 7.1%
2. **beta=1.27对应的期望收益**：
   \( E(R) = R_f + \beta \times (E(R_m) - R_f) = 2.3\% + 1.27 \times 7.1\% = 11.217\% \)
3. **图形**：保存为`sml_plot.png`，包含SML线和三个标记点X、Y、Z。您可以修改`rf`和`market_return`参数重新生成图形。
