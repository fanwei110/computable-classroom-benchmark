下面是一个自包含的 Python 脚本，完全满足您的要求。脚本中无风险利率与市场期望收益被设置为顶部可调参数，绘制证券市场线（SML）并标记三只股票，计算并输出所需指标。

```python
import numpy as np
import matplotlib.pyplot as plt

# ---------- 可调参数 ----------
rf = 0.023        # 无风险利率（2.3%）
E_rm = 0.094      # 市场期望收益（9.4%）
# -----------------------------

# 股票数据：beta, 实际收益
stocks = {
    'X': {'beta': 0.62, 'return': 0.081},
    'Y': {'beta': 1.18, 'return': 0.131},
    'Z': {'beta': 1.51, 'return': 0.099}
}

# 计算 SML 斜率（市场风险溢价）
sml_slope = E_rm - rf

# 计算 beta = 1.27 处的 CAPM 期望收益
beta_target = 1.27
er_at_beta_127 = rf + beta_target * sml_slope

# 生成 beta 从 0 到 2 的 SML 线
beta_line = np.linspace(0, 2, 100)
sml_line = rf + beta_line * sml_slope

# ---------- 画图 ----------
plt.figure(figsize=(8, 6))

# 绘制 SML 直线
plt.plot(beta_line, sml_line, 'b-', linewidth=2, label='Security Market Line (SML)')

# 标记无风险资产和市场组合
plt.scatter(0, rf, color='green', s=120, zorder=5, label=f'Risk-free (β=0, {rf:.1%})')
plt.scatter(1, E_rm, color='orange', s=120, zorder=5, label=f'Market (β=1, {E_rm:.1%})')

# 标记三只股票
for name, data in stocks.items():
    b = data['beta']
    r = data['return']
    plt.scatter(b, r, color='red', marker='x', s=120, zorder=5)
    plt.annotate(
        f' Stock {name}\n(β={b:.2f}, r={r:.1%})',
        (b, r),
        textcoords="offset points",
        xytext=(12, 12),
        ha='left',
        fontsize=9,
        arrowprops=dict(arrowstyle='->', color='grey'),
        bbox=dict(boxstyle='round,pad=0.3', fc='white', alpha=0.7)
    )

plt.xlabel('Beta (β)')
plt.ylabel('Expected Return')
plt.title('Capital Asset Pricing Model - Security Market Line')
plt.grid(True, linestyle='--', alpha=0.6)
plt.legend()

# 自动设置坐标轴范围，保证所有点可见
all_returns = [rf, E_rm] + [s['return'] for s in stocks.values()]
y_min = min(all_returns) - 0.01
y_max = max(all_returns) + 0.02
plt.xlim(0, 2)
plt.ylim(y_min, y_max)

plt.tight_layout()

# 保存图像
figure_path = 'sml.png'
plt.savefig(figure_path, dpi=150)
plt.close()

# ---------- 输出结果 ----------
result = {
    'sml_slope': sml_slope,
    'er_at_beta_127': er_at_beta_127,
    'figure_path': figure_path
}

# 课堂展示用：直接打印 result 字典
print(">>> CAPM 分析结果 <<<")
print(f"SML 斜率 (市场风险溢价): {sml_slope:.4f}  ({sml_slope:.2%})")
print(f"Beta = {beta_target} 处的 CAPM 期望收益: {er_at_beta_127:.4f}  ({er_at_beta_127:.2%})")
print(f"图像已保存至: {figure_path}")
print("\n结果字典:", result)
```

**脚本说明：**
- `rf` 和 `E_rm` 是顶部的可调参数，教师可当堂修改并重新运行。
- 证券市场线（SML）方程为 \(E(r) = r_f + \beta \times (E(r_m) - r_f)\)，斜率即市场风险溢价。
- 三只股票以红色 × 标出，并附有注释标签。无风险资产与市场组合也一并标出。
- 所有计算结果存入 `result` 字典，键名严格按题目要求为 `'sml_slope'`、`'er_at_beta_127'`、`'figure_path'`。
