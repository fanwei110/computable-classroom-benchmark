根据题目要求，我们使用资本资产定价模型（CAPM）计算三只股票的期望收益率，并计算股票Y的Alpha值。以下是详细的计算过程：

### 1. CAPM公式
CAPM的期望收益率公式为：
\[ E(R_i) = R_f + \beta_i \times (E(R_m) - R_f) \]
其中：
- \( E(R_i) \)：股票i的期望收益率
- \( R_f \)：无风险利率（2.3%或0.023）
- \( \beta_i \)：股票i的Beta系数
- \( E(R_m) \)：市场期望收益率（9.4%或0.094）

### 2. 计算三只股票的期望收益率
- **股票X（β=0.62）**：
  \[ E(R_x) = 0.023 + 0.62 \times (0.094 - 0.023) = 0.023 + 0.62 \times 0.071 = 0.023 + 0.04402 = 0.06702 \]
  年化期望收益率为6.702%。

- **股票Y（β=1.18）**：
  \[ E(R_y) = 0.023 + 1.18 \times (0.094 - 0.023) = 0.023 + 1.18 \times 0.071 = 0.023 + 0.08378 = 0.10678 \]
  年化期望收益率为10.678%。

- **股票Z（β=1.51）**：
  \[ E(R_z) = 0.023 + 1.51 \times (0.094 - 0.023) = 0.023 + 1.51 \times 0.071 = 0.023 + 0.10721 = 0.13021 \]
  年化期望收益率为13.021%。

### 3. 计算股票Y的Alpha
Alpha的计算公式为：
\[ \alpha = R_i - E(R_i) \]
其中：
- \( R_i \)：股票Y的实际收益率（13.1%或0.131）
- \( E(R_i) \)：股票Y的期望收益率（10.678%或0.10678）

\[ \alpha_y = 0.131 - 0.10678 = 0.02422 \]
年化Alpha为2.422%。

### 4. 输出结果
将结果存入字典 `result` 中：

result = {
