### 核心计算逻辑与约定对应：
1. **无风险利率换算**：年化 $r_f = 2.1\% = 0.021$。约定指出“债券收益率按年复利报价”，因此日度无风险利率需按年复利折算：$r_{f,daily} = (1 + 0.021)^{1/252} - 1$。
2. **日度超额收益**：$R_{ex,t} = R_{fund,t} - r_{f,daily}$
3. **样本标准差**：约定要求使用样本估计量（ddof=1），即分母为 $n-1$。
4. **年化夏普比率**：根据“所有年化按252个交易日”的约定，年化夏普 = 日度夏普 $\times \sqrt{252}$，即：
   $$Sharpe_{annual} = \frac{\text{mean}(R_{ex})}{\text{std}(R_{ex}, ddof=1)} \times \sqrt{252}$$

### Python 实现代码：

```python
import numpy as np
import pandas as pd

# 假设 df 为包含基金日收益率数据的 DataFrame，列名为 'fund'
# df = pd.read_csv("your_data.csv") 

rf_annual = 0.021  # 2.1% 转换为小数表示

# 1. 根据债券收益率年复利报价约定，计算日度无风险利率
rf_daily = (1 + rf_annual) ** (1 / 252) - 1

# 2. 计算日度超额收益率
excess_daily = df['fund'] - rf_daily

# 3. 计算日度超额收益率的均值和样本标准差（ddof=1）
mu_daily = excess_daily.mean()
sigma_daily = excess_daily.std(ddof=1)

# 4. 计算年化夏普比率（按 252 个交易日年化）
sharpe_annual = (mu_daily / sigma_daily) * np.sqrt(252)

# 5. 按输出契约存入字典
result = {'sharpe_annual': sharpe_annual}

print(result)
```
