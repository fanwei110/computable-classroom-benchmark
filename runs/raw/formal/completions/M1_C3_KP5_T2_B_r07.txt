我将按照您的要求计算历史法VaR，并绘制损益直方图。以下是实现代码：

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import os

# 读取数据
data = pd.read_csv('data/market_snapshot_v1.csv')
returns = data['fund'].pct_change().dropna()  # 日收益率序列

# 计算参数
position = 1_000_000  # 头寸100万
confidence_level = 0.95  # 置信度95%

# 计算历史法VaR
historical_pnl = returns * position
var_95_1d = -np.percentile(historical_pnl, 100 * (1 - confidence_level))

# 绘制损益直方图
plt.figure(figsize=(10, 6))
plt.hist(historical_pnl, bins=50, alpha=0.75, color='blue', edgecolor='black')

# 添加VaR标根线
plt.axvline(x=-var_95_1d, color='red', linestyle='--', label=f'95% 1-day VaR: {var_95_1d:,.2f}')

plt.title('Historical P&L Distribution with VaR')
plt.xlabel('P&L')
plt.ylabel('Frequency')
plt.legend()
plt.grid(True, alpha=0.3)

# 保存图片
figure_path = 'hist_var_plot.png'
plt.savefig(figure_path)
plt.close()

# 存储结果
result = {
    'hist_var_95_1d': var_95_1d,
    'figure_path': os.path.abspath(figure_path)
}

# 输出结果
print(f"95% 1-day Historical VaR: {var_95_1d:,.2f} 元")
print(f"Figure saved to: {result['figure_path']}")
```

输出结果将包括：
1. `result`字典包含：
   - `hist_var_95_1d`: 95%置信度下的1日历史VaR值（正数表示损失金额）
   - `figure_path`: 损益直方图的保存路径

2. 控制台会打印VaR数值和图片保存路径

注意事项：
1. 请确保数据文件路径正确（'data/market_snapshot_v1.csv'）
2. 图片将保存为当前工作目录下的'hist_var_plot.png'
3. 如果需要调整置信度，可以修改`confidence_level`变量
4. VaR值为正数，表示在95%置信度下1日内可能的最大损失金额
