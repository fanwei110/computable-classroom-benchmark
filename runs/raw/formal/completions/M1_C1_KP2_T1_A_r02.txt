根据题目要求，我们使用资本资产定价模型（CAPM）计算三只股票的期望收益，并计算股票Y的Alpha值。以下是计算过程和结果：

### CAPM公式：
\[ \text{期望收益} = r_f + \beta \times (r_m - r_f) \]
其中：
- \( r_f \) = 无风险利率 = 2.3%
- \( r_m \) = 市场期望收益 = 9.4%
- \( \beta \) = 股票的Beta值

### 计算期望收益：
1. 股票X（β = 0.62）：
   \[ \text{er}_x = 2.3\% + 0.62 \times (9.4\% - 2.3\%) \]
   \[ \text{er}_x = 2.3\% + 0.62 \times 7.1\% \]
   \[ \text{er}_x = 2.3\% + 4.402\% = 6.702\% \]

2. 股票Y（β = 1.18）：
   \[ \text{er}_y = 2.3\% + 1.18 \times (9.4\% - 2.3\%) \]
   \[ \text{er}_y = 2.3\% + 1.18 \times 7.1\% \]
   \[ \text{er}_y = 2.3\% + 8.378\% = 10.678\% \]

3. 股票Z（β = 1.51）：
   \[ \text{er}_z = 2.3\% + 1.51 \times (9.4\% - 2.3\%) \]
   \[ \text{er}_z = 2.3\% + 1.51 \times 7.1\% \]
   \[ \text{er}_z = 2.3\% + 10.721\% = 13.021\% \]

### 计算股票Y的Alpha：
Alpha是实际收益与CAPM期望收益的差值：
\[ \text{Alpha}_y = \text{实际收益} - \text{er}_y \]
\[ \text{Alpha}_y = 13.1\% - 10.678\% = 2.422\% \]

### 输出结果：
```python
result = {
    'er_x': 6.702,
    'er_y': 10.678,
    'er_z': 13.021,
    'alpha_y': 2.422
}
```
