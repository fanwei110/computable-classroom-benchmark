```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from pathlib import Path

# 设置中文字体以避免显示问题
plt.rcParams['font.sans-serif'] = ['SimHei']
plt.rcParams['axes.unicode_minus'] = False

# 1. 读取数据并构造日损益
def calculate_var():
    # 读取CSV文件
    data_path = Path('data/market_snapshot_v1.csv')
    df = pd.read_csv(data_path)

    # 提取fund列的日收益率
    daily_returns = df['fund'].dropna().values

    # 计算1,000,000元头寸的日损益（人民币）
    position = 1_000_000
    daily_pnl = position * daily_returns

    # 2. 计算95%历史VaR（人民币）
    confidence_level = 0.95
    var_95 = np.percentile(daily_pnl, 100 * (1 - confidence_level))

    # 3. 绘制直方图并标注VaR线
    plt.figure(figsize=(10, 6))
    plt.hist(daily_pnl, bins=50, alpha=0.75, color='skyblue', edgecolor='black')

    # 添加VaR线
    plt.axvline(var_95, color='red', linestyle='--', linewidth=2)
    plt.text(var_95 * 1.05, plt.ylim()[1] * 0.9,
             f'95% VaR: ¥{abs(var_95):,.2f}',
             color='red', fontsize=12, ha='left')

    # 图形设置
    plt.title('1,000,000元头寸的日损益分布', fontsize=14)
    plt.xlabel('日损益（人民币）', fontsize=12)
    plt.ylabel('频数', fontsize=12)
    plt.grid(True, alpha=0.3)

    # 保存图形
    figure_path = Path('var_histogram.png')
    plt.savefig(figure_path, dpi=300, bbox_inches='tight')
    plt.close()

    # 4. 填充result字典
    result = {
        'hist_var_95_1d': round(abs(var_95), 2),
        'figure_path': str(figure_path.resolve())
    }

    return result

# 执行计算并输出结果
result = calculate_var()
print(result)
```

这个脚本完成了以下工作：

1. 读取CSV文件中的"fund"列日收益率数据
2. 计算1,000,000元头寸的日损益（人民币）
3. 使用历史模拟法计算95%置信水平下的1日VaR
4. 绘制日损益分布直方图，并用红色虚线标注VaR值
5. 将结果保存为字典，包含：
   - 'hist_var_95_1d': 95%置信水平下的1日历史VaR（人民币）
   - 'figure_path': 保存的图形文件路径

注意事项：
- 脚本假设CSV文件位于data/market_snapshot_v1.csv
- 使用了历史模拟法计算VaR，直接从经验分布中取分位数
- 图形保存为当前目录下的var_histogram.png
- 使用了中文字体以确保标签显示正常
- 结果中的VaR值为正数（绝对值），表示损失金额
