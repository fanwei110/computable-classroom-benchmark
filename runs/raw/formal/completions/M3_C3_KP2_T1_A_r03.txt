根据资本资产定价模型（CAPM），期望收益率的计算公式为：
$$E[R_i] = r_f + \beta_i \times (E[R_m] - r_f)$$
其中：
- 无风险利率 $r_f = 2.3\% = 0.023$
- 市场期望收益 $E[R_m] = 9.4\% = 0.094$
- 市场风险溢价 $E[R_m] - r_f = 0.094 - 0.023 = 0.071$

**1. 计算三只股票的期望收益：**
- 股票 X：$E[R_X] = 0.023 + 0.62 \times 0.071 = 0.023 + 0.04402 = 0.06702$
- 股票 Y：$E[R_Y] = 0.023 + 1.18 \times 0.071 = 0.023 + 0.08378 = 0.10678$
- 股票 Z：$E[R_Z] = 0.023 + 1.51 \times 0.071 = 0.023 + 0.10721 = 0.13021$

**2. 计算股票 Y 的 Alpha：**
Alpha 为实际收益与期望收益之差：
- $\alpha_Y = 实际收益_Y - 期望收益_Y = 0.131 - 0.10678 = 0.02422$
