根据资本资产定价模型（CAPM），预期收益率的计算公式为：
$$E(R_i) = r_f + \beta_i \times (r_m - r_f)$$

已知数据（转换为小数形式）：
- 无风险利率 $r_f = 0.023$
- 市场收益率 $r_m = 0.094$
- 市场风险溢价 $r_m - r_f = 0.094 - 0.023 = 0.071$
- $\beta_X = 0.62$, $\beta_Y = 1.18$, $\beta_Z = 1.51$
- 股票Y实际收益率 $R_Y = 0.131$

**1. 计算三只股票的预期收益率：**
- $er_x = 0.023 + 0.62 \times 0.071 = 0.023 + 0.04402 = 0.06702$
- $er_y = 0.023 + 1.18 \times 0.071 = 0.023 + 0.08378 = 0.10678$
- $er_z = 0.023 + 1.51 \times 0.071 = 0.023 + 0.10721 = 0.13021$

**2. 计算股票Y的Alpha：**
Alpha 为实际收益率与CAPM预期收益率之差：
- $alpha_y = 0.131 - 0.10678 = 0.02422$
