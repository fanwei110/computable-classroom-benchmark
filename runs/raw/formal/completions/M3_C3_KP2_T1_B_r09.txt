根据资本资产定价模型（CAPM），预期收益率的计算公式为：
$$E(r_i) = r_f + \beta_i \times (r_m - r_f)$$

Alpha 的计算公式为：
$$\alpha_y = r_{y, actual} - E(r_y)$$

已知数据：
- 无风险利率 $r_f = 2.3\% = 0.023$
- 市场收益率 $r_m = 9.4\% = 0.094$
- 市场风险溢价 $r_m - r_f = 0.094 - 0.023 = 0.071$
- $\beta_x = 0.62$, $\beta_y = 1.18$, $\beta_z = 1.51$
- $Y$ 的实际收益率 $r_{y, actual} = 13.1\% = 0.131$

**计算过程：**
1. **$E(r_x)$**: $0.023 + 0.62 \times 0.071 = 0.023 + 0.04402 = 0.06702$
2. **$E(r_y)$**: $0.023 + 1.18 \times 0.071 = 0.023 + 0.08378 = 0.10678$
3. **$E(r_z)$**: $0.023 + 1.51 \times 0.071 = 0.023 + 0.10721 = 0.13021$
4. **$\alpha_y$**: $0.131 - 0.10678 = 0.02422$

按照输出契约，将结果存入字典（所有收益率用小数表示）：

result = {
