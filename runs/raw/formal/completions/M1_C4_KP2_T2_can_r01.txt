以下是自包含的 Python 脚本，满足所有要求：

```python
import numpy as np
import matplotlib.pyplot as plt
import os

# 参数设定
risk_free_rate = 0.023  # 无风险利率 2.3%
market_return = 0.094   # 市场期望收益 9.4%

# 计算SML斜率
sml_slope = market_return - risk_free_rate

# 计算beta=1.27处的期望收益
beta_127 = 1.27
er_at_beta_127 = risk_free_rate + beta_127 * sml_slope

# 生成SML数据
betas = np.linspace(0, 2, 100)
expected_returns = risk_free_rate + betas * sml_slope

# 股票数据
stocks = {
    'X': {'beta': 0.62, 'return': 0.081},
    'Y': {'beta': 1.18, 'return': 0.131},
    'Z': {'beta': 1.51, 'return': 0.099}
}

# 创建图形
plt.figure(figsize=(10, 6))
plt.plot(betas, expected_returns, label='Security Market Line', color='blue')

# 绘制股票点
for name, data in stocks.items():
    plt.scatter(data['beta'], data['return'], label=f'Stock {name}')
    plt.annotate(name,
                 (data['beta'], data['return']),
                 textcoords="offset points",
                 xytext=(10,5),
                 ha='center')

# 添加图形元素
plt.title('Security Market Line (SML) with Stocks')
plt.xlabel('Beta')
plt.ylabel('Expected Return')
plt.legend()
plt.grid(True)

# 保存图形
figure_path = 'sml_plot.png'
plt.savefig(figure_path)
plt.close()

# 准备结果字典
result = {
    'sml_slope': sml_slope,
    'er_at_beta_127': er_at_beta_127,
    'figure_path': os.path.abspath(figure_path)
}

# 输出结果（供课堂展示）
print(result)
```

这个脚本将：
1. 绘制beta从0到2的证券市场线(SML)
2. 将三只股票X、Y、Z作为带标注的点绘制在图上
3. 使用参数化的无风险利率和市场收益率
4. 计算并报告SML的斜率和beta=1.27处的期望收益
5. 将图形保存为'sml_plot.png'文件，并将绝对路径存入result字典

输出的result字典包含：
- 'sml_slope': SML的斜率
- 'er_at_beta_127': beta=1.27处的期望收益
- 'figure_path': 保存的图形文件路径

所有数值均使用小数表示，符合课程约定。
