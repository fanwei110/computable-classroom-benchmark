```python
# 给定参数（小数表示）
Rf = 0.023      # 无风险利率
Rm = 0.094      # 市场期望收益
beta_x = 0.62
beta_y = 1.18
beta_z = 1.51
actual_return_y = 0.131  # Y实际年收益

# 市场风险溢价
market_premium = Rm - Rf  # 0.071

# CAPM期望收益
er_x = Rf + beta_x * market_premium
er_y = Rf + beta_y * market_premium
er_z = Rf + beta_z * market_premium

# Y的Alpha
alpha_y = actual_return_y - er_y

# 结果字典
result = {
    'er_x': er_x,
    'er_y': er_y,
    'er_z': er_z,
    'alpha_y': alpha_y
}

result
```

计算结果：
- `er_x` = 0.06702
- `er_y` = 0.10678
- `er_z` = 0.13021
- `alpha_y` = 0.02422
