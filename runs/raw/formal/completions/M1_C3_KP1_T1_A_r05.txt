要计算最小方差组合（MVP）的权重和组合的年化波动率，我们需要解一个优化问题。给定三只资产的波动率和相关系数，我们可以构建协方差矩阵，然后通过优化求解权重。

### 步骤：
1. **构建协方差矩阵**：
   - 方差 = 波动率²
   - 协方差 = 相关系数 × 波动率₁ × 波动率₂

2. **优化问题**：
   - 最小化组合方差：\( w^T \Sigma w \)
   - 约束条件：\( \sum w_i = 1 \)（资金全部投出去）
   - 允许卖空，即权重可以为负。

3. **求解权重**：
   - 这是一个二次规划问题，可以通过拉格朗日乘数法求解。最小方差组合的权重公式为：
     \[
     w = \frac{\Sigma^{-1} \mathbf{1}}{\mathbf{1}^T \Sigma^{-1} \mathbf{1}}
     \]
     其中，\( \Sigma \) 是协方差矩阵，\( \mathbf{1} \) 是全1向量。

4. **计算组合波动率**：
   - 组合方差 = \( w^T \Sigma w \)
   - 组合波动率 = \( \sqrt{w^T \Sigma w} \)

```python
import numpy as np
from scipy.optimize import minimize

# 输入数据
vols = np.array([0.187, 0.243, 0.312])
corr = np.array([
    [1.0, 0.21, -0.13],
    [0.21, 1.0, 0.37],
    [-0.13, 0.37, 1.0]
])

# 协方差矩阵
cov = corr * np.outer(vols, vols)

# 优化目标：最小化组合方差
def portfolio_variance(w, cov):
    return w.T @ cov @ w

# 约束：权重之和为1
constraints = ({'type': 'eq', 'fun': lambda w: np.sum(w) - 1})
bounds = [(-1, 1) for _ in range(3)]  # 允许卖空

# 初始猜测
w0 = np.array([1/3, 1/3, 1/3])

# 优化
result_opt = minimize(portfolio_variance, w0, args=(cov,), bounds=bounds, constraints=constraints)
mvp_weights = result_opt.x
mvp_vol = np.sqrt(result_opt.fun)

# 输出
result = {
    'mvp_weights': mvp_weights.tolist(),
    'mvp_vol_annual': mvp_vol
}
print(result)
```
