根据题目要求，我们使用资本资产定价模型（CAPM）计算XYZ三只股票的预期收益率（ER），并计算股票Y的Alpha值。

CAPM公式为：
\[ \text{ER}_i = r_f + \beta_i \times (\text{ER}_m - r_f) \]

其中：
- \( r_f = 2.3\% \) （无风险收益率）
- \( \text{ER}_m = 9.4\% \) （市场预期收益率）
- \( \beta \) 分别为：
  - X: 0.62
  - Y: 1.18
  - Z: 1.51

### 计算步骤：
1. 计算市场风险溢价：
   \[ \text{ER}_m - r_f = 9.4\% - 2.3\% = 7.1\% \]

2. 计算各股票的预期收益率：
   - X:
     \[ \text{ER}_x = 2.3\% + 0.62 \times 7.1\% = 2.3\% + 4.402\% = 6.702\% \]
   - Y:
     \[ \text{ER}_y = 2.3\% + 1.18 \times 7.1\% = 2.3\% + 8.378\% = 10.678\% \]
   - Z:
     \[ \text{ER}_z = 2.3\% + 1.51 \times 7.1\% = 2.3\% + 10.721\% = 13.021\% \]

3. 计算股票Y的Alpha：
   Alpha是实际收益率与CAPM预期收益率的差值：
   \[ \alpha_y = \text{实际收益率} - \text{ER}_y = 13.1\% - 10.678\% = 2.422\% \]

### 输出结果：

result = {

    'er_z': 0.13021,
    'alpha_y': 0.02422
}
