根据资本资产定价模型（CAPM），期望收益的计算公式为：
$$E[R_i] = R_f + \beta_i \times (E[R_m] - R_f)$$
其中，无风险利率 $R_f = 0.023$，市场期望收益 $E[R_m] = 0.094$。
市场风险溢价为：$E[R_m] - R_f = 0.094 - 0.023 = 0.071$

1. **计算三只股票的期望收益**：
- $er\_x = 0.023 + 0.62 \times 0.071 = 0.023 + 0.04402 = 0.06702$
- $er\_y = 0.023 + 1.18 \times 0.071 = 0.023 + 0.08378 = 0.10678$
- $er\_z = 0.023 + 1.51 \times 0.071 = 0.023 + 0.10721 = 0.13021$

2. **计算股票Y的Alpha**：
Alpha为实际收益与CAPM期望收益之差：
- $alpha\_y = 实际收益 - er\_y = 0.131 - 0.10678 = 0.02422$

按照输出契约，将结果存入字典 `result`：

```python
result = {
    'er_x': 0.06702,
    'er_y': 0.10678,
    'er_z': 0.13021,
    'alpha_y': 0.02422
}
```
