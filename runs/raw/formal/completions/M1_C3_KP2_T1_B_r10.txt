根据题目要求，我们使用资本资产定价模型（CAPM）计算XYZ三只股票的预期收益率（ER），并计算股票Y的Alpha值。

CAPM公式为：
\[ \text{ER}_i = r_f + \beta_i \times (\text{ER}_m - r_f) \]

其中：
- \( r_f = 2.3\% \)（无风险收益率）
- \( \text{ER}_m = 9.4\% \)（市场预期收益率）
- 三只股票的Beta值分别为：0.62（X）、1.18（Y）、1.51（Z）

### 计算预期收益率：
1. 股票X的预期收益率：
\[ \text{ER}_x = 0.023 + 0.62 \times (0.094 - 0.023) = 0.023 + 0.62 \times 0.071 = 0.023 + 0.04402 = 0.06702 \approx 6.70\% \]

2. 股票Y的预期收益率：
\[ \text{ER}_y = 0.023 + 1.18 \times (0.094 - 0.023) = 0.023 + 1.18 \times 0.071 = 0.023 + 0.08378 = 0.10678 \approx 10.68\% \]

3. 股票Z的预期收益率：
\[ \text{ER}_z = 0.023 + 1.51 \times (0.094 - 0.023) = 0.023 + 1.51 \times 0.071 = 0.023 + 0.10721 = 0.13021 \approx 13.02\% \]

### 计算股票Y的Alpha：
Alpha是实际收益率与CAPM预期收益率的差值：
\[ \text{Alpha}_y = \text{实际收益率} - \text{ER}_y = 0.131 - 0.10678 = 0.02422 \approx 2.42\% \]

result = {
