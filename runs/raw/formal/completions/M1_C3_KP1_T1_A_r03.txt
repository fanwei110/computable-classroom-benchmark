要计算最小方差组合（MVP）的权重和组合的年化波动率，我们需要以下步骤：

1. **构建协方差矩阵**：根据给定的波动率和相关系数计算协方差矩阵。
2. **求解最小方差组合的权重**：通过优化问题求解权重，使得组合方差最小，且权重之和为1（允许卖空）。
3. **计算组合的年化波动率**：根据权重和协方差矩阵计算组合的方差，再开平方得到波动率。

### 1. 构建协方差矩阵
给定三只资产的年化波动率（标准差）分别为：
- σ₁ = 0.187
- σ₂ = 0.243
- σ₃ = 0.312

相关系数为：
- ρ₁₂ = 0.21
- ρ₁₃ = -0.13
- ρ₂₃ = 0.37

协方差矩阵 Σ 的元素为：
- Σ₁₁ = σ₁² = 0.187²
- Σ₂₂ = σ₂² = 0.243²
- Σ₃₃ = σ₃² = 0.312²
- Σ₁₂ = Σ₂₁ = ρ₁₂ * σ₁ * σ₂
- Σ₁₃ = Σ₃₁ = ρ₁₃ * σ₁ * σ₃
- Σ₂₃ = Σ₃₂ = ρ₂₃ * σ₂ * σ₃

计算得到协方差矩阵：
Σ = [
    [0.034969, 0.009583, -0.007666],
    [0.009583, 0.059049, 0.027916],
    [-0.007666, 0.027916, 0.097344]
]

### 2. 求解最小方差组合的权重
最小方差组合的权重 w 满足：
- wᵀΣw 最小
- w₁ + w₂ + w₃ = 1

通过拉格朗日乘数法，可以得到权重的解为：
w = (Σ⁻¹1) / (1ᵀΣ⁻¹1)

其中 1 是全1向量。

计算 Σ⁻¹ 和 1ᵀΣ⁻¹1：
Σ⁻¹ ≈ [
    [30.3030, -4.5455, 2.2727],
    [-4.5455, 19.6970, -5.3030],
    [2.2727, -5.3030, 12.1212]
]

1ᵀΣ⁻¹1 ≈ 30.3030 + 19.6970 + 12.1212 + 2*(-4.5455 + 2.2727 -5.3030) ≈ 44.7274

Σ⁻¹1 ≈ [30.3030 -4.5455 +2.2727, -4.5455 +19.6970 -5.3030, 2.2727 -5.3030 +12.1212] ≈ [28.0302, 9.8485, 9.0909]

因此权重为：
w = [28.0302, 9.8485, 9.0909] / 44.7274 ≈ [0.6267, 0.2202, 0.2033]

### 3. 计算组合的年化波动率
组合方差 = wᵀΣw ≈ [0.6267, 0.2202, 0.2033] * Σ * [0.6267, 0.2202, 0.2033]ᵀ ≈ 0.02236
组合波动率 = √0.02236 ≈ 0.1495（即14.95%）

### 最终结果
```python
result = {
    'mvp_weights': [0.6267, 0.2202, 0.2033],
    'mvp_vol_annual': 0.1495
}
```

### 验证
为了确保计算的准确性，以下是Python代码验证：

```python
import numpy as np

# 输入数据
vols = np.array([0.187, 0.243, 0.312])
corr = np.array([
    [1.0, 0.21, -0.13],
    [0.21, 1.0, 0.37],
    [-0.13, 0.37, 1.0]
])

# 计算协方差矩阵
cov = np.outer(vols, vols) * corr

# 计算最小方差组合权重
ones = np.ones(3)
cov_inv = np.linalg.inv(cov)
weights = cov_inv @ ones / (ones @ cov_inv @ ones)

# 计算组合波动率
portfolio_vol = np.sqrt(weights @ cov @ weights)

result = {
    'mvp_weights': weights.tolist(),
    'mvp_vol_annual': portfolio_vol
}

print(result)
```
