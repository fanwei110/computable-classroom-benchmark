根据资本资产定价模型（CAPM），我们可以计算每只股票的预期收益（Expected Return, ER），然后根据Y股票的实际收益计算其Alpha值。

CAPM公式为：
\[ ER = r_f + \beta \times (r_m - r_f) \]

其中：
- \( r_f \) = 无风险收益率 = 2.3%
- \( r_m \) = 市场收益率 = 9.4%
- \( \beta \) = 股票的Beta值

计算步骤如下：

1. 计算XYZ三只股票的预期收益（ER）：
   - 股票X（β=0.62）：
     \[ ER_X = 2.3\% + 0.62 \times (9.4\% - 2.3\%) \]
   - 股票Y（β=1.18）：
     \[ ER_Y = 2.3\% + 1.18 \times (9.4\% - 2.3\%) \]
   - 股票Z（β=1.51）：
     \[ ER_Z = 2.3\% + 1.51 \times (9.4\% - 2.3\%) \]

2. 计算Y股票的Alpha（α）：
   \[ \alpha_Y = 实际收益 - ER_Y \]
   实际收益 = 13.1%

计算结果如下：

```python
result = {
    'er_x': 2.3 + 0.62 * (9.4 - 2.3),
    'er_y': 2.3 + 1.18 * (9.4 - 2.3),
    'er_z': 2.3 + 1.51 * (9.4 - 2.3),
    'alpha_y': 13.1 - (2.3 + 1.18 * (9.4 - 2.3))
}

result
```
