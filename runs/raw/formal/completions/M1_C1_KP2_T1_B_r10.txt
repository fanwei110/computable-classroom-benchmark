根据资本资产定价模型（CAPM），我们可以计算每只股票的预期收益（Expected Return, ER），然后根据Y股票的实际收益计算其Alpha值。

CAPM公式为：
\[ ER = r_f + \beta \times (r_m - r_f) \]

其中：
- \( r_f \) = 无风险收益率 = 2.3%
- \( r_m \) = 市场收益率 = 9.4%
- \( \beta \) = 股票的Beta值

计算步骤如下：

1. 计算XYZ三只股票的预期收益（ER）：
   - 股票X（β=0.62）：
     \[ ER_X = 2.3\% + 0.62 \times (9.4\% - 2.3\%) \]
   - 股票Y（β=1.18）：
     \[ ER_Y = 2.3\% + 1.18 \times (9.4\% - 2.3\%) \]
   - 股票Z（β=1.51）：
     \[ ER_Z = 2.3\% + 1.51 \times (9.4\% - 2.3\%) \]

2. 计算Y股票的Alpha（实际收益与预期收益的差异）：
   \[ \alpha_Y = 实际收益_Y - ER_Y \]

具体计算结果如下：

```python
# 计算预期收益
rf = 0.023
rm = 0.094
beta_x = 0.62
beta_y = 1.18
beta_z = 1.51

er_x = rf + beta_x * (rm - rf)
er_y = rf + beta_y * (rm - rf)
er_z = rf + beta_z * (rm - rf)

# 计算Y的Alpha
actual_return_y = 0.131
alpha_y = actual_return_y - er_y

# 存入result字典
result = {
    'er_x': er_x,
    'er_y': er_y,
    'er_z': er_z,
    'alpha_y': alpha_y
}

result
```

输出的 `result` 字典为：
```python
{
    'er_x': 0.06674,
    'er_y': 0.10786,
    'er_z': 0.13041,
    'alpha_y': 0.02314
}
```

即：
- `er_x` ≈ 6.67%
- `er_y` ≈ 10.79%
- `er_z` ≈ 13.04%
- `alpha_y` ≈ 2.31%
