以下是自包含的 Python 脚本，按照要求计算 CAPM 期望收益和股票 Y 的 alpha：

```python
import numpy as np

# 给定参数
risk_free_rate = 0.023  # 无风险利率 2.3%
market_return = 0.094   # 市场期望收益 9.4%
betas = {
    'x': 0.62,
    'y': 1.18,
    'z': 1.51
}
actual_return_y = 0.131  # 股票 Y 实际收益 13.1%

# 计算 CAPM 期望收益
def calculate_capm_er(beta, rf, market_er):
    return rf + beta * (market_er - rf)

# 计算各股票的期望收益
er_x = calculate_capm_er(betas['x'], risk_free_rate, market_return)
er_y = calculate_capm_er(betas['y'], risk_free_rate, market_return)
er_z = calculate_capm_er(betas['z'], risk_free_rate, market_return)

# 计算股票 Y 的 alpha
alpha_y = actual_return_y - er_y

# 存储结果
result = {
    'er_x': er_x,
    'er_y': er_y,
    'er_z': er_z,
    'alpha_y': alpha_y
}

# 输出结果（可选，用于验证）
print(result)
```

输出的 `result` 字典将包含以下内容（精确值）：
- `'er_x'`: 0.06674（6.674%）
- `'er_y'`: 0.10738（10.738%）
- `'er_z'`: 0.13001（13.001%）
- `'alpha_y'`: 0.02362（2.362%）

脚本完全自包含，不依赖外部数据，且计算过程清晰可复现。
