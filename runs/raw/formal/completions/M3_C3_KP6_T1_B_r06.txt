### 一、 年化夏普比率
题目中提到“fund列日收益”，但**并未提供具体的日收益数据序列**。没有日收益数据，我们无法计算日收益率的标准差（波动率），因此无法得出具体的夏普比率数值。
根据您的计算约定，如果您有日收益数据（假设为 `fund_daily_returns`），计算代码与逻辑如下：
1. 年化无风险利率 $r_f = 2.1\% = 0.021$，转为日度复利：$r_{f,d} = (1 + 0.021)^{1/252} - 1$
2. 计算日超额收益：$excess = fund\_daily\_returns - r_{f,d}$
3. 按样本标准差（ddof=1）计算日波动率，并年化：$\sigma_{ann} = std(excess, ddof=1) \times \sqrt{252}$
4. 年化夏普比率：$Sharpe = \frac{mean(excess) \times 252}{\sigma_{ann}} = \frac{mean(excess)}{std(excess, ddof=1)} \times \sqrt{252}$

### 二、 Brinson归因分析
根据提供的数据，我们可以完整拆解配置效应、选择效应和交互效应。
已知信息（转为小数）：
- 组合权重 $w_p$ = [0.45, 0.35, 0.20]
- 组合收益 $r_p$ = [0.083, 0.021, -0.014]
- 基准权重 $w_b$ = [0.40, 0.40, 0.20]
- 基准收益 $r_b$ = [0.067, 0.034, -0.009]

**1. 配置效应：**
$$E_{alloc} = \sum (w_p - w_b) \times r_b$$
- 行业1：$(0.45 - 0.40) \times 0.067 = 0.00335$
- 行业2：$(0.35 - 0.40) \times 0.034 = -0.00170$
- 行业3：$(0.20 - 0.20) \times (-0.009) = 0$
- **合计：0.00335 - 0.00170 = 0.00165**

**2. 选择效应：**
$$E_{select} = \sum w_b \times (r_p - r_b)$$
- 行业1：$0.40 \times (0.083 - 0.067) = 0.00640$
- 行业2：$0.40 \times (0.021 - 0.034) = -0.00520$
- 行业3：$0.20 \times (-0.014 - (-0.009)) = -0.00100$
- **合计：0.00640 - 0.00520 - 0.00100 = 0.00020**

**3. 交互效应：**
$$E_{inter} = \sum (w_p - w_b) \times (r_p - r_b)$$
- 行业1：$(0.45 - 0.40) \times (0.083 - 0.067) = 0.00080$
- 行业2：$(0.35 - 0.40) \times (0.021 - 0.034) = 0.00065$
- 行业3：$(0.20 - 0.20) \times (-0.014 - (-0.009)) = 0$
- **合计：0.00080 + 0.00065 = 0.00145**
