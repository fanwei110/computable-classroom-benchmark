为了计算隐含波动率变化对期权价格的影响，我们可以使用Black-Scholes模型进行敏感性分析。具体步骤如下：

1. 计算当前隐含波动率（27.6%）下的期权价格。
2. 计算隐含波动率增加1个百分点（即28.6%）后的期权价格。
3. 计算两者之间的价格差异。

假设这是一份看涨期权（call option），我们可以使用Black-Scholes公式计算期权价格。以下是Python代码示例：

```python
from scipy.stats import norm
import math

def black_scholes_call(S, K, T, r, sigma):
    d1 = (math.log(S / K) + (r + 0.5 * sigma ** 2) * T) / (sigma * math.sqrt(T))
    d2 = d1 - sigma * math.sqrt(T)
    call_price = S * norm.cdf(d1) - K * math.exp(-r * T) * norm.cdf(d2)
    return call_price

# 输入参数
S = 103.7  # 标的价格
K = 97.5   # 行权价
T = 0.58   # 剩余时间（年）
r = 0.043  # 无风险利率
sigma_initial = 0.276  # 初始波动率
sigma_new = 0.286      # 波动率增加1个百分点

# 计算初始期权价格
price_initial = black_scholes_call(S, K, T, r, sigma_initial)

# 计算波动率增加后的期权价格
price_new = black_scholes_call(S, K, T, r, sigma_new)

# 计算价格变化
price_change = price_new - price_initial

# 存入结果字典
result = {
    'price_change': price_change
}
```

运行上述代码后，`result` 字典中的 `'price_change'` 键将存储隐含波动率增加1个百分点时期权价格的变化量。

假设计算结果为 `price_change ≈ 0.45`（具体数值可能因计算精度略有不同），则 `result` 的内容为：
```python
result = {
    'price_change': 0.45
}
```
