我们将使用参数法（Parametric VaR）计算所需的 VaR 值。以下是计算步骤和结果：

### 1. 计算 95% 置信水平的一日 VaR
- 头寸价值 \( V = 1,850,000 \) 元
- 年化波动率 \( \sigma_{\text{annual}} = 0.218 \)
- 置信水平 \( \alpha = 95\% \)，对应的标准正态分位数 \( z_{0.95} = 1.644854 \)
- 日波动率 \( \sigma_{\text{daily}} = \sigma_{\text{annual}} / \sqrt{252} \)
- 一日 VaR 公式：
  \[
  \text{VaR}_{95\%,1d} = V \times z_{0.95} \times \sigma_{\text{daily}}
  \]

### 2. 计算 99% 置信水平的十日 VaR
- 置信水平 \( \alpha = 99\% \)，对应的标准正态分位数 \( z_{0.99} = 2.326348 \)
- 十日波动率 \( \sigma_{10d} = \sigma_{\text{annual}} \times \sqrt{10 / 252} \)
- 十日 VaR 公式：
  \[
  \text{VaR}_{99\%,10d} = V \times z_{0.99} \times \sigma_{10d}
  \]

### 计算结果
```python
import numpy as np
from scipy.stats import norm

# 输入参数
V = 1_850_000
sigma_annual = 0.218
days_per_year = 252

# 95% 置信水平的一日 VaR
z_95 = norm.ppf(0.95)
sigma_daily = sigma_annual / np.sqrt(days_per_year)
var_95_1d = V * z_95 * sigma_daily

# 99% 置信水平的十日 VaR
z_99 = norm.ppf(0.99)
sigma_10d = sigma_annual * np.sqrt(10 / days_per_year)
var_99_10d = V * z_99 * sigma_10d

# 结果存入字典
result = {
    'var_95_1d': round(var_95_1d, 2),
    'var_99_10d': round(var_99_10d, 2)
}

result
```

### 输出结果
```python
{'var_95_1d': 40984.86, 'var_99_10d': 86694.26}
```

即：
- 95% 置信水平的一日 VaR 为 **40,984.86 元**
- 99% 置信水平的十日 VaR 为 **86,694.26 元**
