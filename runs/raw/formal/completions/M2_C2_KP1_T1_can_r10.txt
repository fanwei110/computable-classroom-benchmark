```python
import numpy as np

# 1. 给定参数
sigma = np.array([0.187, 0.243, 0.312])          # 年化波动率
corr = np.array([[ 1.00,  0.21, -0.13],
                 [ 0.21,  1.00,  0.37],
                 [-0.13,  0.37,  1.00]])         # 相关系数矩阵

# 2. 构造协方差矩阵
D = np.diag(sigma)
cov = D @ corr @ D                              # 等价于 np.outer(sigma, sigma) * corr

# 3. 全局最小方差组合（允许卖空，权重和为1）的闭式解
ones = np.ones(3)
inv_cov = np.linalg.inv(cov)
w_mvp = inv_cov @ ones / (ones @ inv_cov @ ones)  # 权重向量

# 4. 组合年化波动率
mvp_var = w_mvp @ cov @ w_mvp
mvp_vol = np.sqrt(mvp_var)

# 5. 结果存入字典
result = {
    'mvp_weights': w_mvp.tolist(),
    'mvp_vol_annual': float(mvp_vol)
}

# 课堂投屏展示用
print("全局最小方差组合 (MVP)")
print("权重:", result['mvp_weights'])
print(f"年化波动率: {result['mvp_vol_annual']:.4%}")
```
这段代码完整构造了协方差矩阵，用闭式解计算最小方差组合权重，并输出符合要求的字典。运行后可直接获得可复现的数值结果。
