针对您的两项计算需求，处理过程如下：

### 1. 年化夏普比率
计算年化夏普比率需要基金日收益序列的**均值**和**标准差**。由于您仅提供了无风险利率 $r_f = 2.1\%$，未提供具体的“fund列日收益”数据，因此无法得出具体数值。在结果中将以 `NaN` 占位。
*计算公式参考*：$Sharpe_{annual} = \frac{E[R_{daily}] - R_{f,daily}}{\sigma_{daily}} \times \sqrt{252}$，其中 $R_{f,daily} = 2.1\% / 252$。

### 2. Brinson归因分析
基于BHB模型，将超额收益拆解为配置效应、选择效应和交互效应：
*   **配置效应** = $\sum (组合权重 - 基准权重) \times 基准收益$
*   **选择效应** = $\sum 基准权重 \times (组合收益 - 基准收益)$
*   **交互效应** = $\sum (组合权重 - 基准权重) \times (组合收益 - 基准收益)$

**代入数据计算**：
*   **配置效应**：
    $(0.45 - 0.4) \times 6.7\% + (0.35 - 0.4) \times 3.4\% + (0.2 - 0.2) \times (-0.9\%)$
    $= 0.05 \times 0.067 - 0.05 \times 0.034 + 0 = 0.00335 - 0.0017 = 0.00165$ (即 0.165%)
*   **选择效应**：
    $0.4 \times (8.3\% - 6.7\%) + 0.4 \times (2.1\% - 3.4\%) + 0.2 \times (-1.4\% - (-0.9\%))$
    $= 0.4 \times 0.016 + 0.4 \times (-0.013) + 0.2 \times (-0.005) = 0.0064 - 0.0052 - 0.001 = 0.0002$ (即 0.02%)
*   **交互效应**：
    $(0.45 - 0.4) \times (8.3\% - 6.7\%) + (0.35 - 0.4) \times (2.1\% - 3.4\%) + (0.2 - 0.2) \times (-1.4\% - (-0.9\%))$
    $= 0.05 \times 0.016 + (-0.05) \times (-0.013) + 0 = 0.0008 + 0.00065 = 0.00145$ (即 0.145%)
