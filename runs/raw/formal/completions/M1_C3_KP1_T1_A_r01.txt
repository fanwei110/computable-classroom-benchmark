要计算最小方差组合（MVP）的权重和组合的年化波动率，我们需要以下步骤：

1. **构建协方差矩阵**：根据给定的波动率和相关系数，计算协方差矩阵。
2. **求解最小方差组合的权重**：在允许卖空且资金全部投出的约束下，最小化组合方差。
3. **计算组合的年化波动率**：根据权重和协方差矩阵计算组合的波动率。

### 1. 构建协方差矩阵
给定三只资产的年化波动率（标准差）分别为：
- σ₁ = 0.187
- σ₂ = 0.243
- σ₃ = 0.312

相关系数为：
- ρ₁₂ = 0.21
- ρ₁₃ = -0.13
- ρ₂₃ = 0.37

协方差矩阵 Σ 的元素为：
- Σ₁₁ = σ₁² = 0.187²
- Σ₂₂ = σ₂² = 0.243²
- Σ₃₃ = σ₃² = 0.312²
- Σ₁₂ = Σ₂₁ = ρ₁₂ * σ₁ * σ₂
- Σ₁₃ = Σ₃₁ = ρ₁₃ * σ₁ * σ₃
- Σ₂₃ = Σ₃₂ = ρ₂₃ * σ₂ * σ₃

计算得：
Σ = [
    [0.034969, 0.009583, -0.007646],
    [0.009583, 0.059049, 0.027916],
    [-0.007646, 0.027916, 0.097344]
]

### 2. 求解最小方差组合的权重
最小方差组合的权重 w 满足：
- wᵀ Σ w 最小
- w₁ + w₂ + w₃ = 1（资金全部投出）
- 允许卖空（无其他约束）

这是一个带约束的优化问题，可以通过拉格朗日乘数法求解。解为：
w = (Σ⁻¹ 1) / (1ᵀ Σ⁻¹ 1)
其中 1 是全1向量。

计算 Σ⁻¹：
Σ⁻¹ ≈ [
    [30.3030, -4.5455, 2.2727],
    [-4.5455, 19.6970, -5.3030],
    [2.2727, -5.3030, 12.1212]
]

计算 Σ⁻¹ 1：
Σ⁻¹ 1 ≈ [28.0302, 9.8485, 9.0909]

计算 1ᵀ Σ⁻¹ 1：
1ᵀ Σ⁻¹ 1 ≈ 46.9696

因此权重为：
w ≈ [28.0302, 9.8485, 9.0909] / 46.9696 ≈ [0.5968, 0.2097, 0.1935]

### 3. 计算组合的年化波动率
组合方差为 wᵀ Σ w ≈ 0.0266
组合标准差（年化波动率）为 √0.0266 ≈ 0.1631（16.31%）

### 最终结果
```python
result = {
    'mvp_weights': [0.5968, 0.2097, 0.1935],
    'mvp_vol_annual': 0.1631
}
```

### 验证
为了确保计算的准确性，可以使用数值优化库（如 `scipy.optimize`）进行验证。以下是验证代码：

```python
import numpy as np
from scipy.optimize import minimize

# 协方差矩阵
Sigma = np.array([
    [0.187**2, 0.21 * 0.187 * 0.243, -0.13 * 0.187 * 0.312],
    [0.21 * 0.187 * 0.243, 0.243**2, 0.37 * 0.243 * 0.312],
    [-0.13 * 0.187 * 0.312, 0.37 * 0.243 * 0.312, 0.312**2]
])

# 优化目标：最小化组合方差
def portfolio_variance(w, Sigma):
    return w.T @ Sigma @ w

# 约束：权重之和为1
constraints = ({'type': 'eq', 'fun': lambda w: np.sum(w) - 1})

# 初始猜测
w0 = np.array([1/3, 1/3, 1/3])

# 优化
result_opt = minimize(portfolio_variance, w0, args=(Sigma,), constraints=constraints)

# 输出结果
mvp_weights = result_opt.x
mvp_vol_annual = np.sqrt(portfolio_variance(mvp_weights, Sigma))

result = {
    'mvp_weights': mvp_weights.tolist(),
    'mvp_vol_annual': mvp_vol_annual
}

print(result)
```
