根据债券价格与收益率的关系，债券价格变动百分比约等于 -修正久期 × 收益率变动 + 0.5 × 凸度 × (收益率变动)²。

已知：面值100，票息4.6%，收益率5.3%，收益率上升80个基点（0.008）。

首先计算修正久期和凸度。对于7年期债券，每年付息一次：
- 票息C = 4.6
- 收益率y = 0.053
- 期数n = 7
- 面值F = 100

先计算普通久期D（年）：

计算各期现金流现值：
- 第1-6年：每年4.6
- 第7年：4.6 + 100 = 104.6

债券价格P：
P = 4.6/(1.053)^1 + 4.6/(1.053)^2 + 4.6/(1.053)^3 + 4.6/(1.053)^4 + 4.6/(1.053)^5 + 4.6/(1.053)^6 + 104.6/(1.053)^7

计算各因子：
(1.053)^1 = 1.053
(1.053)^2 = 1.108809
(1.053)^3 = 1.167575
(1.053)^4 = 1.229456
(1.053)^5 = 1.294617
(1.053)^6 = 1.363232
(1.053)^7 = 1.435483

各现金流现值：
PV1 = 4.6/1.053 = 4.3685
PV2 = 4.6/1.108809 = 4.1486
PV3 = 4.6/1.167575 = 3.9398
PV4 = 4.6/1.229456 = 3.7415
PV5 = 4.6/1.294617 = 3.5532
PV6 = 4.6/1.363232 = 3.3743
PV7 = 104.6/1.435483 = 72.8617

P = 4.3685 + 4.1486 + 3.9398 + 3.7415 + 3.5532 + 3.3743 + 72.8617 = 95.9876

加权时间计算：
1×4.3685 + 2×4.1486 + 3×3.9398 + 4×3.7415 + 5×3.5532 + 6×3.3743 + 7×72.8617
= 4.3685 + 8.2972 + 11.8194 + 14.9660 + 17.7660 + 20.2458 + 510.0319 = 587.4948

麦考利久期 = 587.4948/95.9876 = 6.1219年

修正久期 = 6.1219/(1+0.053) = 5.8139

计算凸度：
凸度近似 = Σ[t(t+1)CF_t/(1+y)^{t+2}] / P

各期凸度贡献：
t=1: 1×2×4.6/(1.053)^3 = 9.2/1.167575 = 7.8796
t=2: 2×3×4.6/(1.053)^4 = 27.6/1.229456 = 22.4498
t=3: 3×4×4.6/(1.053)^5 = 55.2/1.294617 = 42.6393
t=4: 4×5×4.6/(1.053)^6 = 92/1.363232 = 67.4864
t=5: 5×6×4.6/(1.053)^7 = 138/1.435483 = 96.1349
t=6: 6×7×4.6/(1.053)^8 = 193.2/1.511164 = 127.8612
t=7: 7×8×104.6/(1.053)^9 = 5857.6/1.590563 = 3682.6701

凸度总和 = 7.8796 + 22.4498 + 42.6393 + 67.4864 + 96.1349 + 127.8612 + 3682.6701 = 4047.1213

凸度 = 4047.1213/(95.9876 × 1.053²) = 4047.1213/(95.9876 × 1.108809) = 4047.1213/106.4357 = 38.0235

Δy = 0.008

价格变动百分比 = -5.8139 × 0.008 + 0.5 × 38.0235 × (0.008)²
= -0.04651 + 0.5 × 38.0235 × 0.000064
= -0.04651 + 0.0012167
= -0.04529

即价格下跌约4.53%。
