以下是一个自包含的 Python 脚本，满足所有要求。它计算欧式看涨期权的 delta，绘制三条波动率曲线，报告指定点的 delta，并将结果存入 `result` 字典。

```python
import numpy as np
from scipy.stats import norm
import matplotlib.pyplot as plt

# ============================
# 可调参数（方便教师现场修改）
# ============================
K = 97.5           # 行权价
r = 0.043          # 无风险利率（年化）
T = 0.58           # 剩余期限（年）
S_lower = 70.0     # 标的价格下界
S_upper = 140.0    # 标的价格上界
num_points = 500   # 网格点数

# 波动率列表（可调参数）
sigmas = [0.15, 0.276, 0.40]  # 15%, 27.6%, 40%

# 用于报告的特定点
S_specific = 110.0
sigma_specific = 0.276

# ============================
# 1. 生成标的价格网格，计算 delta
# ============================
S = np.linspace(S_lower, S_upper, num_points)

plt.figure(figsize=(10, 6))
for sigma in sigmas:
    # 计算 d1 和 delta（看涨期权 delta = N(d1)）
    d1 = (np.log(S / K) + (r + 0.5 * sigma**2) * T) / (sigma * np.sqrt(T))
    delta = norm.cdf(d1)
    plt.plot(S, delta, linewidth=2, label=f'σ = {sigma*100:.1f}%')

# ============================
# 2. 图表标注与保存
# ============================
plt.xlabel('Spot Price', fontsize=12)
plt.ylabel('Delta', fontsize=12)
plt.title('Black-Scholes Call Option Delta vs Spot Price', fontsize=14)
plt.legend(fontsize=11)
plt.grid(True, alpha=0.3)
plt.tight_layout()

figure_path = 'delta_curves.png'
plt.savefig(figure_path, dpi=150, bbox_inches='tight')
plt.close()  # 避免在部分环境下重复显示

# ============================
# 3. 报告特定点（S=110, σ=27.6%）的 delta
# ============================
d1_specific = (np.log(S_specific / K) + (r + 0.5 * sigma_specific**2) * T) / (sigma_specific * np.sqrt(T))
delta_specific = norm.cdf(d1_specific)

# ============================
# 4. 输出契约
# ============================
result = {
    'delta_at_s110': delta_specific,
    'figure_path': figure_path
}

# 课堂展示时可直接打印
print("=== 计算结果 ===")
print(f"标的 S = {S_specific}, 波动率 σ = {sigma_specific*100:.1f}% 时，Delta = {delta_specific:.6f}")
print(f"图形已保存至：{figure_path}")
print("result 字典：", result)
```

**代码说明**  
- 完全基于 Black-Scholes 闭式解，仅使用 `numpy`、`scipy.stats.norm` 和 `matplotlib`。  
- 波动率通过列表 `sigmas` 设定，教师可随时修改。  
- 图形保存为 `delta_curves.png`，包含三条清晰图例的曲线。  
- 最终输出字典 `result` 键名严格为 `'delta_at_s110'` 和 `'figure_path'`，可直接投屏展示。
