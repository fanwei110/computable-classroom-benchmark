### 计算过程解析

#### 一、 年化夏普比率
题目要求基于“fund列日收益”计算年化夏普比率，但**题干中并未提供具体的基金日收益序列数据**。因此，夏普比率无法得出具体数值，按照惯例以 `NaN` 填充。
如果补全了日收益数据，根据“计算约定”，其计算逻辑应为：
1. **日无风险利率**：债券收益率按年复利报价，则日化无风险利率 $r_{f,daily} = (1 + 0.021)^{1/252} - 1$
2. **日超额收益均值**：$\bar{R}_{daily} - r_{f,daily}$
3. **日收益样本标准差**：$\sigma_{daily}$ 采用 `ddof=1` 的样本估计量
4. **年化夏普比率**：$Sharpe_{annual} = \frac{\bar{R}_{daily} - r_{f,daily}}{\sigma_{daily}} \times \sqrt{252}$

#### 二、 归因分析（BHB模型）
要求拆出配置、选择、交互三个效应，这是经典的 Brinson-Hood-Beebower (BHB) 模型。
已知数据（转化为小数）：
*   组合权重 $w_p = [0.45, 0.35, 0.2]$，组合行业收益 $r_p = [0.083, 0.021, -0.014]$
*   基准权重 $w_b = [0.4, 0.4, 0.2]$，基准行业收益 $r_b = [0.067, 0.034, -0.009]$

1. **配置效应 (Allocation Effect)**：
   $$E_A = \sum (w_{p,i} - w_{b,i}) \times r_{b,i}$$
   $$= (0.45-0.4)\times0.067 + (0.35-0.4)\times0.034 + (0.2-0.2)\times(-0.009)$$
   $$= 0.05\times0.067 + (-0.05)\times0.034 + 0 = 0.00335 - 0.0017 = \mathbf{0.00165}$$

2. **选择效应 (Selection Effect)**：
   $$E_S = \sum w_{b,i} \times (r_{p,i} - r_{b,i})$$
   $$= 0.4\times(0.083-0.067) + 0.4\times(0.021-0.034) + 0.2\times(-0.014 - (-0.009))$$
   $$= 0.4\times0.016 + 0.4\times(-0.013) + 0.2\times(-0.005) = 0.0064 - 0.0052 - 0.0010 = \mathbf{0.0002}$$

3. **交互效应 (Interaction Effect)**：
   $$E_I = \sum (w_{p,i} - w_{b,i}) \times (r_{p,i} - r_{b,i})$$
   $$= (0.45-0.4)\times(0.083-0.067) + (0.35-0.4)\times(0.021-0.034) + (0.2-0.2)\times(-0.014+0.009)$$
   $$= 0.05\times0.016 + (-0.05)\times(-0.013) + 0 = 0.0008 + 0.00065 = \mathbf{0.00145}$$

*(验算：组合总收益 0.0419 - 基准总收益 0.0386 = 0.0033，三个效应之和 0.00165 + 0.0002 + 0.00145 = 0.0033，完全一致)*
