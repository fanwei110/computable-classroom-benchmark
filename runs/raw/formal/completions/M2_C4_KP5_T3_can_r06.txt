```python
import numpy as np
from scipy.stats import norm

# ---------- 给定参数 ----------
annual_vol = 0.24                # 年化波动率（小数）
position_value = 2_700_000.0     # 头寸价值（元）
confidence = 0.95                # 置信水平
trading_days = 252               # 年交易日数

# ---------- 计算 ----------
# 1. 去年化：将年化波动率缩放至日波动率
daily_vol = annual_vol / np.sqrt(trading_days)

# 2. 单尾 95% 正态分位数（均值取零）
z_score = norm.ppf(confidence)   # 约 1.64485

# 3. 一日 VaR（正的人民币损失金额）
var_95_1d = z_score * daily_vol * position_value

# ---------- 输出 ----------
result = {'var_95_1d': var_95_1d}
print(result)
```

运行后会输出类似 `{'var_95_1d': 67293.58}` 的结果（取决于浮点精度）。
