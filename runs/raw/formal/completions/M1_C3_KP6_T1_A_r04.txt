下面分别计算两个问题，并将结果存入 `result` 字典中。

---

### **第一问：年化夏普比率**
**步骤：**
1. 计算日收益率的均值（`mean_daily_return`）和标准差（`std_daily_return`，样本标准差，`ddof=1`）。
2. 年化收益率 = `mean_daily_return * 252`
3. 年化波动率 = `std_daily_return * sqrt(252)`
4. 年化夏普比率 = `(年化收益率 - 无风险利率) / 年化波动率`，其中无风险利率为 `2.1%`（即 `0.021`）。

假设 `fund` 列的日收益率数据已加载为 `daily_returns`（列表或 pandas Series），代码如下：
```python
import numpy as np

# 假设 daily_returns 是 fund 列的日收益率数据
mean_daily_return = np.mean(daily_returns)
std_daily_return = np.std(daily_returns, ddof=1)  # 样本标准差

annualized_return = mean_daily_return * 252
annualized_volatility = std_daily_return * np.sqrt(252)
sharpe_annual = (annualized_return - 0.021) / annualized_volatility
```

---

### **第二问：业绩归因（Brinson 模型）**
给定：
- 组合权重 `w_p = [0.45, 0.35, 0.20]`
- 组合收益 `r_p = [0.083, 0.021, -0.014]`
- 基准权重 `w_b = [0.40, 0.40, 0.20]`
- 基准收益 `r_b = [0.067, 0.034, -0.009]`

**步骤：**
1. **配置效应（Allocation Effect）**：
   \( \sum (w_{p,i} - w_{b,i}) \cdot r_{b,i} \)
2. **选择效应（Selection Effect）**：
   \( \sum w_{b,i} \cdot (r_{p,i} - r_{b,i}) \)
3. **交互效应（Interaction Effect）**：
   \( \sum (w_{p,i} - w_{b,i}) \cdot (r_{p,i} - r_{b,i}) \)

代码实现：
```python
w_p = np.array([0.45, 0.35, 0.20])
r_p = np.array([0.083, 0.021, -0.014])
w_b = np.array([0.40, 0.40, 0.20])
r_b = np.array([0.067, 0.034, -0.009])

allocation_effect = np.sum((w_p - w_b) * r_b)
selection_effect = np.sum(w_b * (r_p - r_b))
interaction_effect = np.sum((w_p - w_b) * (r_p - r_b))
```

---

### **最终结果**
将所有结果存入 `result` 字典：
```python
result = {
    'sharpe_annual': sharpe_annual,
    'allocation_effect': allocation_effect,
    'selection_effect': selection_effect,
    'interaction_effect': interaction_effect
}
```

#### **具体数值（示例）**
假设 `fund` 列的日收益率数据使得：
- `mean_daily_return = 0.0005`
- `std_daily_return = 0.01`

则：
- 年化收益率 = `0.0005 * 252 ≈ 0.126`（12.6%）
- 年化波动率 = `0.01 * sqrt(252) ≈ 0.1587`（15.87%）
- 夏普比率 = `(0.126 - 0.021) / 0.1587 ≈ 0.661`

业绩归因：
- 配置效应 = `(0.45-0.40)*0.067 + (0.35-0.40)*0.034 + (0.20-0.20)*(-0.009) = 0.00335 - 0.0017 + 0 = 0.00165`
- 选择效应 = `0.40*(0.083-0.067) + 0.40*(0.021-0.034) + 0.20*(-0.014+0.009) = 0.0064 - 0.0052 - 0.001 = 0.0002`
- 交互效应 = `(0.45-0.40)*(0.083-0.067) + (0.35-0.40)*(0.021-0.034) + (0.20-0.20)*(-0.014+0.009) = 0.0008 - 0.00065 + 0 = 0.00015`

因此，`result` 为：
```python
result = {
    'sharpe_annual': 0.661,  # 示例值，需根据实际数据计算
    'allocation_effect': 0.00165,
    'selection_effect': 0.0002,
    'interaction_effect': 0.00015
}
```
