由于第一问缺少计算年化夏普所需的基金日收益数据（如日收益率序列的均值与标准差），无法得出数值结果，归因部分可按 Brinson 模型拆解如下：

```python
# 计算基准总收益与组合总收益
w_p = [0.45, 0.35, 0.2]
R_p = [0.083, 0.021, -0.014]
w_b = [0.4, 0.4, 0.2]
R_b = [0.067, 0.034, -0.009]

R_b_total = sum(w * r for w, r in zip(w_b, R_b))  # 0.0386
R_p_total = sum(w * r for w, r in zip(w_p, R_p))  # 0.0419

# 配置效应 (Allocation Effect) = Σ (w_pi - w_bi) * (R_bi - R_b_total)
allocation = sum((wp - wb) * (rb - R_b_total) for wp, wb, rb in zip(w_p, w_b, R_b))
# selection效应 = Σ w_bi * (R_pi - R_bi)
selection = sum(wb * (rp - rb) for wb, rp, rb in zip(w_b, R_p, R_b))
# interaction效应 = Σ (w_pi - w_bi) * (R_pi - R_bi)
interaction = sum((wp - wb) * (rp - rb) for wp, wb, rp, rb in zip(w_p, w_b, R_p, R_b))
```

计算结果：
- allocation_effect: 0.00165 (0.165%)
- selection_effect: 0.0002 (0.02%)
- interaction_effect: 0.00145 (0.145%)
三效应之和 = 0.0033，等于组合超额收益 0.0419 - 0.0386 = 0.0033。
