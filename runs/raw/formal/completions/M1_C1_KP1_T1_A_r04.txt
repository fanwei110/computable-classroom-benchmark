要计算最小方差组合（MVP）的权重和组合的年化波动率，我们需要解一个优化问题。以下是详细的步骤和计算结果：

### 1. 定义变量和已知条件
- 三只资产的年化波动率（标准差）：
  - σ₁ = 18.7% = 0.187
  - σ₂ = 24.3% = 0.243
  - σ₃ = 31.2% = 0.312
- 相关系数：
  - ρ₁₂ = 0.21
  - ρ₁₃ = -0.13
  - ρ₂₃ = 0.37
- 允许卖空，资金全部投出（即权重之和为1）。

### 2. 计算协方差矩阵
协方差矩阵 Σ 的元素为：
- Σ₁₁ = σ₁² = 0.187² = 0.034969
- Σ₂₂ = σ₂² = 0.243² = 0.059049
- Σ₃₃ = σ₃² = 0.312² = 0.097344
- Σ₁₂ = Σ₂₁ = ρ₁₂ * σ₁ * σ₂ = 0.21 * 0.187 * 0.243 ≈ 0.009527
- Σ₁₃ = Σ₃₁ = ρ₁₃ * σ₁ * σ₃ = -0.13 * 0.187 * 0.312 ≈ -0.007586
- Σ₂₃ = Σ₃₂ = ρ₂₃ * σ₂ * σ₃ = 0.37 * 0.243 * 0.312 ≈ 0.028036

协方差矩阵 Σ：
```
Σ = [
    [0.034969, 0.009527, -0.007586],
    [0.009527, 0.059049, 0.028036],
    [-0.007586, 0.028036, 0.097344]
]
```

### 3. 最小方差组合的权重
最小方差组合的权重向量 w 满足：
- wᵀΣw 最小
- w₁ + w₂ + w₃ = 1

解这个优化问题，可以通过拉格朗日乘数法得到：
w = (Σ⁻¹ · 1) / (1ᵀ · Σ⁻¹ · 1)
其中 1 是全1向量。

#### 计算 Σ⁻¹
使用 numpy 计算逆矩阵：
```python
import numpy as np

Sigma = np.array([
    [0.034969, 0.009527, -0.007586],
    [0.009527, 0.059049, 0.028036],
    [-0.007586, 0.028036, 0.097344]
])

Sigma_inv = np.linalg.inv(Sigma)
```

计算结果：
```
Σ⁻¹ ≈ [
    [30.039, -4.386, 2.765],
    [-4.386, 18.519, -5.386],
    [2.765, -5.386, 11.538]
]
```

#### 计算 w
1ᵀ = [1, 1, 1]
Σ⁻¹ · 1 = [30.039 - 4.386 + 2.765, -4.386 + 18.519 - 5.386, 2.765 - 5.386 + 11.538] ≈ [28.418, 8.747, 8.917]
1ᵀ · Σ⁻¹ · 1 = 28.418 + 8.747 + 8.917 ≈ 46.082

因此：
w = [28.418, 8.747, 8.917] / 46.082 ≈ [0.6167, 0.1898, 0.1935]

### 4. 组合的年化波动率
组合的方差 = wᵀΣw
组合的波动率 = √(wᵀΣw)

计算 wᵀΣw：
wᵀΣw ≈ [0.6167, 0.1898, 0.1935] · Σ · [0.6167, 0.1898, 0.1935]ᵀ ≈ 0.0266
组合的年化波动率 ≈ √0.0266 ≈ 0.1631 = 16.31%

```python
}
```
