根据资本资产定价模型（CAPM），计算过程如下：

1. **计算市场风险溢价：**
   市场收益率 - 无风险利率 = 9.4% - 2.3% = 7.1%

2. **计算各股票预期收益率（$E(R) = r_f + \beta \times (r_m - r_f)$）：**
   * $er_x = 2.3\% + 0.62 \times 7.1\% = 2.3\% + 4.402\% = 6.702\%$
   * $er_y = 2.3\% + 1.18 \times 7.1\% = 2.3\% + 8.378\% = 10.678\%$
   * $er_z = 2.3\% + 1.51 \times 7.1\% = 2.3\% + 10.721\% = 13.021\%$

3. **计算股票Y的Alpha值（$\alpha = 实际收益率 - 预期收益率$）：**
   * $alpha_y = 13.1\% - 10.678\% = 2.422\%$
