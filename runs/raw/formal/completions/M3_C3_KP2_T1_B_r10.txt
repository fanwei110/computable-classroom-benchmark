根据资本资产定价模型（CAPM），预期收益率的计算公式为：
$$E(R_i) = R_f + \beta_i \times (R_m - R_f)$$

已知数据（转换为小数）：
- 无风险利率 $R_f = 0.023$
- 市场收益率 $R_m = 0.094$
- 市场风险溢价 $R_m - R_f = 0.094 - 0.023 = 0.071$

**1. 计算 X、Y、Z 的预期收益率：**
- $E(R_x) = 0.023 + 0.62 \times 0.071 = 0.023 + 0.04402 = 0.06702$
- $E(R_y) = 0.023 + 1.18 \times 0.071 = 0.023 + 0.08378 = 0.10678$
- $E(R_z) = 0.023 + 1.51 \times 0.071 = 0.023 + 0.10721 = 0.13021$

**2. 计算 Y 的 Alpha：**
Alpha 为实际收益率减去 CAPM 计算出的应有预期收益率：
- $\alpha_y = 实际收益率 - E(R_y) = 0.131 - 0.10678 = 0.02422$
