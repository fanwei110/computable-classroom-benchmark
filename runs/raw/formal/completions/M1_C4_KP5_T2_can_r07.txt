```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from scipy.stats import norm

# 1. 读取数据并构造日损益
def calculate_var():
    # 读取CSV文件
    df = pd.read_csv('data/market_snapshot_v1.csv')

    # 提取fund列的日收益率
    daily_returns = df['fund'].dropna().values

    # 计算1,000,000元头寸的日损益（单位：元）
    position = 1_000_000
    daily_pnl = position * daily_returns

    # 2. 计算95%历史VaR（线性插值经验分位数）
    confidence_level = 0.95
    var_quantile = np.percentile(daily_pnl, 100 * (1 - confidence_level), method='linear')
    historical_var_95_1d = abs(var_quantile)  # 转换为正的损失金额

    # 3. 绘制直方图并标注VaR线
    plt.figure(figsize=(10, 6))
    plt.hist(daily_pnl, bins=50, alpha=0.75, color='skyblue', edgecolor='black')

    # 添加VaR线
    plt.axvline(x=-historical_var_95_1d, color='red', linestyle='--', linewidth=2)
    plt.text(-historical_var_95_1d * 1.1, plt.ylim()[1] * 0.9,
             f'95% 1-day VaR: ¥{historical_var_95_1d:,.2f}',
             color='red', ha='right', va='top')

    plt.title('Daily P&L Distribution with 95% Historical VaR')
    plt.xlabel('Daily P&L (RMB)')
    plt.ylabel('Frequency')
    plt.grid(True, alpha=0.3)

    # 保存图形
    figure_path = 'var_plot.png'
    plt.savefig(figure_path)
    plt.close()

    # 4. 填充result字典
    result = {
        'hist_var_95_1d': historical_var_95_1d,
        'figure_path': figure_path
    }

    return result

# 执行计算并输出结果
result = calculate_var()
print(result)
```

这个脚本完成了以下工作：
1. 读取CSV文件中的fund列日收益率数据
2. 计算1,000,000元头寸的日损益序列
3. 使用numpy的线性插值经验分位数计算95%历史VaR
4. 绘制日损益分布直方图，并用红色虚线标注VaR值
5. 将结果保存到result字典中，包括VaR值和图形文件路径

注意事项：
- 脚本假设CSV文件位于data/market_snapshot_v1.csv路径
- 置信水平固定为95%，但可以通过修改confidence_level变量来调整
- VaR值报告为正的人民币金额
- 图形保存为var_plot.png文件
- 所有计算都是自包含的，不需要联网或外部依赖
