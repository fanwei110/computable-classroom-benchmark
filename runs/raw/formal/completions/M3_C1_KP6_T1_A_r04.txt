### 第一问：年化夏普比率
**计算逻辑**：
1. 将年化无风险利率2.1%转换为日无风险利率：$R_{f,daily} = 2.1\% / 252$ （或采用复利 $(1+2.1\%)^{1/252}-1$，通常按单利除以252即可）。
2. 计算日超额收益的均值与标准差：$\mu_d = mean(R_{daily} - R_{f,daily})$，$\sigma_d = std(R_{daily} - R_{f,daily})$。
3. 计算日夏普比率并年化：$Sharpe_{annual} = \frac{\mu_d}{\sigma_d} \times \sqrt{252}$。

### 第二问：业绩归因（BHB模型）
已知数据：
* 组合权重 $W_p = [0.45, 0.35, 0.20]$，组合收益 $R_p = [8.3\%, 2.1\%, -1.4\%]$
* 基准权重 $W_b = [0.40, 0.40, 0.20]$，基准收益 $R_b = [6.7\%, 3.4\%, -0.9\%]$

**步骤1：计算基准总收益**
$R_{b, total} = 0.40 \times 6.7\% + 0.40 \times 3.4\% + 0.20 \times (-0.9\%) = 2.68\% + 1.36\% - 0.18\% = 3.86\%$

**步骤2：计算配置效应**
$配置效应 = \sum (W_{p,i} - W_{b,i}) \times (R_{b,i} - R_{b,total})$
* 行业1: $(0.45 - 0.40) \times (6.7\% - 3.86\%) = 0.05 \times 2.84\% = 0.142\%$
* 行业2: $(0.35 - 0.40) \times (3.4\% - 3.86\%) = -0.05 \times (-0.46\%) = 0.023\%$
* 行业3: $(0.20 - 0.20) \times (-0.9\% - 3.86\%) = 0 \times (-4.76\%) = 0\%$
* **配置效应总计 = 0.165%**

**步骤3：计算选择效应**
$选择效应 = \sum W_{b,i} \times (R_{p,i} - R_{b,i})$
* 行业1: $0.40 \times (8.3\% - 6.7\%) = 0.40 \times 1.6\% = 0.64\%$
* 行业2: $0.40 \times (2.1\% - 3.4\%) = 0.40 \times (-1.3\%) = -0.52\%$
* 行业3: $0.20 \times (-1.4\% - (-0.9\%)) = 0.20 \times (-0.5\%) = -0.10\%$
* **选择效应总计 = 0.02%**

**步骤4：计算交互效应**
$交互效应 = \sum (W_{p,i} - W_{b,i}) \times (R_{p,i} - R_{b,i})$
* 行业1: $(0.45 - 0.40) \times (8.3\% - 6.7\%) = 0.05 \times 1.6\% = 0.08\%$
* 行业2: $(0.35 - 0.40) \times (2.1\% - 3.4\%) = -0.05 \times (-1.3\%) = 0.065\%$
* 行业3: $(0.20 - 0.20) \times (-1.4\% - (-0.9\%)) = 0 \times (-0.5\%) = 0\%$
* **交互效应总计 = 0.145%**

*(验证：组合总收益 $R_{p,total} = 4.19\%$，总超额收益 $4.19\% - 3.86\% = 0.33\%$，且 0.165% + 0.02% + 0.145% = 0.33%，计算闭环)*
