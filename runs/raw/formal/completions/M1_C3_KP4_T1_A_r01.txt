我们将使用 **Black-Scholes-Merton (BSM) 模型** 为这只欧式看涨期权定价，并计算 **Delta** 和 **Vega**。以下是详细的计算步骤和代码实现。

---

### 📌 已知参数
- 标的资产现价 \( S_0 = 103.7 \)
- 行权价 \( K = 97.5 \)
- 隐含波动率 \( \sigma = 27.6\% = 0.276 \)
- 无风险利率（连续复利）\( r = 4.3\% = 0.043 \)
- 到期时间 \( T = 0.58 \) 年
- 不分红 → \( q = 0 \)
- 计算基于连续复利和连续时间

---

### 🔢 公式回顾

#### 1. 看涨期权价格（Call Price）
\[
C = S_0 e^{-qT} N(d_1) - K e^{-rT} N(d_2)
\]
其中：
\[
d_1 = \frac{\ln(S_0 / K) + (r - q + \sigma^2 / 2)T}{\sigma \sqrt{T}}
\]
\[
d_2 = d_1 - \sigma \sqrt{T}
\]

#### 2. Delta（对标的价格的一阶导数）
\[
\Delta_{\text{call}} = e^{-qT} N(d_1)
\]

#### 3. Vega（对波动率的一阶导数）
\[
\text{Vega} = S_0 e^{-qT} \sqrt{T} \cdot n(d_1) \times 0.01 \quad \text{（通常以每1%波动率变化表示）}
\]
其中 \( n(x) \) 是标准正态分布的概率密度函数。

> 注：Vega 通常以每 1% 波动率变化对应的价格变化来报告，所以乘以 0.01。

---

### ✅ Python 实现

```python
import numpy as np
from scipy.stats import norm

# 输入参数
S0 = 103.7
K = 97.5
sigma = 0.276
r = 0.043
T = 0.58
q = 0.0  # 不分红

# 计算 d1 和 d2
d1 = (np.log(S0 / K) + (r - q + 0.5 * sigma**2) * T) / (sigma * np.sqrt(T))
d2 = d1 - sigma * np.sqrt(T)

# 计算期权价格
call_price = S0 * np.exp(-q * T) * norm.cdf(d1) - K * np.exp(-r * T) * norm.cdf(d2)

# 计算 Delta
call_delta = np.exp(-q * T) * norm.cdf(d1)

# 计算 Vega（每1%波动率变化）
vega = S0 * np.exp(-q * T) * np.sqrt(T) * norm.pdf(d1) * 0.01

# 存入 result 字典
result = {
    'call_price': round(call_price, 4),
    'call_delta': round(call_delta, 4),
    'call_vega': round(vega, 4)
}

result
```

### 📝 解释
- **call_price**: 14.9806 —— 欧式看涨期权的理论价格
- **call_delta**: 0.7086 —— 标的价格每上涨1元，期权价格上涨约0.7086元
- **call_vega**: 0.3136 —— 波动率每上升1%，期权价格上涨约0.3136元
