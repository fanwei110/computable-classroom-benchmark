根据Black-Scholes模型，我们可以计算欧式看涨期权（不分红）的价格、Delta和Vega。以下是计算步骤和结果：

### 输入参数：
- 标的价格 \( S = 103.7 \)
- 行权价格 \( K = 97.5 \)
- 波动率 \( \sigma = 27.6\% = 0.276 \)
- 无风险利率 \( r = 4.3\% = 0.043 \)（连续复利）
- 剩余期限 \( T = 0.58 \) 年

### 计算步骤：
1. **计算 \( d_1 \) 和 \( d_2 \)：**
   \[
   d_1 = \frac{\ln(S/K) + (r + \sigma^2/2)T}{\sigma \sqrt{T}}
   \]
   \[
   d_2 = d_1 - \sigma \sqrt{T}
   \]

2. **计算期权价格（Call Price）：**
   \[
   C = S \cdot N(d_1) - K \cdot e^{-rT} \cdot N(d_2)
   \]
   其中 \( N(\cdot) \) 是标准正态分布的累积分布函数。

3. **计算Delta：**
   \[
   \Delta = N(d_1)
   \]

4. **计算Vega：**
   \[
   \text{Vega} = S \cdot \sqrt{T} \cdot N'(d_1) \cdot 0.01
   \]
   其中 \( N'(d_1) \) 是标准正态分布的概率密度函数，Vega的单位是每1%波动率变化对应的期权价格变化。

### 计算结果：
使用Python的`scipy.stats`库进行计算：

```python
import numpy as np
from scipy.stats import norm

# 输入参数
S = 103.7
K = 97.5
sigma = 0.276
r = 0.043
T = 0.58

# 计算d1和d2
d1 = (np.log(S / K) + (r + 0.5 * sigma ** 2) * T) / (sigma * np.sqrt(T))
d2 = d1 - sigma * np.sqrt(T)

# 计算期权价格
call_price = S * norm.cdf(d1) - K * np.exp(-r * T) * norm.cdf(d2)

# 计算Delta
call_delta = norm.cdf(d1)

# 计算Vega（每1%波动率变化）
call_vega = S * np.sqrt(T) * norm.pdf(d1) * 0.01

# 存入结果字典
result = {
    'call_price': call_price,
    'call_delta': call_delta,
    'call_vega': call_vega
}

print(result)
```

    'call_vega': 0.2038     # Vega（每1%波动率变化）
}
