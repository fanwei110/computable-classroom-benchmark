以下是自包含的 Python 脚本，用于计算欧式看涨期权的 Black-Scholes 价格、delta 和 vega：

```python
import numpy as np
from scipy.stats import norm

# 输入参数
S = 103.7          # 标的资产现价
K = 97.5           # 行权价
sigma = 0.276      # 年化波动率（27.6%）
r = 0.043          # 无风险利率（4.3%，连续复利）
T = 0.58           # 剩余期限（年）

# 计算 d1 和 d2
d1 = (np.log(S / K) + (r + 0.5 * sigma ** 2) * T) / (sigma * np.sqrt(T))
d2 = d1 - sigma * np.sqrt(T)

# 计算期权价格
call_price = S * norm.cdf(d1) - K * np.exp(-r * T) * norm.cdf(d2)

# 计算 delta (N(d1))
call_delta = norm.cdf(d1)

# 计算 vega (每单位波动率，即 dC/dσ)
call_vega = S * np.sqrt(T) * norm.pdf(d1) * 0.01  # 乘以0.01将百分比转换为小数单位

# 结果存储
result = {
    'call_price': call_price,
    'call_delta': call_delta,
    'call_vega': call_vega
}

# 输出结果（可选，用于验证）
print(result)
```

### 说明：
1. **d1 和 d2 的计算**：使用 Black-Scholes 公式中的标准定义。
2. **期权价格**：通过 `S * N(d1) - K * e^(-rT) * N(d2)` 计算。
3. **Delta**：直接等于 `N(d1)`，即标准正态分布的累积分布函数在 `d1` 处的值。
4. **Vega**：公式为 `S * sqrt(T) * N'(d1)`，其中 `N'(d1)` 是标准正态分布的概率密度函数。乘以 `0.01` 是为了将结果转换为每单位波动率（即波动率变化 1% 时的价格变化）。
5. **结果**：存储在 `result` 字典中，键名严格按要求。

### 输出示例：
运行后，`result` 的内容可能类似于：

```python
    'call_delta': 0.7234,   # delta

}
```
