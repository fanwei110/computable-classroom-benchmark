以下是自包含的 Python 脚本，用于计算欧式看涨期权的 Black-Scholes 价格、delta 和 vega：

```python
import numpy as np
from scipy.stats import norm

# 输入参数
S = 103.7      # 标的资产现价
K = 97.5       # 行权价
sigma = 0.276  # 年化波动率（27.6%）
r = 0.043      # 无风险利率（4.3%，连续复利）
T = 0.58       # 剩余期限（年）

# 计算 d1 和 d2
d1 = (np.log(S / K) + (r + 0.5 * sigma ** 2) * T) / (sigma * np.sqrt(T))
d2 = d1 - sigma * np.sqrt(T)

# 计算期权价格
call_price = S * norm.cdf(d1) - K * np.exp(-r * T) * norm.cdf(d2)

# 计算 delta (N(d1))
call_delta = norm.cdf(d1)

# 计算 vega (每单位波动率，即 dC/dσ)
call_vega = S * np.sqrt(T) * norm.pdf(d1) * 0.01  # 乘以0.01将vega转换为每1%波动率变化的值

# 由于题目要求vega按每单位波动率报价（即dC/dσ，σ为小数形式），因此不需要乘以0.01
# 修正：vega = S * np.sqrt(T) * norm.pdf(d1)
call_vega = S * np.sqrt(T) * norm.pdf(d1)

# 存储结果
result = {
    'call_price': call_price,
    'call_delta': call_delta,
    'call_vega': call_vega
}

# 输出结果（可选，用于验证）
print(result)
```

### 说明：
1. **d1 和 d2 的计算**：根据 Black-Scholes 公式，d1 和 d2 是计算期权价格和希腊字母的关键中间变量。
2. **期权价格**：欧式看涨期权的价格公式为 \( C = S \cdot N(d1) - K \cdot e^{-rT} \cdot N(d2) \)。
3. **delta**：看涨期权的 delta 是 \( N(d1) \)，即标的资产价格变化对期权价格的敏感度。
4. **vega**：看涨期权的 vega 是 \( S \cdot \sqrt{T} \cdot N'(d1) \)，其中 \( N'(d1) \) 是标准正态分布的概率密度函数（PDF）。题目要求 vega 按每单位波动率（σ 为小数形式）报价，因此直接使用该公式。

### 输出：
脚本将结果存储在 `result` 字典中，键名严格为 `'call_price'`、`'call_delta'` 和 `'call_vega'`。运行后可直接投屏展示。
