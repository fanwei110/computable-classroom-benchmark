### **第一问：年化夏普比率**
**步骤：**
1. 计算日收益率的样本均值（`mean_daily_return`）和样本标准差（`std_daily_return`，`ddof=1`）。
2. 年化收益率 = `mean_daily_return * 252`
3. 年化波动率 = `std_daily_return * sqrt(252)`

### **第二问：业绩归因（Brinson 模型）**
**已知：**
- 组合权重：`w_p = [0.45, 0.35, 0.20]`
- 组合行业收益：`r_p = [0.083, 0.021, -0.014]`
- 基准权重：`w_b = [0.40, 0.40, 0.20]`
- 基准行业收益：`r_b = [0.067, 0.034, -0.009]`

**步骤：**
1. **配置效应（Allocation Effect）**：
   衡量由于权重偏离基准带来的超额收益。
   公式：
   \[
   \text{Allocation Effect} = \sum_{i} (w_{p,i} - w_{b,i}) \cdot r_{b,i}
   \]

2. **选择效应（Selection Effect）**：
   衡量由于行业选择优于基准带来的超额收益。
   公式：
   \[
   \text{Selection Effect} = \sum_{i} w_{b,i} \cdot (r_{p,i} - r_{b,i})
   \]

3. **交互效应（Interaction Effect）**：
   衡量权重和行业选择的协同作用。
   公式：
   \[
   \text{Interaction Effect} = \sum_{i} (w_{p,i} - w_{b,i}) \cdot (r_{p,i} - r_{b,i})
   \]

**计算：**
```python
w_p = np.array([0.45, 0.35, 0.20])
w_b = np.array([0.40, 0.40, 0.20])
r_p = np.array([0.083, 0.021, -0.014])
r_b = np.array([0.067, 0.034, -0.009])

allocation_effect = np.sum((w_p - w_b) * r_b)
selection_effect = np.sum(w_b * (r_p - r_b))
interaction_effect = np.sum((w_p - w_b) * (r_p - r_b))
```

**结果：**
- 配置效应 = `(0.45-0.40)*0.067 + (0.35-0.40)*0.034 + (0.20-0.20)*(-0.009) = 0.00235`
- 选择效应 = `0.40*(0.083-0.067) + 0.40*(0.021-0.034) + 0.20*(-0.014+0.009) = 0.0024`
- 交互效应 = `(0.45-0.40)*(0.083-0.067) + (0.35-0.40)*(0.021-0.034) + (0.20-0.20)*(-0.014+0.009) = 0.00045`
