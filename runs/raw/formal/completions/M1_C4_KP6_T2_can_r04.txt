以下是自包含的Python脚本，完成指定的任务：

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import os

# 1. 读取数据并计算日无风险利率
data_path = 'data/market_snapshot_v1.csv'
df = pd.read_csv(data_path, parse_dates=['date'])
daily_rf_rate = 0.021 / 252  # 年利率2.1%转换为日利率

# 提取基金日收益率
fund_returns = df['fund'].dropna().values  # 确保无空值
dates = df['date'].dropna().values[-len(fund_returns):]  # 对齐日期

# 2. 计算滚动夏普比率
window_size = 60  # 可调窗口长度
rolling_sharpe = []

for i in range(window_size, len(fund_returns)):
    window_returns = fund_returns[i-window_size:i]
    excess_returns = window_returns - daily_rf_rate
    mean_excess = np.mean(excess_returns)
    std_excess = np.std(excess_returns, ddof=1)
    annualized_sharpe = (mean_excess / std_excess) * np.sqrt(252)
    rolling_sharpe.append(annualized_sharpe)

# 3. 报告最后一个窗口的夏普值
rolling_sharpe_last = rolling_sharpe[-1] if rolling_sharpe else np.nan

# 绘制时间序列图
plt.figure(figsize=(10, 6))
plt.plot(dates[window_size:], rolling_sharpe, label='60-Day Rolling Sharpe Ratio')
plt.title('60-Day Rolling Annualized Sharpe Ratio')
plt.xlabel('Date')
plt.ylabel('Sharpe Ratio')
plt.grid(True)
plt.legend()

# 保存图形
figure_dir = 'figures'
os.makedirs(figure_dir, exist_ok=True)
figure_path = os.path.join(figure_dir, 'rolling_sharpe.png')
plt.savefig(figure_path)
plt.close()

# 4. 填充result字典
result = {
    'rolling_sharpe_last': rolling_sharpe_last,
    'figure_path': figure_path
}

# 输出result以供验证（实际使用时可删除）
print(result)
```

### 说明：
1. **数据读取**：从CSV文件中读取基金日收益率和日期，确保数据对齐。
2. **日无风险利率**：将年利率2.1%转换为日利率（简单除法）。
3. **滚动夏普比率**：
   - 使用60日滚动窗口计算超额收益（减去日无风险利率）。
   - 样本标准差（`ddof=1`）计算波动率。
   - 年化处理：均值不变，波动率乘以`sqrt(252)`。
4. **结果输出**：
   - 最后一个窗口的夏普值存入`result['rolling_sharpe_last']`。
   - 图形保存为`figures/rolling_sharpe.png`，路径存入`result['figure_path']`。
5. **可调窗口**：将`window_size`设为变量，方便调整。

### 注意事项：
- 确保CSV文件路径正确（`data/market_snapshot_v1.csv`）。
- 图形保存目录`figures/`会自动创建（如果不存在）。
- 输出结果`result`严格符合契约要求。
