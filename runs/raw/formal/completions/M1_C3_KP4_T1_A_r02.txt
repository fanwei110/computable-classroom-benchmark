我们将使用 **Black-Scholes-Merton (BSM) 模型** 为这只欧式看涨期权定价，并计算 **Delta** 和 **Vega**。以下是详细的计算步骤和 Python 实现。

---

### 🔢 输入参数
- 标的现价 \( S_0 = 103.7 \)
- 行权价 \( K = 97.5 \)
- 隐含波动率 \( \sigma = 27.6\% = 0.276 \)
- 无风险利率（连续复利）\( r = 4.3\% = 0.043 \)
- 剩余到期时间 \( T = 0.58 \) 年
- 不分红 \( q = 0 \)

---

### 📌 公式回顾

1. **看涨期权价格（Call Price）**
   \[
   C = S_0 e^{-qT} N(d_1) - K e^{-rT} N(d_2)
   \]
   其中：
   \[
   d_1 = \frac{\ln(S_0 / K) + (r - q + \sigma^2 / 2)T}{\sigma \sqrt{T}}
   \]
   \[
   d_2 = d_1 - \sigma \sqrt{T}
   \]

2. **Delta（对标的价格的一阶导数）**
   \[
   \Delta_{\text{call}} = e^{-qT} N(d_1)
   \]

3. **Vega（对波动率的一阶导数）**
   \[
   \text{Vega} = S_0 e^{-qT} \sqrt{T} \cdot \frac{1}{\sqrt{2\pi}} e^{-d_1^2 / 2}
   \]
   通常以每1%波动率变化对应的价格变化表示，所以需要乘以 0.01。

---

### ✅ Python 实现

```python
import numpy as np
from scipy.stats import norm

# 输入参数
S0 = 103.7
K = 97.5
sigma = 0.276
r = 0.043
T = 0.58
q = 0.0  # 不分红

# 计算 d1 和 d2
d1 = (np.log(S0 / K) + (r - q + 0.5 * sigma**2) * T) / (sigma * np.sqrt(T))
d2 = d1 - sigma * np.sqrt(T)

# 计算期权价格
call_price = S0 * np.exp(-q * T) * norm.cdf(d1) - K * np.exp(-r * T) * norm.cdf(d2)

# 计算 Delta
call_delta = np.exp(-q * T) * norm.cdf(d1)

# 计算 Vega（每1%波动率变化对应的价格变化）
vega = S0 * np.exp(-q * T) * np.sqrt(T) * norm.pdf(d1) * 0.01  # 乘以0.01转换为每1%

# 存入结果字典
result = {
    'call_price': round(call_price, 4),
    'call_delta': round(call_delta, 4),
    'call_vega': round(vega, 4)
}

result
```
