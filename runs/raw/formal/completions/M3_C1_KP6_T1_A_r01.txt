### 第二问：业绩归因 (Brinson模型)
**已知数据**：
- 组合权重 $w_p = [0.45, 0.35, 0.20]$，组合收益 $r_p = [8.3\%, 2.1\%, -1.4\%]$
- 基准权重 $w_b = [0.40, 0.40, 0.20]$，基准收益 $r_b = [6.7\%, 3.4\%, -0.9\%]$

**计算过程**：
1. **配置效应** $= \sum (w_p - w_b) \times r_b$
   $= (0.45-0.40)\times 6.7\% + (0.35-0.40)\times 3.4\% + (0.20-0.20)\times (-0.9\%)$
   $= 0.05\times 0.067 + (-0.05)\times 0.034 + 0 = 0.00335 - 0.00170 = \mathbf{0.00165}$ (即 0.165%)

2. **选择效应** $= \sum w_b \times (r_p - r_b)$
   $= 0.40\times (8.3\%-6.7\%) + 0.40\times (2.1\%-3.4\%) + 0.20\times (-1.4\%-(-0.9\%))$
   $= 0.40\times 0.016 + 0.40\times (-0.013) + 0.20\times (-0.005) = 0.00640 - 0.00520 - 0.00100 = \mathbf{0.0002}$ (即 0.020%)

3. **交互效应** $= \sum (w_p - w_b) \times (r_p - r_b)$
   $= (0.45-0.40)\times (8.3\%-6.7\%) + (0.35-0.40)\times (2.1\%-3.4\%) + (0.20-0.20)\times (-1.4\%-(-0.9\%))$
   $= 0.05\times 0.016 + (-0.05)\times (-0.013) + 0 = 0.00080 + 0.00065 = \mathbf{0.00145}$ (即 0.145%)

*(验证：总超额收益 = 组合收益 4.190% - 基准收益 3.860% = 0.330%，配置+选择+交互 = 0.165% + 0.020% + 0.145% = 0.330%，完全吻合)*
