```python
import numpy as np
import pandas as pd

# 第一部分：计算年化夏普比率
# 读取数据
data_path = 'data/market_snapshot_v1.csv'
market_snapshot = pd.read_csv(data_path)

# 提取基金日收益率
fund_returns_daily = market_snapshot['fund'].dropna().values

# 无风险利率（年化2.1%，日化=2.1%/252）
risk_free_rate_annual = 0.021
risk_free_rate_daily = risk_free_rate_annual / 252

# 计算超额收益（日收益 - 日无风险利率）
excess_returns_daily = fund_returns_daily - risk_free_rate_daily

# 计算样本标准差（ddof=1）
excess_returns_std_daily = np.std(excess_returns_daily, ddof=1)

# 年化夏普比率（均值 / 日标准差 * sqrt(252)）
sharpe_annual = np.mean(excess_returns_daily) / excess_returns_std_daily * np.sqrt(252)

# 第二部分：Brinson-Hood-Beebower 业绩归因
# 组合和基准的权重与收益
portfolio_weights = np.array([0.45, 0.35, 0.20])
benchmark_weights = np.array([0.40, 0.40, 0.20])
portfolio_returns = np.array([0.083, 0.021, -0.014])
benchmark_returns = np.array([0.067, 0.034, -0.009])

# 计算配置效应：Σ(w_p - w_b) * r_b
allocation_effect = np.sum((portfolio_weights - benchmark_weights) * benchmark_returns)

# 计算选择效应：Σw_b * (r_p - r_b)
selection_effect = np.sum(benchmark_weights * (portfolio_returns - benchmark_returns))

# 计算交互效应：Σ(w_p - w_b) * (r_p - r_b)
interaction_effect = np.sum((portfolio_weights - benchmark_weights) * (portfolio_returns - benchmark_returns))

# 存储结果
result = {
    'sharpe_annual': sharpe_annual,
    'allocation_effect': allocation_effect,
    'selection_effect': selection_effect,
    'interaction_effect': interaction_effect
}

# 输出结果（供课堂展示）
print(result)
```

### 说明：
1. **第一部分**：
   - 读取 CSV 文件中的 `fund` 列日收益率。
   - 计算日超额收益（减去日无风险利率 `2.1%/252`）。
   - 使用样本标准差（`ddof=1`）计算波动率，并通过 `sqrt(252)` 年化夏普比率。

2. **第二部分**：
   - 按照 Brinson-Hood-Beebower 模型，分别计算配置效应、选择效应和交互效应。
   - 所有结果均以小数形式表示（如 `0.01` 代表 1%）。

3. **输出**：
   - 结果存储在字典 `result` 中，键名严格匹配要求。

### 注意事项：
- 脚本假设 CSV 文件路径为 `data/market_snapshot_v1.csv`，且包含 `fund` 列。
- 无需联网，仅依赖本地数据和标准库。
- 结果可复现，变量命名清晰。
