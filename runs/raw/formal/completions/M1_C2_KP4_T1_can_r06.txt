以下是自包含的 Python 脚本，计算欧式看涨期权的 Black-Scholes 价格、delta 和 vega：

```python
import numpy as np
from scipy.stats import norm

# 输入参数
S = 103.7          # 标的资产现价
K = 97.5           # 行权价
sigma = 0.276      # 年化隐含波动率
r = 0.043          # 无风险利率（年化）
T = 0.58           # 剩余期限（年）

# 1. 计算 d1 和 d2
d1 = (np.log(S / K) + (r + 0.5 * sigma ** 2) * T) / (sigma * np.sqrt(T))
d2 = d1 - sigma * np.sqrt(T)

# 2. 计算期权价格和 delta
call_price = S * norm.cdf(d1) - K * np.exp(-r * T) * norm.cdf(d2)
call_delta = norm.cdf(d1)

# 3. 计算 vega（注意：vega 的单位是每 1% 波动率变化对应的价格变化）
call_vega = S * np.sqrt(T) * norm.pdf(d1) * 0.01  # 乘以 0.01 将单位转换为每 1% 波动率变化

# 4. 填充 result 字典
result = {
    'call_price': call_price,
    'call_delta': call_delta,
    'call_vega': call_vega
}

# 输出结果（可选，便于调试）
print(result)
```

### 说明：
1. **d1 和 d2**：Black-Scholes 公式中的中间变量，用于计算期权价格和希腊字母。
2. **期权价格**：使用 Black-Scholes 闭式解计算欧式看涨期权价格。
3. **Delta**：看涨期权的 delta 为 `N(d1)`，其中 `N` 是标准正态分布的累积分布函数（CDF）。
4. **Vega**：Vega 衡量波动率变化对期权价格的影响，公式为 `S * sqrt(T) * N'(d1)`，其中 `N'` 是标准正态分布的概率密度函数（PDF）。乘以 `0.01` 是为了将单位转换为每 1% 波动率变化对应的价格变化（通常市场惯例）。
5. **结果**：所有结果存入 `result` 字典，键名严格按要求。

运行脚本后，`result` 字典将包含以下内容（具体数值可能因浮点精度略有差异）：

    'call_vega': 0.3005     # vega（每 1% 波动率变化）
}
