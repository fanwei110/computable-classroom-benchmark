根据资本资产定价模型（CAPM），期望收益的计算公式为：
$$E(R_i) = R_f + \beta_i \times (E(R_m) - R_f)$$

已知：
- 无风险利率 $R_f = 2.3\% = 0.023$
- 市场期望收益 $E(R_m) = 9.4\% = 0.094$
- 市场风险溢价 $E(R_m) - R_f = 0.094 - 0.023 = 0.071$

**1. 计算三只股票的期望收益：**
- 股票X：$E(R_x) = 0.023 + 0.62 \times 0.071 = 0.023 + 0.04402 = 0.06702$
- 股票Y：$E(R_y) = 0.023 + 1.18 \times 0.071 = 0.023 + 0.08378 = 0.10678$
- 股票Z：$E(R_z) = 0.023 + 1.51 \times 0.071 = 0.023 + 0.10721 = 0.13021$

**2. 计算股票Y的Alpha：**
Alpha的计算公式为实际收益减去期望收益：
$$\alpha_y = R_{y, actual} - E(R_y)$$
- 股票Y的实际收益 $R_{y, actual} = 13.1\% = 0.131$
- $\alpha_y = 0.131 - 0.10678 = 0.02422$
