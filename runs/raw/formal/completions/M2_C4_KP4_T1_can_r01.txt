以下是一个自包含的 Python 脚本，它根据给定的参数计算欧式看涨期权的 Black–Scholes 价格、delta 和 vega，并将结果存入字典 `result`。

```python
import numpy as np
from scipy.stats import norm

# 已知参数
S = 103.7          # 标的现价
K = 97.5           # 行权价
sigma = 0.276      # 年化波动率（小数）
r = 0.043          # 连续复利无风险利率（小数）
T = 0.58           # 剩余期限（年）

# 1. 计算 d1 和 d2
d1 = (np.log(S / K) + (r + 0.5 * sigma**2) * T) / (sigma * np.sqrt(T))
d2 = d1 - sigma * np.sqrt(T)

# 2. 计算期权价格与 delta
call_price = S * norm.cdf(d1) - K * np.exp(-r * T) * norm.cdf(d2)
call_delta = norm.cdf(d1)

# 3. 计算 vega（每单位波动率，dC/dσ）
#    N'(d1) = norm.pdf(d1)
call_vega = S * np.sqrt(T) * norm.pdf(d1)

# 4. 填充结果字典
result = {
    'call_price': call_price,
    'call_delta': call_delta,
    'call_vega': call_vega
}

# 输出结果供课堂投屏查看
print(result)
```

**说明**：
- `d1` 和 `d2` 使用连续复利利率计算。
- 价格和 delta 均基于标准正态累积分布函数 `norm.cdf`。
- vega 按 `dC/dσ` 给出，即波动率每变动 1（100%），期权价格的变动量，并以小数表示；实际使用时，若波动率单位为 1%（0.01），需相应缩放。
- 脚本仅依赖 `numpy` 和 `scipy`，无需联网，结果确定且可复现。
