```python
import numpy as np

# 给定参数（小数表示）
beta = 1.42
market_return = -0.058          # 上月市场收益率
risk_free_annual = 0.047        # 年无风险利率

# 1. 将年无风险利率按简单除法折算为月利率
risk_free_monthly = risk_free_annual / 12

# 2. 在月度层面套用 CAPM 公式：E(R_i) = R_f + beta * (R_m - R_f)
capm_return_monthly = risk_free_monthly + beta * (market_return - risk_free_monthly)

# 3. 输出结果字典
result = {
    'capm_return_monthly': capm_return_monthly
}

print(result)
```

运行即可得到包含期望月度收益的字典，例如：  
`{'capm_return_monthly': -0.08400500000000001}` （约为 -8.40%）。
