### 1. 年化夏普比率计算逻辑
年化夏普比率的计算公式为：
$$Sharpe_{annual} = \frac{R_p - R_f}{\sigma_p} \times \sqrt{252}$$
其中：
*   $R_p$ 为日收益率的均值
*   $R_f$ 为日无风险利率，由年化2.1%折算：$R_{f,daily} = 2.1\% / 252$
*   $\sigma_p$ 为日收益率的标准差
*   $\sqrt{252}$ 为交易日年化调整因子

### 2. 业绩归因（Brinson模型）计算
根据Brinson模型，计算各效应如下：

*   **配置效应** $= \sum (W_{p,i} - W_{b,i}) \times R_{b,i}$
    $= (0.45-0.40)\times 6.7\% + (0.35-0.40)\times 3.4\% + (0.20-0.20)\times (-0.9\%)$
    $= 0.00335 - 0.00170 + 0 = 0.00165$

*   **选择效应** $= \sum W_{b,i} \times (R_{p,i} - R_{b,i})$
    $= 0.40\times (8.3\%-6.7\%) + 0.40\times (2.1\%-3.4\%) + 0.20\times (-1.4\%-(-0.9\%))$
    $= 0.00640 - 0.00520 - 0.00100 = 0.00020$

*   **交互效应** $= \sum (W_{p,i} - W_{b,i}) \times (R_{p,i} - R_{b,i})$
    $= (0.45-0.40)\times (8.3\%-6.7\%) + (0.35-0.40)\times (2.1\%-3.4\%) + (0.20-0.20)\times (-1.4\%-(-0.9\%))$
    $= 0.00080 + 0.00065 + 0 = 0.00145$

*(验证：总超额收益 = 组合收益4.19% - 基准收益3.86% = 0.33%，配置0.165% + 选择0.020% + 交互0.145% = 0.330%，结果一致)*

### 完整计算代码与输出契约

您可以将以下代码在本地运行，只需将文件读取部分替换为您的实际文件路径即可得到包含确切夏普比率的 `result` 字典：

```python
import pandas as pd
import numpy as np

# ===== 第一问：计算年化夏普比率 =====
# 请将 'course_data.csv' 替换为您真实的课程数据文件名
try:
    df = pd.read_csv('course_data.csv')
    daily_returns = df['fund']
    
    rf_annual = 0.021
    rf_daily = rf_annual / 252  # 日无风险利率
    
    # 计算年化夏普比率
    mean_excess_daily = daily_returns.mean() - rf_daily
    std_daily = daily_returns.std()
    sharpe_annual = (mean_excess_daily / std_daily) * np.sqrt(252)
except Exception as e:
    print(f"数据文件读取失败，夏普比率暂设为None: {e}")
    sharpe_annual = None

# ===== 第二问：业绩归因计算 =====
W_p = np.array([0.45, 0.35, 0.20])
R_p = np.array([0.083, 0.021, -0.014])
W_b = np.array([0.40, 0.40, 0.20])
R_b = np.array([0.067, 0.034, -0.009])

allocation_effect = np.sum((W_p - W_b) * R_b)
selection_effect = np.sum(W_b * (R_p - R_b))
interaction_effect = np.sum((W_p - W_b) * (R_p - R_b))

# ===== 输出契约 =====
result = {
    'sharpe_annual': sharpe_annual,  # 若数据读取成功将为具体数值
    'allocation_effect': float(allocation_effect),
    'selection_effect': float(selection_effect),
    'interaction_effect': float(interaction_effect)
}

print(result)
```
