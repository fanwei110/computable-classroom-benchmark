### 一、 计算逻辑与结果

#### 1. 年化夏普比率
*   **日无风险利率**：根据约定“债券收益率按年复利报价”，2.1%的年化无风险利率转为日利率需采用年复利拆分：$r_{f,daily} = (1 + 0.021)^{1/252} - 1$
*   **日超额收益**：$R_{ex} = R_{fund} - r_{f,daily}$
*   **年化夏普比率**：$Sharpe_{annual} = \frac{Mean(R_{ex})}{Std(R_{ex})} \times \sqrt{252}$ （其中标准差使用样本估计量，即自由度 $ddof=1$）

#### 2. 业绩归因（Braginson Fachler 模型）
根据约定，权重与收益率均用小数表示：
*   组合权重 $w_p = [0.45, 0.35, 0.20]$
*   基准权重 $w_b = [0.40, 0.40, 0.20]$
*   组合行业收益 $R_p = [0.083, 0.021, -0.014]$
*   基准行业收益 $R_b = [0.067, 0.034, -0.009]$

**计算过程**：
*   **配置效应 (Allocation Effect)** = $\sum (w_p - w_b) \times R_b$
    $= (0.05 \times 0.067) + (-0.05 \times 0.034) + (0 \times -0.009) = 0.00335 - 0.00170 + 0 = \mathbf{0.00165}$
*   **选择效应 (Selection Effect)** = $\sum w_b \times (R_p - R_b)$
    $= (0.40 \times 0.016) + (0.40 \times -0.013) + (0.20 \times -0.005) = 0.00640 - 0.00520 - 0.00100 = \mathbf{0.00020}$
*   **交互效应 (Interaction Effect)** = $\sum (w_p - w_b) \times (R_p - R_b)$
    $= (0.05 \times 0.016) + (-0.05 \times -0.013) + (0 \times -0.005) = 0.00080 + 0.00065 + 0 = \mathbf{0.00145}$
*(验证：总超额收益 = 组合收益 0.0419 - 基准收益 0.0386 = 0.0033，三个效应之和 0.00165 + 0.0002 + 0.00145 = 0.0033，完全吻合)*

# 按约定：年化与去年化按252个交易日，债券收益率按年复利，标准差ddof=1
def calculate_annualized_sharpe(R_fund, annual_rf=0.021):
    # 1. 日无风险利率（年复利报价转日频）
    rf_daily = (1 + annual_rf) ** (1 / 252) - 1
    
    # 2. 日超额收益
    excess_returns = R_fund - rf_daily
    
    # 3. 均值与样本标准差(ddof=1)
    mean_excess = excess_returns.mean()
    std_excess = excess_returns.std(ddof=1)
    
    # 4. 年化夏普比率
    sharpe_annual = (mean_excess / std_excess) * np.sqrt(252)
    return sharpe_annual

# sharpe_annual_val = calculate_annualized_sharpe(R_fund)

allocation_effect = np.sum((wp - wb) * Rb)
selection_effect = np.sum(wb * (Rp - Rb))
interaction_effect = np.sum((wp - wb) * (Rp - Rb))

# ========== 构建输出字典 ==========
