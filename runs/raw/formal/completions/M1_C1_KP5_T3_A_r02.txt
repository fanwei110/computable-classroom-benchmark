根据题目描述，我们需要计算95%的一日VaR（Value at Risk）。计算步骤如下：

1. 年化波动率为24%，即σ_annual = 0.24。
2. 一日波动率σ_daily = σ_annual / √252（假设一年有252个交易日）。
3. 95%的置信水平对应的正态分布分位数为1.645（单尾）。
4. 一日VaR = 头寸 × σ_daily × 1.645。

计算过程：
- σ_daily = 0.24 / √252 ≈ 0.24 / 15.8745 ≈ 0.01512
- VaR_95_1d = 2,700,000 × 0.01512 × 1.645 ≈ 2,700,000 × 0.02487 ≈ 67,149

因此，结果存入字典 `result` 中：

```python
result = {
    'var_95_1d': 67149
}
```
