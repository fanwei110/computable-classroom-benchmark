以下是一个自包含的 Python 脚本，用于计算债券的价格、麦考利久期、修正久期和凸性。脚本使用 `numpy` 进行数值计算，并将结果存入 `result` 字典中。

```python
import numpy as np

# 债券参数
face_value = 100.0          # 面值
coupon_rate = 0.046         # 票息率（年化）
years_to_maturity = 7       # 剩余期限（年）
ytm = 0.053                 # 到期收益率（年化）
coupon_frequency = 1        # 每年付息次数（假设每年付息一次）

# 计算每期票息
coupon_payment = face_value * coupon_rate / coupon_frequency

# 生成现金流
cash_flows = np.full(years_to_maturity, coupon_payment)
cash_flows[-1] += face_value  # 最后一期包含本金

# 计算价格（现金流贴现之和）
periods = np.arange(1, years_to_maturity + 1)
discount_factors = (1 + ytm / coupon_frequency) ** (-periods)
price = np.sum(cash_flows * discount_factors)

# 计算麦考利久期
weighted_cash_flows = cash_flows * periods * discount_factors
macaulay_duration = np.sum(weighted_cash_flows) / price / coupon_frequency

# 计算修正久期
modified_duration = macaulay_duration / (1 + ytm / coupon_frequency)

# 计算凸性
weighted_cash_flows_convexity = cash_flows * periods * (periods + 1) * discount_factors
convexity = np.sum(weighted_cash_flows_convexity) / (price * (1 + ytm / coupon_frequency) ** 2) / (coupon_frequency ** 2)

# 存储结果
result = {
    'price': price,
    'macaulay_duration_years': macaulay_duration,
    'modified_duration_years': modified_duration,
    'convexity': convexity
}

# 输出结果（可选，便于调试）
print(result)
```

### 说明：
1. **价格计算**：通过将每期现金流（票息 + 最后一期的本金）按到期收益率贴现求和得到。
2. **麦考利久期**：现金流的加权平均期限，权重为现金流的现值占价格的比例。
3. **修正久期**：麦考利久期除以 `(1 + ytm / 付息频率)`，衡量价格对收益率变动的敏感性。
4. **凸性**：衡量久期随收益率变化的敏感性，计算公式为加权现金流的二阶矩除以价格和 `(1 + ytm)^2`。
