以下是自包含的 Python 脚本，用于计算欧式看涨期权的价格、delta 和 vega：

```python
import numpy as np
from scipy.stats import norm

# 输入参数
S = 103.7          # 标的资产现价
K = 97.5           # 行权价
sigma = 0.276      # 隐含波动率（年化）
r = 0.043          # 无风险利率（年化）
T = 0.58           # 剩余期限（年）

# 1. 计算 d1 和 d2
d1 = (np.log(S / K) + (r + 0.5 * sigma ** 2) * T) / (sigma * np.sqrt(T))
d2 = d1 - sigma * np.sqrt(T)

# 2. 计算期权价格和 delta
call_price = S * norm.cdf(d1) - K * np.exp(-r * T) * norm.cdf(d2)
call_delta = norm.cdf(d1)

# 3. 计算 vega（注意：vega 的单位是每 1% 波动率变化对应的价格变化）
call_vega = S * np.sqrt(T) * norm.pdf(d1) * 0.01  # 乘以 0.01 将单位转换为每 1% 波动率变化

# 4. 填充 result 字典
result = {
    'call_price': call_price,
    'call_delta': call_delta,
    'call_vega': call_vega
}

# 输出结果（可选，便于调试）
print(result)
```

### 说明：
1. **d1 和 d2**：根据 Black-Scholes 公式计算。
2. **期权价格**：使用 `S * N(d1) - K * e^(-rT) * N(d2)` 计算。
3. **Delta**：看涨期权的 delta 是 `N(d1)`。
4. **Vega**：计算公式为 `S * sqrt(T) * N'(d1)`，其中 `N'(d1)` 是标准正态分布的概率密度函数。乘以 `0.01` 是为了将单位转换为每 1% 波动率变化对应的价格变化（通常 vega 的单位是每 1% 波动率变化）。

### 输出：
脚本将结果存入 `result` 字典，键名严格为 `'call_price'`、`'call_delta'` 和 `'call_vega'`。输出结果可直接投屏展示。
