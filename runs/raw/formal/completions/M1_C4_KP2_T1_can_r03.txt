以下是自包含的 Python 脚本，按照要求计算 CAPM 期望收益和股票 Y 的 alpha：

```python
import numpy as np

# 给定参数
rf = 0.023          # 无风险利率
market_er = 0.094   # 市场期望收益
betas = {
    'x': 0.62,
    'y': 1.18,
    'z': 1.51
}
actual_return_y = 0.131  # 股票 Y 的实际收益

# 计算风险溢价
risk_premium = market_er - rf

# 计算各股票的 CAPM 期望收益
er_x = rf + betas['x'] * risk_premium
er_y = rf + betas['y'] * risk_premium
er_z = rf + betas['z'] * risk_premium

# 计算股票 Y 的 alpha
alpha_y = actual_return_y - er_y

# 存储结果
result = {
    'er_x': er_x,
    'er_y': er_y,
    'er_z': er_z,
    'alpha_y': alpha_y
}

# 输出结果（可选，用于验证）
print(result)
```

运行后，`result` 字典将包含以下内容：
- `er_x`: 股票 X 的 CAPM 期望收益（约 0.06674）
- `er_y`: 股票 Y 的 CAPM 期望收益（约 0.10738）
- `er_z`: 股票 Z 的 CAPM 期望收益（约 0.13009）
- `alpha_y`: 股票 Y 的 alpha（约 0.02362）

所有值均为小数形式，符合课程约定。
