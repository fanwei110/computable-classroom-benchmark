根据组合波动率公式：

**组合波动率 = √(w₁²σ₁² + w₂²σ₂² + 2w₁w₂ρσ₁σ₂)**

其中：
- σ₁ = 18.4% (A波动)
- σ₂ = 29.7% (B波动)
- 权重：A:B = 60:40，即 w₁=0.6, w₂=0.4
- ρ_before = 0.3
- ρ_after = 0.8

**相关性为0.3时：**
组合方差 = 0.6²×0.184² + 0.4²×0.297² + 2×0.6×0.4×0.3×0.184×0.297
= 0.012192 + 0.014114 + 0.007867 = 0.034173
组合波动率 = √0.034173 = 18.49%

**相关性为0.8时：**
组合方差 = 0.6²×0.184² + 0.4²×0.297² + 2×0.6×0.4×0.8×0.184×0.297
= 0.012192 + 0.014114 + 0.020979 = 0.047285
组合波动率 = √0.047285 = 21.75%
