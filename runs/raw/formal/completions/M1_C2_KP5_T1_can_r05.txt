以下是自包含的 Python 脚本，按照题目要求计算 VaR 并输出结果：

```python
import numpy as np
from scipy.stats import norm

# 输入参数
position_value = 1_850_000  # 头寸价值（元）
annual_volatility = 0.218   # 年化波动率（21.8%）

# 1. 年化波动率换算到一日波动率（假设一年252个交易日）
daily_volatility = annual_volatility / np.sqrt(252)

# 2. 计算正态分位数（Z-score）
z_95 = norm.ppf(0.05)      # 95%置信水平对应的分位数（单尾）
z_99 = norm.ppf(0.01)      # 99%置信水平对应的分位数（单尾）

# 3. 计算 VaR
# (i) 95% 一日 VaR
var_95_1d = position_value * (-z_95) * daily_volatility

# (ii) 99% 十日 VaR
# 十日波动率 = 一日波动率 * sqrt(10)
ten_day_volatility = daily_volatility * np.sqrt(10)
var_99_10d = position_value * (-z_99) * ten_day_volatility

# 4. 结果存入字典（四舍五入到整数元）
result = {
    'var_95_1d': round(var_95_1d),
    'var_99_10d': round(var_99_10d)
}

# 输出结果（可选，用于验证）
print(result)
```

### 说明：
1. **波动率换算**：年化波动率转换为日波动率时，假设一年有 252 个交易日（金融市场常用假设）。
2. **正态分位数**：使用 `scipy.stats.norm.ppf` 计算单尾分位数（因为 VaR 关注损失尾部）。
3. **时间缩放**：十日 VaR 通过平方根法则（√10）缩放日波动率。
4. **结果**：`result` 字典严格按照题目要求的键名存储，并四舍五入到整数元。

运行脚本后，`result` 将包含：
- `var_95_1d`: 95% 置信水平下的 1 日 VaR（元）
- `var_99_10d`: 99% 置信水平下的 10 日 VaR（元）
