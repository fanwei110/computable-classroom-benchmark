```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# ==========================================
# 1. 参数与假设设定
# ==========================================
# 可调滚动窗口长度（题目要求60日，此处设为变量以方便调节）
WINDOW = 60
# 无风险利率（年化）
RF_ANNUAL = 0.021
# 一年交易日（学术界与实务中通常按252天计算年化）
TRADING_DAYS = 252

# ==========================================
# 2. 读取数据与预处理
# ==========================================
# 读取课程数据快照
df = pd.read_csv('data/market_snapshot_v1.csv')

# 提取基金日收益列
returns = df['fund']

# 计算日无风险利率（采用单利近似，与常见的日超额收益计算方法一致）
rf_daily = RF_ANNUAL / TRADING_DAYS

# 计算日超额收益
excess_returns = returns - rf_daily

# ==========================================
# 3. 计算滚动年化夏普比率
# ==========================================
# 计算指定窗口的滚动均值与滚动标准差
rolling_mean = excess_returns.rolling(window=WINDOW).mean()
rolling_std = excess_returns.rolling(window=WINDOW).std()

# 计算日度夏普比率，并年化处理
# 年化夏普 = 日夏普 * sqrt(252)
rolling_sharpe_daily = rolling_mean / rolling_std
rolling_sharpe_annualized = rolling_sharpe_daily * np.sqrt(TRADING_DAYS)

# ==========================================
# 4. 提取最近一个窗口的夏普值
# ==========================================
sharpe_last_value = rolling_sharpe_annualized.iloc[-1]

# 确保输出类型为原生Python float，避免后续序列化问题
if pd.isna(sharpe_last_value):
    sharpe_last_value = None
else:
    sharpe_last_value = float(sharpe_last_value)

# ==========================================
# 5. 绘图与保存
# ==========================================
plt.figure(figsize=(12, 6))
plt.plot(rolling_sharpe_annualized.index, rolling_sharpe_annualized.values, 
         label=f'{WINDOW}-Day Rolling Annualized Sharpe', color='royalblue', linewidth=1.5)

# 添加零线参考
plt.axhline(0, color='gray', linestyle='--', linewidth=1)

plt.title(f'{WINDOW}-Day Rolling Annualized Sharpe Ratio (Rf={RF_ANNUAL*100:.1f}%)', fontsize=14)
plt.xlabel('Date / Index', fontsize=12)
plt.ylabel('Annualized Sharpe Ratio', fontsize=12)
plt.grid(True, linestyle='--', alpha=0.5)
plt.legend(fontsize=11)

# 保存图形
figure_path = 'rolling_sharpe_ratio.png'
plt.savefig(figure_path, dpi=150, bbox_inches='tight')
plt.close()

# ==========================================
# 6. 封装输出结果
# ==========================================
result = {
    'rolling_sharpe_last': sharpe_last_value,
    'figure_path': figure_path
}

# 课堂投屏打印展示
print(f"最近一个 {WINDOW} 日窗口的年化夏普比率: {sharpe_last_value:.4f}")
print(f"图形已保存至: {figure_path}")
```

### 设计说明：
1. **无风险利率折算**：采用业界标准的 `Rf_daily = Rf_annual / 252` 计算日无风险利率，随后用日收益减去该值得出日超额收益。
2. **年化处理**：基于日度夏普（均值/标准差）乘以 `√252` 进行年化，这是《证券投资学》中最标准的年化转换方式。
3. **窗口可调**：将窗口长度抽象为变量 `WINDOW`，教师在课堂上可直接修改该参数并重新运行，动态观察不同窗口对平滑度的影响。
4. **数据严谨性**：使用 `pandas.DataFrame.rolling` 原生支持，标准差默认使用 `ddof=1`（样本标准差），符合统计学最佳实践。若数据不足一个窗口期，产生的 `NaN` 会被 `pandas` 自动处理，确保不报错。
5. **契约遵守**：最终结果精准存入 `result` 字典，键名严格匹配要求，变量无占位值，脚本完全自包含。
