以下是满足您要求的Python脚本。它将完成马科维茨均值-方差前沿的绘制，并计算所需的波动率，最后输出结果字典。

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.optimize import minimize
import os

# 基础参数设定
mu = np.array([0.071, 0.124])
sigma = np.array([0.163, 0.289])
rho_list = [0.15, 0.45, 0.75]

# 用于绘图的期望收益率网格（从最小方差组合往右上角覆盖）
# 注意：由于允许卖空，组合收益范围将超越两个资产的收益区间
# 我们适当扩展收益范围以确保有效前沿完整展示
ret_min = -0.15
ret_max = 0.35
grid_points = 200

# 存储结果的字典
result = {}

# ------------------------------------------------------------
# 工具函数：给定权重 w = [w1, 1-w1]，计算组合收益与标准差
def portfolio_stats(w1, mu, cov):
    """返回 (组合收益, 组合标准差)"""
    w = np.array([w1, 1.0 - w1])
    ret = np.dot(w, mu)
    std = np.sqrt(np.dot(w.T, np.dot(cov, w)))
    return ret, std

# ------------------------------------------------------------
# 设置绘图
fig, ax = plt.subplots(figsize=(10, 7))

# 用于标记最小方差组合的颜色与样式
colors = ['blue', 'red', 'green']
markers = ['o', 's', 'D']

# ------------------------------------------------------------
# 对每个相关系数进行循环处理
for idx, rho in enumerate(rho_list):
    # 构建协方差矩阵
    cov = np.array([[sigma[0]**2, rho * sigma[0] * sigma[1]],
                    [rho * sigma[0] * sigma[1], sigma[1]**2]])
    
    # 最小化波动率（寻找最小方差组合 w1）
    def min_std(w1):
        w = np.array([w1, 1.0 - w1])
        return np.sqrt(np.dot(w.T, np.dot(cov, w)))
    
    # 无卖空限制，仅需一维优化，初始猜测在0.5
    res = minimize(min_std, 0.5, method='BFGS')
    w1_mvp = res.x[0]
    ret_mvp, std_mvp = portfolio_stats(w1_mvp, mu, cov)
    
    # 保存 rho = 0.45 时的最小方差组合波动率
    if abs(rho - 0.45) < 1e-12:
        result['mvp_vol_at_rho45'] = std_mvp
    
    # 绘制有效前沿：通过扫描权重并计算所有组合的收益/风险，然后选出有效边界
    w1_range = np.linspace(-2.5, 3.5, 800)  # 足够宽以包含卖空
    rets = []
    stds = []
    for w1 in w1_range:
        r, s = portfolio_stats(w1, mu, cov)
        rets.append(r)
        stds.append(s)
    rets = np.array(rets)
    stds = np.array(stds)
    
    # 确定有效前沿：对于每个波动率，取最大收益；并按波动率排序
    sorted_idx = np.argsort(stds)
    stds_sorted = stds[sorted_idx]
    rets_sorted = rets[sorted_idx]
    
    # 从低波动到高波动，保留收益递增的序列（有效边界）
    max_ret_so_far = -np.inf
    ef_stds = []
    ef_rets = []
    for i in range(len(stds_sorted)):
        if rets_sorted[i] > max_ret_so_far:
            ef_stds.append(stds_sorted[i])
            ef_rets.append(rets_sorted[i])
            max_ret_so_far = rets_sorted[i]
    
    ef_stds = np.array(ef_stds)
    ef_rets = np.array(ef_rets)
    
    # 绘制有效前沿
    ax.plot(ef_stds, ef_rets, color=colors[idx], label=f'ρ = {rho}')
    
    # 标记最小方差组合点
    ax.scatter(std_mvp, ret_mvp, color=colors[idx], marker=markers[idx],
               s=80, zorder=5, label=f'MVP (ρ={rho})')

# ------------------------------------------------------------
# 处理目标收益 10% 且 rho=0.45 时的最小波动率
# 我们需要求解权重使得收益 = 0.10 并最小化方差
rho_target = 0.45
cov_target = np.array([[sigma[0]**2, rho_target*sigma[0]*sigma[1]],
                      [rho_target*sigma[0]*sigma[1], sigma[1]**2]])
target_ret = 0.10

# 建立约束：收益必须等于目标收益且权重之和为1
cons = ({'type': 'eq', 'fun': lambda w: w[0]*mu[0] + w[1]*mu[1] - target_ret},
        {'type': 'eq', 'fun': lambda w: w[0] + w[1] - 1.0})

# 初始值（资产1权重设为0.5）
w0 = np.array([0.5, 0.5])

# 最小化方差 (0.5 * w'Σw)
def portfolio_variance(w):
    return np.dot(w.T, np.dot(cov_target, w))

opt = minimize(portfolio_variance, w0, constraints=cons, bounds=None)
w_opt = opt.x
ret_opt, vol_opt = portfolio_stats(w_opt[0], mu, cov_target)
# 注意 portfolio_stats 返回 (ret, std)，这里我们直接用最小化的方差开方
result['frontier_vol_at_target'] = vol_opt

# ------------------------------------------------------------
# 图形修饰
ax.set_xlabel('Annualized Volatility (σ)')
ax.set_ylabel('Expected Annual Return')
ax.set_title('Mean-Variance Efficient Frontiers')
ax.legend(loc='upper left')
ax.grid(True, linestyle='--', alpha=0.6)

# 保存图形
figure_path = os.path.join(os.getcwd(), 'efficient_frontiers.png')
plt.savefig(figure_path, dpi=150, bbox_inches='tight')
plt.show()  # 教师可能会直接显示图形

result['figure_path'] = figure_path

# ------------------------------------------------------------
# 输出结果
print("计算结果字典：")
print(result)

# 最终 result 字典包含：
# 'mvp_vol_at_rho45', 'frontier_vol_at_target', 'figure_path'
```

### 代码说明：

1. **参数设定**：以小数形式定义资产的年化收益率和波动率，以及三种相关系数。
2. **构建协方差矩阵**：依据每个相关系数以循环的方式构建协方差矩阵，并对权重进行扫描以获得全部组合的收益-风险数据集，再筛选出有效前沿。
3. **最小方差组合标识**：使用 `scipy.optimize.minimize` 求解使得组合标准差最小的权重，记下其收益与标准差，并标出点（对 $\rho=0.45$ 特地保存其波动率）。
4. **目标收益 10% 下的最小波动率**：通过带等式约束（收益=0.10，权重和=1）的优化求解器得到最小化方差时的权重组合，进而计算波动率存入结果。
5. **输出契约**：`result` 字典严格包含所需三个键，图形保存为本地文件。所有数值均为小数形式且自包含。

您可以直接在 Python 环境中执行此脚本。它将生成一幅图（三种颜色的前沿曲线及其最小方差组合点），并打印出字典，其中所有数值符合小数表示惯例。
