根据资本资产定价模型（CAPM），我们可以计算每只股票的预期收益（Expected Return, ER），公式为：

\[ ER = r_f + \beta \times (r_m - r_f) \]

其中：
- \( r_f \) = 无风险收益率 = 2.3%
- \( r_m \) = 市场收益率 = 9.4%
- \( \beta \) = 股票的贝塔系数

然后，计算Y股票的Alpha（α），公式为：

\[ \alpha = 实际收益 - 预期收益 \]

以下是计算过程：

1. 计算XYZ三只股票的预期收益：
   - 股票X的预期收益（β=0.62）：
     \[ ER_X = 2.3\% + 0.62 \times (9.4\% - 2.3\%) \]
   - 股票Y的预期收益（β=1.18）：
     \[ ER_Y = 2.3\% + 1.18 \times (9.4\% - 2.3\%) \]
   - 股票Z的预期收益（β=1.51）：
     \[ ER_Z = 2.3\% + 1.51 \times (9.4\% - 2.3\%) \]

2. 计算Y股票的Alpha：
   - Y的实际收益 = 13.1%
   - Y的预期收益 = ER_Y
   - Alpha = 实际收益 - 预期收益

计算结果存入 `result` 字典：

```python
result = {
    'er_x': 2.3 + 0.62 * (9.4 - 2.3),
    'er_y': 2.3 + 1.18 * (9.4 - 2.3),
    'er_z': 2.3 + 1.51 * (9.4 - 2.3),
    'alpha_y': 13.1 - (2.3 + 1.18 * (9.4 - 2.3))
}

# 计算具体数值（百分比形式）
result = {
    'er_x': round(2.3 + 0.62 * 7.1, 2),
    'er_y': round(2.3 + 1.18 * 7.1, 2),
    'er_z': round(2.3 + 1.51 * 7.1, 2),
    'alpha_y': round(13.1 - (2.3 + 1.18 * 7.1), 2)
}
```
