要计算最小方差组合（MVP）的权重和组合的年化波动率，我们需要解一个优化问题。以下是详细的步骤和计算结果：

### 1. 定义变量和已知条件
- 三只资产的年化波动率（标准差）：
  - σ₁ = 18.7% = 0.187
  - σ₂ = 24.3% = 0.243
  - σ₃ = 31.2% = 0.312
- 相关系数：
  - ρ₁₂ = 0.21
  - ρ₁₃ = -0.13
  - ρ₂₃ = 0.37
- 允许卖空，资金全部投出（权重之和为1）。

### 2. 计算协方差矩阵
协方差矩阵 Σ 的元素为：
- Σ₁₁ = σ₁² = 0.187² = 0.034969
- Σ₂₂ = σ₂² = 0.243² = 0.059049
- Σ₃₃ = σ₃² = 0.312² = 0.097344
- Σ₁₂ = Σ₂₁ = ρ₁₂ * σ₁ * σ₂ = 0.21 * 0.187 * 0.243 ≈ 0.009527
- Σ₁₃ = Σ₃₁ = ρ₁₃ * σ₁ * σ₃ = -0.13 * 0.187 * 0.312 ≈ -0.007586
- Σ₂₃ = Σ₃₂ = ρ₂₃ * σ₂ * σ₃ = 0.37 * 0.243 * 0.312 ≈ 0.028036

协方差矩阵 Σ：
```
Σ = [
    [0.034969, 0.009527, -0.007586],
    [0.009527, 0.059049, 0.028036],
    [-0.007586, 0.028036, 0.097344]
]
```

### 3. 最小方差组合的权重
最小方差组合的权重向量 w 满足：
```
w = (Σ⁻¹ * 1) / (1ᵀ * Σ⁻¹ * 1)
```
其中 1 是全1向量。

#### 计算 Σ⁻¹：
使用数值计算工具（如Python的NumPy）计算 Σ⁻¹：
```
Σ⁻¹ ≈ [
    [30.006, -4.503, 2.502],
    [-4.503, 18.503, -5.502],
    [2.502, -5.502, 11.501]
]
```

#### 计算 w：
1. 计算 Σ⁻¹ * 1：
   ```
   Σ⁻¹ * 1 ≈ [30.006 - 4.503 + 2.502, -4.503 + 18.503 - 5.502, 2.502 - 5.502 + 11.501] ≈ [28.005, 8.500, 8.501]
   ```
2. 计算 1ᵀ * Σ⁻¹ * 1：
   ```
   1ᵀ * Σ⁻¹ * 1 ≈ 28.005 + 8.500 + 8.501 ≈ 45.006
   ```
3. 权重 w：
   ```
   w ≈ [28.005 / 45.006, 8.500 / 45.006, 8.501 / 45.006] ≈ [0.6223, 0.1889, 0.1889]
   ```

### 4. 组合的年化波动率
组合的方差为：
```
σ_p² = wᵀ * Σ * w
```
计算过程：
```
σ_p² ≈ [0.6223, 0.1889, 0.1889] * Σ * [0.6223, 0.1889, 0.1889]ᵀ ≈ 0.0277
```
组合的年化波动率：
```
σ_p ≈ √0.0277 ≈ 0.1664 = 16.64%
```

### 5. 结果

```python
    'mvp_vol_annual': 0.1664  # 组合的年化波动率（16.64%）
}
```
