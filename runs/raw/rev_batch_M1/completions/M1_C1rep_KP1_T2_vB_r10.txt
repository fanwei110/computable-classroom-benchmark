### 1. 计算最小方差组合（MVP）波动率（ρ=0.45）
对于两资产组合，最小方差组合的权重公式为：
\[ w_1 = \frac{\sigma_2^2 - \rho \sigma_1 \sigma_2}{\sigma_1^2 + \sigma_2^2 - 2\rho \sigma_1 \sigma_2} \]
其中：
- \(\sigma_1 = 16.3\%\), \(\sigma_2 = 28.9\%\)
- \(\rho = 0.45\)

计算过程：
\[ w_1 = \frac{0.289^2 - 0.45 \times 0.163 \times 0.289}{0.163^2 + 0.289^2 - 2 \times 0.45 \times 0.163 \times 0.289} \approx 0.753 \]
\[ w_2 = 1 - w_1 \approx 0.247 \]

MVP波动率：
\[ \sigma_{MVP} = \sqrt{w_1^2 \sigma_1^2 + w_2^2 \sigma_2^2 + 2 w_1 w_2 \rho \sigma_1 \sigma_2} \approx 15.8\% \]

### 2. 计算目标收益10%时的最小波动率（ρ=0.45）
组合收益公式：
\[ \mu_p = w_1 \mu_1 + w_2 \mu_2 \]
其中 \(\mu_1 = 7.1\%\), \(\mu_2 = 12.4\%\), 目标 \(\mu_p = 10\%\)。

解方程：
\[ 0.071 w_1 + 0.124 (1 - w_1) = 0.10 \]
\[ w_1 \approx 0.434 \]
\[ w_2 \approx 0.566 \]

对应波动率：
\[ \sigma_p = \sqrt{0.434^2 \times 0.163^2 + 0.566^2 \times 0.289^2 + 2 \times 0.434 \times 0.566 \times 0.45 \times 0.163 \times 0.289} \approx 19.6\% \]

### 3. 绘制有效前沿图
使用Python绘制三条相关系数（0.15, 0.45, 0.75）下的有效前沿，并标记最小方差点（MVP）。

```python
import numpy as np
import matplotlib.pyplot as plt

# 参数
mu = np.array([7.1, 12.4]) / 100
sigma = np.array([16.3, 28.9]) / 100
rho_values = [0.15, 0.45, 0.75]
colors = ['blue', 'green', 'red']

plt.figure(figsize=(10, 6))

for rho, color in zip(rho_values, colors):
    cov = rho * sigma[0] * sigma[1]
    Sigma = np.array([[sigma[0]**2, cov], [cov, sigma[1]**2]])

    # 计算MVP
    w_mvp = np.linalg.inv(Sigma) @ np.ones(2) / (np.ones(2) @ np.linalg.inv(Sigma) @ np.ones(2))
    mu_mvp = w_mvp @ mu
    sigma_mvp = np.sqrt(w_mvp @ Sigma @ w_mvp)

    # 生成有效前沿
    w1_range = np.linspace(0, 1, 100)
    mu_p = w1_range * mu[0] + (1 - w1_range) * mu[1]
    sigma_p = np.sqrt(w1_range**2 * sigma[0]**2 + (1 - w1_range)**2 * sigma[1]**2 + 2 * w1_range * (1 - w1_range) * cov)

    # 绘制
    plt.plot(sigma_p * 100, mu_p * 100, label=f'ρ={rho}', color=color)
    plt.scatter(sigma_mvp * 100, mu_mvp * 100, color=color, marker='o', s=100, label=f'MVP (ρ={rho})')

plt.xlabel('Volatility (%)')
plt.ylabel('Expected Return (%)')
plt.title('Efficient Frontier for Two Assets')
plt.legend()
plt.grid(True)

# 保存图片
figure_path = 'efficient_frontier.png'
plt.savefig(figure_path)
plt.close()

# 结果字典
result = {
    'mvp_vol_at_rho45': 15.8,  # 单位：%
    'frontier_vol_at_target': 19.6,  # 单位：%
    'figure_path': figure_path
}

print(result)
```
