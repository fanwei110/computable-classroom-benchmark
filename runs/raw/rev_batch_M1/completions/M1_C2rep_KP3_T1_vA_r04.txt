以下是自包含的 Python 脚本，计算债券的价格、麦考利久期、修正久期和凸性：

```python
import numpy as np
from scipy.optimize import newton

# 债券参数
face_value = 100.0
coupon_rate = 0.046
years_to_maturity = 7
ytm = 0.053  # 到期收益率
coupon_payment = face_value * coupon_rate
periods_per_year = 1  # 假设每年付息一次
total_periods = years_to_maturity * periods_per_year

# 1. 计算债券价格（现金流贴现之和）
def bond_price(yield_to_maturity):
    cash_flows = np.array([coupon_payment] * (total_periods - 1) + [coupon_payment + face_value])
    discount_factors = np.array([(1 + yield_to_maturity) ** (-t) for t in range(1, total_periods + 1)])
    return np.sum(cash_flows * discount_factors)

price = bond_price(ytm)

# 2. 计算麦考利久期和修正久期
def macaulay_duration(yield_to_maturity):
    cash_flows = np.array([coupon_payment] * (total_periods - 1) + [coupon_payment + face_value])
    times = np.arange(1, total_periods + 1)
    discount_factors = np.array([(1 + yield_to_maturity) ** (-t) for t in times])
    discounted_cash_flows = cash_flows * discount_factors
    weighted_times = times * discounted_cash_flows
    return np.sum(weighted_times) / price

macaulay_duration_years = macaulay_duration(ytm) / periods_per_year
modified_duration_years = macaulay_duration_years / (1 + ytm / periods_per_year)

# 3. 计算凸性
def convexity(yield_to_maturity):
    cash_flows = np.array([coupon_payment] * (total_periods - 1) + [coupon_payment + face_value])
    times = np.arange(1, total_periods + 1)
    discount_factors = np.array([(1 + yield_to_maturity) ** (-t) for t in times])
    discounted_cash_flows = cash_flows * discount_factors
    weighted_times = times * (times + 1) * discounted_cash_flows
    return np.sum(weighted_times) / (price * (1 + yield_to_maturity) ** 2)

convexity_value = convexity(ytm) / (periods_per_year ** 2)

# 4. 填充结果字典
result = {
    'price': round(price, 4),
    'macaulay_duration_years': round(macaulay_duration_years, 4),
    'modified_duration_years': round(modified_duration_years, 4),
    'convexity': round(convexity_value, 4)
}

print(result)
```

输出结果将存储在 `result` 字典中，包含以下键值对：
- `price`: 债券价格（保留4位小数）
- `macaulay_duration_years`: 麦考利久期（年）
- `modified_duration_years`: 修正久期（年）
- `convexity`: 凸性（年²）

运行此脚本将得到确定可复现的结果，且不依赖外部网络或占位值。假设每年付息一次（`periods_per_year = 1`），与题目描述一致。
