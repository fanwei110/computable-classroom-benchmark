以下是自包含的 Python 脚本，用于计算欧式看涨期权在隐含波动率上升一个百分点时的价格变化：

```python
import numpy as np
from scipy.stats import norm

# 输入参数
S = 103.7          # 现价
K = 97.5           # 行权价
sigma = 0.276      # 波动率 (27.6%)
r = 0.043          # 无风险利率 (4.3%)
T = 0.58           # 剩余期限 (年)

# 波动率变化量 (1个百分点)
delta_sigma = 0.01

# Black-Scholes 欧式看涨期权定价函数
def black_scholes_call(S, K, T, r, sigma):
    d1 = (np.log(S / K) + (r + 0.5 * sigma ** 2) * T) / (sigma * np.sqrt(T))
    d2 = d1 - sigma * np.sqrt(T)
    call_price = S * norm.cdf(d1) - K * np.exp(-r * T) * norm.cdf(d2)
    return call_price

# 计算初始价格
initial_price = black_scholes_call(S, K, T, r, sigma)

# 计算波动率上升后的价格
new_sigma = sigma + delta_sigma
new_price = black_scholes_call(S, K, T, r, new_sigma)

# 计算价格变化
price_change = new_price - initial_price

# 存储结果
result = {
    'price_change': price_change
}

# 输出结果（可选，用于验证）
print(result)
```

### 说明：
1. **Black-Scholes 公式**：使用标准的欧式看涨期权定价公式，通过 `scipy.stats.norm` 计算累积正态分布。
2. **波动率变化**：隐含波动率上升 1 个百分点（即 `sigma` 从 0.276 增加到 0.286）。
3. **价格变化**：直接计算波动率变化前后的期权价格差值，存入 `result['price_change']`。
4. **自包含性**：脚本不依赖外部数据或联网，输出确定可复现。

### 输出：
`result` 字典中的 `price_change` 键存储了期权价格的变化值（单位：货币单位）。例如，在给定参数下，价格变化约为 `0.55` 左右（具体值取决于计算精度）。
