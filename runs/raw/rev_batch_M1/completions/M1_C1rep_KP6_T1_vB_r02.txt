### 2. 归因分析（Brummer & Brunner 模型）
给定数据：
- 组合权重：[0.45, 0.35, 0.2]
- 行业收益：[8.3%, 2.1%, -1.4%]
- 基准权重：[0.4, 0.4, 0.2]
- 基准收益：[6.7%, 3.4%, -0.9%]

#### 计算步骤：
1. **组合总收益**：
   \[
   R_p = \sum (w_i \times r_i) = 0.45 \times 8.3\% + 0.35 \times 2.1\% + 0.2 \times (-1.4\%) = 3.735\% + 0.735\% - 0.28\% = 4.19\%
   \]
2. **基准总收益**：
   \[
   R_b = \sum (W_i \times R_i) = 0.4 \times 6.7\% + 0.4 \times 3.4\% + 0.2 \times (-0.9\%) = 2.68\% + 1.36\% - 0.18\% = 3.86\%
   \]
3. **超额收益**：
   \[
   \Delta R = R_p - R_b = 4.19\% - 3.86\% = 0.33\%
   \]
4. **配置效应（Allocation Effect）**：
   \[
   \text{Allocation Effect} = \sum \left( (w_i - W_i) \times (R_i - R_b) \right)
   \]
   计算：
   \[
   (0.45 - 0.4) \times (6.7\% - 3.86\%) = 0.05 \times 2.84\% = 0.142\%
   \]
   \[
   (0.35 - 0.4) \times (3.4\% - 3.86\%) = -0.05 \times (-0.46\%) = 0.023\%
   \]
   \[
   (0.2 - 0.2) \times (-0.9\% - 3.86\%) = 0 \times (-4.76\%) = 0\%
   \]
   总和：
   \[
   0.142\% + 0.023\% + 0 = 0.165\%
   \]
5. **选择效应（Selection Effect）**：
   \[
   \text{Selection Effect} = \sum \left( W_i \times (r_i - R_i) \right)
   \]
   计算：
   \[
   0.4 \times (8.3\% - 6.7\%) = 0.4 \times 1.6\% = 0.64\%
   \]
   \[
   0.4 \times (2.1\% - 3.4\%) = 0.4 \times (-1.3\%) = -0.52\%
   \]
   \[
   0.2 \times (-1.4\% - (-0.9\%)) = 0.2 \times (-0.5\%) = -0.1\%
   \]
   总和：
   \[
   0.64\% - 0.52\% - 0.1\% = 0.02\%
   \]
6. **交互效应（Interaction Effect）**：
   \[
   \text{Interaction Effect} = \sum \left( (w_i - W_i) \times (r_i - R_i) \right)
   \]
   计算：
   \[
   (0.45 - 0.4) \times (8.3\% - 6.7\%) = 0.05 \times 1.6\% = 0.08\%
   \]
   \[
   (0.35 - 0.4) \times (2.1\% - 3.4\%) = -0.05 \times (-1.3\%) = 0.065\%
   \]
   \[
   (0.2 - 0.2) \times (-1.4\% - (-0.9\%)) = 0 \times (-0.5\%) = 0\%
   \]
   总和：
   \[
   0.08\% + 0.065\% + 0 = 0.145\%
   \]
7. **验证**：
   \[
   \text{Allocation} + \text{Selection} + \text{Interaction} = 0.165\% + 0.02\% + 0.145\% = 0.33\% = \Delta R
