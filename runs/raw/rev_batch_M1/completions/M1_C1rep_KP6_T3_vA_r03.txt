要计算整个样本的年化夏普比率（Sharpe Ratio），我们需要按照以下步骤进行：

1. **计算超额收益率**：每期收益率减去无风险利率（2.1%）。
2. **计算超额收益率的均值和标准差**：样本内的超额收益率的均值和标准差。
3. **年化夏普比率**：
   - 均值年化：如果数据是月度数据，乘以12；如果是日度数据，乘以252（假设交易日）。
   - 标准差年化：如果数据是月度数据，乘以√12；如果是日度数据，乘以√252。
   - 年化夏普比率 = (年化均值) / (年化标准差)

假设 `fund` 是一个包含基金收益率的序列（例如月度或日度），以下是计算代码：

```python
import numpy as np

# 假设 fund 是一个 pandas Series，包含基金的收益率数据
# 无风险利率
risk_free_rate = 0.021

# 计算超额收益率
excess_returns = fund - risk_free_rate / 12  # 如果是月度数据，无风险利率也要调整为月度

# 计算超额收益率的均值和标准差
mean_excess_return = excess_returns.mean()
std_excess_return = excess_returns.std()

# 年化夏普比率
# 假设数据是月度数据，年化因子为12（均值）和 sqrt(12)（标准差）
annualized_sharpe = (mean_excess_return * 12) / (std_excess_return * np.sqrt(12))

# 存入结果字典
result = {
    'sharpe_annual': annualized_sharpe
}
```

如果 `fund` 是日度数据，将年化因子改为252和√252：
```python
annualized_sharpe = (mean_excess_return * 252) / (std_excess_return * np.sqrt(252))
```

最终 `result` 字典将包含年化夏普比率。
