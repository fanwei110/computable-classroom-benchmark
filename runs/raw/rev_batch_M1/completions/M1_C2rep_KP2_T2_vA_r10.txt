以下是自包含的 Python 脚本，满足所有要求：

```python
import numpy as np
import matplotlib.pyplot as plt
import os

# 参数设定
risk_free_rate = 0.023  # 无风险利率 2.3%
market_return = 0.094   # 市场期望收益 9.4%

# 证券市场线 (SML) 函数
def calculate_sml_return(beta, risk_free_rate, market_return):
    return risk_free_rate + beta * (market_return - risk_free_rate)

# 计算 SML 斜率
sml_slope = market_return - risk_free_rate

# 计算 beta=1.27 处的期望收益
beta_127 = 1.27
er_at_beta_127 = calculate_sml_return(beta_127, risk_free_rate, market_return)

# 生成 beta 从 0 到 2 的 SML 数据
betas = np.linspace(0, 2, 100)
sml_returns = calculate_sml_return(betas, risk_free_rate, market_return)

# 股票数据
stocks = {
    'X': {'beta': 0.62, 'return': 0.081},
    'Y': {'beta': 1.18, 'return': 0.131},
    'Z': {'beta': 1.51, 'return': 0.099}
}

# 绘图
plt.figure(figsize=(10, 6))
plt.plot(betas, sml_returns, label='Security Market Line', color='blue')

# 绘制股票点
for stock, data in stocks.items():
    plt.scatter(data['beta'], data['return'], label=f'Stock {stock}', s=100)
    plt.annotate(stock, (data['beta'] + 0.02, data['return'] - 0.005))

# 标记无风险利率点
plt.scatter(0, risk_free_rate, color='red', label='Risk-free Rate', s=100)
plt.annotate('RF', (0.02, risk_free_rate - 0.005))

# 标记市场组合点
plt.scatter(1, market_return, color='green', label='Market Portfolio', s=100)
plt.annotate('M', (1.02, market_return - 0.005))

# 图形设置
plt.title('Security Market Line (SML) with Stocks X, Y, Z')
plt.xlabel('Beta (β)')
plt.ylabel('Expected Return')
plt.xlim(0, 2)
plt.ylim(0, 0.15)
plt.grid(True)
plt.legend()

# 保存图形
figure_path = 'sml_plot.png'
plt.savefig(figure_path)
plt.close()

# 准备结果
result = {
    'sml_slope': sml_slope,
    'er_at_beta_127': er_at_beta_127,
    'figure_path': os.path.abspath(figure_path)
}

# 输出结果（供教师使用）
print(result)
```

这个脚本将：
1. 绘制 beta 从 0 到 2 的证券市场线（SML）
2. 将无风险利率和市场收益参数化
3. 在图上标出股票 X、Y、Z 的点
4. 计算并报告 SML 的斜率（市场风险溢价）
5. 计算 beta=1.27 处的 CAPM 期望收益
6. 将图形保存为文件并将所有结果存入 result 字典

输出的 result 字典包含：
- 'sml_slope': SML 的斜率（市场风险溢价）
- 'er_at_beta_127': beta=1.27 处的期望收益
- 'figure_path': 保存的图形文件的绝对路径

图形会显示 SML 线、三只股票的位置、无风险利率点和市场组合点，并有适当的标注和图例。
