**如果题目意图是直接给出年化无风险利率 `rf = 2.1%`，且假设 `fund` 的年化收益率和年化波动率已知（但未给出），则无法计算夏普比率。**

### 2. 归因分析（Brinson Model）
给定数据：
- 组合权重：`w_p = [0.45, 0.35, 0.2]`
- 行业收益：`r_p = [8.3%, 2.1%, -1.4%]`
- 基准权重：`w_b = [0.4, 0.4, 0.2]`
- 基准收益：`r_b = [6.7%, 3.4%, -0.9%]`

#### 计算步骤：
1. **总超额收益（Active Return）**：
   \[
   R_p = \sum w_p \cdot r_p = 0.45 \times 8.3\% + 0.35 \times 2.1\% + 0.2 \times (-1.4\%) = 3.735\% + 0.735\% - 0.28\% = 4.19\%
   \]
   \[
   R_b = \sum w_b \cdot r_b = 0.4 \times 6.7\% + 0.4 \times 3.4\% + 0.2 \times (-0.9\%) = 2.68\% + 1.36\% - 0.18\% = 3.86\%
   \]
   \[
   \text{Active Return} = R_p - R_b = 4.19\% - 3.86\% = 0.33\%
   \]

2. **配置效应（Allocation Effect）**：
   \[
   \text{Allocation} = \sum (w_p - w_b) \cdot r_b = (0.45-0.4) \times 6.7\% + (0.35-0.4) \times 3.4\% + (0.2-0.2) \times (-0.9\%) = 0.05 \times 6.7\% - 0.05 \times 3.4\% + 0 = 0.335\% - 0.17\% = 0.165\%
   \]

3. **选择效应（Selection Effect）**：
   \[
   \text{Selection} = \sum w_b \cdot (r_p - r_b) = 0.4 \times (8.3\%-6.7\%) + 0.4 \times (2.1\%-3.4\%) + 0.2 \times (-1.4\% - (-0.9\%)) = 0.4 \times 1.6\% + 0.4 \times (-1.3\%) + 0.2 \times (-0.5\%) = 0.64\% - 0.52\% - 0.1\% = 0.02\%
   \]

4. **交互效应（Interaction Effect）**：
   \[
   \text{Interaction} = \sum (w_p - w_b) \cdot (r_p - r_b) = (0.45-0.4) \times (8.3\%-6.7\%) + (0.35-0.4) \times (2.1\%-3.4\%) + (0.2-0.2) \times (-1.4\% - (-0.9\%)) = 0.05 \times 1.6\% - 0.05 \times (-1.3\%) + 0 = 0.08\% + 0.065\% = 0.145\%
   \]

5. **验证**：
   \[
   \text{Allocation} + \text{Selection} + \text{Interaction} = 0.165\% + 0.02\% + 0.145\% = 0.33\% = \text{Active Return}
   \]
   验证通过。
