以下是自包含的 Python 脚本，计算债券的价格、麦考利久期、修正久期和凸性：

```python
import numpy as np
from scipy.optimize import newton

# 债券参数
face_value = 100.0
coupon_rate = 0.046
years_to_maturity = 7
ytm = 0.053  # 到期收益率
periods_per_year = 1  # 假设每年付息一次（年度付息债券）

# 计算票息支付额
coupon_payment = face_value * coupon_rate

# 生成现金流
cash_flows = np.full(years_to_maturity, coupon_payment)
cash_flows[-1] += face_value  # 最后一期包含本金

# 1. 计算价格（现金流贴现之和）
def bond_price(yield_to_maturity):
    periods = np.arange(1, years_to_maturity + 1)
    discounted_cash_flows = cash_flows / ((1 + yield_to_maturity) ** periods)
    return np.sum(discounted_cash_flows)

price = bond_price(ytm)

# 2. 计算麦考利久期和修正久期
def macaulay_duration(yield_to_maturity):
    periods = np.arange(1, years_to_maturity + 1)
    discounted_cash_flows = cash_flows / ((1 + yield_to_maturity) ** periods)
    weighted_cash_flows = periods * discounted_cash_flows
    return np.sum(weighted_cash_flows) / price

macaulay_duration_years = macaulay_duration(ytm) / periods_per_year
modified_duration_years = macaulay_duration_years / (1 + ytm / periods_per_year)

# 3. 计算凸性
def convexity(yield_to_maturity):
    periods = np.arange(1, years_to_maturity + 1)
    discounted_cash_flows = cash_flows / ((1 + yield_to_maturity) ** periods)
    weighted_cash_flows = periods * (periods + 1) * discounted_cash_flows
    return np.sum(weighted_cash_flows) / (price * (1 + yield_to_maturity) ** 2)

convexity_value = convexity(ytm) / (periods_per_year ** 2)

# 4. 填充结果字典
result = {
    'price': price,
    'macaulay_duration_years': macaulay_duration_years,
    'modified_duration_years': modified_duration_years,
    'convexity': convexity_value
}

# 输出结果（可选，用于验证）
print(result)
```

### 说明：
1. **价格计算**：通过将每期现金流按到期收益率贴现后求和得到债券价格。
2. **麦考利久期**：现金流的加权平均期限，权重为贴现后的现金流占价格的比例。
3. **修正久期**：麦考利久期除以 (1 + ytm/付息频率)，衡量价格对收益率变动的敏感性。
4. **凸性**：现金流的二阶加权平均期限，反映价格对收益率变动的非线性敏感性。
