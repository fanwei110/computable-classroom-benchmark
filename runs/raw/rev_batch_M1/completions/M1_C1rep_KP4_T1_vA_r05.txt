我们可以使用 Black-Scholes 模型为这只欧式看涨期权定价，并计算 Delta 和 Vega。以下是计算步骤和结果：

### 输入参数：
- 标的现价 \( S = 103.7 \)
- 行权价 \( K = 97.5 \)
- 隐含波动率 \( \sigma = 27.6\% = 0.276 \)
- 无风险利率 \( r = 4.3\% = 0.043 \)
- 剩余到期时间 \( T = 0.58 \) 年
- 不分红（\( q = 0 \)）

### 计算步骤：
1. **计算 \( d_1 \) 和 \( d_2 \)：**
   \[
   d_1 = \frac{\ln(S/K) + (r - q + \sigma^2/2)T}{\sigma \sqrt{T}}
   \]
   \[
   d_2 = d_1 - \sigma \sqrt{T}
   \]

2. **计算看涨期权价格（Call Price）：**
   \[
   C = S e^{-qT} N(d_1) - K e^{-rT} N(d_2)
   \]
   其中 \( N(\cdot) \) 是标准正态分布的累积分布函数（CDF）。

3. **计算 Delta：**
   \[
   \Delta_{\text{call}} = e^{-qT} N(d_1)
   \]

4. **计算 Vega：**
   \[
   \text{Vega} = S e^{-qT} \sqrt{T} N'(d_1)
   \]
   其中 \( N'(d_1) \) 是标准正态分布的概率密度函数（PDF）。

### Python 代码实现：
```python
import numpy as np
from scipy.stats import norm

# 输入参数
S = 103.7
K = 97.5
sigma = 0.276
r = 0.043
T = 0.58
q = 0.0  # 不分红

# 计算 d1 和 d2
d1 = (np.log(S / K) + (r - q + 0.5 * sigma ** 2) * T) / (sigma * np.sqrt(T))
d2 = d1 - sigma * np.sqrt(T)

# 计算看涨期权价格
call_price = S * np.exp(-q * T) * norm.cdf(d1) - K * np.exp(-r * T) * norm.cdf(d2)

# 计算 Delta
call_delta = np.exp(-q * T) * norm.cdf(d1)

# 计算 Vega
call_vega = S * np.exp(-q * T) * np.sqrt(T) * norm.pdf(d1) * 0.01  # 单位为每1%波动率变化

# 存入结果字典
result = {
    'call_price': call_price,
    'call_delta': call_delta,
    'call_vega': call_vega
}

print(result)
```
