以下是自包含的 Python 脚本，用于计算欧式看涨期权的价格、delta 和 vega：

```python
import numpy as np
from scipy.stats import norm

# 输入参数
S = 103.7          # 标的资产现价
K = 97.5           # 行权价
sigma = 0.276      # 隐含波动率（年化）
r = 0.043          # 无风险利率（年化）
T = 0.58           # 剩余期限（年）

# 1. 计算 d1 和 d2
d1 = (np.log(S / K) + (r + 0.5 * sigma ** 2) * T) / (sigma * np.sqrt(T))
d2 = d1 - sigma * np.sqrt(T)

# 2. 计算期权价格和 delta
call_price = S * norm.cdf(d1) - K * np.exp(-r * T) * norm.cdf(d2)
call_delta = norm.cdf(d1)

# 3. 计算 vega（注意：vega 的单位是每 1% 波动率变化对应的价格变化）
call_vega = S * norm.pdf(d1) * np.sqrt(T) * 0.01  # 乘以 0.01 将单位转换为每 1% 波动率变化

# 4. 填充 result 字典
result = {
    'call_price': call_price,
    'call_delta': call_delta,
    'call_vega': call_vega
}

# 输出结果（可选，便于调试）
print(result)
```

### 说明：
1. **d1 和 d2**：Black-Scholes 公式中的中间变量，用于计算期权价格和希腊字母。
2. **期权价格**：使用 Black-Scholes 闭式解计算欧式看涨期权的价格。
3. **Delta**：看涨期权的 delta 是 `N(d1)`，即标的资产价格变化对期权价格的敏感度。
4. **Vega**：计算公式为 `S * N'(d1) * sqrt(T)`，其中 `N'(d1)` 是标准正态分布的概率密度函数。乘以 `0.01` 是为了将单位转换为每 1% 波动率变化对应的价格变化（业界惯例）。
5. **结果**：所有结果存储在 `result` 字典中，键名严格符合要求。

运行该脚本将输出确定可复现的结果。
