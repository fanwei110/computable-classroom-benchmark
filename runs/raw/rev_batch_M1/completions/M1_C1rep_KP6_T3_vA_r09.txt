要计算整个样本的年化夏普比率（Sharpe Ratio），我们需要按照以下步骤进行：

1. **计算超额收益**：基金的每日收益率减去无风险利率（2.1% 年化，转换为每日无风险利率）。
2. **计算超额收益的均值和标准差**：基于超额收益序列。
3. **年化夏普比率**：将超额收益的均值和标准差年化（均值乘以252，标准差乘以√252），然后用年化均值除以年化标准差。

假设 `fund` 是一个包含基金每日收益率的 pandas Series，以下是计算代码：

```python
import numpy as np

# 无风险利率（年化）
risk_free_rate_annual = 0.021

# 将年化无风险利率转换为每日无风险利率
risk_free_rate_daily = (1 + risk_free_rate_annual) ** (1/252) - 1

# 计算超额收益（每日收益率 - 每日无风险利率）
excess_returns = fund - risk_free_rate_daily

# 计算超额收益的均值和标准差
mean_excess_return = excess_returns.mean()
std_excess_return = excess_returns.std()

# 年化夏普比率
sharpe_annual = (mean_excess_return * 252) / (std_excess_return * np.sqrt(252))

# 存入结果字典
result = {
    'sharpe_annual': sharpe_annual
}
```

### 注意事项：
1. 确保 `fund` 是一个包含每日收益率的 pandas Series（例如 `fund = df['daily_return']`）。
2. 如果 `fund` 是累计收益率或其他形式，需要先转换为每日收益率。
3. 如果样本期间不是完整的252个交易日，可以调整年化因子（如 `np.sqrt(len(excess_returns))` 替代 `np.sqrt(252)`）。

最终结果会存入 `result` 字典中，键为 `'sharpe_annual'`。
