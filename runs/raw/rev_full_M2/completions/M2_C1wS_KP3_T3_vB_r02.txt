下面给出一个完整的 Python 脚本，按照题目要求计算债券在当前收益率下的利率敏感性（修正久期、凸性），并用二阶近似估计收益率上升 80 个基点时的价格跌幅百分比。最后将结果存入 `result` 字典。

```python
import numpy as np

# ==================== 债券参数 ====================
face_value = 100.0            # 面值
coupon_rate = 0.046           # 票面利率（年化）
ytm = 0.053                  # 当前到期收益率（年化）
maturity = 7                 # 剩余年限
freq = 1                     # 付息频率（1 = 年付息，假设年付息）
delta_y = 0.008              # 收益率变动：80 bp

# ==================== 现金流生成 ====================
# 时间点（年）：第1年到第maturity年
periods = np.arange(1, maturity + 1, dtype=float)
coupon = face_value * coupon_rate
cash_flows = np.full(maturity, coupon)
cash_flows[-1] += face_value  # 最后一期归还本金

# ==================== 价格计算函数 ====================
def bond_price(ytm_now):
    """给定到期收益率，计算债券价格"""
    disc = 1 / (1 + ytm_now / freq) ** (periods * freq)
    return np.sum(cash_flows * disc)

price0 = bond_price(ytm)

# ==================== 久期与凸性计算 ====================
# 麦考利久期
pv_cf = cash_flows / (1 + ytm) ** periods
mac_duration = np.sum(periods * pv_cf) / price0

# 修正久期（年付息时 freq=1）
mod_duration = mac_duration / (1 + ytm / freq)

# 凸性（二阶修正用）
# Convexity = 1/P * sum( t*(t+1)*CF / (1+y)^(t+2) )
convexity = np.sum(periods * (periods + 1) * pv_cf / (1 + ytm) ** 2) / price0

# ==================== 价格跌幅估计（二阶近似） ====================
# ΔP/P ≈ -ModDuration * Δy + 0.5 * Convexity * (Δy)^2
delta_p_pct_approx = -mod_duration * delta_y + 0.5 * convexity * delta_y ** 2
# 跌幅为正数百分比
price_drop_pct_approx = -delta_p_pct_approx * 100

# ==================== 精确价格跌幅（用于验证） ====================
price1 = bond_price(ytm + delta_y)
price_drop_pct_exact = (price0 - price1) / price0 * 100

# ==================== 输出结果 ====================
result = {
    'price_drop_pct': round(price_drop_pct_approx, 6)   # 使用近似估计值作为题目要求的输出
}

# 投屏时显示详细信息
print(f"当前收益率: {ytm*100:.2f}%")
print(f"当前价格: {price0:.6f}")
print(f"麦考利久期: {mac_duration:.6f} 年")
print(f"修正久期: {mod_duration:.6f}")
print(f"凸性: {convexity:.6f}")
print(f"收益率上升 {delta_y*100:.0f} bp 后:")
print(f"  近似价格跌幅: {price_drop_pct_approx:.4f}%")
print(f"  精确价格跌幅: {price_drop_pct_exact:.4f}%")
print("\n最终 result 字典:")
print(result)
```

**输出结果说明：**  
- `result['price_drop_pct']` 是使用修正久期与凸性进行二阶近似估计的价格跌幅百分比。  
- 若需采用精确重定价结果，可将最后一处改为 `'price_drop_pct': round(price_drop_pct_exact, 6)`，但题目明确要求“估算”，因此默认提供二阶近似值。  
- 运行结果确定、可复现，无任何占位值或外部依赖。
