以下脚本使用年付息一次假设进行定价与风险指标计算，并将结果存入 `result` 字典。

```python
import numpy as np

# 债券参数
face_value = 100.0
coupon_rate = 0.046       # 票面利率（年化）
maturity = 7              # 期限（年）
ytm = 0.053               # 到期收益率（年化）

# 付息频率设为每年一次（题目未指定，按惯例默认年付息）
times = np.arange(1, maturity + 1)  # 现金流发生时间：1,2,...,7 年
coupon = face_value * coupon_rate

# 构造各期现金流（最后一期包含本金）
cash_flows = np.full(maturity, coupon)
cash_flows[-1] += face_value

# 贴现因子与现金流现值
discount_factors = (1 + ytm) ** times
present_values = cash_flows / discount_factors

# 1. 债券价格
price = np.sum(present_values)

# 2. 麦考利久期（加权平均时间）
weighted_times = np.sum(times * present_values)
macaulay_duration = weighted_times / price

# 3. 修正久期
modified_duration = macaulay_duration / (1 + ytm)

# 4. 凸性（使用离散年复利下的定义）
# 公式：Convexity = Σ[ t*(t+1)*PV(t) ] / [ P * (1+y)^2 ]
convexity = np.sum(times * (times + 1) * present_values) / (price * (1 + ytm)**2)

# 按要求输出字典
result = {
    'price': price,
    'macaulay_duration_years': macaulay_duration,
    'modified_duration_years': modified_duration,
    'convexity': convexity
}

print(result)
```
