根据资本资产定价模型（CAPM），计算公式为：
$E(R_i) = R_f + \beta_i \times (E(R_m) - R_f)$

已知数据：
*   无风险利率 $R_f = 2.3\% = 0.023$
*   市场预期收益率 $E(R_m) = 9.4\% = 0.094$
*   市场风险溢价 $E(R_m) - R_f = 9.4\% - 2.3\% = 7.1\% = 0.071$
*   Y的实际收益率 $R_y = 13.1\% = 0.131$

计算各股票的预期收益率：
1. **X股票的预期收益率**：
   $E(R_x) = 2.3\% + 0.62 \times 7.1\% = 2.3\% + 4.402\% = 6.702\% = 0.06702$

2. **Y股票的预期收益率**：
   $E(R_y) = 2.3\% + 1.18 \times 7.1\% = 2.3\% + 8.378\% = 10.678\% = 0.10678$

3. **Z股票的预期收益率**：
   $E(R_z) = 2.3\% + 1.51 \times 7.1\% = 2.3\% + 10.721\% = 13.021\% = 0.13021$

4. **Y股票的Alpha值**（实际收益率 - CAPM预期收益率）：
   $\alpha_y = 13.1\% - 10.678\% = 2.422\% = 0.02422$
