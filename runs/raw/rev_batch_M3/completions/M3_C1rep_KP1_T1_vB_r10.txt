为了计算最小方差组合（Minimum Variance Portfolio, MVP），我们需要求解以下优化问题：
最小化组合方差 $\min \mathbf{w}^T \Sigma \mathbf{w}$
约束条件 $\mathbf{w}^T \mathbf{1} = 1$（资金全投出去，权重之和为1）

在允许做空的情况下，最小方差组合的权重有解析解：
$$\mathbf{w}_{mvp} = \frac{\Sigma^{-1} \mathbf{1}}{\mathbf{1}^T \Sigma^{-1} \mathbf{1}}$$
组合的方差为 $\sigma_{mvp}^2 = \frac{1}{\mathbf{1}^T \Sigma^{-1} \mathbf{1}}$

**1. 构建协方差矩阵 $\Sigma$**
将波动率转换为小数：$\sigma_1 = 0.187, \sigma_2 = 0.243, \sigma_3 = 0.312$
- $\Sigma_{11} = 0.187^2 = 0.034969$
- $\Sigma_{22} = 0.243^2 = 0.059049$
- $\Sigma_{33} = 0.312^2 = 0.097344$
- $\Sigma_{12} = \Sigma_{21} = 0.21 \times 0.187 \times 0.243 = 0.00954981$
- $\Sigma_{13} = \Sigma_{31} = -0.13 \times 0.187 \times 0.312 = -0.00759072$
- $\Sigma_{23} = \Sigma_{32} = 0.37 \times 0.243 \times 0.312 = 0.02805432$

**2. 计算协方差矩阵的逆矩阵 $\Sigma^{-1}$ 及相关向量**
利用矩阵求逆公式计算 $\Sigma^{-1}$，然后计算 $\Sigma^{-1} \mathbf{1}$ 和 $\mathbf{1}^T \Sigma^{-1} \mathbf{1}$：
$\Sigma^{-1} \mathbf{1} = [28.8531, 7.3132, 10.4048]^T$
$\mathbf{1}^T \Sigma^{-1} \mathbf{1} = 28.8531 + 7.3132 + 10.4048 = 46.5711$

**3. 求解权重与波动率**
- 资产1权重：$w_1 = 28.8531 / 46.5711 \approx 0.6196$
- 资产2权重：$w_2 = 7.3132 / 46.5711 \approx 0.1570$
- 资产3权重：$w_3 = 10.4048 / 46.5711 \approx 0.2234$
（权重和为 1.0000，满足全额投资要求）

- MVP组合方差：$\sigma_{mvp}^2 = 1 / 46.5711 \approx 0.021473$
- MVP组合年化波动率：$\sigma_{mvp} = \sqrt{0.021473} \approx 0.1465$（即 14.65%）

最终，按要求将结果存入字典 `result`：

```python
result = {
    'mvp_weights': [0.6196, 0.1570, 0.2234],
    'mvp_vol_annual': 0.1465
}
```
