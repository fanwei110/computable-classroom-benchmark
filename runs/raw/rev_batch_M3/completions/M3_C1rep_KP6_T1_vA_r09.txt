### 第一题：年化夏普比率计算逻辑
1. **日无风险利率**：年化2.1%转换为日度，通常按交易日拆分，即 $R_{f,daily} = 2.1\% / 252$
2. **日夏普比率**：$Sharpe_{daily} = \frac{E(R_{fund}) - R_{f,daily}}{\sigma_{fund}}$
3. **年化夏普比率**：$Sharpe_{annual} = Sharpe_{daily} \times \sqrt{252}$

*Python计算代码参考：*
```python
import numpy as np
# 假设 df['fund'] 是日收益率数据
rf_daily = 0.021 / 252
excess_return = df['fund'] - rf_daily
sharpe_daily = excess_return.mean() / excess_return.std()
sharpe_annual = sharpe_daily * np.sqrt(252)
```

### 第二题：业绩归因（BHB模型）
已知数据：
* 组合权重 $W_p = [0.45, 0.35, 0.20]$
* 组合收益 $R_p = [8.3\%, 2.1\%, -1.4\%]$
* 基准权重 $W_b = [0.40, 0.40, 0.20]$
* 基准收益 $R_b = [6.7\%, 3.4\%, -0.9\%]$

**1. 配置效应** = $\sum (W_{p,i} - W_{b,i}) \times R_{b,i}$
* 行业1：$(0.45 - 0.40) \times 6.7\% = 0.05 \times 0.067 = 0.00335$
* 行业2：$(0.35 - 0.40) \times 3.4\% = -0.05 \times 0.034 = -0.0017$
* 行业3：$(0.20 - 0.20) \times (-0.9\%) = 0$
* **配置效应总计** = $0.00335 - 0.0017 + 0 = 0.00165$ (即 0.165%)

**2. 选择效应** = $\sum W_{b,i} \times (R_{p,i} - R_{b,i})$
* 行业1：$0.40 \times (8.3\% - 6.7\%) = 0.40 \times 0.016 = 0.0064$
* 行业2：$0.40 \times (2.1\% - 3.4\%) = 0.40 \times (-0.013) = -0.0052$
* 行业3：$0.20 \times (-1.4\% - (-0.9\%)) = 0.20 \times (-0.005) = -0.0010$
* **选择效应总计** = $0.0064 - 0.0052 - 0.0010 = 0.0002$ (即 0.02%)

**3. 交互效应** = $\sum (W_{p,i} - W_{b,i}) \times (R_{p,i} - R_{b,i})$
* 行业1：$(0.45 - 0.40) \times (8.3\% - 6.7\%) = 0.05 \times 0.016 = 0.0008$
* 行业2：$(0.35 - 0.40) \times (2.1\% - 3.4\%) = -0.05 \times (-0.013) = 0.00065$
* 行业3：$(0.20 - 0.20) \times (-0.5\%) = 0$
* **交互效应总计** = $0.0008 + 0.00065 + 0 = 0.00145$ (即 0.145%)

*(验证：总超额收益 = 组合收益4.19% - 基准收益3.86% = 0.33%，配置0.165% + 选择0.02% + 交互0.145% = 0.33%，完全吻合)*
