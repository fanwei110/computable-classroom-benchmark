为了绘制有效前沿并计算所需的数值，我们可以使用投资组合理论中的基本公式。

对于两只资产：
- 期望收益：$\mu_1 = 7.1\%$, $\mu_2 = 12.4\%$
- 波动率：$\sigma_1 = 16.3\%$, $\sigma_2 = 28.9\%$
- 相关系数：$\rho$

给定资产1的权重为 $w$，资产2的权重为 $1-w$，组合的期望收益 $\mu_p$ 和波动率 $\sigma_p$ 为：
$$ \mu_p = w \mu_1 + (1-w) \mu_2 $$
$$ \sigma_p = \sqrt{w^2 \sigma_1^2 + (1-w)^2 \sigma_2^2 + 2 w (1-w) \rho \sigma_1 \sigma_2} $$

**最小方差组合 (MVP) 的权重计算公式：**
$$ w_{mvp} = \frac{\sigma_2^2 - \rho \sigma_1 \sigma_2}{\sigma_1^2 + \sigma_2^2 - 2 \rho \sigma_1 \sigma_2} $$

**目标收益下的权重：**
当目标收益为 $\mu_{target}$ 时：
$$ w_{target} = \frac{\mu_2 - \mu_{target}}{\mu_2 - \mu_1} $$

根据上述公式计算 $\rho=0.45$ 时的关键指标：
1. **最小方差组合的波动率**：$w_{mvp} \approx 0.9206$，计算得 $\sigma_{mvp} \approx 16.17\%$
2. **目标收益10%时的最小波动率**：$w_{target} = (0.124 - 0.10) / (0.124 - 0.071) \approx 0.4528$，计算得 $\sigma_{target} \approx 20.24\%$

以下是完整的Python代码实现，包含绘图与结果字典的生成：

```python
import numpy as np
import matplotlib.pyplot as plt

# 资产参数
mu1, mu2 = 0.071, 0.124
sig1, sig2 = 0.163, 0.289
rhos = [0.15, 0.45, 0.75]
target_return = 0.10

# 权重范围，稍微延伸到0-1之外以展示完整的双曲线
w = np.linspace(-0.2, 1.2, 500)
mu_p = w * mu1 + (1 - w) * mu2

mvp_vol_45 = None
frontier_vol_target = None

plt.figure(figsize=(10, 6))

for i, rho in enumerate(rhos):
    cov12 = rho * sig1 * sig2
    sig_p = np.sqrt((w * sig1)**2 + ((1 - w) * sig2)**2 + 2 * w * (1 - w) * cov12)
    
    # 计算最小方差组合(MVP)
    w_mvp = (sig2**2 - cov12) / (sig1**2 + sig2**2 - 2 * cov12)
    mu_mvp = w_mvp * mu1 + (1 - w_mvp) * mu2
    sig_mvp = np.sqrt((w_mvp * sig1)**2 + ((1 - w_mvp) * sig2)**2 + 2 * w_mvp * (1 - w_mvp) * cov12)
    
    # 绘制有效前沿
    plt.plot(sig_p, mu_p, label=f'ρ = {rho}')
    
    # 标出最小方差组合
    plt.scatter(sig_mvp, mu_mvp, marker='D', s=60, zorder=5, edgecolors='black')
    plt.annotate(f'MVP(ρ={rho})\nσ={sig_mvp:.2%}', 
                 xy=(sig_mvp, mu_mvp), 
                 xytext=(10, 10 - i*20), 
                 textcoords='offset points',
                 bbox=dict(boxstyle='round,pad=0.3', fc='yellow', alpha=0.6),
                 arrowprops=dict(arrowstyle='->', connectionstyle='arc3,rad=0'))

    # 针对 rho = 0.45 计算特定指标
    if rho == 0.45:
        mvp_vol_45 = sig_mvp
        
        # 计算目标收益10%时的最小波动率
        w_target = (mu2 - target_return) / (mu2 - mu1)
        sig_target = np.sqrt((w_target * sig1)**2 + ((1 - w_target) * sig2)**2 + 2 * w_target * (1 - w_target) * cov12)
        frontier_vol_target = sig_target

# 图表美化
plt.xlabel('Volatility (Annualized)')
plt.ylabel('Expected Return (Annualized)')
plt.title('Efficient Frontier for Two Assets with Different Correlations')
plt.legend()
plt.grid(True, linestyle='--', alpha=0.6)
plt.xlim(left=0)

# 保存图表
figure_path = 'efficient_frontier.png'
plt.savefig(figure_path, dpi=150, bbox_inches='tight')
plt.close()

# 按照输出契约构建result字典
result = {
    'mvp_vol_at_rho45': round(mvp_vol_45, 6),
    'frontier_vol_at_target': round(frontier_vol_target, 6),
    'figure_path': figure_path
}

print(result)
```
