为了绘制有效前沿并计算所需的数值，我们可以使用马科维茨投资组合理论中的公式。

给定两只资产：
- 资产1：期望收益 $E_1 = 7.1\%$，波动率 $\sigma_1 = 16.3\%$
- 资产2：期望收益 $E_2 = 12.4\%$，波动率 $\sigma_2 = 28.9\%$

组合的期望收益和方差公式为：
- $E_p = w_1 E_1 + w_2 E_2$
- $\sigma_p^2 = w_1^2 \sigma_1^2 + w_2^2 \sigma_2^2 + 2 w_1 w_2 \rho \sigma_1 \sigma_2$

**1. 计算 $\rho=0.45$ 时的最小方差组合（MVP）波动率：**
最小方差组合权重公式为：
$w_1^{MVP} = \frac{\sigma_2^2 - \rho \sigma_1 \sigma_2}{\sigma_1^2 + \sigma_2^2 - 2 \rho \sigma_1 \sigma_2}$
代入 $\rho=0.45$：
$w_1^{MVP} = \frac{0.289^2 - 0.45 \times 0.163 \times 0.289}{0.163^2 + 0.289^2 - 2 \times 0.45 \times 0.163 \times 0.289} \approx 0.9207$
$w_2^{MVP} = 1 - 0.9207 = 0.0793$
计算该组合方差并开方得到波动率：$\sigma_{MVP} \approx 16.17\%$ (即 0.16166)

**2. 计算 $\rho=0.45$ 且目标收益为 10% 时的最小波动率：**
由 $10\% = w_1 \times 7.1\% + w_2 \times 12.4\%$，解得：
$w_1 = \frac{0.124 - 0.10}{0.124 - 0.071} \approx 0.4528$
$w_2 = 1 - 0.4528 = 0.5472$
计算该组合方差并开方得到波动率：$\sigma_{target} \approx 20.24\%$ (即 0.20239)

以下是用于生成图片并计算结果的完整Python代码：

```python
import numpy as np
import matplotlib.pyplot as plt

# 资产参数
E1, E2 = 0.071, 0.124
s1, s2 = 0.163, 0.289
rhos = [0.15, 0.45, 0.75]
target_ret = 0.10

result = {
    'mvp_vol_at_rho45': None,
    'frontier_vol_at_target': None,
    'figure_path': 'efficient_frontier.png'
}

# 权重范围（允许一定卖空以展现完整双曲线）
w1 = np.linspace(-0.5, 1.5, 1000)

plt.figure(figsize=(10, 7))

for rho in rhos:
    # 计算组合收益与波动率
    Ep = w1 * E1 + (1 - w1) * E2
    sp = np.sqrt(w1**2 * s1**2 + (1-w1)**2 * s2**2 + 2 * w1 * (1-w1) * rho * s1 * s2)
    
    # 绘制前沿曲线
    plt.plot(sp, Ep, label=f'ρ = {rho}', linewidth=2)
    
    # 计算并标出最小方差组合 (MVP)
    w1_mvp = (s2**2 - rho * s1 * s2) / (s1**2 + s2**2 - 2 * rho * s1 * s2)
    w2_mvp = 1 - w1_mvp
    Ep_mvp = w1_mvp * E1 + w2_mvp * E2
    sp_mvp = np.sqrt(w1_mvp**2 * s1**2 + w2_mvp**2 * s2**2 + 2 * w1_mvp * w2_mvp * rho * s1 * s2)
    
    plt.scatter(sp_mvp, Ep_mvp, s=60, zorder=5)
    plt.annotate(f'MVP (ρ={rho})\n({sp_mvp:.2%}, {Ep_mvp:.2%})',
                 xy=(sp_mvp, Ep_mvp), xytext=(5, 5), textcoords='offset points', fontsize=9)

    # 针对rho=0.45提取所需数值
    if rho == 0.45:
        result['mvp_vol_at_rho45'] = float(sp_mvp)
        
        # 计算目标收益10%时的最小波动率
        w1_target = (target_ret - E2) / (E1 - E2)
        w2_target = 1 - w1_target
        sp_target = np.sqrt(w1_target**2 * s1**2 + w2_target**2 * s2**2 + 2 * w1_target * w2_target * rho * s1 * s2)
        result['frontier_vol_at_target'] = float(sp_target)

# 格式化图表
plt.title('Efficient Frontiers with Different Correlations', fontsize=14)
plt.xlabel('Volatility (Standard Deviation)', fontsize=12)
plt.ylabel('Expected Return', fontsize=12)
plt.legend()
plt.grid(True, linestyle='--', alpha=0.6)
plt.xlim(0.10, 0.50)
plt.ylim(0.04, 0.15)

# 保存图片
plt.savefig(result['figure_path'], dpi=300, bbox_inches='tight')
plt.close()

# 输出结果字典
print(result)
```
