这里提供完整的Python代码来实现你的需求。代码基于Black-Scholes期权定价模型计算欧式看涨期权的Delta值，绘制了不同波动率下的Delta曲线，将图片保存至本地，并将所需结果存入字典 `result` 中。

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.stats import norm
import os

# ---------------- 参数设置 ----------------
K = 97.5          # 行权价
r = 0.043         # 利率 4.3%
T = 0.58          # 剩余期限 0.58年
S_range = np.linspace(70, 140, 700)  # 标的价格从70到140

# 可调波动率参数（修改此列表即可调整图中的线条）
volatilities = [0.15, 0.276, 0.40]

# ---------------- 核心计算函数 ----------------
def call_delta(S, K, T, r, sigma):
    """
    计算欧式看涨期权的Delta
    """
    d1 = (np.log(S / K) + (r + 0.5 * sigma ** 2) * T) / (sigma * np.sqrt(T))
    return norm.cdf(d1)

# ---------------- 特定值计算 ----------------
# 报标的等于110、波动率27.6%时的delta
target_S = 110
target_sigma = 0.276
delta_at_s110 = call_delta(target_S, K, T, r, target_sigma)

# ---------------- 绘图 ----------------
plt.figure(figsize=(10, 6))

# 遍历波动率参数画线
for sigma in volatilities:
    deltas = call_delta(S_range, K, T, r, sigma)
    # 图例标好具体的波动率百分比
    plt.plot(S_range, deltas, label=f'Vol = {sigma * 100:.1f}%')

plt.title('Delta vs Underlying Price (Call Option)')
plt.xlabel('Underlying Price (S)')
plt.ylabel('Delta')
plt.legend()
plt.grid(True, linestyle='--', alpha=0.7)

# 保存图表
figure_path = 'delta_vs_price.png'
plt.savefig(figure_path, dpi=300, bbox_inches='tight')
plt.close()

# ---------------- 按契约要求存入字典 ----------------
result = {
    'delta_at_s110': delta_at_s110,
    'figure_path': figure_path
}

# 打印结果以供查验
print(f"标的110、波动率27.6%时的Delta: {result['delta_at_s110']:.4f}")
print(f"图片保存路径: {result['figure_path']}")
print("Result Dictionary:", result)
```

### 输出结果说明：
1. **特定Delta值**：当标的价格 $S=110$，波动率 $\sigma=27.6\%$ 时，算得的看涨期权 Delta 约为 `0.7872`（即 `result['delta_at_s110']` 的值）。
2. **图表**：程序会生成一张名为 `delta_vs_price.png` 的图表，并将其相对路径存入 `result['figure_path']`。图中清晰展示了从深度虚值（Delta趋近0）到深度实值（Delta趋近1）的过渡，且波动率越低，Delta曲线在平值附近越陡峭；波动率越高，曲线越平缓。
3. **可调参数**：代码中 `volatilities` 列表被单独提取到最上方，您可以随时增加、删除或修改该列表内的波动率数值，图表和图例均会自动适配更新。
