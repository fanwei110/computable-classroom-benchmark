### 第一问：年化夏普比率
计算日度夏普比率并年化的常用方法如下：
1. 日无风险利率 $R_{f,daily} = 2.1\% / 252$ （一年按252个交易日计算，部分教材按365算，逻辑一致）
2. 组合日超额收益 = 日收益率 - $R_{f,daily}$
3. 年化夏普比率 = $\frac{日超额收益的均值}{日超额收益的标准差} \times \sqrt{252}$

### 第二问：业绩归因（BHB模型）
根据Brinson-Hood-Beebower模型：
* **配置效应** = $\sum (组合权重 - 基准权重) \times 基准收益$
* **选择效应** = $\sum 基准权重 \times (组合收益 - 基准收益)$
* **交互效应** = $\sum (组合权重 - 基准权重) \times (组合收益 - 基准收益)$

代入数据计算：
1. **配置效应**：
   $(0.45 - 0.40) \times 6.7\% + (0.35 - 0.40) \times 3.4\% + (0.20 - 0.20) \times (-0.9\%)$
   $= 0.05 \times 6.7\% - 0.05 \times 3.4\% + 0$
   $= 0.335\% - 0.170\% = 0.165\%$ （即 0.00165）

2. **选择效应**：
   $0.40 \times (8.3\% - 6.7\%) + 0.40 \times (2.1\% - 3.4\%) + 0.20 \times (-1.4\% - (-0.9\%))$
   $= 0.40 \times 1.6\% + 0.40 \times (-1.3\%) + 0.20 \times (-0.5\%)$
   $= 0.640\% - 0.520\% - 0.100\% = 0.020\%$ （即 0.0002）

3. **交互效应**：
   $(0.45 - 0.40) \times (8.3\% - 6.7\%) + (0.35 - 0.40) \times (2.1\% - 3.4\%) + (0.20 - 0.20) \times (-1.4\% - (-0.9\%))$
   $= 0.05 \times 1.6\% + (-0.05) \times (-1.3\%) + 0$
   $= 0.080\% + 0.065\% = 0.145\%$ （即 0.00145）

*(验证：组合总收益4.19% - 基准总收益3.86% = 0.33%，配置0.165% + 选择0.020% + 交互0.145% = 0.33%，完全吻合)*

**附：第一问计算的Python代码（供你填补 `sharpe_annual`）**
```python
import pandas as pd
import numpy as np

# 假设df为你读取的课程数据文件DataFrame
# df = pd.read_csv('你的文件路径.csv')
daily_returns = df['fund']
rf_annual = 0.021
rf_daily = rf_annual / 252  # 日无风险利率

excess_returns = daily_returns - rf_daily
sharpe_daily = excess_returns.mean() / excess_returns.std()
sharpe_annual = sharpe_daily * np.sqrt(252)

# 计算完成后赋值
result['sharpe_annual'] = sharpe_annual
```
