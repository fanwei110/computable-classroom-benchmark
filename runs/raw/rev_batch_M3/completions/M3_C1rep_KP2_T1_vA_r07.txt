根据资本资产定价模型（CAPM），期望收益的计算公式为：
$$E(R_i) = R_f + \beta_i \times (E(R_m) - R_f)$$
其中，$R_f$ 为无风险利率，$E(R_m)$ 为市场期望收益。

Alpha的计算公式为：
$$\alpha = \text{实际收益} - \text{期望收益}$$

**计算过程：**
1. 市场风险溢价 = $9.4\% - 2.3\% = 7.1\%$
2. **X的期望收益 (er_x)** = $2.3\% + 0.62 \times 7.1\% = 2.3\% + 4.402\% = 6.702\%$
3. **Y的期望收益 (er_y)** = $2.3\% + 1.18 \times 7.1\% = 2.3\% + 8.378\% = 10.678\%$
4. **Z的期望收益 (er_z)** = $2.3\% + 1.51 \times 7.1\% = 2.3\% + 10.721\% = 13.021\%$
5. **Y的Alpha (alpha_y)** = $13.1\% - 10.678\% = 2.422\%$
