要计算隐含波动率（IV）上涨1个百分点（即1%）时期权价格的变化，我们需要使用期权定价模型（如Black-Scholes模型）中的Vega值。

根据题目给定的参数格式，通常为：行权价(K) / 标的资产价格(S) / 隐含波动率(IV) / 无风险利率 / 到期时间(T)。
参数提取如下：
- 行权价 (K) = 103.7
- 标的资产价格 (S) = 97.5
- 隐含波动率 (IV, σ) = 27.6% = 0.276
- 无风险利率 = 4.3% = 0.043
- 到期时间 (T) = 0.58年

**1. 计算 d1：**
d1 = [ln(S/K) + (r + σ²/2) * T] / (σ * √T)
- ln(97.5 / 103.7) ≈ -0.06116
- (0.043 + 0.276² / 2) * 0.58 = (0.043 + 0.038088) * 0.58 ≈ 0.04703
- 分子 = -0.06116 + 0.04703 = -0.01413
- 分母 = 0.276 * √0.58 ≈ 0.21040
- d1 ≈ -0.01413 / 0.21040 ≈ -0.0671

**2. 计算正态分布概率密度 N'(d1)：**
N'(d1) = (1 / √(2π)) * e^(-d1² / 2)
- d1² / 2 ≈ 0.00226
- e^(-0.00226) ≈ 0.99775
- N'(d1) ≈ 0.39894 * 0.99775 ≈ 0.39784

**3. 计算 Vega：**
Vega = S * N'(d1) * √T
- Vega = 97.5 * 0.39784 * √0.58 ≈ 38.8064 * 0.76158 ≈ 29.6034

**4. 计算IV上涨1个点（1%）带来的价格变化：**
Vega衡量的是隐含波动率每变动1%（0.01）时期权价格的变化量。
- 价格变化 = Vega * 0.01 = 29.6034 * 0.01 ≈ 0.2960

result = {'price_change': 0.2960}
