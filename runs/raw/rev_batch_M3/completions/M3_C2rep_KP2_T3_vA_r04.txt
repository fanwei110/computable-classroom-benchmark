```python
import numpy as np

def calculate_capm_monthly_return():
    """
    计算 CAPM 下股票的月度期望收益率
    """
    # 已知参数
    beta = 1.42                   # 股票的 Beta 值
    market_return_monthly = -0.058  # 上个月市场收益率 (-5.8%)
    risk_free_rate_annual = 0.047   # 年化无风险利率 (4.7%)
    
    # 1. 把年无风险利率折算为月利率
    # 假设：给定的年无风险利率为有效年利率(EAR)，采用复利折算方式得到有效月利率。
    # 这样能准确反映1个月资金的真实时间价值。
    risk_free_rate_monthly = np.power(1 + risk_free_rate_annual, 1/12) - 1
    
    # 2. 在月度层面套用 CAPM
    # CAPM 公式: E(R_i) = R_f + Beta * (E(R_m) - R_f)
    # 此处使用给定的上月市场实际收益率作为 E(R_m) 的代理变量
    capm_return_monthly = risk_free_rate_monthly + beta * (market_return_monthly - risk_free_rate_monthly)
    
    # 3. 填充 result
    result = {
        'capm_return_monthly': capm_return_monthly
    }
    
    return result

if __name__ == "__main__":
    result = calculate_capm_monthly_return()
    
    # 输出结果，确保可复现
    print("=== CAPM 月度收益计算结果 ===")
    print(f"结果字典: {result}")
    print(f"按 CAPM 本该收益: {result['capm_return_monthly']:.4%}")
```

**代码逻辑与假设说明：**

1. **年化转月化假设**：金融学中常见的年利率转月利率有两种方式：
   - **单利折算（APR惯例）**：直接除以 12（即 `0.047 / 12`）。
   - **复利折算（EAR惯例）**：通过 $(1 + r_{annual})^{1/12} - 1$ 计算。
   本脚本采用**复利折算**，因为这更精确地反映了单月资金占用的时间价值（符合有效年利率定义）。代码中通过 `np.power` 实现该计算。
   
2. **CAPM套用**：在得到月度无风险利率后，直接套用 CAPM 公式 $E(R_i) = R_{f, monthly} + \beta \times (R_{m, monthly} - R_{f, monthly})$。由于市场收益率为 -5.8%，无风险利率约为 0.384%，市场风险溢价为负，因此高 Beta 股票按模型本该承受更大跌幅。

3. **契约履行**：脚本完全自包含，所有结果严格存入字典 `result`，且键名严格为 `'capm_return_monthly'`，变量命名清晰，无占位值，确保每次运行输出确定可复现。
