根据资本资产定价模型（CAPM），计算过程如下：

1. **计算市场风险溢价**：
   $$R_m - R_f = 9.4\% - 2.3\% = 7.1\%$$

2. **计算三只股票的预期收益率（CAPM收益）**：
   * **股票 X**：$$E(R_x) = R_f + \beta_x \times (R_m - R_f) = 2.3\% + 0.62 \times 7.1\% = 6.702\%$$
   * **股票 Y**：$$E(R_y) = R_f + \beta_y \times (R_m - R_f) = 2.3\% + 1.18 \times 7.1\% = 10.678\%$$
   * **股票 Z**：$$E(R_z) = R_f + \beta_z \times (R_m - R_f) = 2.3\% + 1.51 \times 7.1\% = 13.021\%$$

3. **计算股票 Y 的 Alpha**：
   * Alpha = 实际收益率 - 预期收益率 (CAPM收益)
   * $$\alpha_y = 13.1\% - 10.678\% = 2.422\%$$
