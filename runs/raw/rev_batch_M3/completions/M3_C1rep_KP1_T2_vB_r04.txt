为了绘制有效前沿并计算所需的数值，我们可以使用 Python 的 `numpy` 和 `matplotlib` 库。下面是完整的计算与绘图过程。

### 计算逻辑
对于两资产组合：
1. **组合收益**：$R_p = w_1 R_1 + w_2 R_2$
2. **组合波动率**：$\sigma_p = \sqrt{w_1^2 \sigma_1^2 + w_2^2 \sigma_2^2 + 2 w_1 w_2 \rho \sigma_1 \sigma_2}$
3. **最小方差组合权重**：$w_1 = \frac{\sigma_2^2 - \rho \sigma_1 \sigma_2}{\sigma_1^2 + \sigma_2^2 - 2 \rho \sigma_1 \sigma_2}$
4. **目标收益下的权重**：$w_1 = \frac{R_{target} - R_2}{R_1 - R_2}$

### Python 代码实现

```python
import numpy as np
import matplotlib.pyplot as plt
import math

# 资产参数
r1, r2 = 0.071, 0.124
s1, s2 = 0.163, 0.289
rhos = [0.15, 0.45, 0.75]
target_return = 0.10

# 权重范围（包含做空情况以展示完整双曲线）
w1 = np.linspace(-0.5, 1.5, 1000)
w2 = 1 - w1

# 组合收益
port_ret = w1 * r1 + w2 * r2

plt.figure(figsize=(10, 6))
colors = ['blue', 'green', 'red']

mvp_vol_45 = None
target_vol_45 = None

for i, rho in enumerate(rhos):
    # 组合波动率
    port_vol = np.sqrt(w1**2 * s1**2 + w2**2 * s2**2 + 2 * w1 * w2 * rho * s1 * s2)
    
    # 绘制前沿
    plt.plot(port_vol, port_ret, label=f'ρ = {rho}', color=colors[i])
    
    # 计算最小方差组合 (MVP)
    w1_mvp = (s2**2 - rho * s1 * s2) / (s1**2 + s2**2 - 2 * rho * s1 * s2)
    w2_mvp = 1 - w1_mvp
    ret_mvp = w1_mvp * r1 + w2_mvp * r2
    vol_mvp = math.sqrt(w1_mvp**2 * s1**2 + w2_mvp**2 * s2**2 + 2 * w1_mvp * w2_mvp * rho * s1 * s2)
    
    # 标出最小方差点
    plt.scatter(vol_mvp, ret_mvp, marker='o', color=colors[i], s=50, zorder=5)
    plt.annotate(f'MVP ρ={rho}\n({vol_mvp:.2%}, {ret_mvp:.2%})',
                 (vol_mvp, ret_mvp),
                 textcoords="offset points",
                 xytext=(10, 10),
                 fontsize=9,
                 arrowprops=dict(arrowstyle="->", color=colors[i]))
    
    # 针对相关系数 0.45 的专门计算
    if rho == 0.45:
        mvp_vol_45 = vol_mvp
        
        # 目标收益 10% 时的最小波动率
        w1_target = (target_return - r2) / (r1 - r2)
        w2_target = 1 - w1_target
        target_vol_45 = math.sqrt(w1_target**2 * s1**2 + w2_target**2 * s2**2 + 2 * w1_target * w2_target * rho * s1 * s2)

# 图表美化
plt.title('Two-Asset Efficient Frontiers (Different Correlations)')
plt.xlabel('Portfolio Volatility')
plt.ylabel('Portfolio Expected Return')
plt.legend()
plt.grid(True, linestyle='--', alpha=0.6)
plt.xlim(0, 0.50)
plt.ylim(0, 0.20)

# 保存图表
fig_path = 'efficient_frontier.png'
plt.savefig(fig_path, dpi=300, bbox_inches='tight')
plt.close()

# 构造输出字典
result = {
    'mvp_vol_at_rho45': round(mvp_vol_45, 4),
    'frontier_vol_at_target': round(target_vol_45, 4),
    'figure_path': fig_path
}

print(result)
```

### 计算结果说明
- **0.45 相关系数下的最小方差组合波动率 (mvp_vol_at_rho45)**: 约 16.17%
- **0.45 相关系数下目标收益 10% 的最小波动率 (frontier_vol_at_target)**: 约 20.24%
