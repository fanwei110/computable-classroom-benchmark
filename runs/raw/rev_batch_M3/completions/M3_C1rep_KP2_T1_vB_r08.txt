根据资本资产定价模型（CAPM）公式：$E(R_i) = R_f + \beta_i \times (R_m - R_f)$

已知：
*   无风险利率 $R_f = 2.3\% = 0.023$
*   市场收益率 $R_m = 9.4\% = 0.094$
*   市场风险溢价 $R_m - R_f = 9.4\% - 2.3\% = 7.1\% = 0.071$

各股票预期收益率计算如下：
*   **X股票**：$E(R_X) = 2.3\% + 0.62 \times 7.1\% = 6.702\% = 0.06702$
*   **Y股票**：$E(R_Y) = 2.3\% + 1.18 \times 7.1\% = 10.678\% = 0.10678$
*   **Z股票**：$E(R_Z) = 2.3\% + 1.51 \times 7.1\% = 13.021\% = 0.13021$

Y股票的Alpha值计算公式为：$\alpha_Y = 实际收益率 - 预期收益率$
*   **Y的Alpha**：$\alpha_Y = 13.1\% - 10.678\% = 2.422\% = 0.02422$
