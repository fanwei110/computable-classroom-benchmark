要计算同一只期权在隐含波动率（IV）上涨1个点（即1%，或0.01）时价格的变化量，我们需要计算该期权的 Vega 值。Vega 表示隐含波动率每变动1个百分点，期权价格的变化量。

根据题目给出的参数，我们可以推断出：
- 标的资产价格 (S) = 103.7
- 行权价 (K) = 97.5
- 隐含波动率 (σ) = 27.6% = 0.276
- 无风险利率 = 4.3% = 0.043
- 到期时间 (T) = 0.58年

根据 Black-Scholes 模型，Vega 的计算公式为：
Vega = S * N'(d1) * √T

其中 N'(d1) 是标准正态分布的概率密度函数，d1 的计算公式为：
d1 = [ln(S/K) + (r + σ²/2) * T] / (σ * √T)

首先计算 d1：
ln(S/K) = ln(103.7 / 97.5) ≈ 0.061659
(r + σ²/2) * T = (0.043 + 0.276²/2) * 0.58 = (0.043 + 0.038088) * 0.58 ≈ 0.047031
分子 = 0.061659 + 0.047031 = 0.108690
分母 = 0.276 * √0.58 = 0.276 * 0.761577 ≈ 0.210195
d1 = 0.108690 / 0.210195 ≈ 0.517027

接下来计算 N'(d1)：
N'(d1) = e^(-d1²/2) / √(2π) = e^(-0.517027²/2) / √(2π) ≈ e^(-0.13366) / 2.506628 ≈ 0.87486 / 2.506628 ≈ 0.34899

然后计算 Vega：
Vega = 103.7 * 0.34899 * 0.761577 ≈ 27.534

因为 IV 涨1个点（即涨1%，相当于波动率绝对值变化 0.01），期权价格的变化量为：
价格变化 = Vega * 0.01 = 27.534 * 0.01 = 0.27534
