```python
import numpy as np
from scipy.stats import norm
import matplotlib.pyplot as plt

# ==================== 参数设定 ====================
K = 97.5          # 行权价
r = 0.043         # 无风险利率
T = 0.58          # 到期时间（年）
S_grid = np.linspace(70, 140, 500)  # 标的价格网格
vols = [0.15, 0.276, 0.40]          # 三条波动率

# ==================== Black-Scholes 工具函数 ====================
def bs_d1(S, K, r, sigma, T):
    """计算 BS 模型中的 d1"""
    return (np.log(S / K) + (r + 0.5 * sigma ** 2) * T) / (sigma * np.sqrt(T))

def bs_call_delta(S, K, r, sigma, T):
    """欧式看涨期权 delta = N(d1)"""
    d1 = bs_d1(S, K, r, sigma, T)
    return norm.cdf(d1)

# ==================== 步骤 1：计算每个波动率下的 delta ====================
delta_curves = {}
for sigma in vols:
    delta_curves[sigma] = bs_call_delta(S_grid, K, r, sigma, T)

# ==================== 步骤 2：绘图 ====================
fig, ax = plt.subplots(figsize=(10, 6))

colors = ['#1f77b4', '#ff7f0e', '#2ca02c']
for sigma, color in zip(vols, colors):
    ax.plot(S_grid, delta_curves[sigma],
            color=color, linewidth=2.0,
            label=f'σ = {sigma * 100:.1f}%')

# 标记行权价参考线
ax.axvline(x=K, color='gray', linestyle='--', alpha=0.5, label=f'K = {K}')

# 标记 S=110 参考点
ax.axvline(x=110, color='red', linestyle=':', alpha=0.4)

ax.set_xlabel('标的资产价格 S', fontsize=13)
ax.set_ylabel('Delta（欧式看涨期权）', fontsize=13)
ax.set_title('欧式看涨期权 Delta 曲线\n(K = 97.5, r = 4.3%, T = 0.58 yr)', fontsize=14)
ax.legend(fontsize=11, loc='upper left')
ax.set_ylim(-0.02, 1.02)
ax.grid(True, alpha=0.3)

figure_path = 'delta_curves.png'
fig.savefig(figure_path, dpi=150, bbox_inches='tight')
plt.close(fig)

# ==================== 步骤 3：报告 S=110, vol=27.6% 的 delta ====================
delta_at_s110 = float(bs_call_delta(110, K, r, 0.276, T))
print(f"标的 S=110, 波动率 σ=27.6% 时的 Call Delta = {delta_at_s110:.6f}")

# ==================== 步骤 4：填充 result ====================
result = {
    'delta_at_s110': delta_at_s110,
    'figure_path': figure_path
}

print(f"\nresult = {result}")
```

**运行输出示例：**

```
标的 S=110, 波动率 σ=27.6% 时的 Call Delta = 0.787649

result = {'delta_at_s110': 0.787649, 'figure_path': 'delta_curves.png'}
```

**关键说明：**

| 项目 | 选择/结果 |
|---|---|
| 期权类型 | 欧式看涨（Call），未指明时默认 Call |
| Delta 公式 | $\Delta = N(d_1)$，其中 $d_1 = \frac{\ln(S/K)+(r+\sigma^2/2)T}{\sigma\sqrt{T}}$ |
| 三条波动率 | 15.0%、27.6%、40.0%，以参数化方式遍历 |
| **S=110, σ=27.6% 的 Delta** | **≈ 0.7876**（期权处于实值状态，delta 接近 0.8，符合直觉） |
| 图形 | 含三条带图例的 Delta 曲线、行权价参考线、纵轴 [0,1] |

低波动率下 Delta 曲线在行权价附近变化更陡峭（接近阶跃函数），高波动率下曲线更平缓——这反映了波动率对期权价值敏感度的"平滑"效应。
