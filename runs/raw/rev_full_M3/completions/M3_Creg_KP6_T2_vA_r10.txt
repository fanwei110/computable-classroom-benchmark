```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

# ==========================================
# 1. 读取/准备课程数据快照
# ==========================================
# 为保证脚本完全自包含、可复现且无占位值，
# 此处使用固定随机种子生成模拟的日收益数据。
# 若您有实际的课程数据快照文件，可替换为：
# df = pd.read_csv('your_snapshot.csv', parse_dates=['date'], index_col='date')
np.random.seed(42)
num_days = 500
dates = pd.date_range(start='2022-01-01', periods=num_days, freq='B')
# 模拟基金日收益率：均值为 0.0005，标准差为 0.015
simulated_daily_returns = np.random.normal(loc=0.0005, scale=0.015, size=num_days)
df = pd.DataFrame({'fund': simulated_daily_returns}, index=dates)

# ==========================================
# 2. 参数设置
# ==========================================
annual_risk_free_rate = 0.021          # 无风险利率每年 2.1%
trading_days_per_year = 252            # 一年的交易日天数
daily_risk_free_rate = annual_risk_free_rate / trading_days_per_year  # 日无风险利率
rolling_window = 60                    # 滚动窗口长度（可调参数）

# ==========================================
# 3. 计算滚动年化夏普比率
# ==========================================
# 计算超额收益
excess_returns = df['fund'] - daily_risk_free_rate

# 计算滚动均值和滚动标准差
rolling_mean_excess = excess_returns.rolling(window=rolling_window).mean()
rolling_std_excess = excess_returns.rolling(window=rolling_window).std()

# 计算滚动日夏普比率
rolling_sharpe_daily = rolling_mean_excess / rolling_std_excess

# 年化夏普比率 = 日夏普比率 * sqrt(一年交易日天数)
rolling_sharpe_annualized = rolling_sharpe_daily * np.sqrt(trading_days_per_year)

# ==========================================
# 4. 提取最后一个窗口的夏普值
# ==========================================
rolling_sharpe_last = rolling_sharpe_annualized.iloc[-1]

# ==========================================
# 5. 绘图与保存
# ==========================================
plt.figure(figsize=(12, 6))
plt.plot(rolling_sharpe_annualized.index, rolling_sharpe_annualized, 
         label=f'{rolling_window}-Day Rolling Annualized Sharpe', color='tab:blue')
plt.axhline(y=0, color='tab:red', linestyle='--', linewidth=1, alpha=0.8)
plt.title(f'{rolling_window}-Day Rolling Annualized Sharpe Ratio (Risk-Free Rate: {annual_risk_free_rate*100}%)')
plt.xlabel('Date')
plt.ylabel('Annualized Sharpe Ratio')
plt.grid(True, alpha=0.3)
plt.legend()

# 保存图片
figure_path = 'rolling_sharpe_ratio.png'
plt.savefig(figure_path, dpi=150, bbox_inches='tight')
plt.close()

# ==========================================
# 6. 构建输出契约字典
# ==========================================
result = {
    'rolling_sharpe_last': rolling_sharpe_last,
    'figure_path': figure_path
}

# 打印结果以便验证
if __name__ == '__main__':
    print(f"最后 {rolling_window} 日窗口的年化夏普比率: {result['rolling_sharpe_last']:.4f}")
    print(f"图片已保存至: {result['figure_path']}")
```

### 脚本说明：
1. **数据自包含**：由于无法直接读取您的本地数据，脚本使用 `np.random.seed(42)` 生成了一组完全确定、可复现的模拟日收益数据。如果您有真实数据，只需按注释替换 `df = pd.read_csv(...)` 即可，后续逻辑完全通用。
2. **参数可调**：`rolling_window = 60` 被提取为变量，修改此值即可调整窗口长度。
3. **夏普比率计算**：
   - 日无风险利率按 `年化利率 / 252` 折算。
   - 超额收益 = 基金日收益 - 日无风险利率。
   - 滚动日夏普 = 滚动超额收益均值 / 滚动超额收益标准差。
   - 年化夏普 = 滚动日夏普 × $\sqrt{252}$。
4. **输出契约**：严格按要求将最后窗口的夏普值（`rolling_sharpe_last`）和图片保存路径（`figure_path`）存入 `result` 字典中。
