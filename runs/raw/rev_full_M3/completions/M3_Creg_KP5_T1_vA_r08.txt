按 252 个交易日/年、收益均值 0、波动率按平方根法则缩放计算；VaR 以正数表示损失额。

```python
import numpy as np
from scipy.stats import norm
import pandas as pd

# 参数
position_value = 1_850_000.0      # 头寸价值，元
annual_vol = 0.218                 # 年化收益波动率
trading_days_per_year = 252        # 交易日/年

def delta_normal_var(position_value, annual_vol, holding_days, confidence,
                     trading_days_per_year=252):
    """
    Delta-normal 参数法 VaR。
    假设收益均值 0，波动率按 sqrt(holding_days / trading_days_per_year) 缩放。
    返回正数表示损失额。
    """
    z_score = norm.ppf(confidence)
    horizon_vol = annual_vol * np.sqrt(holding_days / trading_days_per_year)
    return float(position_value * z_score * horizon_vol)

# (i) 95% 一日 VaR
var_95_1d = delta_normal_var(
    position_value=position_value,
    annual_vol=annual_vol,
    holding_days=1,
    confidence=0.95,
    trading_days_per_year=trading_days_per_year,
)

# (ii) 99% 十日 VaR
var_99_10d = delta_normal_var(
    position_value=position_value,
    annual_vol=annual_vol,
    holding_days=10,
    confidence=0.99,
    trading_days_per_year=trading_days_per_year,
)

result = {
    "var_95_1d": var_95_1d,
    "var_99_10d": var_99_10d,
}

if __name__ == "__main__":
    summary = pd.DataFrame({
        "指标": ["95% 1日 VaR", "99% 10日 VaR"],
        "VaR_元": [var_95_1d, var_99_10d],
    })
    print(summary.to_string(index=False))
    print(result)
```

运行后 `result` 约为：

```python
{'var_95_1d': 41788.35, 'var_99_10d': 186897.12}
```

单位均为元。
