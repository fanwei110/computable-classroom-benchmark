```python
import numpy as np
from scipy.stats import norm

def calculate_bs_vega(S, K, T, r, sigma):
    """
    计算欧式期权的 Black-Scholes Vega (对看涨和看跌期权相同)
    """
    d1 = (np.log(S / K) + (r + 0.5 * sigma ** 2) * T) / (sigma * np.sqrt(T))
    vega = S * norm.pdf(d1) * np.sqrt(T)
    return vega

# 题目给定的参数
S = 103.7      # 标的资产价格
K = 97.5       # 行权价
sigma = 0.276  # 隐含波动率 (27.6%)
r = 0.043      # 无风险利率 (4.3%)
T = 0.58       # 到期时间 (年)

# 计算当前波动率下的 Vega
vega = calculate_bs_vega(S, K, T, r, sigma)

# IV 涨1个点，即隐含波动率增加 1 个百分点 (1% = 0.01)
delta_sigma = 0.01

# 利用 Vega 推算期权价格对这 1 个百分点波动率变化的响应
price_change = vega * delta_sigma

# 将结果存入符合契约的字典中
result = {'price_change': price_change}

# 教师投屏展示时可直接运行查看结果
print(f"推算的期权价格变化: {result['price_change']:.4f}")
```

**代码说明：**
1. **参数处理**：根据金融常规与题目给定的格式，103.7 为标的资产价格（S），97.5 为行权价（K），27.6% 为隐含波动率（IV，即 $\sigma$），4.3% 为无风险利率（r），0.58 为以年计的到期时间（T）。
2. **希腊字母闭式解**：Vega 的 Black-Scholes 闭式解为 $Vega = S \cdot \phi(d_1) \cdot \sqrt{T}$。由于欧式看涨与看跌期权的 Vega 完全相同，这正好契合了题目未指明期权方向的前提（利用精确价格差会因为看涨/看跌而产生不同的变化，只有用 Vega 推算能得出唯一且内部一致的响应值）。
3. **推算响应**：隐含波动率上涨“1个点”在期权术语中指代 1 个百分点（即 $\Delta\sigma = 0.01$），因此价格响应按 $\Delta P \approx Vega \times \Delta\sigma$ 推算。
