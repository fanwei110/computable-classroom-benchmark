```python
import numpy as np

def calculate_capm_and_alpha():
    # 给定参数 (以小数形式表示百分比)
    risk_free_rate = 0.023      # 无风险利率 2.3%
    market_return = 0.094       # 市场期望收益 9.4%
    
    # 计算市场风险溢价
    market_risk_premium = market_return - risk_free_rate
    
    # 股票 X, Y, Z 的 Beta 值
    beta_x = 0.62
    beta_y = 1.18
    beta_z = 1.51
    
    # 根据 CAPM 公式计算各自的期望年收益: E(R_i) = R_f + β_i * (E(R_m) - R_f)
    er_x = risk_free_rate + beta_x * market_risk_premium
    er_y = risk_free_rate + beta_y * market_risk_premium
    er_z = risk_free_rate + beta_z * market_risk_premium
    
    # 股票 Y 的实际收益
    actual_return_y = 0.131     # 13.1%
    
    # 计算 Alpha: α = 实际收益 - 期望收益
    alpha_y = actual_return_y - er_y
    
    # 将结果存入字典，键名严格按要求命名
    result = {
        'er_x': er_x,
        'er_y': er_y,
        'er_z': er_z,
        'alpha_y': alpha_y
    }
    
    return result

if __name__ == "__main__":
    result = calculate_capm_and_alpha()
    
    # 打印结果以便验证
    print("CAPM 计算结果:")
    for key, value in result.items():
        print(f"{key}: {value:.5f} ({value*100:.3f}%)")
```

### 计算逻辑说明：
1. **CAPM 公式**： $E(R_i) = R_f + \beta_i \times (E(R_m) - R_f)$
   - 市场风险溢价 $= 9.4\% - 2.3\% = 7.1\%$
   - $E(R_X) = 2.3\% + 0.62 \times 7.1\% = 6.702\%$
   - $E(R_Y) = 2.3\% + 1.18 \times 7.1\% = 10.678\%$
   - $E(R_Z) = 2.3\% + 1.51 \times 7.1\% = 13.021\%$

2. **Alpha 计算**： $\alpha = 实际收益 - 期望收益$
   - $\alpha_Y = 13.1\% - 10.678\% = 2.422\%$

所有要求的输出均已存入 `result` 字典中，键名严格符合契约要求，值以小数形式保存（例如 0.06702），确保计算精确与可复现性。
