要计算整个样本期的年化夏普比率，你需要用 **fund** 列日收益数据，与年化无风险利率 2.1% 一起处理。  
下面给出可直接运行的 Python 代码（假设数据文件是 CSV 格式，其中包含 `fund` 列）。  
如果没有具体数据，代码将无法算出具体数值，但逻辑是完备的。

```python
import pandas as pd
import numpy as np

# 1. 读取数据（请根据实际文件路径和格式修改）
df = pd.read_csv('your_data.csv')          # 也可能是 Excel: pd.read_excel()
daily_returns = df['fund']                 # 日收益序列（例如小数形式，0.01 代表 1%）

# 2. 设定无风险利率与年化交易日数
rf_annual = 0.021           # 2.1%
trading_days = 252          # 一般假设252个交易日
rf_daily = rf_annual / trading_days

# 3. 计算日超额收益
excess_daily = daily_returns - rf_daily

# 4. 年化夏普比率
#    使用样本标准差（ddof=1），更符合金融实务
sharpe_daily = excess_daily.mean() / excess_daily.std(ddof=1)
sharpe_annual = np.sqrt(trading_days) * sharpe_daily

# 5. 按要求存入字典
result = {'sharpe_annual': sharpe_annual}
print(result)
```

**说明**：  
- 无风险利率 2.1% 是年化值，转换为日无风险利率 **2.1% ÷ 252**。  
- 年化夏普 = √252 × (日超额收益均值 / 日超额收益标准差)。  
- 如果你的数据文件中“日期”列是索引，或者需要先按日期排序，请自行调整。  
- 若需要使用总体标准差，可将 `ddof=1` 改为 `ddof=0`。

运行代码后，`result` 字典中就包含了键 `'sharpe_annual'` 及其对应的数值，完全符合你的输出契约。
