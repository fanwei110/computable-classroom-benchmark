根据题目要求，我们使用资本资产定价模型（CAPM）计算三只股票的期望收益率，并计算股票Y的Alpha值。

CAPM公式为：
\[ E(R_i) = R_f + \beta_i \times (E(R_m) - R_f) \]

其中：
- \( R_f \) = 无风险收益率 = 2.3% = 0.023
- \( E(R_m) \) = 市场收益率 = 9.4% = 0.094
- \( \beta_i \) = 各股票的Beta值

### 1. 计算三只股票的期望收益率
三只股票的Beta值分别为：0.62, 1.18, 1.51。

- 股票X（Beta = 0.62）：
  \[ E(R_x) = 0.023 + 0.62 \times (0.094 - 0.023) = 0.023 + 0.62 \times 0.071 = 0.023 + 0.04402 = 0.06702 \]
  期望收益率 = 6.702%

- 股票Y（Beta = 1.18）：
  \[ E(R_y) = 0.023 + 1.18 \times (0.094 - 0.023) = 0.023 + 1.18 \times 0.071 = 0.023 + 0.08378 = 0.10678 \]
  期望收益率 = 10.678%

- 股票Z（Beta = 1.51）：
  \[ E(R_z) = 0.023 + 1.51 \times (0.094 - 0.023) = 0.023 + 1.51 \times 0.071 = 0.023 + 0.10721 = 0.13021 \]
  期望收益率 = 13.021%

### 2. 计算股票Y的Alpha
Alpha的计算公式为：
\[ \alpha_y = R_y - E(R_y) \]
其中：
- \( R_y \) = 股票Y的实际收益率 = 13.1% = 0.131
- \( E(R_y) \) = 股票Y的期望收益率 = 10.678% = 0.10678

\[ \alpha_y = 0.131 - 0.10678 = 0.02422 \]
Alpha = 2.422%
