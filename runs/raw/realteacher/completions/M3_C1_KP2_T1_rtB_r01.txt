根据资本资产定价模型（CAPM），期望收益的计算公式为：
$$E(R_i) = R_f + \beta_i \times (E(R_m) - R_f)$$

已知数据：
- 无风险利率 $R_f = 2.3\% = 0.023$
- 市场期望收益 $E(R_m) = 9.4\% = 0.094$
- 市场风险溢价 $E(R_m) - R_f = 9.4\% - 2.3\% = 7.1\% = 0.071$

**1. 计算三只股票的期望收益：**
- X的期望收益：$E(R_X) = 0.023 + 0.62 \times 0.071 = 0.023 + 0.04402 = 0.06702$ (即6.702%)
- Y的期望收益：$E(R_Y) = 0.023 + 1.18 \times 0.071 = 0.023 + 0.08378 = 0.10678$ (即10.678%)
- Z的期望收益：$E(R_Z) = 0.023 + 1.51 \times 0.071 = 0.023 + 0.10721 = 0.13021$ (即13.021%)

**2. 计算Y的Alpha：**
Alpha的计算公式为实际收益减去CAPM计算的期望收益：
$$\alpha_Y = R_{actual\_Y} - E(R_Y)$$
- Y的Alpha：$\alpha_Y = 0.131 - 0.10678 = 0.02422$ (即2.422%)
