根据资本资产定价模型（CAPM），期望收益率的计算公式为：

\[ \text{期望收益率} = \text{无风险利率} + \beta \times (\text{市场期望收益率} - \text{无风险利率}) \]

Y的alpha计算公式为：

\[ \alpha = \text{实际收益率} - \text{期望收益率} \]

以下是计算结果：

```python
result = {
    'er_x': 2.3 + 0.62 * (9.4 - 2.3),
    'er_y': 2.3 + 1.18 * (9.4 - 2.3),
    'er_z': 2.3 + 1.51 * (9.4 - 2.3),
    'alpha_y': 13.1 - (2.3 + 1.18 * (9.4 - 2.3))
}
```

具体数值如下：
