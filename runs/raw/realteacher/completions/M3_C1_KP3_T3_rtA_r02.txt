要计算这只7年期债券在收益率上涨80个基点（0.80%）时的价格大概下跌幅度，我们可以通过精确的债券定价公式来计算。

**1. 计算初始价格 (P0)**
已知：面值 F = 100，票息 C = 4.6，期限 n = 7，初始收益率 y = 5.3% = 0.053
P0 = C * [1 - (1+y)^(-n)] / y + F * (1+y)^(-n)
P0 = 4.6 * [1 - 1.053^(-7)] / 0.053 + 100 * 1.053^(-7)
P0 ≈ 4.6 * 5.7240 + 100 * 0.69661
P0 ≈ 26.3304 + 69.6614 = 95.9918

**2. 计算收益率上涨后的新价格 (P1)**
新收益率 y' = 5.3% + 0.80% = 6.1% = 0.061
P1 = 4.6 * [1 - 1.061^(-7)] / 0.061 + 100 * 1.061^(-7)
P1 ≈ 4.6 * 5.5365 + 100 * 0.66227
P1 ≈ 25.4680 + 66.2272 = 91.6952

**3. 计算价格下跌百分比**
价格变动 = (P1 - P0) / P0 = (91.6952 - 95.9918) / 95.9918 ≈ -0.04476
即价格大概下跌 4.48%。
