根据资本资产定价模型（CAPM），期望收益率的计算公式为：
$$E(R_i) = R_f + \beta_i \times (R_m - R_f)$$
Alpha 的计算公式为：
$$\alpha_i = R_{i, actual} - E(R_i)$$

已知参数：
- 无风险利率 $R_f = 2.3\% = 0.023$
- 市场收益率 $R_m = 9.4\% = 0.094$
- 市场风险溢价 $R_m - R_f = 0.094 - 0.023 = 0.071$
- $\beta_x = 0.62$, $\beta_y = 1.18$, $\beta_z = 1.51$
- Y的实际收益率 $R_{y, actual} = 13.1\% = 0.131$

**计算过程：**
1. X的期望收益：
   $E(R_x) = 0.023 + 0.62 \times 0.071 = 0.023 + 0.04402 = 0.06702$

2. Y的期望收益：
   $E(R_y) = 0.023 + 1.18 \times 0.071 = 0.023 + 0.08378 = 0.10678$

3. Z的期望收益：
   $E(R_z) = 0.023 + 1.51 \times 0.071 = 0.023 + 0.10721 = 0.13021$

4. Y的Alpha：
   $\alpha_y = 0.131 - 0.10678 = 0.02422$

（注：给定的计算约定如252交易日、连续复利、ddof等均针对特定产品如债券、期权或统计量，CAPM直接使用年化利率输入，无需进行日度转换或特殊调整）
