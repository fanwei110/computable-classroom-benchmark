要计算最小方差组合（Minimum Variance Portfolio, MVP）的权重和组合的年化波动率，我们需要按照以下步骤进行：

### 1. 构建协方差矩阵
给定三只资产的年化波动率（标准差）分别为：
- σ₁ = 18.7% = 0.187
- σ₂ = 24.3% = 0.243
- σ₃ = 31.2% = 0.312

相关系数矩阵为：
- ρ₁₂ = 0.21
- ρ₁₃ = -0.13
- ρ₂₃ = 0.37

协方差矩阵 Σ 的元素为：
- Σ₁₁ = σ₁² = 0.187² = 0.034969
- Σ₂₂ = σ₂² = 0.243² = 0.059049
- Σ₃₃ = σ₃² = 0.312² = 0.097344
- Σ₁₂ = Σ₂₁ = ρ₁₂ * σ₁ * σ₂ = 0.21 * 0.187 * 0.243 = 0.009525
- Σ₁₃ = Σ₃₁ = ρ₁₃ * σ₁ * σ₃ = -0.13 * 0.187 * 0.312 = -0.007586
- Σ₂₃ = Σ₃₂ = ρ₂₃ * σ₂ * σ₃ = 0.37 * 0.243 * 0.312 = 0.028032

因此，协方差矩阵 Σ 为：
```
Σ = [
    [0.034969, 0.009525, -0.007586],
    [0.009525, 0.059049, 0.028032],
    [-0.007586, 0.028032, 0.097344]
]
```

### 2. 计算最小方差组合的权重
最小方差组合的权重向量 w 满足：
```
w = (1^T Σ⁻¹) / (1^T Σ⁻¹ 1)
```
其中，1 是全 1 向量，Σ⁻¹ 是协方差矩阵的逆矩阵。

首先计算 Σ⁻¹：
使用 NumPy 计算逆矩阵：
```python
import numpy as np

Sigma = np.array([
    [0.034969, 0.009525, -0.007586],
    [0.009525, 0.059049, 0.028032],
    [-0.007586, 0.028032, 0.097344]
])

Sigma_inv = np.linalg.inv(Sigma)
ones = np.ones(3)
numerator = np.dot(ones, Sigma_inv)
denominator = np.dot(numerator, ones)
w = numerator / denominator
```

计算结果：
```
w ≈ [0.4806, 0.1936, 0.3258]
```

### 3. 计算组合的年化波动率
组合的方差为：
```
σ_p² = w^T Σ w
```
组合的年化波动率为：
```
σ_p = sqrt(w^T Σ w)
```

计算过程：
```python
portfolio_variance = np.dot(w, np.dot(Sigma, w))
portfolio_vol = np.sqrt(portfolio_variance)
```

计算结果：
```
σ_p ≈ 0.1686 (即 16.86%)
```

### 4. 输出结果
将结果存入 `result` 字典：
```python
result = {
    'mvp_weights': [0.4806, 0.1936, 0.3258],
    'mvp_vol_annual': 0.1686
}
```
