根据资本资产定价模型（CAPM），期望收益的计算公式为：
$$E(R_i) = R_f + \beta_i \times (E(R_m) - R_f)$$

其中：
- 无风险利率 $R_f = 2.3\%$
- 市场期望收益 $E(R_m) = 9.4\%$
- 市场风险溢价 $E(R_m) - R_f = 9.4\% - 2.3\% = 7.1\%$

**计算过程：**
1. **股票X的期望收益 (er_x):** 
   $E(R_x) = 2.3\% + 0.62 \times 7.1\% = 2.3\% + 4.402\% = 6.702\%$

2. **股票Y的期望收益 (er_y):** 
   $E(R_y) = 2.3\% + 1.18 \times 7.1\% = 2.3\% + 8.378\% = 10.678\%$

3. **股票Z的期望收益 (er_z):** 
   $E(R_z) = 2.3\% + 1.51 \times 7.1\% = 2.3\% + 10.721\% = 13.021\%$

4. **股票Y的Alpha (alpha_y):**
   Alpha是实际收益与CAPM模型预测的期望收益之差，即 $\alpha_y = 实际收益 - E(R_y)$
   $\alpha_y = 13.1\% - 10.678\% = 2.422\%$
