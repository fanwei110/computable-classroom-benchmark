要计算整个样本期的年化夏普比率，需要从数据文件中读取 `fund` 列的**日收益率**（通常为小数形式，例如 0.01 表示 1%）。无风险利率按**年化 2.1%** 转换为日无风险利率，然后依据以下步骤计算：

1. 日无风险利率 = 2.1% / 252（假设一年有 252 个交易日）；
2. 日超额收益 = 日收益率 - 日无风险利率；
3. 年化夏普比率 = √252 × (日超额收益均值 / 日超额收益标准差)。

具体实现代码如下（假设数据文件为 `data.csv` 且包含 `fund` 列；若为其他格式请相应调整读取函数）：

```python
import pandas as pd
import numpy as np

# 读取数据文件（请根据实际路径/格式修改）
df = pd.read_csv('data.csv')          # 若为 Excel 可用 pd.read_excel
daily_returns = df['fund']

# 若收益率是百分比形式（如 1.0 代表 1%），转换为小数
# daily_returns = daily_returns / 100

# 参数设定
rf_annual = 0.021                     # 年化无风险利率
trading_days = 252                    # 年度交易日数
rf_daily = rf_annual / trading_days   # 日无风险利率

# 计算日超额收益
excess_returns = daily_returns - rf_daily

# 年化夏普比率
mean_excess = excess_returns.mean()
std_excess = excess_returns.std()
sharpe_annual = np.sqrt(trading_days) * (mean_excess / std_excess)

# 按要求存入字典
result = {'sharpe_annual': sharpe_annual}
```

运行后，`result` 字典中即包含最终的 `sharpe_annual` 值。
