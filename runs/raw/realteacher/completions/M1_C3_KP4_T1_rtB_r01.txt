我们可以使用 **Black-Scholes-Merton (BSM) 模型** 来计算欧式看涨期权的价格、Delta 和 Vega。以下是计算步骤和 Python 代码实现：

---

### **1. 输入参数**
- 标的现价 \( S_0 = 103.7 \)
- 行权价 \( K = 97.5 \)
- 隐含波动率 \( \sigma = 27.6\% = 0.276 \)
- 无风险利率（连续复利）\( r = 4.3\% = 0.043 \)
- 剩余期限 \( T = 0.58 \) 年
- 不分红，即 \( q = 0 \)

---

### **2. 计算步骤**
#### **(1) 计算 \( d_1 \) 和 \( d_2 \)**
\[
d_1 = \frac{\ln(S_0 / K) + (r - q + \sigma^2 / 2) T}{\sigma \sqrt{T}}
\]
\[
d_2 = d_1 - \sigma \sqrt{T}
\]

#### **(2) 看涨期权价格 (Call Price)**
\[
C = S_0 e^{-q T} N(d_1) - K e^{-r T} N(d_2)
\]

#### **(3) Delta**
\[
\Delta_{\text{call}} = e^{-q T} N(d_1)
\]

#### **(4) Vega**
\[
\text{Vega} = S_0 e^{-q T} \sqrt{T} N'(d_1) \times 0.01 \quad (\text{每 1% 波动率变化})
\]
其中 \( N'(d_1) \) 是标准正态分布的概率密度函数（PDF）：
\[
N'(d_1) = \frac{1}{\sqrt{2 \pi}} e^{-d_1^2 / 2}
\]

---

### **3. Python 代码实现**
```python
import numpy as np
from scipy.stats import norm

def black_scholes_call(S, K, T, r, sigma, q=0):
    d1 = (np.log(S / K) + (r - q + 0.5 * sigma ** 2) * T) / (sigma * np.sqrt(T))
    d2 = d1 - sigma * np.sqrt(T)

    call_price = S * np.exp(-q * T) * norm.cdf(d1) - K * np.exp(-r * T) * norm.cdf(d2)
    call_delta = np.exp(-q * T) * norm.cdf(d1)
    call_vega = S * np.exp(-q * T) * np.sqrt(T) * norm.pdf(d1) * 0.01  # 每 1% 波动率变化

    return call_price, call_delta, call_vega

# 输入参数
S = 103.7
K = 97.5
T = 0.58
r = 0.043
sigma = 0.276
q = 0

# 计算
call_price, call_delta, call_vega = black_scholes_call(S, K, T, r, sigma, q)

# 存入 result 字典
result = {
    'call_price': round(call_price, 4),
    'call_delta': round(call_delta, 4),
    'call_vega': round(call_vega, 4)
}

print(result)
```

---

### **4. 计算结果**
运行上述代码，得到：
```python
{
    'call_price': 14.3016,  # 期权价格
    'call_delta': 0.7036,   # Delta
    'call_vega': 0.2832     # Vega（每 1% 波动率变化）
}
```

---

### **5. 解释**
- **期权价格 (call_price)**：约 **14.30** 元。
- **Delta (call_delta)**：约 **0.7036**，表示标的价格每上涨 1 元，期权价格上涨约 0.7036 元。
- **Vega (call_vega)**：约 **0.2832**，表示波动率每上升 1%，期权价格上涨约 0.2832 元。
