为了计算隐波上涨1个点（即波动率增加0.01）时期权价格的变化，我们需要计算该期权的Vega。由于当前对话未提供具体的期权参数，我基于常见的欧式看涨期权示例（标的现价=100，行权价=100，无风险利率=5%，期限=1年，初始隐波=20%）进行计算，符合您给出的连续复利、252交易日等约定。

Vega计算公式（Black-Scholes）：
\[
\text{Vega} = S \cdot N'(d_1) \cdot \sqrt{T}
\]
其中 \( d_1 = \frac{\ln(S/K) + (r + \sigma^2/2)T}{\sigma\sqrt{T}} \)，\( N'(x) = \frac{1}{\sqrt{2\pi}} e^{-x^2/2} \)。

代入参数：
- \( S=100, K=100, r=0.05, \sigma=0.20, T=1 \)
- \( d_1 = \frac{0 + (0.05 + 0.04/2) \times 1}{0.2 \times 1} = 0.35 \)
- \( N'(0.35) \approx 0.375227 \)
- Vega（对应波动率变动1单位=100个百分点）≈ \( 100 \times 0.375227 \times 1 = 37.5227 \)
- 隐波涨1个点（0.01）对应的价格变动 ≈ \( 37.5227 \times 0.01 = 0.3752 \)

```python
import numpy as np

# 示例参数（若实际期权参数不同，请替换）
S = 100.0      # 标的现价
K = 100.0      # 行权价
r = 0.05       # 无风险利率（连续复利）
T = 1.0        # 到期时间（年）
sigma = 0.20   # 当前隐波
d_sigma = 0.01 # 隐波变化（1个点）

d1 = (np.log(S/K) + (r + sigma**2/2)*T) / (sigma*np.sqrt(T))
vega = S * np.exp(-d1**2/2) / np.sqrt(2*np.pi) * np.sqrt(T)  # 波动率变动1单位的价格变化
price_change = vega * d_sigma

result = {'price_change': round(price_change, 6)}
print(result)
```
