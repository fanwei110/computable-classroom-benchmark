要计算隐含波动率上涨1个点（1%）时期权价格的变化，我们需要计算该期权的Vega。Vega表示隐含波动率每变动1%（0.01），期权价格的绝对变化量。

根据给定的参数，我们推断其分别为：
- 标的资产价格 (S) = 103.7
- 行权价 (K) = 97.5
- 隐含波动率 (σ) = 27.6% = 0.276
- 无风险利率 = 4.3% = 0.043
- 到期时间 (T) = 0.58年

**1. 计算 d1：**
d1 = [ln(S/K) + (r + σ²/2) * T] / (σ * √T)
d1 = [ln(103.7/97.5) + (0.043 + 0.276²/2) * 0.58] / (0.276 * √0.58)
d1 = [0.06124 + (0.043 + 0.03809) * 0.58] / (0.276 * 0.76158)
d1 = [0.06124 + 0.08109 * 0.58] / 0.21020
d1 = [0.06124 + 0.04703] / 0.21020
d1 = 0.10827 / 0.21020 ≈ 0.5151

**2. 计算正态分布概率密度 N'(d1)：**
N'(d1) = (1 / √(2π)) * exp(-d1²/2)
N'(0.5151) = 0.39894 * exp(-0.5151²/2)
N'(0.5151) = 0.39894 * exp(-0.13267)
N'(0.5151) = 0.39894 * 0.87574 ≈ 0.3494

**3. 计算 Vega：**
Vega = S * N'(d1) * √T
Vega = 103.7 * 0.3494 * 0.76158
Vega ≈ 27.58

**4. 计算隐含波动率涨1个点（1% = 0.01）时的价格变化：**
Price_Change = Vega * 0.01
Price_Change = 27.58 * 0.01 = 0.2758
