根据资本资产定价模型（CAPM）计算如下：

1. **计算市场风险溢价**：
   $$MRP = R_m - R_f = 9.4\% - 2.3\% = 7.1\%$$

2. **计算三只股票的期望收益**：
   - 股票 X: $$E(R_x) = 2.3\% + 0.62 \times 7.1\% = 2.3\% + 4.402\% = 6.702\%$$
   - 股票 Y: $$E(R_y) = 2.3\% + 1.18 \times 7.1\% = 2.3\% + 8.378\% = 10.678\%$$
   - 股票 Z: $$E(R_z) = 2.3\% + 1.51 \times 7.1\% = 2.3\% + 10.721\% = 13.021\%$$

3. **计算股票 Y 的 Alpha**：
   $$\alpha_y = 实际收益 - 期望收益 = 13.1\% - 10.678\% = 2.422\%$$
