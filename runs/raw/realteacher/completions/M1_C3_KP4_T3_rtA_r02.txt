要计算隐含波动率（隐波）上涨1个点（即隐波增加0.01）时期权价格的变化，我们可以使用**Vega**（即期权价格对隐含波动率的敏感性）来近似估计。

Vega的定义是期权价格对隐含波动率变化的偏导数，即：
\[ \text{Vega} = \frac{\partial C}{\partial \sigma} \]

对于标准的欧式期权（Black-Scholes模型），Vega的计算公式为：
\[ \text{Vega} = S \cdot \sqrt{T} \cdot N'(d_1) \]
其中：
- \( S \) 是标的资产价格
- \( T \) 是期权到期时间（以年为单位）
- \( N'(d_1) \) 是标准正态分布的概率密度函数在 \( d_1 \) 处的值
- \( d_1 = \frac{\ln(S/K) + (r + \sigma^2/2)T}{\sigma \sqrt{T}} \)
- \( K \) 是行权价
- \( r \) 是无风险利率
- \( \sigma \) 是隐含波动率

### 计算步骤：
1. 计算当前隐波下的Vega。
2. 隐波上涨1个点（即增加0.01），期权价格的变化近似为：
   \[ \Delta C \approx \text{Vega} \times \Delta \sigma \]
   其中 \( \Delta \sigma = 0.01 \)。

### 输出：
将结果存入 `result` 字典，键为 `'price_change'`。

### 示例代码（假设已知期权参数）：
```python
import numpy as np
from scipy.stats import norm

def calculate_vega(S, K, T, r, sigma):
    d1 = (np.log(S / K) + (r + 0.5 * sigma ** 2) * T) / (sigma * np.sqrt(T))
    vega = S * np.sqrt(T) * norm.pdf(d1)
    return vega

# 假设期权参数（示例值，需替换为实际值）
S = 100       # 标的资产价格
K = 100       # 行权价
T = 0.5       # 到期时间（年）
r = 0.05      # 无风险利率（连续复利）
sigma = 0.2   # 隐含波动率

# 计算Vega
vega = calculate_vega(S, K, T, r, sigma)

# 隐波上涨1个点（0.01）时的价格变化
price_change = vega * 0.01

# 存入结果字典
result = {
    'price_change': price_change
}
```

### 结果说明：
- `price_change` 是隐波上涨1个点时，期权价格的近似变化量（单位：与标的资产价格相同的货币单位）。
- 例如，如果Vega为0.2，则 `price_change = 0.2 * 0.01 = 0.002`，即期权价格上涨约0.002个单位。

请根据实际期权参数替换示例中的 `S, K, T, r, sigma` 值。
