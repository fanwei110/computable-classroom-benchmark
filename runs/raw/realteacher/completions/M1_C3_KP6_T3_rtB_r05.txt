要计算整个样本期的年化夏普比率（Sharpe ratio），我们需要按照以下步骤进行：

1. **计算日超额收益**：基金的日收益减去无风险利率的日等价收益（2.1% 年化无风险利率，按每年 252 个交易日计算）。
2. **计算日超额收益的均值和标准差**：使用样本估计量（ddof=1）。
3. **年化处理**：将日超额收益的均值和标准差年化（乘以 √252）。
4. **计算年化夏普比率**：年化超额收益均值除以年化超额收益标准差。

### 计算步骤代码（Python 示例）：
假设 `fund_returns` 是基金的日收益率序列（小数形式，如 0.01 表示 1%），无风险利率为 2.1%（即 0.021），则：

```python
import numpy as np

# 假设 fund_returns 是基金的日收益率序列（小数形式）
# 示例：fund_returns = np.array([0.001, -0.002, 0.003, ...])

# 无风险利率（年化）
risk_free_rate_annual = 0.021

# 计算日无风险利率（按 252 个交易日复利）
risk_free_rate_daily = (1 + risk_free_rate_annual) ** (1/252) - 1

# 计算日超额收益
excess_returns_daily = fund_returns - risk_free_rate_daily

# 计算日超额收益的均值和标准差（样本标准差，ddof=1）
mean_excess_daily = np.mean(excess_returns_daily)
std_excess_daily = np.std(excess_returns_daily, ddof=1)

# 年化处理
mean_excess_annual = mean_excess_daily * 252
std_excess_annual = std_excess_daily * np.sqrt(252)

# 计算年化夏普比率
sharpe_annual = mean_excess_annual / std_excess_annual

# 存入结果字典
result = {
    'sharpe_annual': sharpe_annual
}
```

### 注意事项：
1. 确保 `fund_returns` 是基金的日收益率序列（小数形式，如 0.01 表示 1%）。
2. 如果 `fund_returns` 是从数据文件中读取的，请先加载数据并提取基金收益列。
3. 如果样本期内有缺失值（NaN），需要先处理（如删除或填充）。
