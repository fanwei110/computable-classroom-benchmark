要计算整个样本期的年化夏普比率（Sharpe Ratio），我们需要按照以下步骤进行：

1. 计算每日超额收益（日收益 - 无风险收益率的日等价）。
2. 计算超额收益的均值和标准差。
3. 年化夏普比率 = (超额收益均值 / 超额收益标准差) * √252（假设一年有252个交易日）。

无风险收益率为2.1%，其日等价为：(1 + 0.021)^(1/252) - 1 ≈ 0.00008279（即0.008279%）。

以下是Python代码实现：

```python
import numpy as np
import pandas as pd

# 假设df是包含fund列的DataFrame
# 示例代码（请替换为实际数据加载方式）
# df = pd.read_csv('your_course_data_file.csv')

# 计算日超额收益
daily_risk_free_rate = (1 + 0.021) ** (1/252) - 1
excess_returns = df['fund'] - daily_risk_free_rate

# 计算年化夏普比率
mean_excess_return = excess_returns.mean()
std_excess_return = excess_returns.std()
sharpe_annual = (mean_excess_return / std_excess_return) * np.sqrt(252)

# 存入result字典
result = {
    'sharpe_annual': sharpe_annual
}
```

请确保：
1. `df['fund']` 是基金的日收益率（非累计收益）。
2. 样本期足够长（通常至少几个月以上），以确保统计的有效性。
3. 如果数据中有缺失值，需要提前处理（如 `df.dropna()`）。

最终结果会存储在 `result['sharpe_annual']` 中。
