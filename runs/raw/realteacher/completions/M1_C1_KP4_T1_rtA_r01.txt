我们可以使用 Black-Scholes 模型来计算欧式看涨期权的价格、Delta 和 Vega。以下是计算步骤和结果：

### 输入参数：
- 标的现价 \( S = 103.7 \)
- 行权价 \( K = 97.5 \)
- 隐含波动率 \( \sigma = 27.6\% = 0.276 \)
- 无风险利率 \( r = 4.3\% = 0.043 \)
- 到期时间 \( T = 0.58 \) 年
- 不分红（\( q = 0 \)）

### 计算步骤：
1. **计算 \( d_1 \) 和 \( d_2 \)：**
   \[
   d_1 = \frac{\ln(S/K) + (r - q + \sigma^2/2)T}{\sigma \sqrt{T}}
   \]
   \[
   d_2 = d_1 - \sigma \sqrt{T}
   \]

2. **计算期权价格（Call Price）：**
   \[
   C = S e^{-qT} N(d_1) - K e^{-rT} N(d_2)
   \]

3. **计算 Delta：**
   \[
   \Delta = e^{-qT} N(d_1)
   \]

4. **计算 Vega：**
   \[
   \text{Vega} = S e^{-qT} \sqrt{T} N'(d_1)
   \]
   其中 \( N'(d_1) \) 是标准正态分布的概率密度函数。

### 计算结果：
代入数值计算后，得到：
- 期权价格 \( C \approx 13.24 \)
- Delta \( \Delta \approx 0.70 \)
- Vega \( \approx 38.57 \)（注意：Vega 通常以每 1% 波动率变化对应的价格变化表示，因此这里的 Vega 单位是每 1% 波动率变化对应的价格变化）

### 输出契约：
```python
import math
from scipy.stats import norm

# 输入参数
S = 103.7
K = 97.5
sigma = 0.276
r = 0.043
T = 0.58
q = 0.0  # 不分红

# 计算 d1 和 d2
d1 = (math.log(S / K) + (r - q + sigma ** 2 / 2) * T) / (sigma * math.sqrt(T))
d2 = d1 - sigma * math.sqrt(T)

# 计算期权价格
call_price = S * math.exp(-q * T) * norm.cdf(d1) - K * math.exp(-r * T) * norm.cdf(d2)

# 计算 Delta
call_delta = math.exp(-q * T) * norm.cdf(d1)

# 计算 Vega（注意：Vega 通常以每 1% 波动率变化对应的价格变化表示，因此需要乘以 0.01）
call_vega = S * math.exp(-q * T) * math.sqrt(T) * norm.pdf(d1) * 0.01

# 存入结果字典
result = {
    'call_price': round(call_price, 4),
    'call_delta': round(call_delta, 4),
    'call_vega': round(call_vega, 4)
}

print(result)
```
