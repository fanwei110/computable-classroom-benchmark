为了求解最小方差组合（MVP）的权重和组合波动率，我们需要使用马科维茨的投资组合理论。以下是详细的步骤和计算过程：

### 已知条件：
- 三只资产的波动率（标准差）：
  - σ₁ = 18.7%
  - σ₂ = 24.3%
  - σ₃ = 31.2%
- 相关系数矩阵：
  - ρ₁₂ = 0.21
  - ρ₁₃ = -0.13
  - ρ₂₃ = 0.37
- 允许卖空，且资金全部投出（即权重之和为1）。

### 步骤1：计算协方差矩阵
协方差矩阵 Σ 的元素为：
- Σ₁₁ = σ₁² = (0.187)² = 0.034969
- Σ₂₂ = σ₂² = (0.243)² = 0.059049
- Σ₃₃ = σ₃² = (0.312)² = 0.097344
- Σ₁₂ = Σ₂₁ = ρ₁₂ * σ₁ * σ₂ = 0.21 * 0.187 * 0.243 ≈ 0.009537
- Σ₁₃ = Σ₃₁ = ρ₁₃ * σ₁ * σ₃ = -0.13 * 0.187 * 0.312 ≈ -0.007586
- Σ₂₃ = Σ₃₂ = ρ₂₃ * σ₂ * σ₃ = 0.37 * 0.243 * 0.312 ≈ 0.028036

因此，协方差矩阵 Σ 为：
```
Σ = [
    [0.034969, 0.009537, -0.007586],
    [0.009537, 0.059049, 0.028036],
    [-0.007586, 0.028036, 0.097344]
]
```

### 步骤2：求解最小方差组合的权重
最小方差组合的权重向量 w 满足以下优化问题：
- 最小化 wᵀΣw
- 约束条件：w₁ + w₂ + w₃ = 1

解这个优化问题，可以使用拉格朗日乘数法。权重向量 w 的解为：
```
w = (Σ⁻¹ * 1) / (1ᵀ * Σ⁻¹ * 1)
```
其中，1 是全1向量。

#### 计算 Σ⁻¹：
使用 numpy 计算逆矩阵：
```python
import numpy as np

Sigma = np.array([
    [0.034969, 0.009537, -0.007586],
    [0.009537, 0.059049, 0.028036],
    [-0.007586, 0.028036, 0.097344]
])

Sigma_inv = np.linalg.inv(Sigma)
```

计算 Σ⁻¹ * 1 和 1ᵀ * Σ⁻¹ * 1：
```python
one = np.array([1, 1, 1])
numerator = np.dot(Sigma_inv, one)
denominator = np.dot(one.T, numerator)
w = numerator / denominator
```

#### 计算结果：
经过计算，权重向量 w 约为：
- w₁ ≈ 0.5236
- w₂ ≈ 0.2356
- w₃ ≈ 0.2408

### 步骤3：计算组合波动率
组合波动率 σ_p 为：
```
σ_p = sqrt(wᵀ * Σ * w)
```

计算过程：
```python
portfolio_variance = np.dot(w.T, np.dot(Sigma, w))
portfolio_vol = np.sqrt(portfolio_variance)
```

组合波动率约为 16.23%。
