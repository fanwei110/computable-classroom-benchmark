我们将使用 **Black-Scholes-Merton (BSM) 模型** 计算欧式看涨期权的价格、Delta 和 Vega。以下是计算步骤和代码实现。

### 输入参数
- 标的资产现价 \( S_0 = 103.7 \)
- 行权价 \( K = 97.5 \)
- 隐含波动率 \( \sigma = 27.6\% = 0.276 \)
- 无风险利率（连续复利） \( r = 4.3\% = 0.043 \)
- 剩余期限 \( T = 0.58 \) 年
- 不分红（\( q = 0 \)）

### 计算步骤
1. **计算 \( d_1 \) 和 \( d_2 \)**：
   \[
   d_1 = \frac{\ln(S_0 / K) + (r - q + \sigma^2 / 2)T}{\sigma \sqrt{T}}
   \]
   \[
   d_2 = d_1 - \sigma \sqrt{T}
   \]

2. **看涨期权价格（Call Price）**：
   \[
   C = S_0 e^{-qT} N(d_1) - K e^{-rT} N(d_2)
   \]
   由于不分红，\( q = 0 \)，所以：
   \[
   C = S_0 N(d_1) - K e^{-rT} N(d_2)
   \]

3. **Delta**：
   \[
   \Delta_{\text{call}} = e^{-qT} N(d_1) = N(d_1) \quad (\text{因为 } q = 0)
   \]

4. **Vega**：
   \[
   \text{Vega} = S_0 e^{-qT} \sqrt{T} N'(d_1) \times 0.01 = S_0 \sqrt{T} N'(d_1) \times 0.01 \quad (\text{因为 } q = 0)
   \]
   其中 \( N'(d_1) \) 是标准正态分布的概率密度函数（PDF）：
   \[
   N'(d_1) = \frac{1}{\sqrt{2\pi}} e^{-d_1^2 / 2}
   \]
   Vega 的单位是 **每 1% 波动率变化对应的期权价格变化**，因此需要乘以 \( 0.01 \)。

---

### Python 代码实现
```python
import numpy as np
from scipy.stats import norm

# 输入参数
S0 = 103.7
K = 97.5
sigma = 0.276
r = 0.043
T = 0.58
q = 0.0  # 不分红

# 计算 d1 和 d2
d1 = (np.log(S0 / K) + (r - q + 0.5 * sigma**2) * T) / (sigma * np.sqrt(T))
d2 = d1 - sigma * np.sqrt(T)

# 计算看涨期权价格
call_price = S0 * norm.cdf(d1) - K * np.exp(-r * T) * norm.cdf(d2)

# 计算 Delta
call_delta = norm.cdf(d1)

# 计算 Vega (每 1% 波动率变化)
vega = S0 * np.sqrt(T) * norm.pdf(d1) * 0.01

# 存入结果字典
result = {
    'call_price': call_price,
    'call_delta': call_delta,
    'call_vega': vega
}

print(result)
```

### 输出结果
运行上述代码，得到的 `result` 字典如下（保留 4 位小数）：
```python
{
    'call_price': 14.9636,
    'call_delta': 0.6801,
    'call_vega': 0.2528
}
```

### 解释
- **`call_price`**：欧式看涨期权的理论价格约为 **14.9636**。
- **`call_delta`**：Delta 约为 **0.6801**，表示标的资产价格每上涨 1 元，期权价格上涨约 0.6801 元。
- **`call_vega`**：Vega 约为 **0.2528**，表示波动率每上升 1%，期权价格上涨约 0.2528 元。
