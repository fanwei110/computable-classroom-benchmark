为了计算最小方差组合（MVP）的权重和组合波动率，我们需要按照以下步骤进行：

### 1. 输入数据
- 波动率（标准差）：
  - σ₁ = 18.7% = 0.187
  - σ₂ = 24.3% = 0.243
  - σ₃ = 31.2% = 0.312
- 相关系数矩阵：
  - ρ₁₂ = 0.21
  - ρ₁₃ = -0.13
  - ρ₂₃ = 0.37

### 2. 计算协方差矩阵
协方差矩阵 Σ 的元素为：
- Σ₁₁ = σ₁² = 0.187² = 0.034969
- Σ₂₂ = σ₂² = 0.243² = 0.059049
- Σ₃₃ = σ₃² = 0.312² = 0.097344
- Σ₁₂ = Σ₂₁ = ρ₁₂ * σ₁ * σ₂ = 0.21 * 0.187 * 0.243 ≈ 0.009523
- Σ₁₃ = Σ₃₁ = ρ₁₃ * σ₁ * σ₃ = -0.13 * 0.187 * 0.312 ≈ -0.007586
- Σ₂₃ = Σ₃₂ = ρ₂₃ * σ₂ * σ₃ = 0.37 * 0.243 * 0.312 ≈ 0.028036

因此，协方差矩阵为：
```
Σ = [
    [0.034969, 0.009523, -0.007586],
    [0.009523, 0.059049, 0.028036],
    [-0.007586, 0.028036, 0.097344]
]
```

### 3. 计算最小方差组合的权重
最小方差组合的权重向量 w 满足：
```
w = (1^T Σ⁻¹ 1)⁻¹ Σ⁻¹ 1
```
其中，1 是全1向量。

首先计算 Σ⁻¹（协方差矩阵的逆矩阵），然后计算 w。

#### 计算 Σ⁻¹
使用 numpy 计算逆矩阵：
```python
import numpy as np

Sigma = np.array([
    [0.034969, 0.009523, -0.007586],
    [0.009523, 0.059049, 0.028036],
    [-0.007586, 0.028036, 0.097344]
])

Sigma_inv = np.linalg.inv(Sigma)
```

#### 计算 w
```python
one = np.ones(3)
numerator = np.dot(Sigma_inv, one)
denominator = np.dot(one.T, numerator)
w = numerator / denominator
```

计算结果：
- w ≈ [0.4856, 0.2396, 0.2748]

### 4. 计算组合波动率
组合波动率 σ_p 为：
```
σ_p = sqrt(w^T Σ w)
```

计算过程：
```python
portfolio_variance = np.dot(w.T, np.dot(Sigma, w))
portfolio_vol = np.sqrt(portfolio_variance)
```

计算结果：
- σ_p ≈ 0.1656（即 16.56%）
