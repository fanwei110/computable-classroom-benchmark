### 计算逻辑说明
1. **无风险利率日化**：根据约定“债券收益率按年复利报价”，年化无风险利率2.1%（即0.021）需按年复利折算为日无风险利率：$r_{f,d} = (1 + 0.021)^{1/252} - 1$。
2. **日超额收益**：$r_{ex,d} = r_{d} - r_{f,d}$。
3. **标准差**：根据约定“标准差用样本估计量（ddof=1）”，计算日超额收益的样本标准差。
4. **年化夏普比率**：根据约定“年化与去年化一律按每年252个交易日”，年化夏普 = (日均超额收益 / 日超额收益样本标准差) × $\sqrt{252}$。

### Python实现代码

```python
import numpy as np
import pandas as pd

# --- 假设您已通过 pd.read_csv() 或其他方式加载数据为 df ---
# daily_returns = df['fund']  # 确保 fund 列的日收益是小数表示（如 0.05 表示 5%）

# 1. 无风险利率参数（小数表示）
rf_annual = 0.021

# 2. 债券收益率按年复利报价，折算为日无风险利率
rf_daily = (1 + rf_annual) ** (1 / 252) - 1

# 3. 计算日超额收益
daily_ex_returns = daily_returns - rf_daily

# 4. 计算日均超额收益与日超额收益样本标准差（ddof=1）
mean_ex_daily = np.mean(daily_ex_returns)
std_ex_daily = np.std(daily_ex_returns, ddof=1)

# 5. 计算年化夏普比率 (Sharpe = (均值/标准差) * sqrt(252))
sharpe_annual = (mean_ex_daily / std_ex_daily) * np.sqrt(252)

# 6. 按输出契约存入字典
result = {'sharpe_annual': sharpe_annual}

print(result)
```

**重点提醒**：
- 输入的`fund`列日收益必须是小数格式（即5%应表示为`0.05`而不是`5`）。
- 采用日度相减后乘以 $\sqrt{252}$ 的方式年化，这在数学上等价于（年化超额收益 / 年化超额标准差），是业界最标准且无偏差的年化夏普计算方法。
