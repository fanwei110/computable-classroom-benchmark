要计算整个样本期的年化夏普比率（Sharpe ratio），我们按照以下步骤进行：

1. **计算日超额收益**：基金的日收益减去无风险利率的日等价收益（2.1% 年化，按 252 个交易日计算）。
2. **计算超额收益的均值和标准差**：使用样本估计量（`ddof=1`）。
3. **年化夏普比率**：将日超额收益的均值和标准差年化（乘以 √252），然后计算夏普比率。

### 计算步骤：
1. 无风险利率的日等价收益：
   \[
   r_f^{daily} = \frac{0.021}{252}
   \]
2. 日超额收益：
   \[
   R_{excess} = R_{fund} - r_f^{daily}
   \]
3. 日超额收益的均值和标准差：
   \[
   \mu_{excess} = \text{mean}(R_{excess})
   \]
   \[
   \sigma_{excess} = \text{std}(R_{excess}, ddof=1)
   \]
4. 年化夏普比率：
   \[
   \text{Sharpe}_{annual} = \frac{\mu_{excess} \times \sqrt{252}}{\sigma_{excess} \times \sqrt{252}} = \frac{\mu_{excess}}{\sigma_{excess}} \times \sqrt{252}
   \]

### Python 代码实现：
假设 `fund_returns` 是基金日收益的 pandas Series，代码如下：

```python
import numpy as np
import pandas as pd

# 假设 fund_returns 是基金日收益的 Series
# 示例：fund_returns = pd.Series([0.001, -0.002, 0.003, ...])

# 无风险利率（年化）
rf_annual = 0.021
rf_daily = rf_annual / 252

# 日超额收益
excess_returns = fund_returns - rf_daily

# 日超额收益的均值和标准差（样本估计量）
mu_excess = excess_returns.mean()
sigma_excess = excess_returns.std(ddof=1)

# 年化夏普比率
sharpe_annual = (mu_excess / sigma_excess) * np.sqrt(252)

# 存入结果字典
result = {
    'sharpe_annual': sharpe_annual
}
```

### 输出：
`result` 字典中的 `'sharpe_annual'` 即为年化夏普比率。例如，如果计算结果为 1.2，则 `result` 为：
```python
{'sharpe_annual': 1.2}
```
