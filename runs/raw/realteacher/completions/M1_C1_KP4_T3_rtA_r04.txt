要计算隐含波动率（隐波）上涨1个点时期权价格的变化，我们可以使用期权的Vega值。Vega衡量的是期权价格对隐含波动率变化的敏感性，即隐含波动率每变化1个百分点（1%），期权价格的变化量。

因此，**隐波涨1个点（即隐含波动率上涨1%）时，期权价格的变化等于该期权的Vega值**。

假设题目中提到的期权Vega值为`vega`（例如0.05，即隐波每变化1%，期权价格变化0.05元），则结果如下：

```python
result = {
    'price_change': vega  # 隐波涨1个点，期权价格变化的金额（单位：元或美元等）
}
```

如果题目中未给出具体Vega值，你需要先计算或获取该期权的Vega值，再填入`result`字典中。例如，若Vega=0.03，则：

```python
result = {
    'price_change': 0.03
}
```
