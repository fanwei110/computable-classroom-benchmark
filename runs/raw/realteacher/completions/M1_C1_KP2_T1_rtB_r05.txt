根据资本资产定价模型（CAPM），期望收益率的计算公式为：

\[ \text{期望收益率} = \text{无风险利率} + \beta \times (\text{市场期望收益率} - \text{无风险利率}) \]

同时，Alpha（α）的计算公式为：

\[ \alpha = \text{实际收益率} - \text{期望收益率} \]

根据题目给定的数据：
- 无风险利率（Rf）= 2.3%
- 市场期望收益率（Rm）= 9.4%
- βx = 0.62
- βy = 1.18
- βz = 1.51
- Y的实际收益率 = 13.1%

我们可以计算如下：

1. 计算X的期望收益率（er_x）：
\[ er_x = 2.3\% + 0.62 \times (9.4\% - 2.3\%) \]

2. 计算Y的期望收益率（er_y）：
\[ er_y = 2.3\% + 1.18 \times (9.4\% - 2.3\%) \]

3. 计算Z的期望收益率（er_z）：
\[ er_z = 2.3\% + 1.51 \times (9.4\% - 2.3\%) \]

4. 计算Y的Alpha（alpha_y）：
\[ \alpha_y = 13.1\% - er_y \]

现在进行具体计算：

```python
# 计算期望收益率
er_x = 2.3 + 0.62 * (9.4 - 2.3)
er_y = 2.3 + 1.18 * (9.4 - 2.3)
er_z = 2.3 + 1.51 * (9.4 - 2.3)

# 计算Y的Alpha
alpha_y = 13.1 - er_y

# 存入字典
result = {
    'er_x': er_x,
    'er_y': er_y,
    'er_z': er_z,
    'alpha_y': alpha_y
}

result
```

计算结果如下：
- er_x = 6.732%
