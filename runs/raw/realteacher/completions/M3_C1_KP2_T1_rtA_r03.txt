根据资本资产定价模型（CAPM），期望收益率的计算公式为：
$$E(R_i) = R_f + \beta_i \times (R_m - R_f)$$
Alpha的计算公式为：
$$\alpha_y = R_y - E(R_y)$$

已知数据：
- 无风险收益率 $R_f = 2.3\% = 0.023$
- 市场收益率 $R_m = 9.4\% = 0.094$
- 市场风险溢价 $R_m - R_f = 9.4\% - 2.3\% = 7.1\% = 0.071$
- $\beta_x = 0.62$, $\beta_y = 1.18$, $\beta_z = 1.51$
- 股票Y的实际收益 $R_y = 13.1\% = 0.131$

计算三只股票的期望收益率：
1. $E(R_x) = 0.023 + 0.62 \times 0.071 = 0.023 + 0.04402 = 0.06702$ (即 6.702%)
2. $E(R_y) = 0.023 + 1.18 \times 0.071 = 0.023 + 0.08378 = 0.10678$ (即 10.678%)
3. $E(R_z) = 0.023 + 1.51 \times 0.071 = 0.023 + 0.10721 = 0.13021$ (即 13.021%)

计算Y的Alpha：
$\alpha_y = 0.131 - 0.10678 = 0.02422$ (即 2.422%)
