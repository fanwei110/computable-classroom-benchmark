根据给定的头寸价值（185万元）、年化波动率（21.8%，即0.218）以及交易天数约定（252天/年），计算参数化VaR（假设收益服从正态分布，均值为0）：

- **日波动率** = 0.218 / √252 ≈ 0.013733
- **95%单尾正态分位数** ≈ 1.64485
- **95%一日VaR** = 1,850,000 × 0.013733 × 1.64485 ≈ **41,789.47** 元

- **十日波动率** = 0.218 × √(10/252) ≈ 0.043427
- **99%单尾正态分位数** ≈ 2.32635
- **99%十日VaR** = 1,850,000 × 0.043427 × 2.32635 ≈ **186,896.75** 元

```python
import math
from scipy.stats import norm

value = 1850000
sigma_annual = 0.218
days = 252

# 波动率缩放
sigma_d = sigma_annual / math.sqrt(days)
sigma_10 = sigma_annual * math.sqrt(10 / days)

# 分位数
z_95 = norm.ppf(0.95)
z_99 = norm.ppf(0.99)

# VaR（正损失）
var_95_1d = value * sigma_d * z_95
var_99_10d = value * sigma_10 * z_99

result = {
    'var_95_1d': round(var_95_1d, 2),
    'var_99_10d': round(var_99_10d, 2)
}

result
```
