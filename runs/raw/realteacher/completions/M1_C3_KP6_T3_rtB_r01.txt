要计算整个样本期的年化夏普比率（Sharpe ratio），我们按照以下步骤进行：

1. **计算日收益率的均值和标准差**：
   - 日收益率的均值（超额收益）：`mean_daily_return = mean(fund_daily_returns - risk_free_daily)`
   - 日收益率的标准差（波动率）：`std_daily_return = std(fund_daily_returns, ddof=1)`

2. **年化处理**：
   - 年化超额收益：`annualized_return = mean_daily_return * 252`
   - 年化波动率：`annualized_volatility = std_daily_return * sqrt(252)`

3. **计算年化夏普比率**：
   - `sharpe_annual = annualized_return / annualized_volatility`

4. **无风险利率处理**：
   - 年化无风险利率为 2.1%，对应的日无风险利率为 `(1 + 0.021)^(1/252) - 1`（按年复利报价）。

### 实现代码（Python）：
```python
import numpy as np
import pandas as pd

# 假设 df 是包含基金日收益的 DataFrame，fund 列为基金日收益
# 示例：df = pd.read_csv('课程数据文件.csv')

# 提取基金日收益
fund_daily_returns = df['fund'].dropna().values  # 转为 numpy 数组

# 无风险利率（年化 2.1%，按年复利）
risk_free_annual = 0.021
risk_free_daily = (1 + risk_free_annual) ** (1/252) - 1  # 日无风险利率

# 计算日超额收益
excess_daily_returns = fund_daily_returns - risk_free_daily

# 计算日超额收益的均值和标准差（ddof=1 为样本标准差）
mean_daily_excess = np.mean(excess_daily_returns)
std_daily_excess = np.std(excess_daily_returns, ddof=1)

# 年化处理
annualized_return = mean_daily_excess * 252
annualized_volatility = std_daily_excess * np.sqrt(252)

# 计算年化夏普比率
sharpe_annual = annualized_return / annualized_volatility

# 存入结果字典
result = {
    'sharpe_annual': sharpe_annual
}
```

### 输出：
`result` 字典将包含键 `'sharpe_annual'`，其值为计算得到的年化夏普比率。

1. 确保 `fund` 列的数据是日收益率（小数形式，如 `0.01` 表示 1%）。
2. 如果数据中有缺失值（NaN），需先用 `.dropna()` 处理。
3. 无风险利率按年复利报价，日利率转换为 `(1 + r_annual)^(1/252) - 1`。
