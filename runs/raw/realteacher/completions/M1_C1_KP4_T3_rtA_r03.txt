要计算隐含波动率（隐波）上涨1个点时期权价格的变化，我们可以使用期权的Vega值。Vega衡量的是期权价格对隐含波动率变化的敏感性，通常表示为隐含波动率变化1%时期权价格的变化。

假设题目中的期权Vega值已知（例如Vega=0.1，即隐波变化1%时价格变化0.1），那么隐波上涨1个点（即1%）时，期权价格的变化量就是Vega的值。

如果Vega未直接给出，可以通过Black-Scholes模型或其他期权定价模型计算得到。以下是基于Vega的示例输出：

```python
result = {
    'price_change': 0.1  # 假设Vega=0.1，隐波涨1个点（1%）时价格涨0.1
}
```

如果题目中有具体的期权参数（如标的价格、行权价、到期时间、无风险利率等），可以精确计算Vega值并填入`price_change`。请提供更多细节以便精确计算。
