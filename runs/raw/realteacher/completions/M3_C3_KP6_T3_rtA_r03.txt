为了计算整个样本期的年化夏普比率，我们需要根据题目约定的计算规则进行逐步处理：

1. **日无风险利率的折算**：题目约定“债券收益率按年复利报价”，因此给定的 2.1%（0.021）是年复利利率，需要按年复利折算为日无风险利率：
   $$R_{f, daily} = (1 + R_{f, annual})^{1/252} - 1 = (1 + 0.021)^{1/252} - 1$$
2. **计算日超额收益的均值和标准差**：使用样本标准差（`ddof=1`）。
3. **计算年化夏普比率**：根据独立同分布假设，日夏普比率年化的标准方法是乘以 $\sqrt{252}$。

以下是Python代码实现：

```python
import pandas as pd
import numpy as np

# 假设数据文件已读入为 DataFrame 变量 df
# df = pd.read_csv('your_data_file.csv') 

# 提取 fund 列的日收益率
daily_returns = df['fund']

# 1. 年化无风险利率及日化折算（按年复利报价约定）
rf_annual = 0.021
rf_daily = (1 + rf_annual) ** (1 / 252) - 1

# 2. 计算日收益率均值和样本标准差（ddof=1）
mean_daily = daily_returns.mean()
std_daily = daily_returns.std(ddof=1)

# 3. 计算日夏普比率
sharpe_daily = (mean_daily - rf_daily) / std_daily

# 4. 年化夏普比率
sharpe_annual = sharpe_daily * np.sqrt(252)

# 按输出契约存入字典
result = {'sharpe_annual': sharpe_annual}
```

### 核心逻辑说明：
- **复利折算**：题目明确提到“债券收益率按年复利报价”，所以不能使用单利 `0.021 / 252` 进行日化，必须使用 `(1 + 0.021) ** (1/252) - 1`。
- **期权利率区分**：题目提及“期权无风险利率按连续复利”，由于这里计算的是普通基金（债券类报价）的夏普，而非期权定价，故不采用连续复利 $e^{rt}-1$ 的折算方式。
- **样本标准差**：严格按照 `ddof=1` 使用无偏样本标准差，契合题目约定的“标准差用样本估计量”。
- **年化乘数**：日频率夏普年化的标准转换系数为 $\sqrt{252}$。
