为了计算这些指标，我们需要基于以下债券信息：
- 面值 \( FV = 100 \)
- 票息率 \( c = 4.6\% \)，年付息，因此每年票息 \( C = 4.6 \)
- 到期年限 \( T = 7 \)
- 到期收益率 \( y = 5.3\% \)

以下是逐步计算过程：

### 1. 价格 \( P \)
价格是未来现金流（票息和面值）按到期收益率折现的现值之和：
\[
P = \sum_{t=1}^{7} \frac{4.6}{(1+0.053)^t} + \frac{100}{(1+0.053)^7}
\]

### 2. 麦考利久期 \( D_{\text{Mac}} \)
麦考利久期是现金流支付时间的加权平均值，权重为各期现金流现值占价格的比例：
\[
D_{\text{Mac}} = \frac{1}{P} \left( \sum_{t=1}^{7} \frac{t \cdot 4.6}{(1+0.053)^t} + \frac{7 \cdot 100}{(1+0.053)^7} \right)
\]
单位：年。

### 3. 修正久期 \( D_{\text{Mod}} \)
修正久期衡量价格对收益率的敏感度，计算公式：
\[
D_{\text{Mod}} = \frac{D_{\text{Mac}}}{1 + y} = \frac{D_{\text{Mac}}}{1.053}
\]
单位：年。

### 4. 凸性 \( C_{\text{conv}} \)
凸性衡量价格-收益率曲线的弯曲程度，计算公式（年付息债券）：
\[
C_{\text{conv}} = \frac{1}{P \cdot (1+y)^2} \sum_{t=1}^{7} \left( \frac{t(t+1) \cdot 4.6}{(1+y)^t} + \frac{7 \cdot 8 \cdot 100}{(1+y)^7} \right)
\]
但此处标准凸性公式常表示为现值加权：
\[
\text{Convexity} = \frac{1}{P} \sum_{t=1}^{T} \frac{CF_t}{(1+y)^{t+2}} \cdot t \cdot (t+1)
\]
使用后面这种形式更方便计算，其结果乘以 \( \frac{1}{(1+y)^2} \) 的缩放因子，实际上最终给出的凸性指标通常是这个形式的值，货币单位涉及年的平方。我们按照常见定义输出连续复利或离散复利的凸性。这里采用修正久期扩展的常规离散凸性公式：
\[
\text{Convexity} = \frac{1}{P \cdot (1+y)^2} \sum_{t=1}^{7} \frac{t(t+1) \cdot CF_t}{(1+y)^t}
\]
其中 \( CF_t \) 为各期现金流（最后一年包括面值）。注意此处不要重复计算面值的 t(t+1) 部分，我们直接计算：
第1-6年现金流为 4.6，第7年现金流为 104.6。

---

现在用 Python 进行精确计算并存入字典：

```python
import numpy as np

# 债券参数
face_value = 100.0
coupon_rate = 0.046
ytm = 0.053
maturity = 7

coupon = face_value * coupon_rate  # 4.6
periods = np.arange(1, maturity + 1)

# 各期现金流
cash_flows = np.full(maturity, coupon)
cash_flows[-1] += face_value  # 最后一年加上本金

# 折现因子
discount_factors = (1 + ytm) ** (-periods)

# 1. 价格
pv_cf = cash_flows * discount_factors
price = np.sum(pv_cf)

# 2. 麦考利久期
weighted_pv = pv_cf * periods
macaulay_duration = np.sum(weighted_pv) / price

# 3. 修正久期
modified_duration = macaulay_duration / (1 + ytm)

# 4. 凸性 (使用常规的离散凸性公式: sum[ t*(t+1)*CF_t / (1+y)^(t+2) ] / P )
# 或者等效: 1/(P*(1+y)^2) * sum( t*(t+1)*CF_t / (1+y)^t )
t_plus_one = periods * (periods + 1)
weighted_convexity = t_plus_one * cash_flows * discount_factors
sum_convexity = np.sum(weighted_convexity)
convexity = sum_convexity / (price * (1 + ytm)**2)

# 存入字典
result = {
    'price': round(price, 6),  # 保留合理小数
    'macaulay_duration_years': round(macaulay_duration, 6),
    'modified_duration_years': round(modified_duration, 6),
    'convexity': round(convexity, 6)
}

print(result)
```
