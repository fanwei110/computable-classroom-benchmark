要计算整个样本期的年化夏普比率（Sharpe Ratio），我们按照以下步骤进行：

1. **计算日超额收益**：每日收益减去无风险收益率的日等价值（2.1% 年化无风险收益率转换为日收益率）。
2. **计算超额收益的均值和标准差**：基于日超额收益数据。
3. **年化夏普比率**：将日超额收益的均值和标准差年化（乘以 √252），然后计算夏普比率。

假设 `fund` 列的日收益数据存储在变量 `daily_returns` 中（例如 pandas Series），以下是计算代码：

```python
import numpy as np

# 示例数据（假设 daily_returns 是 fund 列的日收益率序列）
# daily_returns = pd.Series([...])  # 实际数据替换这里

# 无风险收益率（年化 2.1%，转换为日收益率）
risk_free_rate_annual = 0.021
risk_free_rate_daily = (1 + risk_free_rate_annual) ** (1/252) - 1

# 计算日超额收益
excess_returns = daily_returns - risk_free_rate_daily

# 计算年化夏普比率
sharpe_annual = np.sqrt(252) * excess_returns.mean() / excess_returns.std()

# 存入结果字典
result = {
    'sharpe_annual': sharpe_annual
}
```

### 输出说明：
- `result['sharpe_annual']` 即为年化夏普比率的计算结果。
