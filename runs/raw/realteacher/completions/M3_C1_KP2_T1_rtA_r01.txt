根据资本资产定价模型（CAPM），期望收益率的计算公式为：
$$E(R_i) = R_f + \beta_i \times (R_m - R_f)$$
Alpha的计算公式为：
$$\alpha = 实际收益率 - 期望收益率$$

已知：
- 无风险利率 $R_f = 2.3\%$
- 市场收益率 $R_m = 9.4\%$
- 市场风险溢价 $R_m - R_f = 9.4\% - 2.3\% = 7.1\%$

**1. 计算三只股票的期望收益率：**
- 股票X：$E(R_X) = 2.3\% + 0.62 \times 7.1\% = 2.3\% + 4.402\% = 6.702\%$
- 股票Y：$E(R_Y) = 2.3\% + 1.18 \times 7.1\% = 2.3\% + 8.378\% = 10.678\%$
- 股票Z：$E(R_Z) = 2.3\% + 1.51 \times 7.1\% = 2.3\% + 10.721\% = 13.021\%$

**2. 计算股票Y的Alpha：**
- $\alpha_Y = 实际收益 - E(R_Y) = 13.1\% - 10.678\% = 2.422\%$

（注：以下字典中的数值以百分比数值形式存入，如6.702代表6.702%）
