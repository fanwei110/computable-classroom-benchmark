根据资本资产定价模型（CAPM），公式为：
$$E(R_i) = R_f + \beta_i \times (E(R_m) - R_f)$$
Alpha的计算公式为：
$$\alpha_Y = 实际收益_Y - E(R_Y)$$

已知数据：
- 无风险利率 $R_f$ = 2.3% = 0.023
- 市场期望收益 $E(R_m)$ = 9.4% = 0.094
- 市场风险溢价 $E(R_m) - R_f$ = 0.094 - 0.023 = 0.071 (7.1%)
- $\beta_X$ = 0.62， $\beta_Y$ = 1.18， $\beta_Z$ = 1.51
- Y的实际收益 = 13.1% = 0.131

**计算过程：**
1. **X的期望收益 ($er_x$)** = 0.023 + 0.62 × 0.071 = 0.023 + 0.04402 = 0.06702 (6.702%)
2. **Y的期望收益 ($er_y$)** = 0.023 + 1.18 × 0.071 = 0.023 + 0.08378 = 0.10678 (10.678%)
3. **Z的期望收益 ($er_z$)** = 0.023 + 1.51 × 0.071 = 0.023 + 0.10721 = 0.13021 (13.021%)
4. **Y的Alpha ($alpha_y$)** = 0.131 - 0.10678 = 0.02422 (2.422%)
