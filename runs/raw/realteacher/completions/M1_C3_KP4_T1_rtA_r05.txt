我们需要计算欧式看涨期权的价格（call_price）、Delta（call_delta）和Vega（call_vega）。根据Black-Scholes模型，我们可以使用以下公式：

### 输入参数：
- 标的现价 \( S = 103.7 \)
- 行权价 \( K = 97.5 \)
- 隐含波动率 \( \sigma = 0.276 \)
- 无风险利率（连续复利） \( r = 0.043 \)
- 到期时间 \( T = 0.58 \) 年
- 不分红（\( q = 0 \)）

### 步骤1：计算 \( d_1 \) 和 \( d_2 \)
\[
d_1 = \frac{\ln(S/K) + (r - q + \sigma^2/2)T}{\sigma \sqrt{T}}
\]
\[
d_2 = d_1 - \sigma \sqrt{T}
\]

### 步骤2：计算期权价格（call_price）
\[
\text{call\_price} = S e^{-qT} N(d_1) - K e^{-rT} N(d_2)
\]
其中 \( N(\cdot) \) 是标准正态分布的累积分布函数（CDF）。

### 步骤3：计算Delta（call_delta）
\[
\text{call\_delta} = e^{-qT} N(d_1)
\]

### 步骤4：计算Vega（call_vega）
\[
\text{call\_vega} = S e^{-qT} \sqrt{T} N'(d_1)
\]
其中 \( N'(d_1) \) 是标准正态分布的概率密度函数（PDF），即：
\[
N'(d_1) = \frac{1}{\sqrt{2\pi}} e^{-d_1^2 / 2}
\]

### Python代码实现：
```python
import numpy as np
from scipy.stats import norm

# 输入参数
S = 103.7
K = 97.5
sigma = 0.276
r = 0.043
T = 0.58
q = 0.0  # 不分红

# 计算d1和d2
d1 = (np.log(S / K) + (r - q + sigma**2 / 2) * T) / (sigma * np.sqrt(T))
d2 = d1 - sigma * np.sqrt(T)

# 计算期权价格
call_price = S * np.exp(-q * T) * norm.cdf(d1) - K * np.exp(-r * T) * norm.cdf(d2)

# 计算Delta
call_delta = np.exp(-q * T) * norm.cdf(d1)

# 计算Vega（注意Vega的单位是每1%波动率变化对应的价格变化，因此需要乘以0.01）
call_vega = S * np.exp(-q * T) * np.sqrt(T) * norm.pdf(d1) * 0.01  # 转换为每1%波动率变化

# 存入结果字典
result = {
    'call_price': call_price,
    'call_delta': call_delta,
    'call_vega': call_vega
}

print(result)
```
