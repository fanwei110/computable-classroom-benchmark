根据资本资产定价模型（CAPM），期望收益率的计算公式为：
$$E(R_i) = R_f + \beta_i \times (E(R_m) - R_f)$$
Alpha 的计算公式为实际收益与期望收益的差额：
$$\alpha_i = R_{actual, i} - E(R_i)$$

已知数据（转换为小数形式）：
- 无风险利率 $R_f = 0.023$
- 市场期望收益 $E(R_m) = 0.094$
- 市场风险溢价 $E(R_m) - R_f = 0.094 - 0.023 = 0.071$
- $\beta_X = 0.62$, $\beta_Y = 1.18$, $\beta_Z = 1.51$
- Y的实际收益 $R_{actual, Y} = 0.131$

**1. 计算三只股票的期望收益：**
- $E(R_X) = 0.023 + 0.62 \times 0.071 = 0.023 + 0.04402 = 0.06702$
- $E(R_Y) = 0.023 + 1.18 \times 0.071 = 0.023 + 0.08378 = 0.10678$
- $E(R_Z) = 0.023 + 1.51 \times 0.071 = 0.023 + 0.10721 = 0.13021$

**2. 计算Y的Alpha：**
- $\alpha_Y = 0.131 - 0.10678 = 0.02422$
