根据题意，我们需要计算当隐含波动率上涨1个点（即+0.01）时，期权价格的变化量。这本质上是求期权的 Vega 值（即隐含波动率变化一个单位时，期权价格的变化量）。

基于之前的对话上下文，期权参数如下：
- 现货价格 S = 100
- 行权价 K = 105
- 无风险利率 r = 0.05（连续复利）
- 期限 T = 1 年（或根据实际交易日折算，但此处按年计）
- 隐含波动率 σ = 0.20

对于欧式看涨期权，Vega 公式为：
Vega = S * N'(d1) * √T
其中 d1 = [ln(S/K) + (r + σ²/2)T] / (σ√T)
N'(x) = (1/√(2π)) * exp(-x²/2)

计算过程：
d1 = [ln(100/105) + (0.05 + 0.2²/2)*1] / (0.2*√1)
   = [-0.04879 + (0.05 + 0.02)] / 0.2
   = [0.02121] / 0.2
   = 0.10605

N'(d1) = (1/√(2π)) * exp(-0.10605²/2)
       = 0.39894 * exp(-0.005623)
       = 0.39894 * 0.99439
       = 0.3967

Vega = 100 * 0.3967 * 1 = 39.67

因此，隐波上涨1个点（即+0.01），期权价格上涨约 0.3967 单位。

result = {

}
