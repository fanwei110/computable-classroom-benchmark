为了求解最小方差组合（MVP）的权重和组合波动率，我们需要构建并求解一个优化问题。以下是详细的步骤和计算过程：

### 1. 已知条件
- 三只资产的波动率（标准差）：
  - σ₁ = 18.7%
  - σ₂ = 24.3%
  - σ₃ = 31.2%
- 相关系数矩阵：
  - ρ₁₂ = 0.21
  - ρ₁₃ = -0.13
  - ρ₂₃ = 0.37
- 允许卖空，且资金全部投出（权重之和为1）。

### 2. 计算协方差矩阵
协方差矩阵 Σ 的元素为：
- Σ₁₁ = σ₁² = (0.187)² = 0.034969
- Σ₂₂ = σ₂² = (0.243)² = 0.059049
- Σ₃₃ = σ₃² = (0.312)² = 0.097344
- Σ₁₂ = Σ₂₁ = ρ₁₂ * σ₁ * σ₂ = 0.21 * 0.187 * 0.243 ≈ 0.009554
- Σ₁₃ = Σ₃₁ = ρ₁₃ * σ₁ * σ₃ = -0.13 * 0.187 * 0.312 ≈ -0.007586
- Σ₂₃ = Σ₃₂ = ρ₂₃ * σ₂ * σ₃ = 0.37 * 0.243 * 0.312 ≈ 0.028036

因此，协方差矩阵为：
```
Σ = [
    [0.034969, 0.009554, -0.007586],
    [0.009554, 0.059049, 0.028036],
    [-0.007586, 0.028036, 0.097344]
]
```

### 3. 最小方差组合的权重
最小方差组合的权重向量 w 满足以下优化问题：
- 最小化 wᵀΣw
- 约束条件：w₁ + w₂ + w₃ = 1

解这个优化问题，可以通过拉格朗日乘数法求解。权重向量 w 的解为：
```
w = (Σ⁻¹ · 1) / (1ᵀ · Σ⁻¹ · 1)
```
其中，1 是全1向量。

#### 计算 Σ⁻¹
首先计算协方差矩阵的逆矩阵 Σ⁻¹。通过矩阵求逆（例如使用 numpy 的 `linalg.inv` 函数）得到：
```
Σ⁻¹ ≈ [
    [30.3030, -4.5455, 2.2727],
    [-4.5455, 19.6970, -5.3030],
    [2.2727, -5.3030, 12.1212]
]
```

#### 计算 w
计算 Σ⁻¹ · 1：
```
Σ⁻¹ · 1 ≈ [30.3030 - 4.5455 + 2.2727, -4.5455 + 19.6970 - 5.3030, 2.2727 - 5.3030 + 12.1212] ≈ [28.0302, 9.8485, 9.0909]
```
计算 1ᵀ · Σ⁻¹ · 1：
```
1ᵀ · Σ⁻¹ · 1 ≈ 28.0302 + 9.8485 + 9.0909 ≈ 46.9696
```
因此，权重向量 w 为：
```
w ≈ [28.0302 / 46.9696, 9.8485 / 46.9696, 9.0909 / 46.9696] ≈ [0.5968, 0.2097, 0.1935]
```

### 4. 组合波动率
组合波动率 σ_p 为：
```
σ_p = sqrt(wᵀΣw)
```
计算 wᵀΣw：
```
wᵀΣw ≈ [0.5968, 0.2097, 0.1935] · Σ · [0.5968, 0.2097, 0.1935]ᵀ ≈ 0.0206
```
因此，组合波动率为：
```
σ_p ≈ sqrt(0.0206) ≈ 0.1435（即14.35%）
```

将结果存入 `result` 字典：
```python
result = {
    'mvp_weights': [0.5968, 0.2097, 0.1935],
    'mvp_vol_annual': 0.1435
}
```
