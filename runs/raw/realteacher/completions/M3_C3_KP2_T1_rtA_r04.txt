根据资本资产定价模型（CAPM），期望收益率的计算公式为：
$$E(R_i) = R_f + \beta_i \times (R_m - R_f)$$
其中，无风险利率 $R_f = 0.023$，市场收益率 $R_m = 0.094$，市场风险溢价 $R_m - R_f = 0.071$。

假设三只股票 X、Y、Z 的 Beta 值依次为 0.62、1.18、1.51。

1. **计算股票 X 的期望收益率 (er_x)**：
$$E(R_X) = 0.023 + 0.62 \times 0.071 = 0.023 + 0.04402 = 0.06702$$

2. **计算股票 Y 的期望收益率 (er_y)**：
$$E(R_Y) = 0.023 + 1.18 \times 0.071 = 0.023 + 0.08378 = 0.10678$$

3. **计算股票 Z 的期望收益率 (er_z)**：
$$E(R_Z) = 0.023 + 1.51 \times 0.071 = 0.023 + 0.10721 = 0.13021$$

4. **计算股票 Y 的 Alpha (alpha_y)**：
Jensen's Alpha 的计算公式为实际收益率减去 CAPM 期望收益率：
$$\alpha_Y = R_{Y, actual} - E(R_Y) = 0.131 - 0.10678 = 0.02422$$
