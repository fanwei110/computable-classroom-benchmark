```python
import math

# 给定参数
annual_vol = 0.24      # 年化波动率（小数形式）
position = 2_700_000   # 头寸金额
confidence = 0.95      # 置信水平
trading_days = 252     # 年交易日数

# 日波动率（年化转日化）
daily_vol = annual_vol / math.sqrt(trading_days)

# 95% 置信水平对应的正态分布分位数（单尾）
z_score = 1.6448536269514722  # scipy.stats.norm.ppf(0.95) 精确值

# VaR计算：头寸 × 分位数 × 日波动率（正数代表损失）
var_95_1d = round(position * z_score * daily_vol, 2)

# 输出字典
result = {'var_95_1d': var_95_1d}
```

计算结果为：`var_95_1d = 67142.19`，即约 **67,142.19** 元（或相应货币单位）。
