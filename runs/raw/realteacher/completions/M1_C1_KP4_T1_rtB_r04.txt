我们可以使用 Black-Scholes 模型来计算欧式看涨期权的价格（call price）、Delta 和 Vega。以下是计算步骤和结果：

### 输入参数：
- 标的现价（S）：103.7
- 行权价（K）：97.5
- 隐含波动率（σ）：27.6% = 0.276
- 无风险利率（r）：4.3% = 0.043
- 剩余时间（T）：0.58 年
- 不分红（q = 0）

### 计算步骤：
1. **计算 d1 和 d2**：
   \[
   d1 = \frac{\ln(S/K) + (r - q + \sigma^2/2)T}{\sigma \sqrt{T}}
   \]
   \[
   d2 = d1 - \sigma \sqrt{T}
   \]

2. **看涨期权价格（call price）**：
   \[
   C = S e^{-qT} N(d1) - K e^{-rT} N(d2)
   \]

3. **Delta**：
   \[
   \Delta = e^{-qT} N(d1)
   \]

4. **Vega**：
   \[
   \text{Vega} = S e^{-qT} \sqrt{T} N'(d1) \times 0.01 \quad (\text{通常以每1%波动率变化表示})
   \]
   其中 \( N'(d1) \) 是标准正态分布的概率密度函数。

### Python 代码实现：
```python
import numpy as np
from scipy.stats import norm

# 输入参数
S = 103.7
K = 97.5
sigma = 0.276
r = 0.043
T = 0.58
q = 0.0

# 计算 d1 和 d2
d1 = (np.log(S / K) + (r - q + 0.5 * sigma ** 2) * T) / (sigma * np.sqrt(T))
d2 = d1 - sigma * np.sqrt(T)

# 计算 call price
call_price = S * np.exp(-q * T) * norm.cdf(d1) - K * np.exp(-r * T) * norm.cdf(d2)

# 计算 Delta
call_delta = np.exp(-q * T) * norm.cdf(d1)

# 计算 Vega (每1%波动率变化)
call_vega = S * np.exp(-q * T) * np.sqrt(T) * norm.pdf(d1) * 0.01

# 存入结果字典
result = {
    'call_price': call_price,
    'call_delta': call_delta,
    'call_vega': call_vega
}

print(result)
```
