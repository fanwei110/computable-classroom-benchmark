根据资本资产定价模型（CAPM），期望收益的计算公式为：
$$E(R_i) = R_f + \beta_i \times (E(R_m) - R_f)$$
Alpha的计算公式为：
$$\alpha = 实际收益 - 期望收益$$

已知数据：
- 无风险利率 $R_f = 2.3\%$
- 市场期望收益 $E(R_m) = 9.4\%$
- 市场风险溢价 $E(R_m) - R_f = 9.4\% - 2.3\% = 7.1\%$

**1. 计算三只股票的期望收益：**
- **X的期望收益**：$E(R_x) = 2.3\% + 0.62 \times 7.1\% = 2.3\% + 4.402\% = 6.702\%$
- **Y的期望收益**：$E(R_y) = 2.3\% + 1.18 \times 7.1\% = 2.3\% + 8.378\% = 10.678\%$
- **Z的期望收益**：$E(R_z) = 2.3\% + 1.51 \times 7.1\% = 2.3\% + 10.721\% = 13.021\%$

**2. 计算Y的Alpha：**
- **Y的Alpha**：$\alpha_y = 13.1\% - 10.678\% = 2.422\%$
