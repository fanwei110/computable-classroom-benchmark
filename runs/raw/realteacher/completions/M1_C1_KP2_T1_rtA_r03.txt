根据题目要求，我们使用资本资产定价模型（CAPM）计算三只股票的期望收益率，并计算股票Y的Alpha值。

CAPM公式为：
\[ E(R_i) = R_f + \beta_i \times (E(R_m) - R_f) \]

其中：
- \( R_f \) = 无风险收益率 = 2.3%
- \( E(R_m) \) = 市场收益率 = 9.4%
- \( \beta_i \) = 各股票的Beta值

三只股票的Beta值分别为：
- 股票X：0.62
- 股票Y：1.18
- 股票Z：1.51

股票Y的实际收益率为13.1%。

**计算过程：**

1. 股票X的期望收益率：
\[ E(R_x) = 2.3\% + 0.62 \times (9.4\% - 2.3\%) = 2.3\% + 0.62 \times 7.1\% = 2.3\% + 4.402\% = 6.702\% \]

2. 股票Y的期望收益率：
\[ E(R_y) = 2.3\% + 1.18 \times (9.4\% - 2.3\%) = 2.3\% + 1.18 \times 7.1\% = 2.3\% + 8.378\% = 10.678\% \]

3. 股票Z的期望收益率：
\[ E(R_z) = 2.3\% + 1.51 \times (9.4\% - 2.3\%) = 2.3\% + 1.51 \times 7.1\% = 2.3\% + 10.721\% = 13.021\% \]

4. 股票Y的Alpha值：
\[ \alpha_y = \text{实际收益率} - E(R_y) = 13.1\% - 10.678\% = 2.422\% \]

result = {
