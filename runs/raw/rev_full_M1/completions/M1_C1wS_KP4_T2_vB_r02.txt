```python
import numpy as np
from scipy.stats import norm
import matplotlib.pyplot as plt
import os

def black_scholes_delta(S, K, T, r, sigma, option_type='call'):
    """
    计算欧式期权的 Black-Scholes Delta
    S: 标的资产价格
    K: 行权价
    T: 到期时间（年）
    r: 无风险利率
    sigma: 波动率
    option_type: 'call' 或 'put'
    """
    d1 = (np.log(S / K) + (r + 0.5 * sigma ** 2) * T) / (sigma * np.sqrt(T))
    if option_type == 'call':
        delta = norm.cdf(d1)
    else:
        delta = norm.cdf(d1) - 1
    return delta

# 参数设置
K = 97.5          # 行权价
r = 0.043         # 无风险利率
T = 0.58          # 到期时间（年）
S_range = np.linspace(70, 140, 100)  # 标的价格范围
volatilities = [0.15, 0.276, 0.40]  # 波动率列表

# 1. 对每个波动率在标的网格上计算 delta
deltas = {}
for sigma in volatilities:
    deltas[sigma] = [black_scholes_delta(S, K, T, r, sigma) for S in S_range]

# 2. 画三条带标注曲线
plt.figure(figsize=(10, 6))
for sigma in volatilities:
    plt.plot(S_range, deltas[sigma], label=f'Vol = {sigma*100:.1f}%')

plt.title('Black-Scholes Delta vs Underlying Price')
plt.xlabel('Underlying Price')
plt.ylabel('Delta')
plt.legend()
plt.grid(True)

# 保存图形
figure_path = 'delta_curve.png'
plt.savefig(figure_path)
plt.close()

# 3. 报告标的 110、波动率 27.6% 的 delta
S_target = 110
sigma_target = 0.276
delta_at_s110 = black_scholes_delta(S_target, K, T, r, sigma_target)

# 4. 填充 result 字典
result = {
    'delta_at_s110': delta_at_s110,
    'figure_path': os.path.abspath(figure_path)
}

# 输出结果以供验证
print(result)
```

这个脚本会：
1. 使用Black-Scholes公式计算不同波动率下的Delta值
2. 绘制三条Delta曲线（波动率分别为15%、27.6%和40%）
3. 计算并报告标的价格110、波动率27.6%时的Delta值
4. 将图形保存为'delta_curve.png'文件
5. 将所有结果存入result字典中，包括：
   - 'delta_at_s110': 在S=110和vol=27.6%时的Delta值
   - 'figure_path': 保存的图形文件的绝对路径

运行后会在当前目录生成图形文件，并输出result字典的内容。
