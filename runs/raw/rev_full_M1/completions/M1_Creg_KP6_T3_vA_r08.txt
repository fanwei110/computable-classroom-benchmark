以下是一个自包含的 Python 脚本，用于计算课程数据文件中 `fund` 列的年化夏普比率（无风险利率为 2.1%）。脚本使用 `pandas` 读取数据，`numpy` 进行计算，并确保结果可复现。

```python
import numpy as np
import pandas as pd

# 设定随机种子以确保可复现性（虽然本例不涉及随机性，但保持良好习惯）
np.random.seed(42)

# 假设数据文件名为 'course_data.csv'，且包含 'fund' 列
# 如果文件名或路径不同，请修改此处
file_path = 'course_data.csv'

# 读取数据
try:
    data = pd.read_csv(file_path)
    fund_returns = data['fund'].dropna().values  # 提取 fund 列并去除缺失值
except FileNotFoundError:
    raise FileNotFoundError(f"数据文件 {file_path} 未找到，请确认文件路径和名称。")
except KeyError:
    raise KeyError("数据文件中未找到 'fund' 列，请检查列名。")

# 无风险利率（年化，2.1%）
risk_free_rate_annual = 0.021

# 计算日频超额收益率（假设 fund 列为日频收益率）
excess_returns = fund_returns - (risk_free_rate_annual / 252)  # 252 个交易日/年

# 计算夏普比率（年化）
sharpe_ratio_annual = np.sqrt(252) * np.mean(excess_returns) / np.std(excess_returns, ddof=1)

# 存储结果
result = {
    'sharpe_annual': sharpe_ratio_annual
}

# 输出结果（可选，便于调试）
print("年化夏普比率:", result['sharpe_annual'])
```

### 说明：
1. **数据读取**：脚本假设数据文件为 `course_data.csv`，且包含 `fund` 列。如果文件名或路径不同，请修改 `file_path`。
2. **无风险利率**：年化无风险利率为 2.1%，转换为日频时除以 252（交易日数）。
3. **夏普比率计算**：
   - 计算超额收益率（fund 收益率减去日频无风险利率）。
   - 年化夏普比率 = `sqrt(252) * mean(excess_returns) / std(excess_returns)`。
4. **结果存储**：结果存入 `result` 字典，键名为 `'sharpe_annual'`。
5. **可复现性**：设定了 `numpy` 的随机种子（虽然本例不涉及随机性，但保持良好习惯）。

### 注意事项：
- 如果 `fund` 列不是日频收益率，请根据实际频率调整年化因子（如月频数据使用 `sqrt(12)`）。
- 如果数据文件格式不同（如 Excel），请使用 `pd.read_excel()` 替代 `pd.read_csv()`。
