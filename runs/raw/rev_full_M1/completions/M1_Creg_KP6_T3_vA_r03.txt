以下是一个自包含的 Python 脚本，用于计算课程数据文件中 `fund` 列的年化夏普比率（无风险利率为 2.1%）。脚本使用 `pandas` 读取数据，`numpy` 进行计算，并将结果存入 `result` 字典。

```python
import numpy as np
import pandas as pd

# 假设数据文件名为 'course_data.csv'，且包含 'fund' 列
# 如果文件名或路径不同，请修改此处
file_path = 'course_data.csv'

# 读取数据
data = pd.read_csv(file_path)

# 提取 fund 列的收益率数据（假设数据为日频收益率）
fund_returns = data['fund'].dropna().values  # 转换为 numpy 数组并去除缺失值

# 无风险利率（年化，2.1%）
risk_free_rate_annual = 0.021

# 计算日频无风险利率（假设一年有252个交易日）
risk_free_rate_daily = risk_free_rate_annual / 252

# 计算超额收益率（fund 收益率 - 无风险利率）
excess_returns = fund_returns - risk_free_rate_daily

# 计算超额收益率的均值和标准差
mean_excess_return = np.mean(excess_returns)
std_excess_return = np.std(excess_returns, ddof=1)  # 样本标准差（ddof=1）

# 计算年化夏普比率
# 年化均值 = 日频均值 * 252
# 年化标准差 = 日频标准差 * sqrt(252)
sharpe_ratio_annual = (mean_excess_return * 252) / (std_excess_return * np.sqrt(252))

# 将结果存入 result 字典
result = {
    'sharpe_annual': sharpe_ratio_annual
}

# 输出结果（可选，用于验证）
print(result)
```

### 说明：
1. **数据读取**：脚本假设数据文件为 `course_data.csv`，且包含 `fund` 列。如果文件名或路径不同，请修改 `file_path`。
2. **无风险利率**：年化无风险利率为 2.1%，转换为日频利率时假设一年有 252 个交易日。
3. **超额收益率**：计算 `fund` 收益率减去无风险利率后的超额收益率。
4. **夏普比率**：
   - 日频超额收益率的均值和标准差。
   - 年化夏普比率 = (日频均值 * 252) / (日频标准差 * √252)。
5. **结果**：存入 `result` 字典，键名为 `'sharpe_annual'`。

### 注意事项：
- 如果数据不是日频收益率，请调整年化因子（如月频收益率则使用 12 和 √12）。
- 确保数据文件存在且格式正确（`fund` 列为数值型）。
