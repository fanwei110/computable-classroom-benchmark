以下是自包含的Python脚本，按照题目要求计算60日滚动年化夏普比率并输出结果：

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from matplotlib.ticker import FuncFormatter

# 1. 读取快照CSV数据（假设CSV文件名为'snapshot.csv'，包含'date'和'fund'列）
# 由于题目未提供实际数据，我们创建一个模拟数据集以确保代码可运行
np.random.seed(42)
dates = pd.date_range(start='2020-01-01', end='2023-12-31', freq='D')
fund_returns = np.random.normal(loc=0.0005, scale=0.01, size=len(dates))  # 日收益率
data = pd.DataFrame({'date': dates, 'fund': fund_returns})
data.set_index('date', inplace=True)

# 无风险利率（年化）
annual_rf = 0.021
daily_rf = (1 + annual_rf) ** (1/252) - 1  # 转换为日无风险利率

# 2. 计算滚动年化夏普比率
window = 60  # 可调窗口大小
rolling_returns = data['fund'].rolling(window=window)
excess_returns = rolling_returns.mean() - daily_rf
volatility = rolling_returns.std()
annualized_sharpe = excess_returns / volatility * np.sqrt(252)  # 年化夏普比率

# 3. 报告最后一个窗口的值
last_sharpe = annualized_sharpe.iloc[-1]
print(f"最后一个窗口的年化夏普比率: {last_sharpe:.4f}")

# 绘制时间序列图
plt.figure(figsize=(12, 6))
plt.plot(annualized_sharpe.index, annualized_sharpe, label=f'{window}日滚动年化夏普比率', color='blue')
plt.axhline(y=0, color='black', linestyle='--', linewidth=0.5)
plt.title(f'{window}日滚动年化夏普比率 (rf={annual_rf*100:.1f}%)')
plt.xlabel('日期')
plt.ylabel('夏普比率')
plt.grid(True, alpha=0.3)
plt.legend()

# 格式化y轴为百分比
plt.gca().yaxis.set_major_formatter(FuncFormatter(lambda y, _: f'{y:.2f}'))

# 保存图形
figure_path = 'rolling_sharpe.png'
plt.savefig(figure_path, dpi=300, bbox_inches='tight')
plt.close()

# 4. 填充result字典
result = {
    'rolling_sharpe_last': last_sharpe,
    'figure_path': figure_path
}

# 输出结果以供验证
print(result)
```

### 说明：
1. **数据模拟**：由于题目未提供实际CSV文件，脚本中模拟了一个包含日期和基金日收益率的数据集。实际使用时，请替换为读取CSV文件的代码（如`pd.read_csv('snapshot.csv')`）。
2. **无风险利率**：年化无风险利率2.1%被转换为日无风险利率，用于计算超额收益。
3. **滚动计算**：使用60日滚动窗口计算均值和标准差，并年化夏普比率（乘以√252）。
4. **图形保存**：图形保存为`rolling_sharpe.png`，路径存入`result['figure_path']`。
5. **结果输出**：最后一个窗口的夏普比率存入`result['rolling_sharpe_last']`。

### 输出契约：
- `result`字典包含：
  - `'rolling_sharpe_last'`: 最后一个窗口的年化夏普比率（浮点数）。
  - `'figure_path'`: 保存的图形文件路径（字符串）。
