以下是一个自包含的 Python 脚本，计算全局最小方差组合（Global Minimum Variance Portfolio）的权重及其年化波动率：

```python
import numpy as np
from scipy.optimize import minimize

# 输入数据
vol_annual = np.array([0.187, 0.243, 0.312])  # 年化波动率
corr_matrix = np.array([
    [1.0, 0.21, -0.13],
    [0.21, 1.0, 0.37],
    [-0.13, 0.37, 1.0]
])

# 计算协方差矩阵
cov_matrix = np.outer(vol_annual, vol_annual) * corr_matrix

# 定义组合方差函数
def portfolio_variance(weights, cov_matrix):
    return weights.T @ cov_matrix @ weights

# 约束条件：权重之和为1
constraints = ({'type': 'eq', 'fun': lambda w: np.sum(w) - 1})

# 初始权重猜测（等权重）
initial_weights = np.array([1/3, 1/3, 1/3])

# 优化求解最小方差组合
result_optimization = minimize(
    fun=portfolio_variance,
    x0=initial_weights,
    args=(cov_matrix,),
    constraints=constraints,
    method='SLSQP'
)

# 提取结果
mvp_weights = result_optimization.x
mvp_variance = portfolio_variance(mvp_weights, cov_matrix)
mvp_vol_annual = np.sqrt(mvp_variance)

# 存储结果
result = {
    'mvp_weights': mvp_weights,
    'mvp_vol_annual': mvp_vol_annual
}

# 输出结果（可选，用于验证）
print("Global Minimum Variance Portfolio:")
print(f"Weights: {mvp_weights}")
print(f"Annualized Volatility: {mvp_vol_annual:.4f}")
```

这个脚本会输出一个名为 `result` 的字典，其中包含：
1. `'mvp_weights'`：全局最小方差组合的权重（numpy array）
2. `'mvp_vol_annual'`：该组合的年化波动率（float）

计算结果可复现，且不依赖任何外部数据或网络连接。脚本使用了标准的优化方法（SLSQP）来求解最小方差组合。
