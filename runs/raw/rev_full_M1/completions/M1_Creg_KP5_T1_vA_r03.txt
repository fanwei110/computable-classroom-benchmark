以下是一个自包含的 Python 脚本，使用 `numpy` 和 `scipy` 计算在 delta-normal 模型下的 VaR 值：

```python
import numpy as np
from scipy.stats import norm

# 输入参数
position_value = 1_850_000  # 头寸价值（元）
annual_volatility = 0.218   # 年化收益波动率

# 计算参数
confidence_95 = 0.95
confidence_99 = 0.99
z_95 = norm.ppf(confidence_95)  # 95% 置信水平的 Z 值
z_99 = norm.ppf(confidence_99)  # 99% 置信水平的 Z 值

# 时间调整（日波动率 = 年波动率 / sqrt(252)）
trading_days_per_year = 252
daily_volatility = annual_volatility / np.sqrt(trading_days_per_year)

# (i) 95% 一日 VaR
var_95_1d = position_value * z_95 * daily_volatility

# (ii) 99% 十日 VaR（时间调整：sqrt(10)）
ten_day_volatility = daily_volatility * np.sqrt(10)
var_99_10d = position_value * z_99 * ten_day_volatility

# 结果存储
result = {
    'var_95_1d': round(var_95_1d, 2),
    'var_99_10d': round(var_99_10d, 2)
}

print(result)
```

### 输出说明：
- `result` 字典包含两个键值对：
  - `'var_95_1d'`: 95% 置信水平下的 1 日 VaR（单位：元）
  - `'var_99_10d'`: 99% 置信水平下的 10 日 VaR（单位：元）
- 结果四舍五入到小数点后 2 位，确保可复现。

### 计算逻辑：
1. **Z 值**：通过 `scipy.stats.norm.ppf` 获取标准正态分布的分位数。
2. **波动率调整**：
   - 日波动率 = 年波动率 / √252
   - 10 日波动率 = 日波动率 × √10
3. **VaR 公式**：`VaR = 头寸价值 × Z 值 × 波动率`（delta-normal 模型假设收益服从正态分布）。
