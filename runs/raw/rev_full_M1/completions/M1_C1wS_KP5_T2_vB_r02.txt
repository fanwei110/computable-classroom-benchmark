```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from pathlib import Path

# 1. 读取数据并构造日损益
def calculate_historical_var():
    # 读取CSV文件
    data_path = Path('data/market_snapshot_v1.csv')
    df = pd.read_csv(data_path)

    # 计算日收益率
    fund_returns = df['fund'].pct_change().dropna()

    # 计算头寸的日损益（头寸100万）
    position = 1_000_000
    daily_pnl = fund_returns * position

    # 2. 计算95%历史VaR
    confidence_level = 0.95
    var_95 = np.percentile(daily_pnl, 100 * (1 - confidence_level))

    # 3. 绘制直方图并添加VaR线
    plt.figure(figsize=(10, 6))
    plt.hist(daily_pnl, bins=50, alpha=0.7, color='skyblue', edgecolor='black')

    # 添加VaR标注线
    plt.axvline(var_95, color='red', linestyle='--', linewidth=2)
    plt.text(var_95 * 1.05, plt.ylim()[1] * 0.9,
             f'95% 1-day VaR: ¥{abs(var_95):,.2f}',
             color='red', fontsize=12, bbox=dict(facecolor='white', alpha=0.8))

    plt.title('Daily P&L Distribution with Historical VaR', fontsize=14)
    plt.xlabel('Daily P&L (RMB)', fontsize=12)
    plt.ylabel('Frequency', fontsize=12)
    plt.grid(True, alpha=0.3)

    # 保存图形
    figure_path = Path('var_histogram.png')
    plt.savefig(figure_path, dpi=300, bbox_inches='tight')
    plt.close()

    # 4. 填充result字典
    result = {
        'hist_var_95_1d': float(var_95),
        'figure_path': str(figure_path.absolute())
    }

    return result

# 执行计算并输出结果
result = calculate_historical_var()
print(result)
```

这个脚本将：
1. 读取data/market_snapshot_v1.csv中的fund列数据
2. 计算日收益率并转换为100万元头寸的日损益
3. 计算95%置信水平下的历史VaR（1日）
4. 绘制日损益直方图，并添加VaR标注线
5. 将结果保存为var_histogram.png文件
6. 返回包含VaR值和图形路径的result字典

注意事项：
- 脚本假设CSV文件中有名为'fund'的列
- 图形保存为当前目录下的var_histogram.png
- VaR值为负数（表示损失），但以绝对值形式显示在标注中
- 置信水平固定为95%，但可以通过修改confidence_level变量调整
