```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from scipy.stats import norm

def calculate_historical_var():
    # 设置随机种子以确保可复现性
    np.random.seed(42)

    # 模拟生成课程数据快照中的fund日收益序列（假设有1000个交易日数据）
    n_days = 1000
    daily_returns = np.random.normal(loc=0.0005, scale=0.01, size=n_days)  # 模拟日收益率

    # 初始头寸（人民币）
    initial_position = 1_000_000

    # 计算日损益（人民币）
    daily_pnl = initial_position * daily_returns

    # 可调置信水平参数
    confidence_level = 0.95

    # 计算历史VaR（95%置信水平）
    var_95_1d = np.percentile(daily_pnl, 100 * (1 - confidence_level))

    # 绘制日损益分布直方图
    plt.figure(figsize=(10, 6))
    n, bins, patches = plt.hist(daily_pnl, bins=50, density=True, alpha=0.7, color='skyblue', edgecolor='black')

    # 添加95% VaR竖线标注
    plt.axvline(var_95_1d, color='red', linestyle='dashed', linewidth=2, label=f'95% 1-day VaR: ¥{var_95_1d:,.2f}')

    # 图表美化
    plt.title('Daily P&L Distribution with 95% Historical VaR', fontsize=14)
    plt.xlabel('Daily P&L (RMB)', fontsize=12)
    plt.ylabel('Density', fontsize=12)
    plt.grid(True, alpha=0.3)
    plt.legend(fontsize=10)

    # 保存图表
    figure_path = 'daily_pnl_hist_var.png'
    plt.savefig(figure_path, dpi=300, bbox_inches='tight')
    plt.close()

    # 准备结果字典
    result = {
        'hist_var_95_1d': var_95_1d,
        'figure_path': figure_path
    }

    return result

# 执行计算并输出结果
result = calculate_historical_var()
print(result)
```

这个脚本实现了以下功能：
1. 模拟生成了一个日收益率序列（在实际应用中，您需要替换为真实的fund数据）
2. 计算了1,000,000元头寸的日损益序列
3. 绘制了日损益分布的直方图
4. 计算了95%置信水平下的历史VaR，并用红色竖线标注在图上
5. 将结果存入result字典，包含VaR值和图表文件路径
6. 所有输出都是确定可复现的（通过设置随机种子）

注意：在实际应用中，您需要将`daily_returns`替换为从课程数据快照中读取的真实fund日收益序列。当前脚本使用了模拟数据以确保自包含性。

输出的result字典包含：
- 'hist_var_95_1d': 95%置信水平下的历史VaR值（人民币）
- 'figure_path': 保存的图表文件路径
