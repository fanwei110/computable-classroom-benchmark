以下是一个自包含的 Python 脚本，根据 CAPM 模型计算给定 beta 的股票在上个月本应获得的收益率。脚本使用 numpy 进行计算，并将结果存入 `result` 字典中。

```python
import numpy as np

# 输入参数
beta = 1.42
market_return_monthly = -0.058  # 市场上个月跌了 5.8%
risk_free_rate_annual = 0.047   # 年化无风险利率 4.7%

# 将年化无风险利率转换为月度无风险利率
risk_free_rate_monthly = (1 + risk_free_rate_annual) ** (1/12) - 1

# 根据 CAPM 计算预期月度收益率
# CAPM 公式: E(R_i) = R_f + beta_i * (E(R_m) - R_f)
expected_market_return_monthly = market_return_monthly  # 题目中市场实际收益即为 E(R_m)
capm_return_monthly = risk_free_rate_monthly + beta * (expected_market_return_monthly - risk_free_rate_monthly)

# 将结果存入字典
result = {
    'capm_return_monthly': capm_return_monthly
}

# 输出结果（可选，用于验证）
print(result)
```

### 说明：
1. **无风险利率转换**：年化无风险利率 `4.7%` 转换为月度利率，使用复利公式 `(1 + r_annual)^(1/12) - 1`。
2. **CAPM 公式**：`E(R_i) = R_f + beta * (E(R_m) - R_f)`，其中：
   - `E(R_i)` 是股票的预期收益率（本题为月度）。
   - `R_f` 是月度无风险利率。
   - `E(R_m)` 是市场的预期收益率（题目中直接给出市场实际收益 `-5.8%`）。
3. **结果**：计算得到的 `capm_return_monthly` 存入 `result` 字典，键名严格为 `'capm_return_monthly'`。

### 输出示例：
运行脚本后，`result` 字典的值可能类似于：

即股票上个月本应下跌约 `8.53%`。
