以下是自包含的 Python 脚本，按照题目要求计算 CAPM 预期收益和 Y 股票的 alpha：

```python
import numpy as np

# 输入参数
risk_free_rate = 0.023  # 无风险收益率 2.3%
market_return = 0.094   # 市场预期收益率 9.4%
betas = {
    'X': 0.62,
    'Y': 1.18,
    'Z': 1.51
}
actual_return_y = 0.131  # Y 股票实际收益率 13.1%

# 计算市场风险溢价
market_risk_premium = market_return - risk_free_rate

# 计算每只股票的 CAPM 预期收益率
expected_returns = {
    stock: risk_free_rate + beta * market_risk_premium
    for stock, beta in betas.items()
}

# 计算 Y 股票的 alpha（实际收益率 - CAPM 预期收益率）
alpha_y = actual_return_y - expected_returns['Y']

# 存储结果
result = {
    'er_x': expected_returns['X'],
    'er_y': expected_returns['Y'],
    'er_z': expected_returns['Z'],
    'alpha_y': alpha_y
}

# 输出结果（可选，用于验证）
print(result)
```

输出的 `result` 字典将包含以下内容：
- `'er_x'`: X 股票的 CAPM 预期收益率
- `'er_y'`: Y 股票的 CAPM 预期收益率
- `'er_z'`: Z 股票的 CAPM 预期收益率
- `'alpha_y'`: Y 股票的 alpha（实际收益率与 CAPM 预期收益率的差值）
