以下是自包含的 Python 脚本，用于计算欧式看涨期权的价格、delta 和 vega：

```python
import numpy as np
from scipy.stats import norm

# 输入参数
S = 103.7          # 标的现价
K = 97.5           # 行权价
sigma = 0.276      # 隐含波动率（年化）
r = 0.043          # 无风险利率（年化）
T = 0.58           # 剩余到期时间（年）
q = 0.0            # 股息率（不分红）

# 1. 计算 d1 和 d2
d1 = (np.log(S / K) + (r - q + 0.5 * sigma ** 2) * T) / (sigma * np.sqrt(T))
d2 = d1 - sigma * np.sqrt(T)

# 2. 计算期权价格和 delta
call_price = S * np.exp(-q * T) * norm.cdf(d1) - K * np.exp(-r * T) * norm.cdf(d2)
call_delta = np.exp(-q * T) * norm.cdf(d1)

# 3. 计算 vega
call_vega = S * np.exp(-q * T) * norm.pdf(d1) * np.sqrt(T) * 0.01  # 乘以0.01将vega转换为每1%波动率变化的价格变化

# 4. 填充 result 字典
result = {
    'call_price': call_price,
    'call_delta': call_delta,
    'call_vega': call_vega
}

# 输出结果（可选，方便调试）
print(result)
```

### 说明：
1. **d1 和 d2**：Black-Scholes 模型中的中间变量，用于计算期权价格和希腊字母。
2. **期权价格**：使用 Black-Scholes 公式计算欧式看涨期权的价格。
3. **Delta**：衡量期权价格对标的资产价格变化的敏感度，计算公式为 `exp(-qT) * N(d1)`。
4. **Vega**：衡量期权价格对波动率变化的敏感度，计算公式为 `S * exp(-qT) * N'(d1) * sqrt(T)`，并乘以 `0.01` 将其转换为每 1% 波动率变化的价格变化（业界常用单位）。
5. **结果**：所有结果存储在 `result` 字典中，键名严格符合要求。

运行该脚本将输出确定可复现的结果。
