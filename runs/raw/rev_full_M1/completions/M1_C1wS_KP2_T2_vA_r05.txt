以下是自包含的 Python 脚本，满足您的所有要求：

```python
import numpy as np
import matplotlib.pyplot as plt
import os

# 参数设置（可调整）
risk_free_rate = 0.023  # 无风险利率 2.3%
market_return = 0.094   # 市场期望收益 9.4%

# 计算SML斜率
sml_slope = market_return - risk_free_rate

# 计算beta=1.27处的期望收益
beta_127 = 1.27
expected_return_at_beta_127 = risk_free_rate + sml_slope * beta_127

# 生成SML数据点
betas = np.linspace(0, 2, 100)
sml_returns = risk_free_rate + sml_slope * betas

# 三个股票点的数据
stocks = {
    'X': {'beta': 0.62, 'return': 0.081},
    'Y': {'beta': 1.18, 'return': 0.131},
    'Z': {'beta': 1.51, 'return': 0.099}
}

# 创建图形
plt.figure(figsize=(10, 6))
plt.plot(betas, sml_returns, label='Security Market Line', color='blue')

# 标记三个股票点
for stock, data in stocks.items():
    plt.scatter(data['beta'], data['return'], label=f'Stock {stock}', s=100)
    plt.text(data['beta'] + 0.02, data['return'] + 0.002, stock,
             fontsize=12, ha='left', va='bottom')

# 添加图形元素
plt.title('Security Market Line (SML) with Sample Stocks', fontsize=14)
plt.xlabel('Beta (β)', fontsize=12)
plt.ylabel('Expected Return', fontsize=12)
plt.axhline(y=risk_free_rate, color='gray', linestyle='--', alpha=0.5)
plt.axvline(x=1, color='gray', linestyle='--', alpha=0.5)
plt.grid(True, alpha=0.3)
plt.legend()

# 保存图形
figure_path = 'sml_plot.png'
plt.savefig(figure_path, dpi=300, bbox_inches='tight')
plt.close()

# 准备结果字典
result = {
    'sml_slope': sml_slope,
    'er_at_beta_127': expected_return_at_beta_127,
    'figure_path': os.path.abspath(figure_path)
}

# 输出结果（供教师查看）
print("Result dictionary:")
print(result)
```

这个脚本会：
1. 绘制从beta=0到2的证券市场线(SML)
2. 在图上标出X、Y、Z三个股票点
3. 将无风险利率和市场收益参数化，方便调整
4. 计算并报告SML的斜率(市场风险溢价)
5. 计算beta=1.27处的期望收益
6. 保存图形为'sml_plot.png'文件
7. 将所有结果存入result字典，键名严格符合要求

您可以直接修改脚本开头的`risk_free_rate`和`market_return`参数来调整无风险利率和市场收益率。脚本运行后会在当前目录生成图形文件，并输出result字典的内容。
