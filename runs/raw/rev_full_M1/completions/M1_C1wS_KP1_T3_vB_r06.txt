以下是自包含的 Python 脚本，按照题目要求计算两种相关系数下的组合波动率：

```python
import numpy as np

# 1. 确定权重对应方式：60% 分配给 A，40% 分配给 B
weights = np.array([0.6, 0.4])

# 2. 资产波动率（年化）
vol_A = 0.184
vol_B = 0.297

# 3. 构造协方差矩阵
# 相关系数 0.3 的情况
corr_before = 0.3
cov_before = corr_before * vol_A * vol_B
Sigma_before = np.array([
    [vol_A**2, cov_before],
    [cov_before, vol_B**2]
])

# 相关系数 0.8 的情况
corr_after = 0.8
cov_after = corr_after * vol_A * vol_B
Sigma_after = np.array([
    [vol_A**2, cov_after],
    [cov_after, vol_B**2]
])

# 4. 计算组合波动率（年化）
portfolio_vol_before = np.sqrt(weights.T @ Sigma_before @ weights)
portfolio_vol_after = np.sqrt(weights.T @ Sigma_after @ weights)

# 5. 填充结果字典
result = {
    'vol_before_annual': portfolio_vol_before,
    'vol_after_annual': portfolio_vol_after
}

print(result)
```

输出结果将存储在 `result` 字典中，包含以下键值对：
- `'vol_before_annual'`: 相关系数为 0.3 时的组合年化波动率
- `'vol_after_annual'`: 相关系数为 0.8 时的组合年化波动率

运行此脚本会得到可复现的精确结果，无需联网或外部依赖。
