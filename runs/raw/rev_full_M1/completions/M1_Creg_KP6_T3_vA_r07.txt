以下是一个自包含的 Python 脚本，用于计算课程数据文件中 `fund` 列的年化夏普比率（无风险利率为 2.1%）。脚本使用 `pandas` 读取数据，`numpy` 进行计算，并将结果存入 `result` 字典。

```python
import numpy as np
import pandas as pd

# 读取数据文件（假设文件名为 'course_data.csv'，且包含 'fund' 列）
# 注意：实际使用时需确保文件路径正确
data = pd.read_csv('course_data.csv')  # 请根据实际文件名调整

# 提取 fund 列的数据
fund_returns = data['fund'].dropna()  # 去除缺失值

# 无风险利率（年化，2.1%）
risk_free_rate_annual = 0.021

# 计算日频超额收益率（假设数据为日频）
excess_returns_daily = fund_returns - (risk_free_rate_annual / 252)  # 252 个交易日/年

# 计算日频夏普比率
sharpe_daily = np.mean(excess_returns_daily) / np.std(excess_returns_daily, ddof=1)

# 年化夏普比率（乘以 sqrt(252)）
sharpe_annual = sharpe_daily * np.sqrt(252)

# 将结果存入 result 字典
result = {
    'sharpe_annual': sharpe_annual
}

# 输出结果（可选，用于验证）
print(result)
```

### 说明：
1. **数据读取**：脚本假设数据文件为 `course_data.csv`，且包含 `fund` 列。请根据实际文件名调整。
2. **无风险利率**：年化无风险利率为 2.1%，转换为日频时除以 252（交易日数）。
3. **夏普比率计算**：
   - 日频超额收益率 = `fund` 收益率 - 日频无风险利率。
   - 日频夏普比率 = 超额收益率均值 / 超额收益率标准差（`ddof=1` 表示样本标准差）。
   - 年化夏普比率 = 日频夏普比率 × √252。
4. **结果**：输出存入 `result` 字典，键名为 `'sharpe_annual'`。

### 注意事项：
- 确保数据文件路径正确，且 `fund` 列为数值型（收益率数据）。
- 如果数据频率不是日频（如月频），需调整年化因子（如 `np.sqrt(12)`）。
