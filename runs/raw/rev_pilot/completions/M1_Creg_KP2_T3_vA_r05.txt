以下是一个自包含的 Python 脚本，使用 CAPM 模型计算给定 beta 的股票在上个月本应获得的收益率：

```python
import numpy as np

# 输入参数
beta = 1.42
market_return_monthly = -0.058  # 市场上个月跌了5.8%
risk_free_rate_annual = 0.047   # 年化无风险利率4.7%

# 将年化无风险利率转换为月度无风险利率
risk_free_rate_monthly = (1 + risk_free_rate_annual) ** (1/12) - 1

# CAPM 公式计算预期月度收益率
# E(R_i) = R_f + beta * (E(R_m) - R_f)
expected_return_monthly = risk_free_rate_monthly + beta * (market_return_monthly - risk_free_rate_monthly)

# 结果存储
result = {
    'capm_return_monthly': expected_return_monthly
}

# 输出结果（可选，用于验证）
print(result)
```

输出契约：
- 结果存储在名为 `result` 的字典中，键名为 `'capm_return_monthly'`，值为根据 CAPM 模型计算出的月度预期收益率（浮点数）。

运行此脚本将得到可复现的结果，不依赖任何外部数据或联网操作。
