以下是一个自包含的 Python 脚本，使用 CAPM 模型计算给定 beta 的股票在上个月本应获得的收益率。脚本仅使用指定的库，不联网，且输出可复现。

```python
import numpy as np

# 输入参数
beta = 1.42
market_return_monthly = -0.058  # 市场上个月跌了 5.8%
risk_free_rate_annual = 0.047   # 年化无风险利率 4.7%

# 将年化无风险利率转换为月度无风险利率
risk_free_rate_monthly = (1 + risk_free_rate_annual) ** (1/12) - 1

# 根据 CAPM 公式计算预期月度收益率
# CAPM: E(R_i) = R_f + beta_i * (E(R_m) - R_f)
expected_market_premium_monthly = market_return_monthly - risk_free_rate_monthly
capm_return_monthly = risk_free_rate_monthly + beta * expected_market_premium_monthly

# 将结果存入字典
result = {
    'capm_return_monthly': capm_return_monthly
}

# 输出结果（可选，用于验证）
print(result)
```

### 说明：
1. **输入参数**：
   - `beta = 1.42`：股票的 beta 值。
   - `market_return_monthly = -0.058`：市场上个月的收益率（跌 5.8%）。
   - `risk_free_rate_annual = 0.047`：年化无风险利率（4.7%）。

2. **无风险利率转换**：
   年化无风险利率转换为月度利率，使用复利公式：
   \( (1 + r_{annual})^{1/12} - 1 \)。

3. **CAPM 计算**：
   根据 CAPM 公式：
   \( E(R_i) = R_f + \beta_i \cdot (E(R_m) - R_f) \)，
   其中：
   - \( E(R_i) \)：股票的预期收益率。
   - \( R_f \)：无风险利率（月度）。
   - \( E(R_m) \)：市场的预期收益率（上个月的实际收益率）。
   - \( \beta_i \)：股票的 beta 值。

4. **输出**：
   结果存入字典 `result`，键名为 `'capm_return_monthly'`，值为计算得到的月度预期收益率（浮点数）。

### 可复现性：
脚本不依赖外部数据或联网，所有输入参数均硬编码，输出确定可复现。
