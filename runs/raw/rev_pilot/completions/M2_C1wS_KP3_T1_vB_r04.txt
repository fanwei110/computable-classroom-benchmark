以下脚本计算了面值100、票息4.6%、7年期、收益率5.3%的债券价格、麦考利久期、修正久期和凸性。假设每年付息一次，复利频率与收益率报价一致。

```python
import numpy as np

# 债券参数
face_value = 100.0          # 面值
coupon_rate = 0.046         # 票息率（年）
maturity = 7                # 年限
ytm = 0.053                 # 到期收益率（年）

# 现金流时间点
t = np.arange(1, maturity + 1)

# 票息现金流
coupon = face_value * coupon_rate
cf = np.full(maturity, coupon)
cf[-1] += face_value        # 最后一期加入面值

# 贴现因子与现值
discount_factors = (1 + ytm) ** t
pv = cf / discount_factors

# 价格
price = np.sum(pv)

# 麦考利久期（年）
macaulay_duration = np.sum(t * pv) / price

# 修正久期
modified_duration = macaulay_duration / (1 + ytm)

# 凸性：使用现金流凸性公式并除以价格
# Convexity = (1/P) * sum( t*(t+1) * CF_t / (1+y)^{t+2} )
convexity = np.sum(t * (t + 1) * cf / (1 + ytm) ** (t + 2)) / price

# 结果存入字典
result = {
    'price': price,
    'macaulay_duration_years': macaulay_duration,
    'modified_duration_years': modified_duration,
    'convexity': convexity
}

# 打印输出（可保留6位小数以便查看）
for key, value in result.items():
    print(f"{key}: {value:.6f}")
```

运行该脚本会输出确定的结果，所有计算均基于给定的年付息假设。
