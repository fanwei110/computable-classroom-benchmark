以下是一个自包含的 Python 脚本，使用 CAPM 模型计算给定 beta 的股票在上个月本应获得的收益率：

```python
import numpy as np

# 输入参数
beta = 1.42
market_return_monthly = -0.058  # 市场上个月跌了5.8%
risk_free_rate_annual = 0.047  # 年化无风险利率4.7%

# 将年化无风险利率转换为月度无风险利率
risk_free_rate_monthly = (1 + risk_free_rate_annual) ** (1/12) - 1

# CAPM 公式计算预期月度收益率
# E(R_i) = R_f + beta * (E(R_m) - R_f)
capm_return_monthly = risk_free_rate_monthly + beta * (market_return_monthly - risk_free_rate_monthly)

# 结果存储
result = {
    'capm_return_monthly': capm_return_monthly
}

# 输出结果（可选，用于验证）
print(result)
```

这个脚本：
1. 使用了给定的 beta 值 1.42
2. 将市场下跌 5.8% 转换为月度收益率 -0.058
3. 将年化无风险利率 4.7% 转换为月度无风险利率
4. 严格按照 CAPM 公式计算预期月度收益率
5. 将结果存入名为 `result` 的字典中，键名为 'capm_return_monthly'
6. 完全可复现，不依赖任何外部数据或网络连接

运行后，`result` 字典中的值即为该股票按 CAPM 模型本应获得的月度收益率。
