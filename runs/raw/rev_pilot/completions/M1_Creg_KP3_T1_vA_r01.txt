以下是一个自包含的 Python 脚本，计算债券的价格、麦考利久期、修正久期和凸性。脚本仅使用指定的库，不联网，输出确定可复现。

```python
import numpy as np
from scipy.optimize import newton

def calculate_bond_metrics(face_value, coupon_rate, years_to_maturity, ytm):
    """
    计算债券的价格、麦考利久期、修正久期和凸性。

    参数:
    - face_value: 债券面值
    - coupon_rate: 年票息率（小数形式）
    - years_to_maturity: 剩余年限
    - ytm: 到期收益率（小数形式）

    返回:
    - result: 包含价格、麦考利久期、修正久期和凸性的字典
    """
    # 计算每期票息（假设每年付息一次）
    coupon_payment = face_value * coupon_rate
    periods = years_to_maturity
    ytm_periodic = ytm  # 年化收益率（每年付息一次）

    # 计算债券价格
    price = sum([coupon_payment / (1 + ytm_periodic) ** t for t in range(1, int(periods) + 1)]) + \
            face_value / (1 + ytm_periodic) ** periods

    # 计算麦考利久期
    discounted_cash_flows = [(t * coupon_payment) / (1 + ytm_periodic) ** t for t in range(1, int(periods) + 1)]
    discounted_cash_flows.append((periods * face_value) / (1 + ytm_periodic) ** periods)
    macaulay_duration = sum(discounted_cash_flows) / price

    # 计算修正久期
    modified_duration = macaulay_duration / (1 + ytm_periodic)

    # 计算凸性
    convexity_terms = [(t * (t + 1) * coupon_payment) / (1 + ytm_periodic) ** (t + 2) for t in range(1, int(periods) + 1)]
    convexity_terms.append((periods * (periods + 1) * face_value) / (1 + ytm_periodic) ** (periods + 2))
    convexity = sum(convexity_terms) / price

    # 结果存入字典
    result = {
        'price': price,
        'macaulay_duration_years': macaulay_duration,
        'modified_duration_years': modified_duration,
        'convexity': convexity
    }

    return result

# 债券参数
face_value = 100
coupon_rate = 0.046
years_to_maturity = 7
ytm = 0.053

# 计算结果
result = calculate_bond_metrics(face_value, coupon_rate, years_to_maturity, ytm)

# 输出结果（保留小数点后6位）
print("债券计算结果:")
for key, value in result.items():
    print(f"{key}: {value:.6f}")
```

### 输出契约：
脚本将所有要求的输出存入名为 `result` 的字典，键名严格为：
- `'price'`: 债券价格
- `'macaulay_duration_years'`: 麦考利久期（年）
- `'modified_duration_years'`: 修正久期（年）
- `'convexity'`: 凸性
