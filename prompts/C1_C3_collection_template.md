# C1/C3 即兴措辞收集模板（致两位外部教师）

**致谢与说明（请先读）**

我们正在测量"教师课堂上即兴向 AI 提问"时大模型生成代码的可靠性。我们需要您为
下面 18 个任务各写 **2 条**您在课堂上会随手敲给 AI 的提问措辞（共 36 条/人）。

**规则（关键，请严格遵守）：**

1. **像上课时那样写**——口语化、简短、可以不完整。想象学生刚提问，您直接把问题
   转述给 AI。中英文按您实际授课习惯。
2. **只含下方"必含参数"中列出的数字与信息**，不要添加任何计算约定——
   不要写年化天数（252/250/365）、复利方式、单位（小数/百分比）、ddof、
   分位数单双尾、VaR 正负号等。如果您平时会说，请这次忍住：实验测的正是
   "不说时模型会怎么猜"。
3. 两条措辞之间要有真实差异（语序、详略、口吻），不是同义改写一两个词。
4. **请勿使用任何 AI 工具起草或润色这些措辞**，也请在提交前不要让任何模型看到
   它们。
5. 您不应参与（也不会被告知）参考答案、模板或判分规则的设计细节。

每条措辞将原样冻结使用：C1 = 您的措辞 + 输出契约句；C3 = 您的措辞 + 一行课程
约定头 + 输出契约句（约定头与契约句由我们统一追加，您无需理会）。
