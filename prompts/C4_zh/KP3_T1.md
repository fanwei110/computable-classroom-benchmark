概念：债券定价与久期、凸性。价格是现金流贴现之和；久期与凸性衡量价格对收益率变动的敏感性。

课程计算约定：
- 债券收益率按年复利报价；修正久期 = 麦考利久期/(1+y)；凸性 = Σ[t(t+1)CF_t/(1+y)^(t+2)]/P，单位为年的平方。
- 所有利率、收益率、波动率与权重用小数表示（0.05 即 5%）。

任务：
一只到期一次还本的债券：面值 100，票息 4.6%，7 年期，到期收益率 5.3%。计算价格、麦考利久期、修正久期与凸性。票息每年支付一次，于付息日估值（无应计利息）。

请按以下步骤进行：
1. 按年复利收益率贴现每年票息与到期面值，得到价格。
2. 计算麦考利久期；除以 (1+y) 得修正久期。
3. 按 Σ[t(t+1)CF/(1+y)^(t+2)]/P 计算凸性（年平方）。
4. 填充 result。

写一个自包含的 Python 脚本。只使用 numpy、scipy、pandas、matplotlib。不可联网，不留占位值，输出确定可复现，变量命名清晰。
