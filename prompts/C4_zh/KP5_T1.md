概念：在险价值（VaR）。损益分布的损失分位数，可用参数法（delta-normal）或历史数据计算。

课程计算约定：
- 年化与去年化一律按每年 252 个交易日（波动率按 sqrt(252) 缩放）。
- VaR 报告为正的损失金额；使用单尾正态分位数，短期限下均值取零。
- 所有利率、收益率、波动率与权重用小数表示（0.05 即 5%）。

任务：
某头寸价值 1,850,000 元，年化收益波动率 21.8%。在 delta-normal（参数法）模型下计算：(i) 95% 一日 VaR；(ii) 99% 十日 VaR。

请按以下步骤进行：
1. 按每年 252 个交易日把波动率去年化到一日。
2. 用单尾正态分位数（95% 与 99%），均值取零。
3. 十日 VaR 按 sqrt(10) 缩放；两者均报为正的人民币金额。
4. 填充 result。

写一个自包含的 Python 脚本。只使用 numpy、scipy、pandas、matplotlib。不可联网，不留占位值，输出确定可复现，变量命名清晰。

输出契约：把所有要求的输出存入名为 `result` 的字典，键名严格为：'var_95_1d', 'var_99_10d'。
