### 第二问：业绩归因计算过程
根据 Brinson-Hood-Beebower (BHB) 模型：
- **配置效应** $= (W_{p} - W_{b}) \times R_{b}$
- **选择效应** $= W_{b} \times (R_{p} - R_{b})$
- **交互效应** $= (W_{p} - W_{b}) \times (R_{p} - R_{b})$

**行业1：**
- 配置效应 = $(0.45 - 0.40) \times 0.067 = 0.00335$
- 选择效应 = $0.40 \times (0.083 - 0.067) = 0.0064$
- 交互效应 = $(0.45 - 0.40) \times (0.083 - 0.067) = 0.0008$

**行业2：**
- 配置效应 = $(0.35 - 0.40) \times 0.034 = -0.0017$
- 选择效应 = $0.40 \times (0.021 - 0.034) = -0.0052$
- 交互效应 = $(0.35 - 0.40) \times (0.021 - 0.034) = 0.00065$

**行业3：**
- 配置效应 = $(0.20 - 0.20) \times (-0.009) = 0$
- 选择效应 = $0.20 \times (-0.014 - (-0.009)) = -0.001$
- 交互效应 = $(0.20 - 0.20) \times (-0.014 - (-0.009)) = 0$

**汇总各效应：**
- 总配置效应 = $0.00335 - 0.0017 + 0 = 0.00165$
- 总选择效应 = $0.0064 - 0.0052 - 0.001 = 0.0002$
- 总交互效应 = $0.0008 + 0.00065 + 0 = 0.00145$

### 第一问：年化夏普比率计算逻辑
1. 读取数据的 `fund` 列作为日收益率 $R_t$。
2. 计算日无风险利率：$R_{f,daily} = 0.021 / 252$。
3. 计算日超额收益均值：$\mu_d = \frac{1}{N}\sum(R_t - R_{f,daily})$。
4. 计算日收益率样本标准差：$\sigma_d = \sqrt{\frac{\sum(R_t - \bar{R}_t)^2}{N-1}}$ （即 `ddof=1`）。
5. 计算年化夏普比率：$\text{Sharpe}_{annual} = \frac{\mu_d}{\sigma_d} \times \sqrt{252}$。
