### 第一问：年化夏普比率计算方法
1. **日无风险利率转换**：年化无风险利率为2.1%，日无风险利率 $R_{f,daily}$ 通常按 $2.1\% / 252$ 计算（或按复利 $(1+2.1\%)^{1/252} - 1$ 计算，依课程具体要求）。
2. **日超额收益**：计算每日的超额收益 $R_{ex,daily} = R_{daily} - R_{f,daily}$。
3. **年化夏普比率**：
   $$Sharpe_{annual} = \frac{E(R_{ex,daily})}{\sigma_{daily}} \times \sqrt{252}$$
   其中 $E(R_{ex,daily})$ 为日超额收益的均值，$\sigma_{daily}$ 为日收益率的标准差（通常取样本标准差）。

### 第二问：Brinson业绩归因计算
根据Brinson-Hood-Beebower (BHB) 模型，总超额收益分解为配置效应、选择效应和交互效应。

**1. 基础收益计算：**
* 组合总收益 $R_p = 0.45 \times 8.3\% + 0.35 \times 2.1\% + 0.20 \times (-1.4\%) = 4.19\%$
* 基准总收益 $R_b = 0.40 \times 6.7\% + 0.40 \times 3.4\% + 0.20 \times (-0.9\%) = 3.86\%$
* 总超额收益 $= 4.19\% - 3.86\% = 0.33\%$

**2. 配置效应 (Allocation Effect):**
衡量因权重偏离基准带来的收益。
$$Allocation = \sum (W_{pi} - W_{bi}) \times R_{bi}$$
* 行业1：$(0.45 - 0.40) \times 6.7\% = 0.335\%$
* 行业2：$(0.35 - 0.40) \times 3.4\% = -0.170\%$
* 行业3：$(0.20 - 0.20) \times (-0.9\%) = 0\%$
* **配置效应总计 = 0.165%**（即0.00165）

**3. 选择效应 (Selection Effect):**
衡量因行业内部个股选择带来的收益。
$$Selection = \sum W_{bi} \times (R_{pi} - R_{bi})$$
* 行业1：$0.40 \times (8.3\% - 6.7\%) = 0.640\%$
* 行业2：$0.40 \times (2.1\% - 3.4\%) = -0.520\%$
* 行业3：$0.20 \times (-1.4\% - (-0.9\%)) = -0.100\%$
* **选择效应总计 = 0.020%**（即0.0002）

**4. 交互效应 (Interaction Effect):**
衡量权重偏离与个股选择共同作用的交叉影响。
$$Interaction = \sum (W_{pi} - W_{bi}) \times (R_{pi} - R_{bi})$$
* 行业1：$(0.45 - 0.40) \times (8.3\% - 6.7\%) = 0.080\%$
* 行业2：$(0.35 - 0.40) \times (2.1\% - 3.4\%) = 0.065\%$
* 行业3：$(0.20 - 0.20) \times (-0.5\%) = 0\%$
* **交互效应总计 = 0.145%**（即0.00145）

*(验证：0.165% + 0.020% + 0.145% = 0.330%，与总超额收益0.33%一致)*
