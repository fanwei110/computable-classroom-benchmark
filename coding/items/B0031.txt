根据资本资产定价模型（CAPM），我们可以计算每只股票的预期收益（Expected Return, ER），公式为：

\[ ER = r_f + \beta \times (r_m - r_f) \]

其中：
- \( r_f \) = 无风险收益率 = 2.3%
- \( r_m \) = 市场收益率 = 9.4%
- \( \beta \) = 股票的贝塔系数

然后，计算股票Y的Alpha（α），公式为：

\[ \alpha = 实际收益 - 预期收益 \]

**计算过程：**

1. 股票X的预期收益（ER_X）：
\[ ER_X = 2.3\% + 0.62 \times (9.4\% - 2.3\%) = 2.3\% + 0.62 \times 7.1\% = 2.3\% + 4.402\% = 6.702\% \]

2. 股票Y的预期收益（ER_Y）：
\[ ER_Y = 2.3\% + 1.18 \times (9.4\% - 2.3\%) = 2.3\% + 1.18 \times 7.1\% = 2.3\% + 8.378\% = 10.678\% \]

3. 股票Z的预期收益（ER_Z）：
\[ ER_Z = 2.3\% + 1.51 \times (9.4\% - 2.3\%) = 2.3\% + 1.51 \times 7.1\% = 2.3\% + 10.721\% = 13.021\% \]

4. 股票Y的Alpha（α_Y）：
\[ \alpha_Y = 实际收益 - ER_Y = 13.1\% - 10.678\% = 2.422\% \]
