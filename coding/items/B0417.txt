根据资本资产定价模型（CAPM），期望收益的计算公式为：
$$E(R_i) = R_f + \beta_i \times (E(R_m) - R_f)$$

其中：
- 无风险利率 $R_f = 2.3\%$
- 市场期望收益 $E(R_m) = 9.4\%$
- 市场风险溢价 $E(R_m) - R_f = 9.4\% - 2.3\% = 7.1\%$

**1. 计算三只股票的期望收益：**
- **股票 X**：$E(R_X) = 2.3\% + 0.62 \times 7.1\% = 2.3\% + 4.402\% = 6.702\%$
- **股票 Y**：$E(R_Y) = 2.3\% + 1.18 \times 7.1\% = 2.3\% + 8.378\% = 10.678\%$
- **股票 Z**：$E(R_Z) = 2.3\% + 1.51 \times 7.1\% = 2.3\% + 10.721\% = 13.021\%$

**2. 计算股票 Y 的 Alpha：**
Alpha 的计算公式为实际收益减去CAPM模型计算的期望收益：
$$\alpha_Y = R_{Y, actual} - E(R_Y)$$
- **Alpha Y**：$\alpha_Y = 13.1\% - 10.678\% = 2.422\%$
