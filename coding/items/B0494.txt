### 已知条件：
- 面值（Face Value, FV）：100
- 票息率（Coupon Rate）：4.6% → 每年票息（C）= 100 × 4.6% = 4.6
- 期限（n）：7年
- 收益率（YTM）：5.3% → 年化收益率（y）= 5.3% = 0.053
- 付息频率：假设每年付息一次（题目未明确说明，通常默认每年付息一次）

### 1. 计算债券价格（Price）：
债券价格是未来现金流的现值总和：
\[
P = \sum_{t=1}^{n} \frac{C}{(1 + y)^t} + \frac{FV}{(1 + y)^n}
\]
代入数值：
\[
P = \sum_{t=1}^{7} \frac{4.6}{(1 + 0.053)^t} + \frac{100}{(1 + 0.053)^7}
\]
计算得：
\[
P \approx 4.6 \times \left( \frac{1 - (1 + 0.053)^{-7}}{0.053} \right) + \frac{100}{(1 + 0.053)^7} \approx 95.50
\]

### 2. 计算麦考利久期（Macaulay Duration）：
麦考利久期是现金流的加权平均时间：
\[
\text{Macaulay Duration} = \frac{1}{P} \sum_{t=1}^{n} \frac{t \cdot C}{(1 + y)^t} + \frac{n \cdot FV}{(1 + y)^n}
\]
计算得：
\[
\text{Macaulay Duration} \approx \frac{1}{95.50} \left( \sum_{t=1}^{7} \frac{t \cdot 4.6}{(1 + 0.053)^t} + \frac{7 \cdot 100}{(1 + 0.053)^7} \right) \approx 6.05 \text{ 年}
\]

### 3. 计算修正久期（Modified Duration）：
修正久期是麦考利久期对收益率的敏感度：
\[
\text{Modified Duration} = \frac{\text{Macaulay Duration}}{1 + y}
\]
计算得：
\[
\text{Modified Duration} \approx \frac{6.05}{1 + 0.053} \approx 5.75 \text{ 年}
\]

### 4. 计算凸性（Convexity）：
凸性是价格对收益率的二阶导数：
\[
\text{Convexity} = \frac{1}{P} \sum_{t=1}^{n} \frac{t(t + 1) \cdot C}{(1 + y)^{t + 2}} + \frac{n(n + 1) \cdot FV}{(1 + y)^{n + 2}}
\]
计算得：
\[
\text{Convexity} \approx \frac{1}{95.50} \left( \sum_{t=1}^{7} \frac{t(t + 1) \cdot 4.6}{(1 + 0.053)^{t + 2}} + \frac{7 \cdot 8 \cdot 100}{(1 + 0.053)^9} \right) \approx 40.5
\]

```python
import numpy as np

def bond_price(coupon, face_value, ytm, n):
    price = sum([coupon / (1 + ytm)**t for t in range(1, n + 1)]) + face_value / (1 + ytm)**n
    return price

def macaulay_duration(coupon, face_value, ytm, n):
    price = bond_price(coupon, face_value, ytm, n)
    duration = sum([t * coupon / (1 + ytm)**t for t in range(1, n + 1)]) + n * face_value / (1 + ytm)**n
    return duration / price

def modified_duration(macaulay_dur, ytm):
    return macaulay_dur / (1 + ytm)

def convexity(coupon, face_value, ytm, n):
    price = bond_price(coupon, face_value, ytm, n)
    conv = sum([t * (t + 1) * coupon / (1 + ytm)**(t + 2) for t in range(1, n + 1)]) + n * (n + 1) * face_value / (1 + ytm)**(n + 2)
    return conv / price

# 参数
face_value = 100
coupon_rate = 0.046
coupon = face_value * coupon_rate
ytm = 0.053
n = 7

# 计算
price = bond_price(coupon, face_value, ytm, n)
macaulay_dur = macaulay_duration(coupon, face_value, ytm, n)
modified_dur = modified_duration(macaulay_dur, ytm)
conv = convexity(coupon, face_value, ytm, n)

result = {
    'price': round(price, 2),
    'macaulay_duration_years': round(macaulay_dur, 2),
    'modified_duration_years': round(modified_dur, 2),
    'convexity': round(conv, 2)
}

print(result)
```
